# 小火车英语启蒙 · 资源清单与方案（2026-09-16）

孩子：4 岁 · 兴趣：《小火车联盟》= **Chuggington**（恰恰特快车/火车宝宝，英国 Ludorum 出品，BBC CBeebies 播出，1-6 季 178集）

## 一、视频资源（英文原版，免费）

| 资源 | 说明 |
|---|---|
| **Chuggington 官方 YouTube**（@chuggington，美区，~100万订阅） | 完整分集合集（30-40 分钟 compilations）、片段、singalong 儿歌；持续更新中 |
| **Chuggington UK 官方 YouTube**（@chuggingtonuk） | 10 分钟单集，英音 |
| **BBC iPlayer / CBeebies**（英国区内免费） | 第 3-6 季完整版 |
| **Disney Junior / DisneyNOW / Hulu**（美区） | 第 1-5 季 |
| 国内平台 | 央视少儿播出过中文配音版；腾讯视频/爱奇艺有部分季（多为中文或双语） |
| 备选火车题材 | Thomas & Friends（托马斯官方频道）、Mighty Express（Netflix）、Titipo Titipo（Netflix） |

**获取本地文件**：官方 YouTube 视频可用 yt-dlp 下载（`brew install yt-dlp; yt-dlp <链接>`），仅限家庭自用。

## 二、同类型的开源/现成工具（GitHub 及网络）

| 工具 | 适合谁 | 结论 |
|---|---|---|
| LLPlayer（4100★） | 成人/大童 | 双字幕+查词+Whisper 本地字幕，太复杂不适合 4 岁 |
| YTReps | 成人 | YouTube 播放+Anki 闪卡复习，界面成人向 |
| english-for-kids | 儿童词汇游戏 | 思路可借鉴：Web Speech API 朗读+图片卡+答题，但无视频联动 |
| TubeVocab | 成人 | YouTube 字幕→AI 单词卡，需要账号且成人向 |

**结论：没有现成的「视频播放+自动暂停弹卡+幼儿友好」工具，自研原型填补。**

## 三、三条路线

1. **弹卡播放器（已做，`chuggington-english-player.html`）** ✅
   - 视频原样播放（官方资源本地文件），到点自动暂停弹英文卡，TTS 朗读、可重复听、继续播放。
   - 不修改视频 → 无版权问题（家庭自用）；纯本地 HTML，双击浏览器打开即用。
   - 词表可自定义（JSON），支持精确到秒的弹卡点和随机间隔两种模式。
   - 下一步可做：跟读打分（录音对比）、表情包奖励、接入更大词库。

2. **AI 生成原创小火车英语短视频（补充）**
   - 用 AI 视频/图像工具生成「火车主题原创角色」的单词卡动画（每集 1-2 分钟教 3-5 个词），
     角色不用 Chuggington 原版形象即可避开版权，还能定制孩子正在学的词。
   - 适合做「睡前复习卡」，与正片观看互补。

3. **纯 YouTube 陪看方案（零开发）**
   - 官方频道全集 + Super Simple Songs 等，家长手动暂停互动。
   - 免费但依赖家长时间，可与方案 1 混用。

## 四、4 岁启蒙小建议
- 每次看 15-20 分钟封顶，一天 1-2 次；弹卡间隔建议 1.5-2 分钟（避免打断剧情太多）。
- 先「看画面猜意思」再弹卡，卡片出现时家长跟着读一遍效果最好。
- 同一批词重复出现在不同视频里（词表固定 10-20 个词，轮换视频），比一集换一堆词有效。
- 已学词用「单词复习」模式每天过一遍，配合实物指认（看到火车就说 train）。
