## 三、如何恢复

按需单库恢复（同盘 `mv` 秒级）：

```bash
cd "/Volumes/固态硬盘1T/002-探索项目/040-OpenBiliClaw"
mv _archive/求职知识库引擎-20260917/面试资料总库.db 求职知识库/_系统_知识库引擎/数据/
mv _archive/求职知识库引擎-20260917/面试处理库.db   求职知识库/_系统_知识库引擎/数据/
```

**恢复后受影响的离线命令即可用**：`kb.py 索引` / `doctor.py` / `kb_ingest.py` /
`kb_search_hybrid.py` / `kb_embed.py` / `kb_ocr.py` / `kb_layers.py` / `slides_pipeline.py`。

> 💡 不依赖任何 db、随时可用的命令：`kb.py 查|岗位|数字|速记|方向|全部`（直接扫文件 + 读 7 个 CSV）。

## 四、不影响什么

- **OpenBiliClaw 在线服务完全不受影响**。归档后以 FastAPI TestClient 直测验证：
  `/api/interview/job/status|jobs|search|numbers|projects` **5 个端点全部 HTTP 200**，
  `configured=True`、7 岗位 / 40 检索命中 / 60 数字 / 24 项目。
- git：`_archive/` 下 `.db` 及 `-shm/-wal` 均已被 `*.db` 类规则忽略，移动/删除对版本库无副作用。
