## 三、个人项目答辩口径（OpenBiliClaw · 2026.06 起独立开发）

**可讲的真实能力**（全部有代码/文档背书）：
- 多源采集（B站/知乎/小红书/YouTube）→ LLM 批量评估 + admission 分数门入池（300+）
- 排序：tier/相关性/新鲜度（3 天半衰期）；MMR + 来源硬配比 + 风格限流 + topic 疲劳双轴
- RankAgent：规则 × 语义质心 × 点赞学习（α）× 停留时长（β）混合 + Thompson 采样探索轴（Beta 后验零均值注入）
- LLM 批量文案：按内容 ID 绑定防错位、重复整组丢弃、限流降级拆半重试
- 反馈闭环：显式反馈 + dwell 隐式信号 → 画像重建回流；兴趣探针（LLM 猜方向→用户确认）
- 性能：换一批 2.6s→0.6s（embedding 并发预热 / 缓存命中率 0→100% / 10 次 fsync→1）

**红线**：①不提 RQ-VAE/语义 ID 生成式召回（代码里没有）②被深挖实现细节时按代码实际讲，不外推 ③架构判断标准句：「LLM 不进毫秒级主链路，全部近线/异步——这是延迟与成本约束下的选择」。
