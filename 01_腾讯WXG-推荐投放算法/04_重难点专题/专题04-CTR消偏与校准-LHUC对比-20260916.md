# 专题 04 · CTR 消偏与校准：LHUC 对比（2026-09-16）

> 对方痛点：视频号「CTR（LHUC 消偏、PCOC 修复）」。
> 简历钩子：CTR 多位置消偏（MMoE 分位置专家 + 门控，对比 LHUC 路线，偏差 30%+→20% 以内、ARPU +1.04%）。

## 一、LHUC 机理（先讲对结构再谈优劣）

- LHUC = Learning Hidden Unit Contributions（NeurIPS 2016，源自 ASR 说话人自适应；腾讯广告移植到 CTR 消偏）。
- **偏置特征（广告位/位置/场景）不走主通路**：位置 embedding → 小网络 → 生成门控系数 → 调制隐层激活 `h' = 2σ(a ⊙ h + b)`（逐隐单元放大/抑制）。
- **消偏原理**：位置效应只能经由调制旁路表达，污染不了主网络的兴趣表征；推理时把偏置条件置空/默认，主网络直接输出「无位置效应的兴趣 CTR」——**消偏在表征层前置完成，而非事后校准**。

## 二、对比表（面试直接输出）

| 维度 | LHUC 消偏（调制旁路） | 多位置多任务+后置校准（我的 OPPO 做法） |
|---|---|---|
| 消偏位置 | 表征层前置：位置进不了兴趣表征 | 输出层后置：各位置学出带偏估计，再校准 |
| 参数成本 | 极小（每层一个门控向量） | 每位置一个头/校准曲线，位置数线性增长 |
| 长尾位置 | 门控共享结构，新位置平滑泛化 | 曝光少的位置头欠拟合，需校准数据兜底 |
| 拟合容量 | 调制容量有限，位置效应复杂时可能欠拟合 | 各位置独立建模，效应刻画更充分 |
| 跨位可比性 | 天然可比（同一个无偏分） | 需依赖校准曲线拉回同一标尺 |
| 校准需求 | 仍建议后接 PCOC 兜分布漂移 | 校准就是方案本体 |
| 工程复杂度 | 一套模型+旁路 | 多任务/多头+多条校准管线 |
| 归因可解释性 | 位置效应藏在门控里，归因较难 | 分位置数字直白，好汇报 |

## 三、标准答法（三段）

1. **两者不是对立而是互补**：「LHUC 解决『别让位置污染兴趣表征』，多任务+校准解决『各位置响应差异要刻画准』——前者管无偏，后者管精准。」
2. **用我的数据说话**：「OPPO 场景里位置差异不止是偏置——闪屏位和信息流位的用户意图本身不同（强推 vs 主动浏览），多任务分开学是对的；但如果位置只是曝光序位差异，LHUC 更优雅，参数省、跨位天然可比。」
3. **混合方案收尾**：「业界常见组合是 PAL/LHUC 前置消偏 + PCOC 后置校准：表征层去偏、输出层修分布漂移。视频号的做法（LHUC+PCOC）正是这个组合——我在 OPPO 做的是后半段，前半段我懂原理、知道工程上偏置条件不能泄漏进主路径这个关键坑。」

## 四、两层问题要分清（关键提醒）

- **意图偏差**（位置改变了用户意图本身）→ LHUC/多任务管。
- **曝光分布漂移**（模型在不同位置上的校准曲线不同）→ PCOC 管的是这个，LHUC 无能为力。
- 被追问时先反问澄清对方指哪层——这是展示问题定义能力的机会。

## 五、档位与红线

- LHUC 没实操过 → **B 档「深入评估过」**：答机理+选型对比+「当时为什么选多任务路线（位置意图差异大）」最稳；不冒领实现细节（如门控初始化技巧）。
- PCOC/校准曲线是真做过（偏差 30%+→20%、ARPU +1.04%）→ **A 档**，敢谈踩坑（如校准数据的时间窗切分、长尾位置校准样本不足的兜底）。
- **金句**：「消偏不是把位置特征删掉，是让位置效应有地方去、且走得回来。」
