# 专题 12：我的改造清单——业界范式与我的差异（"不照搬"的证据）

> 定位：这份是 v4 简历的灵魂配套。面试官看简历只会看到「我做了 X」，但**真正区分"背书型候选人"和"能干活的人"的，是你能不能讲清「业界做法是 A，我在这个场景改成 B，因为 C」**。
> 用法：每条 = 30 秒讲清改造点 → 被追问「为什么」时用「验证方式」接 → 被质疑时用「为什么不照做」顶回去。
> 对应简历 v4 条目顺序排列。

---

## 零、总纲：我什么时候不照搬——三个判据

讲任何一个改造前，先立这三个判据（这是"有方法论"的表现，比单个改造点更高级）：

| 判据 | 含义 | 典型例子 |
|---|---|---|
| **①场景分布不同** | 业界的假设（分布、周期、量级）在我的场景不成立 | 回本周期差一个量级 → 折现窗不能全局固定 |
| **②目标函数不同** | 业界优化的是预测准度，我要的是决策对 | Gini 高但分位偏高 → 出价全档超耗 |
| **③约束不同** | 业界默认无约束/软约束，我有硬约束 | 配额是硬约束 → 硬截断浪费曝光，改影子价格 |

> **开口句**：「我看业界方案一般先问三个问题——它的分布假设在我这成立吗、它优化的目标和我决策的目标是一回事吗、它的约束和我的一样硬吗。三条里只要有一条不成立，就得改。」

## 一、统一竞价：差异化折现窗 + 影子价格配额

**业界做法**：value-based bidding —— 把每种候选的期望价值统一折算成 eCPM（= pCTR × pCVR × value），按同一时间窗（通常固定，如 D7/D30）折现，然后统一排序。

**我的场景约束**：
- 联运（IAP）收入后置归收，精品游戏回本周期 30 天以上；小游戏 IAA 当天/次日结算。两者**差一个量级**
- 配额（自然结果占比、广告密度）是业务硬约束，不是软偏好

**我的改造（两点）**：

1. **折现窗按品类回本周期差异化，不取全局固定值**
   - 为什么：全局固定窗（哪怕取中间值）都会系统性偏袒一边——窗长了对 IAA 高估、窗短了对精品 IAP 低估。这不是精度损失，是**方向性偏差**，会直接改变排序结果
   - 怎么做：每个品类/游戏用自己的回收曲线定窗（对齐买量侧的首日回收/7 日回本口径）
   - 追问接法：「窗长不是超参，是业务事实——它应该由那个游戏的真实回收曲线决定，我去和商务/买量侧对齐口径，而不是在模型里调参」

2. **配额护栏用影子价格（对偶量），不做硬截断**
   - 为什么：硬截断（配额用满后一律降权/不出）会在**配额未用完的低峰时段白白浪费剩余曝光机会**；而且硬截断不可微、无法参与出价
   - 怎么做：把配额约束写成拉格朗日松弛项，约束的影子价格自然转成一个出价折扣因子 λ_quota，出价高的候选"买"配额、出价低的自动让位——**配额约束变成了价格信号**
   - 追问接法：「硬约束在排序系统里的通病是它不连续、没法参与优化。转成影子价格之后，配额从'规则'变成了'成本'，模型可以自然权衡」

**验证方式**：AB 看两侧——收入侧 eCPM/ARPU，生态侧留存/时长；护栏必须双指标不劣化（这是"生态健康"的业务要求）

## 二、pLTV：按不确定性路由专家 + 决策层回检

**业界做法**：ZILN（Zero-Inflated Lognormal）拆「付费概率 p × 对数正态金额 (μ, σ)」；ODMN（多分布专家分治）把金额分布切成若干区间，每个区间一个专家。

**我的改造（两点）**：

1. **专家按 σ（预测不确定性）路由，不按金额区间硬分桶**
   - 为什么：ODMN 的原始动机是"重尾扭曲梯度"，但**真正扭曲梯度的不是金额大，是猜不准**。一个稳定的大 R（行为特征明确的高付费用户）梯度是干净的；一个"可能是大 R 也可能不付费"的样本才是噪声源。按金额分桶会把"稳定的大 R"和"不确定的大额"塞进同一个专家
   - 怎么做：路由依据是模型输出的不确定性（σ 或集成方差），让每个专家拿到**方差相近**的子分布
   - 追问接法：「按金额分桶是结果导向，按不确定性路由是误差导向——我要解决的是梯度污染，那就该按误差结构分」

2. **评估补一层"决策层回检"，不只看 MSE/Gini**
   - 为什么：预测指标和决策指标会脱节。典型失效：**Gini 很高但分位数系统性偏高** → 每个档位出价都偏高 → 全档超耗。这在买量侧是致命的，因为超耗是能被广告主直接感知的投诉
   - 怎么做：按出价档位回检实际 ROI 与回本周期，看预测分位 vs 实际达成的偏差
   - 追问接法：「预测模型的服务对象不是损失函数，是出价决策。所以我的评估也分层：预测层看 Gini/分位校准，决策层看出价档位的实际 ROI」

**附带（第三条）**：**出价用分位数下界而非点估计，且分位随样本量自适应**
- 新游样本少 → 取保守分位（宁可少买不可超耗）；样本积累够 → 放开到中位
- 为什么：非对称分布下点估计的下行风险远大于上行收益（少买只是少赚，超耗是亏损+投诉）

## 三、oCPX：λ 两维驱动 + 抗积分饱和

**业界做法**：PID 控制器调价（或 RL 出价），误差信号通常取「实际成本 vs 目标成本」。

**我的改造（两点）**：

1. **λ 由两维驱动：成本达成率 × 预算 pacing 进度**
   - 为什么：只盯成本的控制器会出现两种典型事故——**上午把预算花光**（下午没量）或**晚上剩量花不出去**（成本被抬高的假象下反而压价）。因为成本是比值，pacing 是绝对进度，两者正交
   - 怎么做：误差项 = f(成本偏差, 预算消耗进度 vs 时间进度)，λ 随超耗风险自适应，每 30 分钟更新
   - 追问接法：「成本达标但预算没花完，和成本超了但花得快，是两种完全不同的状态，只用一个误差信号分不开」

2. **抗积分饱和 + 按日重置积分**
   - 为什么：日预算场景下，积分项跨日累积 → 新的一天起步时控制器带着昨天的"历史包袱"，开局就跑偏（要么过冲要么迟钝）
   - 怎么做：加 anti-windup（积分限幅），并在预算周期边界重置积分项
   - 追问接法：「这是控制理论的老问题，但在广告里特别容易踩——因为广告的'被控对象'每天都被重置一次，控制器却不会自动重置」

**选型**：对比 RL 出价后选 PID —— 理由不是"PID 简单"，是**样本效率与可控性**：RL 需要大量交互样本且线上不可解释，出价这种直接影响广告主钱袋子的环节，可控性 > 理论最优性

## 四、多位置消偏：位置当任务维度，校准在线收缩

**业界两条路线**：LHUC（位置作为偏置特征，走旁路生成门控调制隐层激活，推理时置空 → 表征层消偏）；PCOC（后置校准，按曝光分布修正预估）。

**我的改造（两点）**：

1. **不用 LHUC 消偏，位置进主网络当任务维度（MMoE）**
   - 关键判断：**在这个场景，位置本身就是意图，不是偏置**。闪屏强推 vs 信息流主动浏览，用户对广告的接受度不是同一个量——这不是"同一个兴趣在不同位置的展示偏差"，是"两种使用心态"
   - 把位置当偏置调制掉，等于强行要求模型用一套兴趣表达覆盖两种心态 → 两边都学不好
   - 按位置为任务维度建专家 + 门控，让不同位置有自己的响应曲线，同时共享底层兴趣表征
   - 追问接法：「LHUC 的假设是'位置是一个需要被剔除的干扰'，我的场景里位置是一个需要被建模的信号。判断标准很简单：把位置置空之后，剩下的东西还是不是同一个语义？」

2. **PCOC 校准：在线滑动更新 + 小样本位向全局收缩**
   - 为什么：离线算一次固定校准曲线，扛不住曝光分布漂移（这正是偏差的根因）；但纯在线又会让**长尾广告位因几条样本剧烈抖动**（高位方差）
   - 怎么做：滑动窗在线更新 + 贝叶斯收缩（样本量越小，越向全局校准因子收缩）
   - 追问接法：「在线更新和稳定性是一对矛盾，收缩系数就是那个权衡旋钮——样本够就信自己，样本不够就信大盘」

## 五、延迟转化：观测时长作为条件 + 无偏加权

**业界常见做法**：设一个固定观测窗口（如 24h/72h），窗口内回传算正样本、未回传算负样本。

**我的改造（两点）**：

1. **把「已观测时长 t」作为条件输入，学 P(转化 | 已观测 t)**
   - 为什么：固定窗口的代价是**样本必须"变老"才能用**，模型永远在学"过期"的分布；而且 T+1 回传的延迟随素材/人群漂移，固定窗口在不同 slice 上的完整度不同
   - 怎么做：观测时长进特征，模型自己学"已经等了这么久还没回传，转化概率还剩多少"——新样本进来立刻可用，按回传进度纠偏
   - 追问接法：「与其等数据变完整，不如让模型理解'不完整'这件事本身」

2. **早期未回传不当负样本，用观测概率倒数做无偏加权**
   - 为什么：延迟回传场景下，把"还没回传"当负样本 = **系统性低估**（尤其对延迟长的人群，等于惩罚了他们）
   - 怎么做：importance weighting，用观测概率的倒数加权，保证期望意义下无偏
   - 追问接法：「这是延迟反馈建模的标准处理，但很多线上系统图省事直接当负样本——代价是模型对慢回传人群的预估系统性偏低，而慢回传的往往正是高价值人群」

## 六、冷启动：先决定"在哪探索"

**业界做法**：EE 三件套（保护期 / 探索流量池 / 先验平滑），关注的是"探索多少"。

**我的改造**：**先决定在哪探索，再决定探索多少**
- 为什么：探索是有机会成本的。在高价值流量位（首屏、高峰时段）做探索，牺牲的是最贵的曝光；同样的探索预算放在低峰/低价值位，信息收益几乎一样，成本却低一个量级
- 怎么做：低机会成本位承担主要探索量 → 学到的先验迁移回高价值位（分层先验/迁移）
- 追问接法：「EE 的教科书都在讲分多少流量给探索，但工业里真正值钱的问题是这个探索放在哪——因为流量不是同质的，探索的'价格'差很多」

**配套**：分层贝叶斯先验 —— 新品类借用父类先验，而非全局先验（新品类冷启动时全局先验太糊，父类先验信息量大得多）

**回捞的额外改造**：加**剩余机会系数** —— 即将流失的曝光按"这次不捞就没了"提价。回捞不是简单重排，而是在给"最后一次机会"定价

## 七、端云/预取：熵驱动深度 + 作废率进成本账

**业界做法**：预取/预请求通常按固定深度（预取 N 条）或按固定触发条件。

**我的改造（两点）**：

1. **预取深度按「下一落点分布的熵」自适应**
   - 行为确定性高（连续看同 topic）→ 分布熵低 → 预取深，命中率高
   - 分布熵高（行为发散）→ 预取浅，只取头部高质量候选
   - 为什么：固定深度在两个方向都浪费——确定性高时预取不够（还要再取），发散时预取作废

2. **把预取作废率计进成本账**
   - 为什么：只看命中率会把策略引向"多预取总没错"（多预取命中率自然高），但作废的预取消耗的是带宽和端侧算力
   - 目标函数 = 命中收益 − 作废成本，而不是命中率
   - 追问接法：「指标决定行为。你要省成本，就不能只考核命中率」

## 八、个人项目：LLM 只当门控 + 零均值探索

1. **LLM 分只当门控、不当主分**
   - 为什么：LLM 打分有系统性偏差（偏好长内容、偏好热点/权威来源），直接拿它排序会**放大**这个偏差；而且 LLM 不可解释、不可调
   - 怎么做：LLM 只决定"能不能进池"（离散决策，容错高），排序交给可解释的多路融合分
   - 加上**用 dwell 残差在线校准门限**：某类内容 LLM 分高但真实停留低 → 说明门限在该类失效 → 自动收紧

2. **Thompson 采样改造：零均值注入 + 探索预算按后验不确定性分配**
   - 零均值注入：探索只抬"后验不确定"的臂，注入量的均值为 0 → **不整体抬高也不压低分数均值**，探索期大盘指标不明显下滑（这是探索能上线的前提：探索不能让大盘难看，否则没人让你探索）
   - 预算按后验不确定性分配而非均匀撒：不确定大的臂多给，已经确定的臂不给

## 十、被挑战时的通用防御

| 挑战 | 应答 |
|---|---|
| "这些业界不都做过吗" | 「范式是公开的，但范式落地时的参数来源、约束处理、评估口径都是场景绑定的。我讲的是我在 OPPO 那个具体约束下怎么把范式改到能用」 |
| "你有 AB 验证吗" | 有数字的直接给数字；没有数字的改造（如影子价格/熵驱动预取）答：「这类属于机制设计改造，我的验证方式是分桶对照 + 双指标不劣化检查，具体幅度受当时实验资源限制没跑到大样本，这点如实说」 |
| "为什么不直接用 X" | 用三判据回：分布/目标/约束哪一条不成立 |
| 追问到实现细节答不上 | 立刻降级到设计动机层：「实现细节是工程问题，我讲的是为什么这么设计」——不要编造细节 |

> **红线**：本专题所有改造都是"在那个场景下合理的做法与思考"，不是可量化的独立成果。**凡是没有台账数字支撑的改造，被追问效果时必须如实说明**，不得编造实验数据。
