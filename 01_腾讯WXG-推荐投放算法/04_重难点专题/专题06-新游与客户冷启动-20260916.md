# 专题 06 · 新游与客户冷启动（2026-09-16）

> 对方痛点：视频号「客户冷启」、DAU 推荐「召回池优化（低 DAU 过滤）」、广告卡「覆盖 IAA 游戏扩量」。
> 简历钩子：冷启动 EE 三件套（通过率 +15%、新广告平均曝光 +30%）。

## 一、先拆题

- **供给冷启**（新游戏/新广告主/新素材）≠ **用户冷启**（新用户）——对方清单「客户冷启」= 广告主/游戏侧供给冷启，重点备这个。
- 冷启的三个阶段：**初始化**（先验从哪来）→ **探索**（流量怎么给）→ **毕业**（何时转常规竞价）。

## 二、业界做法

1. **内容理解扛冷启**：品类/题材/美术/视频素材多模态特征（CNN/BERT），同品类老游戏先验迁移（embedding 迁移、品类 CTR/CVR prior）——新游没有行为，但有「相似游戏的行为」。
2. **EE 框架化投放**（我 OPPO 的机制本体）：
   - 保护期 = 预算内纯探索（不考核成本，只攒分布）
   - 专属探索流量池 = 受控探索（固定配额隔离，不挤占常规竞价）
   - 贝叶斯平滑初始化 = 同品类 Beta/Dirichlet 先验收缩（小样本不极端）
   - 效果：通过率 +15%、新广告平均曝光 +30%
3. **早期信号加速**：用素材粒度 day0 互动（曝光/点击/停留）而非等转化回传——转化信号 T+1 且稀疏，day0 互动是冷启期的主信号（Tenjin 用 day0 广告互动预测 D30 同思路）。
4. **客户冷启（广告主侧）**：行业品类 rate card 定初始出价 → 小额试投收集分布 → 成本保障缓冲期 → 按 pLTV 置信度放开预算；配额上防头部广告主垄断探索流量。
5. **元学习/跨游迁移**（口头提级即可）：MAML 类、参数解耦微调——不讲深，点到为止。

## 三、我的场景嫁接（A 档）

OPPO 冷启动扶持机制全套真做过（EE 三件套 + 贝叶斯平滑）。客户冷启与之同构：「我做过 EE 冷启的完整闭环，游戏侧冷启把先验源从『同品类广告』换成『同品类游戏』即可」。

个人项目补充证据：新内容入池走统一 LLM 评估 + admission 分数门——「没有行为数据的内容先过内容理解关」，与业界『内容理解扛冷启』同一逻辑的独立实现。

## 四、面试三段答法

1. 「我做过」：EE 三件套完整闭环 + 数字。
2. 「业界怎么做」：先验迁移 / day0 信号加速 / rate card + 缓冲期 / 探索配额防垄断。
3. 「落地第一步」：先建「相似游戏先验」检索（品类+题材+素材 embedding），再上保护期机制，最后做毕业判据（pLTV 置信度而非固定天数）。

## 五、追问防御

- 「保护期多长？」→ 不给死数：按探索流量攒到的分布置信度动态毕业，固定天数会误伤好游戏/养坏坏广告主。
- 「探索流量池多大？」→ 流量大盘的 1-3% 量级起，按新供给占比动态调；关键是隔离而非大小。
- **金句**：「冷启动不是给新人让利，是花预算买分布——买的是这个游戏真实价值的后验。」
