# 专题 15 · 从统一计量到流量占比：占比怎么判合理、多任务怎么调、ARPU 怎么讲圆

> 触发：追问「差异化口径怎么和推荐流量分配结合起来？观察到不同类别的流量占比，怎么判断合理不合理？怎么用多任务建模调配占比、提升整体 ARPU？这个故事怎么讲圆？」
> 承接：专题 14（计量统一：观测窗 + 外推系数）讲的是**上游**；本专题讲**下游**——计量统一之后，占比怎么产生、怎么判断、怎么修正、怎么证明。
> 一句话立场：**占比是诊断指标，不是优化目标**——把占比当目标去调，就是 Goodhart。

---

## 一、故事骨架（一句话主线，先背这句）

> **先统一计量口径 → 让占比作为排序的"结果"自然涌现 → 只在"市场失灵"的地方把占比作为"约束"显式介入 → 用影子价格（不是硬配额）温和修正 → 用长周期指标 + 生态指标 + 净口径验证，证明 ARPU 的提升不是补贴换来的。**

讲圆的关键是三个"不"：

1. **不把占比当目标**——目标是长期总价值，占比是它的结果；
2. **不拍占比数字**——"精品应该占 30%"这种话，面试里一个字都不能说；
3. **不用硬配额**——用影子价格 + 容忍带，温和纠偏。

**为什么这三点能"圆"**：因为一旦你把占比当目标，逻辑上就必然要回答"凭什么定这个数"——而这个数**没有数据来源**（数据里没有反事实），答不上来就崩。把占比放回"结果 + 约束"的位置，这个洞就不存在了。

---

## 二、"合理占比"怎么定义：三条判据合取，不拍数字

这是用户这一问的核心。答案是：**合理不是一个数字，是三个条件的合取。**

### 判据 1：边际均衡（最根本、内生，不需要外部标准）

- **标准**：把最后一单位曝光从类别 A 挪到类别 B，**总价值不再增加**——即各类别的**边际价值相等**（这是分配最优的定义，不是我的发明）。
- **实操**：看各类别的**边际价值曲线**——该类别曝光 +1%，带来多少增量收入、挤掉多少其它收入，净增量为正还是负。
- **怎么用**：若长期存在"一类高边际、一类低边际"的持续缺口 → 说明分配没到位（**注意：缺口存在且持续，才是信号；短期波动不是**）。
- **这个判据的价值**：它**不需要一个先验的"正确占比"**——占比是均衡的自然结果。这是整套说法的地基：**先讲清"合理性可以从系统内部定义"，才能理直气壮地拒绝拍数字。**

### 判据 2：三个市场失灵信号（决定"自然占比"可不可信）

| 失灵 | 表现 | 本质（对应专题 13） |
|---|---|---|
| **冷启动循环** | 某类别占比低，是因为"**没数据**"，不是"不值得" | 反馈延迟导致的自我强化（§三第 4 条） |
| **外部性未定价** | 某类别占比高，但留存、负反馈、跳出在恶化 | 它"便宜"是因为**成本没入账**（§三第 8 条） |
| **反馈速度不对等** | 短期指标主导在线学习，长周期类别被系统性压低 | 可测性偏差 → 排序偏差（§八第 2 条） |

**出现任一条，占比偏离就"不是最优的结果，而是失灵的产物"**——这才是真正需要干预的地方，也正是"该用算法的人出场"的地方。

### 判据 3：生态与结构健康（业务判据）

- **供给侧**：有效供给数、新供给存活率、头部集中度（是不是只剩头部在跑）；
- **用户侧**：留存 / 时长、负反馈率、跳出率；
- **商务侧**：重点合作方保量、分成结构、平台自己的生态健康口径——**对方小游戏排行里"生态健康"占约 25% 权重，就是"结构约束"真实存在的现成证据**（用对方的证据说对方的事，很有力）。

### 结论（这句话必须完整说出来）

> **"合理"不是一个数字，是三个条件的合取：边际均衡 + 无市场失灵 + 生态不劣化。** 任何"某类别应该占 X%"的说法都是拍脑袋——数据里没有反事实，这个数**学不出来**，只能是业务决策（且要能回滚）。

## 三、多任务建模到底用来干什么（先纠正一个最常见的误解）

**❌ 错误理解**：把多任务的输出加权成一个总分，拿它排序。
→ 这就是"**把结构性问题拍成了一个权重**"，被追问"权重怎么定"必崩（与专题 13 §八 的防御同款）。

**✅ 正确分工：多任务负责"分开估"，不负责"分配"**

| 多任务输出 | 去哪 | 回答什么 |
|---|---|---|
| **收入类**任务（eCPM / pLTV / 折现价值） | **进分数**（排序主目标） | 值多少 |
| **长期类**任务（留存、复访、时长） | **进约束 / 惩罚项**（机制层） | 会不会伤生态 |
| **质量与结构类**任务（多样性、疲劳、供给质量） | **进配额与门控** | 能不能放、放几条 |

> 一句话：**多任务的价值在于"把不可合成的东西分开估"，不是"把多个目标拍成一个数"。** 分开估之后，分数管价值、机制管约束——这才是多任务与流量分配之间的正确接口。

多任务还有一个容易被忽略的作用：**归因**。占比变了之后，要能说清"是收入项变了，还是长期项变了、还是质量项把量压回去了"——单一标量分说不出这件事。

## 四、分配怎么落地：三层结构 + 一个控制器 + 三个安全阀

### 三层结构

1. **价值层**：多任务预估 → 统一计量口径（专题 14）→ 排序分数。
2. **约束层（影子价格）**：把"类别占比的目标带"写成约束 → 解对偶量（影子价格 λ）→ 作为该类别的**出价调整因子**。
   - 占比低于目标带 → 因子 > 1（温和抬）；高于 → 因子 < 1；
   - **为什么不用硬配额**：硬截断会浪费曝光（配额没用完就白白空着）、又会在边界产生断层；影子价格是连续信号，且随供需自动变化（专题 12 改造点 ②）。
3. **探索层（EE）**：给低数据 / 新供给独立预算——否则它永远攒不出数据，回到"没量 → 没数据 → 更没量"（专题 13 §三第 4 条）。

### 占比控制器（把"目标带"变成闭环）

```
每个业务周期（周级）：
  1) 观测各类别占比 p_k
  2) 与目标带 [lo_k, hi_k] 比较 → 偏差 e_k（带内 e_k = 0）
  3) 更新影子价格（对偶梯度上升 / PID）：λ_k ← λ_k + η·e_k
  4) 下发出价因子 (1 + λ_k) 到排序层 → 影响下一周期占比
```

### 三个安全阀（不讲这三条，这套东西就是失控的）

1. **修正幅度上限**：λ 有界（`|λ_k| ≤ λ_max`）——**防止出价被掰弯到"严重偏离真实价值"**（短期占比达标、长期价值崩）；
2. **时间衰减**：λ 随时间回归中性——市场变了不用等人工重置；
3. **偏离监控**：持续监控"**有效出价 vs 真实价值**"的偏离度，超阈值告警并暂停自动调节。

> 一句话：**影子价格是"温和纠偏"，不是"强行达标"。**

## 五、"提升整体 ARPU"怎么讲成可归因（三种贡献 + 一个必讲的陷阱）

### 三种贡献，分开说（别混成一句"ARPU 提升了"）

| 贡献 | 机理 | 我的经历钩子 |
|---|---|---|
| **① 口径贡献**（结构变化） | 计量对齐后，长周期类别的价值不再被低估 → 拿量份额回升 → 总价值提升 | 统一竞价 + 差异化观测窗/外推（专题 14） |
| **② 约束贡献**（防下行） | 生态约束 + 影子价格避免过度商业化 → 留存不劣化 → 长期 ARPU 不塌 | 配额与频次护栏（收入涨的同时大盘时长不跌的量级） |
| **③ 探索贡献**（找增量） | 新供给拿到独立预算 → 跑出新的高价值类别 | 冷启动 EE / 回捞（新广告平均曝光 +30% 量级） |

### ⚠️ 陷阱：ARPU 的分母游戏（这一条最值钱，一定要主动说）

> `ARPU = 收入 / 活跃用户`。**只要用户流失得比收入快，ARPU 照样会涨**——最省事的"提升 ARPU"办法就是把低价值用户赶走，指标还更漂亮。
> 所以我从来不看单一 ARPU：**总收入 + 留存（DAU / D30）+ 供给结构（有效供给数、新供给存活率）三件一起看**，而且所有收益走**净口径**——新增收入要扣掉被挤掉的其它收入与生态损失。

### 实验设计（怎么证明不是讲故事）

- **分群 A/B**：按类别的混排权重 / 影子价格强度随机化 → 同时观测：占比变化 × 短期收入 × 长期 LTV × 留存 × 内容多样性；
- **判据**：短期与长期**同向改善**，或"短期小幅让利、长期明显提升"（让利幅度可解释、有上界）；
- **必须报告净口径 + 置信区间**，不能只给一个 ARPU 增幅数字。

## 六、完整口述稿（90 秒）

> 这个问题我是分四步看的。
> **第一步，先把计量口径统一**——不同品类回收周期差一个量级，我用观测窗加外推系数把它们折算到同一个完整生命周期口径；这一步不做，后面的占比根本不成立，因为比的是不同时间尺度的钱。
> **第二步，说完口径统一，占比就应该是排序的"结果"，不该是我的"目标"。** 那我怎么判断它合理不合理？三条判据合取：一是**边际均衡**——把最后一单位曝光从一类挪到另一类，总价值不再增加；二是**没有市场失灵**——占比低是不是因为"没数据"而不是"不值"、占比高是不是因为"成本没入账"、长周期品类是不是被短期指标压着；三是**生态不劣化**——留存、供给结构、负反馈都稳住。三条都过就是合理；有一条不过，那个偏离就不是"最优"，是"失灵"。**我不会给一个"某类应该占百分之多少"的数字——数据里没有反事实，那个数学不出来。**
> **第三步，只有确认是失灵，我才把占比做成一个带容忍带的软约束**，用影子价格去温和纠偏——不是硬配额，因为硬截断会浪费曝光还有断层。具体是：多任务分开估（收入进分数、长期项进约束、质量项进配额），占比偏差驱动影子价格，影子价格再作为出价因子回到排序。而且必须挂三个安全阀：修正幅度上限、时间衰减、出价与真实价值的偏离监控——**它是纠偏，不是强行达标**。
> **第四步，验证。** 我会把 ARPU 的提升拆成三份说：口径对齐带来的结构变化、约束带来的留存不下滑、探索带来的新供给增量；并且所有收益走净口径。还要主动说一句：**ARPU 的分母会骗人，用户流失比收入快 ARPU 也会涨**——所以我同时看总收入、留存和供给结构。

## 七、追问防御

| 追问 | 怎么接 |
|---|---|
| **「现在各类别占比，你怎么判断合理不合理？」** | 不拍数字，三条合取：**边际均衡**（把最后一单位曝光从一类挪到另一类，总价值不再增加）+ **无市场失灵**（冷启动循环 / 外部性未定价 / 反馈速度不对等）+ **生态不劣化**（留存、供给结构、负反馈）。三条都过 → 合理；有一条不过 → 那是"失灵"不是"最优"。 |
| 「那你到底想调成什么占比？」 | 我没有目标占比。目标是**长期总价值**，占比是它的结果。只有在"失灵"处我才把占比做成**带容忍带的软约束**，用影子价格温和修正。 |
| 「多任务模型怎么用来分配流量？」 | 多任务负责**预估**，不负责分配：收入进分数、长期项进约束、质量项进配额；分配由"分数 + 影子价格 + EE"三层完成。**把多任务加权成一个分去排序是不对的**——那等于把结构问题拍成权重，权重还定不出来。 |
| 「为什么不直接设硬配额？」 | 硬配额会浪费曝光（配额没用完）并在边界产生断层；影子价格是连续价格信号，还能随供需自动调整。 |
| 「影子价格会不会把出价掰弯？」 | 会，所以三个安全阀：**修正幅度上限、时间衰减、偏离监控告警**。它是温和纠偏，不是强行达标；一旦"有效出价 vs 真实价值"偏离超阈值，自动调节暂停。 |
| **「ARPU 提升会不会是靠赶走低价值用户？」** | 这正是我要防的——**ARPU 的分母会骗人**。我同时看总收入、DAU/D30 留存、供给结构，收益全部走净口径。 |
| 「怎么保证不是短期把长期的钱花了？」 | 评估周期先定：分群 AB + D30 留存 + 长期 LTV；短期涨、长期跌的方案直接否掉。 |
| 「这套和业界的混排有什么不同？」 | 业界多数在做"统一分数"，我做的是"统一分数 **+ 显式约束层 + 可审计的计量口径**"。差别在**结构问题用机制解，不用权重解**。 |
| 「占比多久调一次、会不会震荡？」 | 按业务周期（周级）滚动；带容忍带（带内不干预）防震荡；λ 有界 + 衰减防过冲。 |
| 「这套在小游戏场景怎么落？」 | 对方的"生态健康约 25% 权重"就是现成的结构约束入口；清单里的"低 DAU 过滤""新游扶持""素材优选"都是这类调节的抓手——我把它们统一成"**计量 → 约束 → 探索**"三层。 |

**金句**

> **占比不是目标，是账单**——它告诉你哪里在漏钱，但不该由它来决定钱怎么分。

> 一条能讲圆的链路是：**口径先对齐（不然比不了）→ 占比自然涌现（别拍）→ 只在失灵处约束（三判据）→ 影子价格温和修正（带安全阀）→ 净口径与长期指标验证（防分母游戏）。**

## 八、这条和已有材料的接口

- **上游**：专题 14（观测窗 + 外推 → 统一口径）——**没有它，占比不可比，本专题全部不成立**。
- **同源**：专题 13 §三第 4/7/8 条（冷启动循环、eCPM 内生、外部性未定价）是本专题"失灵信号"的来源；§八第 2 条（反馈速度不对等）。
- **改造点对应**：专题 12 改造点 ②（影子价格配额，把约束变价格信号）、④（决策层回检，防"预测好但出价错"）。
- **简历钩子**：统一竞价（IAP×IAA 统一打分）、配额与频次护栏、冷启动 EE 与回捞——**三条合成一条线讲，就是本专题**。
