## 使用方式

- **面试前三天**：读 06_背诵材料（**先背 §三之二 改造点 16 条**，这是 v4 的灵魂）+ 逐条目讲法 + 05 两份
- **面试前一天**：速答卡 90 秒版 + 专题 08（对方近期重点）+ 专题 12 速查表
- **被问「你为什么这么改」**：直接背 §三之二 对应条；被质疑「业界不都做过吗」用该节通用防御
- **被问到某题**：速答卡 90 秒版起手 → 追问跳专题文档深度层
- **改简历**：改 `03_简历版本/现役/*.md` → 跑 `scripts/resume_library/build_resume_files.py` → 校验 → 认可则存快照
- **档位纪律**：A 做过敢谈踩坑 / B 评估过讲选型 / C 只答落地第一步——红线见各专题「追问防御」
