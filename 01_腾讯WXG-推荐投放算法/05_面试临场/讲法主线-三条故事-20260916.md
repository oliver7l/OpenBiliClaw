# 面试临场 · 三条主讲故事（2026-09-16）

> 对方内推人原话：「如果真有项目论证过重点，面试会比较好过」——被问「讲讲你的项目」时按线输出，不散打。每条线 3-5 分钟版，可按追问展开到对应专题。

## 主线一：广告出价全链路（广告线主力）

**覆盖**：AMS 调价 / ECMP 混排 / 校准 / 冷启（他们「广告流量=近期重点」板块大部分）

- 开场：「我在 OPPO 负责游戏中心和应用商店的广告全链路——预估、出价、机制、冷启都碰过一线。」
- 出价：人工调价 → 反馈控制（bid = tCPA × pCTR × pCVR/(1+λ)，PID 30min，策略/执行解耦）→ 对比 RL 的取舍
- 混排：百度 pCVR × price（eCPM +24%）——预估与机制解耦
- 校准：分位置 MMoE + 校准曲线（30%+→20%，ARPU +1.04%）+ LHUC 对比（专题 04）
- 冷启：EE 三件套（+15% / +30%）
- **追问映射**：出价细节→专题 03/09；校准→专题 04；冷启→专题 06

## 主线二：游戏变现与统一变现（游戏线主力，与微信小游戏同构）

**覆盖**：LTV 融合 / 大 R / IAP-IAA / 联运打分（他们游戏中心+视频号核心）

- 开场：「OPPO 游戏中心和微信小游戏是同构场景——小游戏分发、广告×联运双变现我做过完整闭环。」
- LTV：体系（D1/D7、付费率、ARPPU 折现）+ pLTV 进精排 + 大 R lognormal（专题 01）
- 统一：IAP 付费意图 vs IAA 注意力，折现同一时间窗进融合分（专题 02）
- 联运：内部广告主出价 + 护栏（专题 03）
- 延迟转化：T+1 回传双路建模（呼应 FKV T+1 延迟）
- **收尾**：「赚更多的钱，但留存曲线不动——这是我判断变现系统健康的标准。」

## 主线三：工程纵深 + LLM 演进观（差异化，别人没有）

**覆盖**：预请求架构 / Lite / scaling / AI agent / genrec（基础模型线）

- 端云协同：三范式 + 量化剪枝 Lite（-25%）→ 三种「前置」同构（专题 05）
- 个人项目：端到端 LLM 推荐系统——LLM 评估入池 / RankAgent / Thompson 采样 / 批量文案三重防护 / dwell 闭环 / 2.6s→0.6s（专题 07）
- scaling 观：稀疏 embedding 是瓶颈，GPSD 冻结迁移 + 蒸馏落地路线（专题 08）
- genrec 观：TIGER→OneRec 谱系 + 语义 ID 试验田第一步（专题 11，C 档坦诚）
- **收尾**：「JD 里『关注业界前沿并落地』这条，我自己在自己身上执行了三年——个人项目就是我的落地场。」

## 使用纪律

1. 每条主线控制在 3-5 分钟，先结论后细节，数字嵌在动作里。
2. 对方追问哪个点就跳对应专题文档的深度层。
3. 档位意识：A 档敢谈踩坑，B 档讲选型对比，C 档只答「落地第一步」——不硬撑。
4. 组长（字节系）在场的场合：先给结论和数字，再给机理；避免长铺垫。
