## 一、S 级 · 必讲（5 条，独特性最高）

### S1 · 三形态自然 × 商业同池排序（我最不可替代的一条）

- **钩子**：「自然结果和商业结果怎么放在一个池子里排，我在**三种形态**下都做过——应用商店、搜索、游戏中心。」
- **支撑事实（台账）**：百度 Mobojoy `pCVR × price` 混排 → **eCPM +24%**（小流量）｜百度 MoboMarket 搜索 `pCTR × price` → **eCPM +21%+**｜腾讯搜索混排**由点击率预估改为 LTR** 解决时效性/权威性 badcase｜OPPO 广义 eCPM + 配额护栏。后续在百度还补过一层**质量因子**（纯按 price 排会让高价低质应用长期占位 → 下载完成率/卸载率回灌进排序）。
- **命中对方**：**自然流量模块**（对方独立列的一个业务模块）+ 商业中台「ECMP 预估模型 / 混排逻辑」
- **独特性**：**三种形态都做过的人极少**；且结尾能收到方法论：**统一计量口径 → 可解释因子权衡 → 配额与护栏兜生态**
- **展开**：专题 13 §十（含四个真问题、机会成本定价）
- **会被追问**：① 为什么搜索要从 CTR 改 LTR？→ 点击率预估表达不了「该给谁」，时效/权威 badcase 压不住；② 质量因子为什么只降权不提权？→ 提权等于平台给商业内容做信用背书。

### S2 · 联运 IAP × 广告 IAA 统一竞价（同构场景，主战场）

- **钩子**：「OPPO 游戏中心和微信小游戏是**同构场景**——联运分成和广告变现两个轮子放在一个池子里排，我做过完整闭环。」
- **支撑事实（台账/现役简历）**：统一竞价（pLTV 折现当出价 vs 广告 eCPM）｜**折现窗按品类回本周期差异化**｜**配额不做硬截断、写成影子价格**转出价折扣因子｜IAP 提权设计为**带业务先验的可解释乘性因子**｜付费深度四层差异化分发｜LTV 折现口径直接对齐买量回收模型（首日回收 / 7 日回本）并与商务对齐分成结构
- **命中对方**：**「融合公式 IAP 提权与物理意义」**（对方原文）+「PC 找游戏流精排 / LTV 融合」+「联营 IAP 游戏打分」
- **独特性**：同构场景 + 每一处都有改造（折现窗 / 影子价格 / IAP 提权），**不是把业界方案背一遍**
- **展开**：专题 02、专题 03、专题 14（折现窗怎么差异化）
- **会被追问**：IAP 提权凭什么可解释？→「**乘性因子 = 在同一价值标尺上做业务先验的缩放；加性会破坏量纲可比性**」。

### S3 · pLTV 进精排 + 大 R 处理（对方同时在做的两件事）

- **钩子**：「LTV 我做的不是评估，是**直接进精排融合分**的。」
- **支撑事实（台账 + 现役简历）**：pLTV 进精排融合分输入｜业界 ZILN（付费概率 × 对数正态金额）、ODMN 多分布专家分治，我的两处改造：**①专家按 σ（不确定性）路由而非金额分桶**、**②评估补决策层回检**（按出价档位看实际 ROI 与回本周期）｜**分位数下界出价且分位随样本量自适应**｜CTR 多位置校准 **偏差 30%+ → 20% 以内、ARPU +1.04%**（台账 B 级）
- **命中对方**：视频号 LTV（**大 R 辅助任务、lognormal 损失**）+「PC 找游戏流 LTV 融合」+「分人群调价」
- **独特性**：对方在做「把大 R 拆出去做辅助任务」，我能讲**同一个问题的另一个解法**——「扭曲梯度的不是金额大，是猜不准」
- **展开**：专题 01 + 专题 12 §二
- **会被追问**：Gini 很高为什么还不行？→ 「Gini 高但分位系统性偏高 → 出价全档超耗；预测指标好不等于出价对」。

### S4 · T+1 延迟转化（他们正在头疼的正是这个）

- **钩子**：「T+1 回传的失真，我的做法不是等数据变完整，而是**让模型理解"不完整"这件事本身**。」
- **支撑事实（台账/现役简历）**：**「已观测时长 t」作为条件输入**（学 P(转化｜已观测 t)，新样本立刻可用）｜**早期未回传不当负样本**，用观测概率倒数做无偏加权｜延迟路以 lognormal 时延刻画，**参数按素材 × 人群分群**而非全局一套
- **命中对方**：**AMS 集资「FKV 打分（T+1 延迟）」** —— 这是"**他们正在做 + 我有同款一手**"的完美对应
- **独特性**：大多数团队图省事直接"未回传当负样本"，我能讲清代价（**系统性低估慢回传人群，而慢回传的往往正是高价值人群**）
- **展开**：专题 12 §五
- **会被追问**：加权会不会引入偏差？→ 期望意义下无偏，代价是方差上升，要盯住。

### S5 · 冷启动 EE + IAA 扩量（接住我唯一的"偏弱项"）

- **钩子**：「IAA 游戏不敢放量我理解——**它的 LTV 短期内本来就不可测**。我的做法是先给一笔**可承受的探索预算去换数据**，而不是靠先验判断敢不敢放。」
- **支撑事实（台账 B 级 + 现役简历）**：EE 三件套（保护期 = 预算内纯探索 / 专属流量池 = 受控探索 / 贝叶斯平滑 = **新品类借用父类先验而非全局先验**）｜关键改造「**先决定"在哪探索"再决定"探索多少"**」（低峰/低价值位承担探索，先验迁移回高价值位）｜**冷启动广告通过率 +15%、新广告平均曝光量 +30%**
- **命中对方**：**「客户冷启」** + ★ **「覆盖 IAA 游戏扩量」**（23 问里唯一明确标"偏弱"的一条）
- **独特性**：把偏弱项**用原理接住**，并给出可执行的第一步
- **展开**：专题 06
- ⚠️ **纪律**：**`ROAS +8%` 这个数字不用**（用户已要求从简历删除）。

## 二、A 级 · 差异化（4 条，别人少讲）

### A1 · 端到端 LLM 推荐系统（个人项目，真在跑）

- **钩子**：「JD 里『关注业界前沿大模型推荐进展并落地』这条，**我自己在自己身上执行了三年**——手上这个系统就是我每周在跑的落地场。」
- **支撑事实**：多源发现 + **LLM 评估入池**（300+ 候选）｜**LLM 分只当门控、不当主分** + **用 dwell 残差在线校准门限**｜排序用 MMR + 来源硬配比 + 风格限流 + **topic 疲劳双轴**（单批 10 条主题零重复）｜LLM 重排 agent + Thompson 采样（**零均值注入**）｜批量文案三重防护（内容 ID 绑定 / 重复整组丢弃 / 限流降级重试）｜显式 + 隐式双反馈闭环 + 兴趣探针｜**换一批延迟 2.6s → 0.6s**
- **命中对方**：**JD 硬要求「基于大模型提升推荐效率」** + 基础模型「推荐 AI agent」+ 预请求架构（2.6s→0.6s 是缓存/预热的同类问题）
- **独特性**：**别人最多背论文，我是真在跑**；且有三个一手判断——①LLM 适合当"裁判"不适合当主排序算子 ②探索必须显式建模 ③隐式信号密度高但噪声大，要与显式分开建模
- **展开**：专题 07 + 专题 11
- ⚠️ **纪律**：**不进简历**，只在面试里展开。

### A2 · 端云协同 + 端侧 Lite 模型（对接他们没被覆盖的一条）

- **钩子**：「我做过端云协同，量化剪枝产出**端侧 Lite 模型**，云端负载成本降了 **25%**。」
- **支撑事实（台账 B 级）**：云训 / 端推 / 端云联合三范式｜量化剪枝 → 端侧 Lite｜**云端负载成本 −25%**｜预取深度**熵驱动自适应** + **作废率计进成本账**
- **命中对方**：★ 清单里的「**公众号卡片 Lite 模型**」——这是 39 条里**没被 23 问覆盖**的一条，**别人根本不会想到去接**
- **独特性**：能看出他们**同时做 scaling up 和 Lite 模型是"分工"不是"矛盾"**（该大的地方大、该小的地方小）——**这本身就是判断力**（详见 `02_提取与分析/对方关心的问题总清单` 文末「补遗」）
- **展开**：专题 05
- **会被追问**：预取深度怎么定？→ 熵驱动 + 作废率进成本账，**不说"固定预取 N 条"**。

### A3 · 一站式模型诊断系统（"系统性"三个字正中要害）

- **钩子**：「推荐问题我不是一个个 case 修，**先做工具、再定流程**。」
- **支撑事实（台账 A 级）**：特征归因（slot / Shapley / 梯度）+ AUC 下钻做成**自助工具**，沉淀为团队**排查标准流程**（腾讯）
- **命中对方**：「社区推荐**系统性**诊断」——"系统性"三个字说明他们要的是方法论，不是刷指标
- **独特性**：**"把排查流程工具化"比讲某个模型结构稀缺得多**
- **展开**：专题 10

### A4 · oCPX 策略 / 执行解耦（最短的"我懂你们"路径）

- **钩子**：「人工调价我重构成带预算约束的反馈控制，并且**把策略层和执行层解耦**——这一条正好对上你们 AMS 的『**lua 调价拆分**』。」
- **支撑事实（现役简历）**：`bid = tCPA × pCTR × pCVR / (1+λ)`，PID 30 分钟更新｜**λ 两维驱动**（成本达成率 × 预算 pacing 进度）｜抗积分饱和 + **按日重置积分**｜CPC / CPA / oCPM 三类结算分别适配｜**策略层与执行层解耦，独立迭代回滚**｜对比 RL 出价后选 PID（理由是样本效率与可控性）
- **命中对方**：**AMS 集资「lua 调价拆分」+「实验系统接入」**
- **独特性**：**同一个工程诉求的两种表达**——这是让对方瞬间确认"你懂我们在干什么"的最短路径
- **展开**：专题 12 §三
- **会被追问**：为什么不用 RL？→ **出价直接影响广告主钱袋子，可控性 > 理论最优性**。
