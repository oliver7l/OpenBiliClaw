## 二、逐条口述（按简历顺序）

### 【个人优势】

#### 1. 同构场景直接迁移
- **开口**：我特别想强调一点，OPPO 游戏中心和微信小游戏是**同构**的，不是类比。
- **展开**：同样都是联运 IAP 加广告 IAA 的双轮收入，同样要解决统一打分、融合公式的物理意义、oCPX 出价、频控配额、延迟转化和素材优选——这几件事我全是**一手落地**的，不是看过论文。
- **收尾**：所以我过来不是从零理解业务，是换一套数据把做过的事再做一遍。

#### 2. 变现与生态双视角（★ 高命中）
- **开口**：我做统一混排最大的体会是——**它本质是流水收入和生态健康的权衡**。
- **展开**：收入侧我的数字是广告混排 eCPM +24%、校准带来 ARPU +1.04%；生态侧是大盘时长 +0.42%、中长尾用户 ARPU +2.3%。这两组数字我都拿得出来，因为当初就是一起看的。
- **收尾**：如果只知道堆广告密度换短期收入，生态侧会反噬——这个我在 OPPO 是踩过的。

#### 3. 多目标与从 0 到 1
- **开口**：腾讯 4 年我主要做两件事：多品类统一排序，和从 0 搭新场景。
- **展开**：多目标这块 MMoE 做点击+互动，短内容互动 +35%、浮层时长 +6.8%；从 0 到 1 有两个，小说主 feeds 点击率 +15.3%，图集推荐核心指标 +20% 以上。
- **收尾**：期间拿了 1 次五星、3 次四星。

#### 4. LLM × 推荐动手派
- **开口**：LLM 这块我不是只停留在看论文，我是**自己端到端写了一套系统**。
- **展开**：LLM 评估入池、重排、表达生成，加上 Agent 编排和 Thompson 采样做探索，全是我一个人从数据爬到线上跑通。
- **收尾**：所以我对 LLM 上线的延迟、成本、质量护栏，是有**工程手感**的，不是估算。

#### 5. 三套 LLM 场景的完整认知（★ 差异化）
- **开口**：我在三种场景里用过 LLM，所以对它**在哪增值、在哪是坑**有比较成体系的判断。
- **展开**：金融是领域 SFT；内容推荐是端到端系统；广告侧是素材多模态理解。三个场景的瓶颈完全不同。
- **收尾**：比如我的核心判断之一——LLM 适合做**裁判**，不适合做**主排序算子**，这个一会儿可以展开。

### 【OPPO · 游戏分发与变现】（主战场，投入最多时间）

#### 6. 广告 × 联运统一竞价（★ 最可能开场的深挖题）
- **开口**：这个问题我先把**痛点**说清楚：联运收入是 LTV 后置归收，长周期折现；广告收入是即时按次结算，eCPM。两个**计量口径不可比**，排序天然会偏向广告。
- **展开**：我的做法是——把联运游戏当成一个**内部广告主**参与竞价：联运用 pLTV 折现值出价，广告用预估曝光乘 eCPM，折算到**同一个时间窗**再进融合分。这和业界 value-based bidding 是同一个思路。
- **再展开**：IAP 提权我没做成黑箱系数，而是**带业务先验的可解释乘性因子**——业务方知道自己在调什么。自然供给走配额加频次护栏。
- **收尾**：结果就是短期收入和大盘留存兼得，不会为了当期 ROI 把生态做坏。
- **追问预置**：
  - Q「融合公式具体怎么定？」→ 先讲口径统一（时间窗 + 折现率），再讲乘性因子的物理意义，最后讲护栏是硬约束不是软惩罚。
  - Q「为什么不用学习式排序？」→ 因为业务方要能解释和干预，可解释性在这个问题上优先级高于离线 AUC。

#### 7. pLTV 建模与大 R 处理（★ 他们清单上的原题）
- **开口**：pLTV 我是直接**进精排融合分**的，不是只做评估指标。
- **展开**：先按 IAP 付费深度做四层差异化分发，因为**头部极小比例的用户贡献主要流水**，必须单独对待。
- **再展开**：建模上重尾按业界 ZILN 范式拆成「付费概率 × 对数正态金额」，关键是它输出 σ，我可以拿**分位数下界**去出价——比点估计更适合做预算约束。大 R 走多分布专家分治，也就是 ODMN 的思路，把极度不均衡的长尾拆成几个平滑子分布交给不同专家，避免头部样本**扭曲梯度和 cohort 均值**。
- **收尾**：评估我不只看 MSE，是看 Gini 加分位校准。
- **档位提醒**：ZILN / ODMN 是我**深入评估并借鉴其范式**，讲机理+选型对比+我的改造，别说是自己训过原论文模型。

#### 8. 游戏生态的商业理解
- **开口**：这条我想讲的是——**技术方案能不能落地，取决于算法口径和业务口径有没有打通**。
- **展开**：我把 LTV 折现口径直接对齐游戏买量回收模型，就是首日回收、7 日回本那一套；联运分成结构是和商务侧对齐过的。
- **收尾**：如果口径不通，业务方不会信你的排序结果，再漂亮的技术方案也推不动。

#### 9. oCPX 智能出价
- **开口**：我把人工调价重构成了一个**带预算约束的反馈控制问题**。
- **展开**：公式是 bid = tCPA × pCTR × pCVR / (1+λ)，λ 是成本约束的松弛度，由 PID 控制器**每 30 分钟**随超耗风险自适应更新。
- **再展开**：选型时我对比过 RL 出价，最后选 PID，原因是**样本效率和可控性**——RL 冷启动阶段成本高、线上不可控，PID 出问题能立刻归因。
- **收尾**：架构上策略层和执行层解耦，策略能独立迭代和回滚；CPC、CPA、oCPM 三类结算分别适配出价和成本保障。

#### 10. CTR 多位置消偏
- **开口**：我先定位根因——偏差不是模型容量不够，是**分广告位的曝光分布漂移**。
- **展开**：所以我把广告位做成任务维度，构建 MMoE，分位置专家加门控；也对比过 LHUC 那种前置调制的路线。
- **再展开**：选 MMoE 是因为我这边**位置之间的意图差异很大**——闪屏是强推、信息流是主动浏览，用分任务学更直接；再配合校准曲线修漂移。
- **收尾**：预估偏差从 30% 以上降到 20% 以内，ARPU +1.04%。
- **档位提醒**：LHUC 是 B 档——讲机理（偏置走旁路、推理置空）、讲我为什么没选，别说是自己上过线。

#### 11. 延迟转化建模（T+1 回传）
- **开口**：游戏转化信号是**隔日回传**的，而且随素材和人群漂移。
- **展开**：固定观测窗口必然预估失真——因为你不知道没回传的是"没转化"还是"还没回传"。
- **收尾**：我拆成即时加延迟双路多任务，延迟路用 lognormal 时延分布刻画，支持按回传进度纠偏。

#### 12. 冷启动 EE 与流量回捞（★ 一条经验接两个考点）
- **开口**：冷启动我把它拆成一个**探索利用问题**。
- **展开**：三个组件对应三件事——保护期是预算内纯探索、专属流量池是受控探索、贝叶斯平滑是先验收缩。
- **收尾**：新广告平均曝光 +30%、通过率 +15%。
- **加分延伸**：同一套**低效流量二次定价**的逻辑，我复用到回捞场景——把将要流失的曝光重新按期望收益定价，这和广告回捞是同构的。

#### 13. 素材多模态优选
- **开口**：CNN/BERT 双塔加 Cross-Attention 做图文融合，支撑素材质量分和优选。
- **收尾**：另外做了 SSL4Rec 多粒度对比学习，中长尾用户 ARPU +2.3%。

#### 14. 端云协同与预取式分发（★ 差异化亮点）
- **开口**：这条是别人不一定有的——我做过**端侧**。
- **展开**：云训、端推、端云联合三种范式都做过，量化和剪枝产出端侧 Lite 模型，云端负载成本降了 25%。
- **加分延伸**：端侧前置计算和**预请求缓存**是同构的——都是按「下一落点分布 × 期望收益」决定预取深度，目的是降首屏延迟和云端带宽。

### 【个人项目 · LLM 推荐系统】（第二主战场，全 A 档随便挖）

#### 15. 多源发现与 LLM 评估入池
- **开口**：我自己爬了 B 站、YouTube、知乎、小红书，还有播客、音乐、听书这些源，走平台 API 加 RSS 双通道。
- **展开**：四类发现策略——explore、search、trending、related_chain，统一走 LLM 批量评估，相关性打分加分数门 admission 入池，一次 300 多个候选。
- **收尾**：LLM 在这里干的是**裁判**的活，不是主算子——这是成本决定的。

#### 16. 排序与多样性
- **开口**：排序是 tier、相关性、新鲜度三维混合，新鲜度用 3 天半衰期。
- **展开**：多样性做了四层——MMR 用 embedding 余弦打散近义主题、来源硬配比、风格限流，再加一个 topic 疲劳双轴，细粒度和粗粒度取 max。
- **收尾**：效果是单批 10 条主题零重复。

#### 17. LLM 重排 agent
- **开口**：重排是会话式的，四个分数相乘——规则分、语义分（兴趣质心余弦）、点赞学习分、停留时长分。
- **展开**：我特意加了一个 Thompson 采样探索轴，Beta 后验、零均值注入。
- **收尾**：原因是确定性排序有个致命问题——**没点过的新兴趣会永久不可见**。

#### 18. LLM 表达生成
- **开口**：文案是批量预生成的，朋友式推荐语气。
- **展开**：这里坑很多，我做了三重防护——按内容 ID 绑定防乱序错位、跨内容重复文案整组丢弃、限流时降级重试。
- **收尾**：语气由画像驱动，所以不同人看到的表达风格不一样。

#### 19. 反馈闭环
- **开口**：显式反馈是 like 和 dismiss，隐式是停留时长 dwell。
- **展开**：dwell 累计到阈值触发画像重建，回流影响发现评分和排序。
- **收尾**：还做了兴趣探针——LLM 猜方向，用户确认或拒绝，结论入画像。

#### 20. 性能优化
- **开口**：换一批的延迟我从 2.6 秒压到 0.6 秒。
- **展开**：三件事——embedding 并发预热、缓存命中率从 0 提到 100%、批量写库把 10 次 fsync 合并成 1 次。
- **收尾**：这类优化在 LLM 系统里很关键，因为模型延迟省不下来，只能从工程侧找。

#### 21. 生成式推荐的跟踪与判断（★ 主动埋的钩子）
- **开口**：生成式推荐我在跟进，比如快手 OneRec 那套——RQ-KMeans 语义 ID、端到端替代级联、推理侧 Pass@K 用算力换效果。
- **展开**：我的判断是**短期应该单点切入**，先用语义 ID 做召回或重排增强；全链路替换的门槛不在算法，在工程和成本。长期价值在 OPEX 结构。
- **红线**：代码里没有语义 ID 实现，这条是**跟踪与判断**，不是实操——被问"你做过吗"要如实说"跟踪和判断，没上线"。

#### 22. 三个一手判断（★ 面试官最容易挑的钩子）
- ① **LLM 适合做裁判，不适合做主排序算子**——全量打分的延迟和成本，跟模型分差两个量级。
- ② **探索必须显式建模**——任何确定性排序都会让没点过的新兴趣永久不可见。
- ③ **dwell 比显式反馈密度高一个量级但噪声大**——两者分开建模、加权融合，优于混作单一标签。
- 准备：每一条都要能举出系统里的具体例子（①成本对比 ②Thompson 轴 ③双通道建模）。

## 三之二、改造点口述（v4 核心 · 16 条，逐字可背）

> **这一节是 v4 的灵魂**。面试官看到简历上的改造点，一定会问「你为什么这么改」。每条只背三句话：**业界是 A → 我这不成立因为 B → 所以我改成 C**。
> 通用开口句（先立方法论，比单个改造点更高级）：
> 「我看业界方案先问三个问题——**它的分布假设在我这成立吗、它优化的目标和我决策的目标是一回事吗、它的约束和我的一样硬吗**。三条里只要有一条不成立，就得改。」

**1. 折现窗按品类差异化**（统一竞价）
「业界统一折现窗，我这个是按品类回本周期定的。因为精品游戏回本 30 天以上，小游戏 IAA 当天就结算，差一个量级——全局取一个窗，不管取哪边都是**方向性偏差**，会直接改变排序结果，不是精度损失。」

**2. 配额用影子价格不硬截断**（统一竞价）
「配额如果用硬截断，配额没用完的时段——比如低峰——会白白浪费剩余曝光。我把它写成拉格朗日松弛项，约束的影子价格自然变成一个出价折扣因子，**配额从'规则'变成了'成本'**，模型能自己权衡要不要买这个配额。」

**3. 专家按不确定性路由不按金额分桶**（pLTV）
「ODMN 的动机是重尾扭曲梯度，但**真正扭曲梯度的不是金额大，是猜不准**。一个稳定的大 R 梯度是干净的，一个'可能是大 R 也可能不付费'的才是噪声源。按金额分桶会把这两种塞进同一个专家，所以我按 σ 路由，让每个专家拿到方差相近的子分布。」

**4. 补决策层回检**（pLTV）
「预测指标和决策指标会脱节。典型失效是**Gini 很高但分位数系统性偏高** → 每个档位出价都偏高 → 全档超耗。超耗是广告主能直接感知的投诉，所以我除了 Gini 还要按出价档位回检实际 ROI 和回本周期。」

**5. 分位数下界出价 + 分位随样本量自适应**（pLTV）
「非对称分布下点估计的下行风险远大于上行收益——少买只是少赚，超耗是亏损加投诉。所以用 σ 出分位数下界，而且新游样本少的时候取更保守的分位，样本够了再放开到中位。」

**6. λ 两维驱动**（oCPX）
「只盯成本的控制器会出两种事故：上午把预算花光、或者晚上剩量花不出去。因为成本是个比值，pacing 是绝对进度，**两者正交**。所以误差项我做成成本达成率 × 预算消耗进度对时间进度。」

**7. 抗积分饱和 + 按日重置**（oCPX）
「广告的'被控对象'每天被重置一次，但控制器不会自动重置。积分项跨日累积，新的一天开局就带着昨天的包袱——要么过冲要么迟钝。这是控制理论的老问题，但在广告里特别容易踩。」

**8. 位置是意图不是偏置**（消偏 · 最重要的一条）
「LHUC 的假设是'位置是需要被剔除的干扰'。但我这个场景里位置本身就是意图——闪屏强推和信息流主动浏览，用户对广告的接受度根本不是同一个量。把位置调制掉，等于要求模型用一套兴趣表达覆盖两种心态，两边都学不好。所以位置进主网络，按位置做 MMoE 的任务维度。**判断标准很简单：把位置置空之后，剩下的东西还是不是同一个语义？**」

**9. 校准在线滑动 + 小样本位收缩**（消偏）
「离线算一次固定曲线扛不住曝光分布漂移——可漂移本来就是偏差的根因。但纯在线又会让长尾位因几条样本剧烈抖动。所以滑动窗在线更新 + 贝叶斯收缩：样本够就信自己，样本不够就信大盘。」

**10. 观测时长作为条件输入**（延迟转化）
「固定窗口的代价是样本必须'变老'才能用，模型永远在学过期的分布。我把'已经观测了多久'直接喂进模型，学 P(转化 | 已观测 t)，新样本进来立刻可用，按回传进度纠偏。**与其等数据变完整，不如让模型理解'不完整'这件事本身。**」

**11. 未回传不当负样本**（延迟转化）
「延迟回传场景下把'还没回传'当负样本是系统性低估。而慢回传的往往正是高价值人群——等于模型在惩罚他们。用观测概率倒数做无偏加权，这是延迟反馈建模的标准处理，但很多线上系统图省事直接当负样本。」

**12. 先定"在哪探索"**（冷启动）
「EE 的教科书都在讲分多少流量给探索，但工业里真正值钱的问题是**这个探索放在哪**——因为流量不是同质的，在高价值位探索牺牲的是最贵的曝光，同样的预算放在低峰位信息收益几乎一样，成本却低一个量级。学完的先验再迁回高价值位。」

**13. 剩余机会系数**（回捞）
「回捞不是简单重排，是在给'最后一次机会'定价。即将流失的曝光要按'这次不捞就没了'提价。」

**14. 熵驱动预取深度 + 作废率进成本账**（端云）
「固定深度两头浪费：行为确定性高时预取不够，发散时预取作废。所以按下一落点分布的熵自适应。另外**指标决定行为**——只考核命中率会把策略引向'多预取总没错'，但作废的预取消耗的是带宽和端侧算力，所以目标函数是命中收益减作废成本。」

**15. LLM 只当门控不当主分**（个人项目）
「LLM 打分有系统性偏差——偏好长内容、偏好热点，直接拿它排序会**放大**这个偏差，而且不可解释不可调。所以我让 LLM 只决定'能不能进池'这个离散决策，排序交给可解释的多路融合分。另外用 dwell 残差在线校准门限：某类内容 LLM 分高但真实停留低，说明门限在这类上失效，自动收紧。」

**16. 零均值注入 + 不确定性分配探索预算**（个人项目）
「探索能不能上线，取决于探索期大盘指标难不难看。Thompson 采样我做了个改造：注入量均值为零，只抬后验不确定的臂，不整体抬高也不压低分数均值。另外探索预算按后验不确定性分配，不是均匀撒——已经确定的臂不给。」

### 通用防御（被质疑"这些业界不都做过吗"）

> 「范式是公开的，但范式落地时的**参数来源、约束处理、评估口径都是场景绑定的**。我讲的是我在 OPPO 那个具体约束下怎么把范式改到能用。」

### 效果类追问的诚实口径

有台账数字的直接给数字；改造类（影子价格、熵驱动预取、门限校准等）**没有独立 AB 数字**的，标准答法：

> 「这类属于机制设计改造，当时的验证方式是分桶对照 + 双指标不劣化检查，具体幅度受实验资源限制没跑到大样本，这点如实说。」

**绝不为改造点编造效果数字**——这是红线。
