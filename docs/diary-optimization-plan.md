# 日记系统优化计划

> 基于 4 个开源项目（memex、ai-journal、echolog、Personal-Knowledge-Wiki）的深度分析，结合现有 925 篇日记、33 万字、5 个来源的数据基础，制定的分阶段优化计划。

---

## 📊 现状盘点

### 已有能力
- **数据规模**：925 篇日记，330,716 字，时间跨度 2016-04-12 ~ 2026-09-03（10 年）
- **多源导入**：MindBack(657)、有道云(126)、苹果备忘录(85)、乐乐成长日记(47)、WPS(10)
- **AI 能力**：标签人物自动提取（27 个标签、10 个人物）、日记分析、数据洞察
- **前端页面**：统计卡片、筛选搜索、双栏布局、写日记弹窗、AI 分析展示、导入弹窗、数据洞察、随手记、人物与标签
- **AI 分析记录**：12 篇（来自有道云的 AI 分析）

### 核心优势
- **数据量足够大**：33 万字、10 年跨度，是最有价值的资产
- **多源整合完成**：5 个来源的数据已经统一到一个数据库
- **基础架构完善**：后端模块、API、前端页面、测试都已就绪

## 🎯 参考项目核心亮点

### 1. memex（碎片化记录 + 多 Agent + 时间线卡片）
- **碎片化记录**：text/photo/voice，不用写完整日记，AI 自动组织
- **多 Agent 系统**：super_agent 协调 specialist skills（时间线卡片、PKM、洞察、记忆）
- **10 种卡片类型**：任务、日常、事件、文章、引用、人物、地点、指标、评分、画廊
- **P.A.R.A 知识组织**：Projects / Areas / Resources / Archives
- **AI 陪伴角色**：自动评论新日记、1v1 聊天、长期记忆
- **纯 Markdown 存储**：零厂商锁定，Obsidian 友好
- **自定义 Agent**：事件驱动、Skill 插件、JS 执行、依赖链

### 2. ai-journal（RAG 语义搜索 + 向量记忆）
- **RAG 语义记忆**：1024 维向量，pgvector，HNSW 索引，亚毫秒级检索
- **相似日记检索**：写新日记时自动检索相似的历史日记作为上下文
- **LLM 深度分析**：情绪、关键场景、成长洞察、行动建议
- **流式响应**：实时看到 AI 思考过程
- **完全本地运行**：Ollama + Qwen3，数据不出机器

### 3. echolog（对话即采集 + 证据驱动日记）
- **对话即采集**：飞书/Telegram bot，文字/图片/语音/视频
- **按发送时间归档**：离线写后同步也能落到正确日期
- **证据驱动日记**：事实先行，不堆空洞形容词，每条结论要有 log 支撑
- **视觉模型**：图片自动描述，按文件名缓存
- **whisper.cpp**：本地语音转录
- **语义检索**：/recall 在 embedding 索引上做语义检索
- **草稿流水线**：/draft 把灵感变成推特/长文/视频脚本
- **周报**：/week 过去 7 天回顾
- **本地 Markdown vault**：Obsidian 友好

### 4. Personal-Knowledge-Wiki（个人知识网络 + LLM Agent）
- **三层架构**：raw sources → entries → wiki
- **LLM Agent 维护**：agent 自动编写和维护所有 wiki 文章
- **自动双向链接**：_backlinks.json 反向链接索引
- **Wikipedia 风格 UI**：分类、目录、反向链接、相关文章、全文搜索
- **多源导入**：Day One、Apple Notes、Obsidian、Notion、iMessage
- **深度问答**："我和某人的关系如何？"、"我对产品设计的哲学是什么？"

## 🚀 分阶段优化计划

### 🔥 第一阶段：RAG 语义搜索 + 日记对话（2-3 周）
**优先级：最高** — 发挥 33 万字数据价值的最关键功能

#### 核心功能
1. **向量嵌入存储**
   - 用 SQLite-vss 或 chromadb 本地向量库（保持轻量，不用 PostgreSQL）
   - 对所有 925 篇日记生成 embedding（用 OpenAI / 豆包 / 本地 Ollama）
   - 增量更新：新日记自动生成 embedding

2. **语义搜索**
   - 自然语言搜索："我和艳艳吵架最多的月份"、"我去年这个时候在想什么"
   - 相似日记推荐：查看一篇日记时，自动推荐 3-5 篇相似的历史日记
   - 时间范围筛选 + 语义排序

3. **和我的日记对话**
   - RAG 问答：基于日记内容回答问题，引用具体日记作为证据
   - 支持追问和多轮对话
   - 可以问："总结一下我 2024 年的成长"、"我和妈妈的关系变化轨迹"

4. **写日记时的上下文洞察**
   - 写新日记时，自动检索相似的历史日记
   - AI 提示："去年今天你也写了类似的内容..."、"你之前提到过这个问题..."

#### 技术实现
- 向量库：SQLite-vss（零依赖，和现有数据库一致）或 chromadb（功能更全）
- Embedding：豆包 embedding API（便宜、中文好）或本地 Ollama
- RAG 框架：自己实现（简单）或用 LangChain（功能全）
- 前端：新增"🔍 语义搜索"Tab + "💬 日记对话"Tab

#### 预期效果
- 可以用自然语言探索 10 年的日记数据
- 发现之前看不到的模式和关联
- 写日记时有历史上下文，更有深度

---

### ⭐ 第二阶段：碎片化快速记录 + 随手记增强（1-2 周）
**优先级：高** — 降低记录门槛，让记录成为习惯

#### 核心功能
1. **随手记增强**
   - 支持一句话、一张图快速记录（不用写完整日记）
   - 碎片记录自动按天归档
   - 一键"整理成日记"：AI 把当天的碎片整理成结构化日记

2. **证据驱动日记生成**
   - 借鉴 echolog：事实先行，不堆空洞形容词
   - 每条结论都要有原始记录支撑
   - Action Items 用 checkbox 格式

3. **语音输入**
   - whisper.cpp 本地语音转录（免费、私密）
   - 语音自动转文字，整理成日记

4. **图片理解**
   - 视觉模型自动描述图片内容
   - 图片描述缓存，不重复解析

#### 技术实现
- 碎片记录表：diary_fragments（已有，需要增强）
- 语音转录：whisper.cpp（本地）或豆包语音 API
- 图片理解：豆包视觉模型或 GPT-4V
- 前端：增强"✏️ 随手记"Tab，支持语音、图片、快速输入

#### 预期效果
- 记录门槛大幅降低，碎片时间也能记录
- 不用每次都写完整日记，AI 自动整理
- 记录频率提升，数据更丰富

---

### 📊 第三阶段：月度/年度自动反思 + 周报（1-2 周）
**优先级：高** — 从数据中提取洞察，实现自我成长

#### 核心功能
1. **月度自动反思**
   - 每月 1 号自动生成上月反思报告
   - 包含：情绪曲线、高频主题、人物互动统计、高光时刻、低谷时刻、成长洞察
   - 可以手动触发重新生成

2. **周报生成**
   - 一键生成过去 7 天的周报
   - 包含：本周关键词、情绪曲线、完成事项、下周展望
   - 借鉴 echolog 的 /week 命令

3. **年度回顾**
   - 你已经有 10 年数据，可以生成非常有深度的年度回顾
   - 每年的：核心事件、情绪变化、关系变化、成长主题、关键决策
   - 10 年全景：人生阶段划分、重大转折点、长期趋势

4. **情绪追踪可视化**
   - 情绪热力图（按天/周/月）
   - 情绪趋势曲线
   - 情绪与人物/事件的关联分析

#### 技术实现
- 报告生成：LLM 批量分析 + 模板化输出
- 可视化：ECharts（热力图、趋势图、雷达图）
- 定时任务：APScheduler 或 cron
- 前端：新增"📊 月度反思"Tab + "📈 数据洞察"增强

#### 预期效果
- 每月/每年自动有深度反思，不用自己写
- 可视化展示情绪和成长趋势
- 10 年数据变成有价值的人生回顾

---

### 🕸️ 第四阶段：个人知识网络 + 人物关系图谱（2-3 周）
**优先级：中** — 把日记变成个人知识库，发现深层关联

#### 核心功能
1. **人物档案深化**
   - 你已经有人物提取（10 个人物），需要深化
   - 每个人物的：互动时间线、情绪关联、高频话题、关系变化曲线
   - 人物关系网络：谁和谁经常一起出现、关系亲密度

2. **主题知识网络**
   - 自动识别核心主题：工作、家庭、成长、焦虑、运动、旅行...
   - 每个主题的：相关日记、时间分布、情绪关联、演变轨迹
   - 主题之间的关联：焦虑和工作的关系、运动和情绪的关系

3. **自动双向链接**
   - 借鉴 Personal-Knowledge-Wiki
   - 日记之间的自动关联（相似内容、相关人物、同一事件）
   - 查看一篇日记时，显示"相关日记"

4. **个人 Wiki**
   - 自动生成人物 Wiki、主题 Wiki、事件 Wiki
   - Wikipedia 风格：目录、反向链接、相关文章
   - 可以问："总结一下我和艳艳的关系变化"、"我对工作的态度演变"

#### 技术实现
- 知识图谱：NetworkX 或简单的邻接表
- 实体关联：基于共现分析 + 语义相似度
- Wiki 生成：LLM 自动编写 + 模板化
- 前端：新增"🕸️ 知识网络"Tab + 人物详情页增强

#### 预期效果
- 10 年日记变成结构化的个人知识库
- 发现人物关系、主题演变的深层模式
- 可以像查 Wikipedia 一样查自己的人生

---

### 🤖 第五阶段：AI 陪伴 + 自动评论（2 周）
**优先级：中** — 让日记有温度，AI 成为成长伙伴

#### 核心功能
1. **AI 自动评论**
   - 借鉴 memex：写新日记后，AI 角色自动评论
   - 像朋友一样回应：共情、提问、鼓励、不同视角
   - 可以选择 AI 角色性格：温暖朋友、理性分析师、严厉教练

2. **1v1 日记对话**
   - 和 AI 聊你的日记，AI 记得你的生活上下文
   - 可以倾诉、寻求建议、复盘事件
   - 长期记忆：跨对话记住重要信息

3. **AI 角色自定义**
   - 创建多个 AI 角色，不同性格和专长
   - 角色有长期记忆，和你一起成长
   - 可以导入角色卡（SillyTavern 兼容）

#### 技术实现
- 记忆系统：向量检索 + 摘要记忆
- 角色系统：System Prompt + 角色设定
- 自动评论：事件触发 + 异步生成
- 前端：日记详情页增加 AI 评论区 + "💬 AI 对话"Tab

#### 预期效果
- 写日记有回应，不再是单向输出
- AI 成为成长伙伴，提供支持和视角
- 记录更有动力，因为知道会有回应

---

### 📱 第六阶段：多端同步 + 移动端（2-3 周）
**优先级：低** — 随时随地记录，数据同步

#### 核心功能
1. **飞书/Telegram Bot 快速记录**
   - 借鉴 echolog：给 bot 发消息就是记录
   - 支持文字、图片、语音
   - 自动按发送时间归档

2. **PWA 移动端**
   - 现有桌面端改成响应式 PWA
   - 手机浏览器可以添加到桌面，像 App 一样用
   - 支持离线记录，联网后同步

3. **多端同步**
   - 本地优先，数据存在本机
   - 可选同步：WebDAV、Git、飞书云文档
   - 冲突自动合并

#### 技术实现
- Bot：飞书开放平台 / Telegram Bot API
- PWA：Service Worker + Manifest
- 同步：WebDAV 协议 / Git 仓库
- 前端：响应式布局 + 移动端优化

#### 预期效果
- 随时随地可以记录，不用开电脑
- 手机上也能查看和搜索日记
- 数据多端同步，不丢失

## 💰 资源需求

### API 成本估算
- **Embedding**：925 篇 × 平均 350 字 ≈ 32 万字，豆包 embedding 约 ¥0.5
- **RAG 问答**：每次约 ¥0.01-0.05，每天 10 次约 ¥100/月
- **月度反思**：每月 1 次，约 ¥1-5
- **AI 评论**：每篇日记约 ¥0.01-0.05

### 本地运行选项
- **Ollama**：完全免费，本地运行 Qwen3 / Llama3
- **whisper.cpp**：免费本地语音转录
- **SQLite-vss**：免费本地向量搜索

### 开发工作量
- 总计约 15 周（3-4 个月）
- 可以按优先级逐步实施，第一阶段完成后就能看到明显效果
- 每个阶段都是独立可交付的，可以随时暂停
