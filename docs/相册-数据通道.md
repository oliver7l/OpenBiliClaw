# 相册数据通道：快照 + 签名 URL

> 2026-09-18 建立。给宝贝成长册（云端 WorkBuddy 应用）提供相册数据，不把 5206 张照片搬到云端。

## 数据流向

```
8420 后端
├─ /album/thumbs/<name>?k=<HMAC>     ← 签名缩略图（实时取，HMAC 校验）
├─ /album/heic/<stem>.jpg?k=<HMAC>   ← 签名原图 heic 预览
├─ /album/full/<ym>/<name>?k=<HMAC>  ← 签名原图 jpg
└─ /public-album/public_index.json   ← 月度清单（公开，含预签名 URL）
                                       生成：scripts/build_album_public_index.py

云端应用（class-album-99010.app.workbuddy.host）
├─ fetch /public-album/public_index.json   1.6MB 一次
├─ 渲染月度 chips + 缩略图网格
└─ 点击缩略图 → 大图（_signed_full_url）
```

## 为什么这么走

三条候选路径拍板：

| 路径 | 代价 | 实时性 | 选用 |
|---|---|---|---|
| A. 快照清单 + 实时拉图（HMAC 签名） | 改 4 文件，零状态、零令牌 | 缩略图实时 / 清单快照 | ✅ |
| B. 实时 API + 应用令牌机制 | 改 6 文件，新增令牌生命周期 | ✅ 全实时 |  |
| C. 一次性迁移（已有工具） | 已就绪 | 否 |  |

A 路径的本质：**访问门槛由 HMAC 签名承担**——清单本身不含敏感内容（月度分组 + 文件名 + 拍摄时间），把签名嵌入 URL，云端拿着预签名 URL 直接 fetch 就能取图。这意味着：

- 清单**可公开**（路径不在 `_PROTECTED_STATIC_PREFIXES`）
- **真实访问门槛**在 `_album_media_ok`（路径必须以 `/album/{thumbs,heic,full}/` 开头 + HMAC 校验通过）
- 整体作废只需换 `session_secret`（HMAC 重派生 → 所有 URL 失效）

## 关键文件

```
src/openbiliclaw/api/_web_ui_routes.py   # mount /public-album → web/public_album/
src/openbiliclaw/api/auth.py            # _album_media_ok（HMAC 校验，路径限定三个媒体子路径）
src/openbiliclaw/auth_core.py           # album_media_token(secret) → 32 字符 HMAC
scripts/build_album_public_index.py     # 生成 public_index.json
云端应用/宝贝成长册-web/index.html       # viewAlbum 视图 + loadAlbum 函数
```

## 生成清单

```bash
.venv/bin/python scripts/build_album_public_index.py
# → src/openbiliclaw/web/public_album/public_index.json (1.6MB)
```

源库新增照片后重跑——所有 URL 用同一个 HMAC token 派生，旧 URL 仍有效（除非 session_secret 换）。

## 撤销/换密钥

编辑 `config.toml` 的 `[api.auth] session_secret`（重启后所有已分发的 URL 全部失效）。
