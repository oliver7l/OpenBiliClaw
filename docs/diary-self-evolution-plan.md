# 自进化日记系统优化计划

> 基于 GitHub 优秀项目（OpenGriffin、Dear Agent、Doppelganger AI、nightDiary、Lotti）的设计理念，将日记系统从"被动记录工具"升级为"主动学习、自我进化的 AI 伙伴"。

## 总体愿景

让日记系统不再只是一个存储你文字的地方，而是一个：
- **主动学习**：每天自动分析你的日记，理解你的变化
- **自我进化**：根据你的反馈和行为，持续优化分析策略
- **主动洞察**：在你提问之前，就发现值得关注的模式和变化
- **记忆分层**：像人脑一样，近期记忆详细，远期记忆精炼
- **人格一致**：理解你的性格、偏好、价值观，回应风格始终如一

## 第一阶段：🌙 夜间自我改进循环

### 目标
让日记系统每天凌晨自动运行，分析你昨天的日记，更新对你的理解，发现你的变化，并生成一篇可读的"夜间日志"记录它学到了什么。

### 借鉴来源
- **OpenGriffin**：夜间 4:30 AM 自我改进循环、漂移检测、可读的夜间日志
- **Dear Agent**：reflect 主动循环、模式发现

### 核心功能

#### 1. 用户画像自动构建与更新
- **画像维度**：
  - 性格特质（内向/外向、感性/理性、乐观/悲观等）
  - 偏好习惯（作息、饮食、运动、娱乐偏好）
  - 关注焦点（工作、家庭、健康、财务、学习等领域的关注度分布）
  - 人际关系（核心人物、关系亲密度、关系变化趋势）
  - 情绪基调（整体情绪倾向、情绪波动频率）
  - 价值观（从日记中提取的核心信念和人生态度）
- **更新机制**：
  - 每天夜间分析新日记，增量更新画像
  - 记录画像变化历史，可追溯"3个月前的你 vs 现在的你"
  - 画像变化超过阈值时触发漂移检测

#### 2. 漂移检测（Drift Detection）
- **检测类型**：
  - **行为漂移**："3个月前你说讨厌开会，今天你安排了5个"
  - **情绪漂移**："最近一周情绪明显偏低，过去一个月平均情绪分下降了0.3"
  - **关注漂移**："你对工作的关注度从40%上升到60%，家庭关注度下降"
  - **关系漂移**："你和艳艳的共现次数从每周5次降到每周2次"
  - **习惯漂移**："你过去每天都写日记，最近一周只写了2篇"
- **检测机制**：
  - 对比当前画像与历史画像（30天/90天/180天前）
  - 变化超过阈值时标记为漂移
  - 每个漂移都附带证据（具体的日记引用）
  - 漂移严重程度分级（提示/关注/警告）

#### 3. 夜间日志（Nightly Log）
- **日志内容**：
  - 📊 **今日摘要**：昨天日记的基本统计（篇数、字数、情绪、标签）
  - 🧠 **学到了什么**：从昨天日记中新学到的关于你的信息
  - 🔍 **发现的模式**：新发现的行为模式、情绪模式、关系模式
  - ⚠️ **漂移警报**：检测到的漂移及其证据
  - 💡 **系统建议**：基于分析给出的温和建议（不说教）
  - 🔧 **自我优化**：系统对自己的分析策略做了什么调整
- **可读性**：
  - 用自然语言写成，像一篇日记
  - 所有结论都附带证据（引用具体日记）
  - 可以在前端查看历史夜间日志
  - 支持手动触发夜间循环（不用等到凌晨）

#### 4. 自动标签优化
- **新标签发现**：从日记中发现高频但未被标记的概念
- **相似标签合并**：检测语义相似的标签，建议合并
- **标签层级构建**：自动构建标签的层级关系（如"工作"→"加班"→"项目A"）
- **标签使用统计**：跟踪标签使用频率变化，标记"过时标签"

### 技术实现

#### 后端模块
- 新建 `src/openbiliclaw/diary/self_evolution.py`
- 数据结构：
  - `UserProfile`：用户画像（性格、偏好、关注、关系、情绪、价值观）
  - `ProfileSnapshot`：画像快照（带时间戳，用于历史对比）
  - `DriftEvent`：漂移事件（类型、描述、证据、严重程度、检测时间）
  - `NightlyLog`：夜间日志（日期、摘要、学到的、模式、漂移、建议、自我优化）
  - `TagOptimization`：标签优化建议（新标签、合并建议、层级）
- 核心服务：`SelfEvolutionService`
  - `run_nightly_cycle()`：执行完整夜间循环
  - `update_user_profile()`：增量更新用户画像
  - `detect_drifts()`：漂移检测
  - `generate_nightly_log()`：生成夜间日志
  - `optimize_tags()`：标签优化
  - `get_user_profile()`：获取当前画像
  - `get_profile_history()`：获取画像历史
  - `get_drifts()`：获取漂移事件列表
  - `get_nightly_logs()`：获取夜间日志历史

#### 数据库表
- `diary_user_profiles`：用户画像表（当前画像 + 历史快照）
- `diary_drift_events`：漂移事件表
- `diary_nightly_logs`：夜间日志表
- `diary_tag_optimizations`：标签优化建议表

#### API 端点
- `GET /api/diary/self-evolution/profile`：获取当前用户画像
- `GET /api/diary/self-evolution/profile/history`：获取画像历史
- `GET /api/diary/self-evolution/drifts`：获取漂移事件列表
- `GET /api/diary/self-evolution/nightly-logs`：获取夜间日志列表
- `GET /api/diary/self-evolution/nightly-logs/{date}`：获取指定日期的夜间日志
- `POST /api/diary/self-evolution/run-nightly`：手动触发夜间循环
- `GET /api/diary/self-evolution/tag-optimizations`：获取标签优化建议

#### 前端页面
- 新增"🧬 自进化中心"主 Tab
- 子 Tab：
  - **👤 用户画像**：展示当前画像的各个维度，画像变化趋势图
  - **⚠️ 漂移检测**：漂移事件列表，按严重程度分类，每个漂移附带证据
  - **🌙 夜间日志**：夜间日志历史列表，可查看每天的夜间日志详情
  - **🏷️ 标签优化**：标签优化建议（新标签、合并建议、层级）
- 手动触发按钮："立即运行夜间循环"

#### 定时任务
- 支持配置夜间循环的执行时间（默认凌晨 4:30）
- 可以用 APScheduler 或系统 cron 触发
- 提供 CLI 命令：`openbiliclaw diary nightly-run`

## 技术原则

1. **本地优先**：所有分析在本地完成，数据不离开你的设备
2. **隐私保护**：用户画像、漂移检测等敏感数据加密存储
3. **可解释性**：所有结论都附带证据，不做无依据的判断
4. **温和不说教**：建议用温和的语气，不批评、不教育
5. **可追溯**：所有系统决策都记录在案，可以回溯
6. **渐进式**：每个阶段独立可用，不依赖后续阶段
7. **用户可控**：用户可以随时关闭任何自动功能，手动触发所有操作
