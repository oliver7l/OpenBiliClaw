## 3. 项目记忆

### 拆分模式（已验证，可直接复用）

```python
# 在 app.py 的 create_app 中：
from openbiliclaw.api.xxx_routes import register_xxx_routes
_exports = register_xxx_routes(app, ctx, ..., deps=deps)

# 在 *_routes.py 中：
def register_xxx_routes(app, ctx, *, deps) -> dict:
    # 闭包内定义路由函数
    @app.get("/api/xxx")
    def handler():
        ...
    return {"exported_func": func}
```

### 关键约束

- `app.py` 路由定义在 `create_app` 闭包内，拆分需通过参数传递闭包变量
- 路由函数名与原始版本一致即可，签名和逻辑不变
- 拆分后需对比路由完整性（已自动化脚本 `/tmp/route_audit.py`）
- 不删除 `app.py` 中的原函数定义，只搬移到新文件
- 数据库路径使用相对路径，禁止硬编码绝对路径

### 用户偏好

- 沟通语言：中文
- 代码风格：最小化修改，不引入不必要的抽象
- 拆分策略：按功能边界分批提取，每批验证后再继续
