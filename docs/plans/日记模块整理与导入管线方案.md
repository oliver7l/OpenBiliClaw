## 4. 可复用导入管线（期 1）

### 4.1 设计目标

- **可增量**：支持"上次导入之后的新笔记"，而不是每次全量重灌。
- **幂等**：重复运行不产生重复日记。
- **可 dry-run**：先看要导入多少篇，再决定落库。
- **来源可插拔**：新增来源只写一个 adapter，不动主流程。

### 4.2 目录与分层

```
src/openbiliclaw/diary/sources/          # 新增子包
├── __init__.py
├── base.py          # RawNote 数据类 + NoteSource 协议 + 去重键函数（纯逻辑，不碰 IO）
├── apple_notes.py   # 适配器：只读 SQLite（见 4.5）
├── youdao.py        # 适配器：Cookie + 浏览器自动化
├── wps.py           # 适配器：Cookie + 浏览器自动化
└── upsert.py        # 幂等落库：RawNote -> DiaryEntryCreate -> DiaryService
scripts/import_diary.py                   # 薄 CLI，参数解析 + 调 sources
```

分层纪律（借鉴 `references/apple-notes-cli`）：**解析层与 IO 层分离**，`base.py` / 各 adapter 的解析函数为纯函数，可直接单测。

### 4.3 统一接口

```python
@dataclass
class RawNote:
    title: str
    body: str            # 纯文本正文
    note_date: str | None  # ISO 日期，可空（由解析层推断）
    source: str          # apple_notes / youdao_note / wps_note
    raw_id: str          # 来源内唯一 ID，用于增量

class NoteSource(Protocol):
    def fetch(self, since: str | None = None) -> Iterator[RawNote]: ...
```

月度汇总拆分（苹果备忘录、有道云、WPS 都存在）抽象为共享工具：识别 `2022年06月07日` / `YYYY-MM-DD` 等分隔符，按日期切分并**合并同一天的多段**。

### 4.4 幂等与去重

沿用历史策略并显式固化：

- **去重键** = `fragment_date + 正文前 50 字`（历史 changelog v0.3.180 即用此规则）。
- 落库前查 `diary_entries` 同 `(entry_date, source, 正文前 50 字)`，命中则跳过。
- `--dry-run` 输出「将导入 N 篇 / 跳过 M 篇重复」且**不写库**。

### 4.5 关键决策：苹果备忘录走 SQLite 直读，不走 AppleScript

2026-09-06 的实现用 AppleScript 控制备忘录应用导出，本次**建议改方案**：

| | AppleScript（旧） | 只读 SQLite（建议） |
|---|---|---|
| 依赖 | 备忘录 App 需运行、需自动化权限 | 无，直接读 `NoteStore.sqlite` |
| 正文 | 导出 HTML 再清洗 | gzip + protobuf 解码（手写 varint，零第三方依赖） |
| 稳定性 | 受 UI 状态影响 | `mode=ro` 并发读安全，永远见最新提交 |
| 现成参考 | 无 | **`references/apple-notes-cli/` 完整源码已在仓库**，分析见 `references/AppleNotesCLI-借鉴分析.md` |

要点提醒（来自该分析）：**绝不用 `immutable=1`**（会跳过 WAL 静默给陈旧快照）；长操作先 `backup()` 拷稳定副本。

### 4.6 三个来源的可行性

| 来源 | 机制 | 自动化程度 | 前置条件 |
|---|---|---|---|
| 苹果备忘录 | 只读 SQLite | **可全自动 + 定时** | 无（仅本机磁盘读取权限） |
| 有道云笔记 | Cookie 注入 + 浏览器自动化 | 手动触发 | `YNOTE_PERS`/`YNOTE_SESS`/`YNOTE_CSTK` 有效 |
| WPS 笔记 | Cookie 注入 + 浏览器自动化 | 手动触发 | `wps_sid`/`kso_sid` 有效 |

> 有道云新版编辑器正文在 `bulb-editor` iframe 内，需从 iframe 提取；WPS 官方 V7 API 无云盘文件列表接口，只能走浏览器自动化。

### 4.7 CLI 形态

```bash
# 预览
python scripts/import_diary.py --source apple --folder "每日记录" --since 2026-09-01 --dry-run
# 落库
python scripts/import_diary.py --source apple --folder "每日记录" --since 2026-09-01 --apply
```

调度建议：苹果备忘录挂**每日定时自动化**；有道云 / WPS 保持手动，Cookie 失效时脚本给出明确报错与续期指引。

## 7. 风险与验证

| 风险 | 应对 |
|---|---|
| Apple Notes 库位于受保护目录，读取被拒 | 先做权限探测；失败则回退 AppleScript 方案 |
| 月度汇总拆分误判（旧记录曾出现 `202026年` 异常格式） | 保留日期格式修复逻辑；补单测覆盖 |
| 重复导入污染 928 篇现有数据 | 强制 `--dry-run` 先行；幂等键 + 事务 |
| Cookie 过期导致静默失败 | 显式报错 + 退出码非 0；绝不吞异常 |
| 服务在线时并发写 `data/diary.db` 锁冲突 | 导入脚本走短事务，必要时暂停写路径；参考 `bili_next_task` 锁忙等经验 |
