# 求职知识库 · 总索引（三层架构总入口）

> 最后更新：2026-09-05
> 体系：三层知识库 + 系统引擎 —— 底层=原始资料库(01)，中层=方向知识库(02)，上层=岗位弹药库(03)，系统层=_系统_知识库引擎(检索/数据/规范)
> 用途：面试前按"岗位→方向→原始资料"三级下钻，快速定位任何弹药
> 导航方式：每层都有 README 索引；全库检索用 `python3 _系统_知识库引擎/scripts/kb.py 查 <关键词>`（见系统层 README）

## 使用方法建议

1. **面试前 30 分钟**：读对应岗位 `03_速成包/预测题库` → 快速过 `02_面试备战资料/面试攻略`
2. **面试中卡壳**：按方向调 `02_方向知识库/` 的方法论弹药
3. **深挖项目**：进 `01_原始资料库/` 找原始工作文档解码，还原细节
4. **日常积累**：面试完补充复盘到对应岗位目录
5. **新岗位入职流程**：见 `03_岗位弹药库/README.md` 的"新建岗位流程"
