## 三、预测面试题 + 参考答案(数据科学岗定向)

### 3.1 因果推断(本岗重点,务必准备)
**Q1: 怎么衡量一个策略的真实效果?随机实验和观测数据怎么选?**
- 标准答:**AB 随机实验是黄金标准**(随机化消除混淆,因果识别干净);无法随机时(如客群层面、政策类干预)用观测因果——**双重差分 DID**(政策前后×处理/对照组)、**倾向得分匹配 PSM**(构造可比组)、**工具变量 IV**、**断点回归 RDD**、**合成控制**。
- 你的素材:中信做策略因果归因,优先 AB,客群层面用 DID/PSM 剥离混淆。
- 加分:点出「相关性≠因果, 取数分析师常踩的坑是把同期自然增长算成策略效果, 要用增量口径」。

**Q2: AB 实验显著性、peeking、CUPED?**
- 标准答:t 检验/置信区间判断;固定样本量避免 **peeking**(反复看 p 值 inflates 一类错误);**CUPED** 用预实验协变量降方差、缩样本量;注意新策略的辛普森悖论与长短期指标冲突。
- 你的素材:微视/OPPO 全量 AB 体系,关注页 +10.59% 是真实实验结论。

### 3.2 策略挖掘 / 客群
**Q3: 怎么做一个客群分层并设计差异化策略?**
- 标准答:明确业务目标→特征工程(行为/价值/风险)→分群(规则/聚类/模型)→每群诊断痛点→设计可量化策略→AB/观测验证。
- 你的素材:中信三期客群(目标/抢夺/竞品)分层 + 六大渠道漏斗 + 余额抢夺定价/额度矩阵,直接当范例讲。

**Q4: 渠道效能怎么分析、怎么定位低效环节?**
- 标准答:建全链路漏斗,分渠道算触达率/响应率/转化率,对比 benchmark 定位掉点环节,结合客户属性+活动节奏给渠道组合与触达频次建议。
- 你的素材:中信六大渠道漏斗,定位低效环节输出优化建议。

### 3.3 SQL / Python / 大数据(如实答)
**Q5: 给你一张用户行为表,写 SQL 算次日留存?**
- 准备:写出 `LEFT JOIN` 次日活跃 + `CASE WHEN` 标记留存 + 分组算率的写法;会问窗口函数(`ROW_NUMBER`/`LAG`)。
- 你的口径:日常用 SQL 取数 + Python(pandas/sklearn) 清洗建模;大数据量走 Hive/Spark。Spark 我做过 [具体程度待你确认],核心是会用 SQL 思维映射到分布式。

**Q6: 怎么处理样本不平衡 / 特征重要性?**
- 标准答:采样(过/欠)、加权损失、评估用 AUC/PR 而非准确率;特征重要性用树模型/SHAP,结合业务解释。
- 你的素材:微视排序正负 1:10 样本配比 + 交叉特征,百家号资源方模型用特征重要性+多模型融合。

### 3.4 用户生命周期 / 留存
**Q7: 怎么提升用户留存?全生命周期怎么建模?**
- 标准答:新用户激活(关键行为引导)→成长期(兴趣养成/内容匹配)→沉默召回(分层触达);用留存曲线/同期群(cohort)分析定位流失点,算法干预(个性化推荐/激励)。
- 你的素材:中信全生命周期客群经营 + 腾讯留存分析 + 微视重排的 E&E 与曝光降权(本质就是留存导向的干预)。

### 3.5 推荐系统理解(平台侧,差异化)
**Q8: 超大规模推荐系统怎么优化分发效率?**
- 标准答:召回多路(向量+CF+实时)→粗排双塔→精排深模型→重排(多样性+E&E+业务约束)→分层配额;用 eCPM/时长/留存多目标融合驱动。
- 你的素材:微视全链路 + OPPO 端云协同,直接讲生产经验。

**Q9: 为什么看字节?职业规划?**
