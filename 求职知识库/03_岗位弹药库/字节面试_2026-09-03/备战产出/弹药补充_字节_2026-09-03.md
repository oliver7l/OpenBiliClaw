## 弹药A｜腾讯QQ看点：关注行为→留存/时长的真实因果分析（★最强，用户侧因果实操）

- **钩子（主动抛）**：「我在腾讯做过一个真实因果分析——用户『关注账号』行为到底有没有真的提升留存和时长，我用双重差分 DID 验证增量，而不是只看相关性。」
- **数字（描述性对比，可直接甩）**：
  - 6/1 当天新增关注关系用户 **862,108 位**；
  - 关注后周活跃天数 **+21.2%**（4.57→5.54 天）；
  - 6 天留存率 **93.9%**，vs 当日总用户 84.5%、vs 从未关注用户 75% → 即 +9.4pp / +18.9pp；
  - 分维度：一线城市关注后日均时长 **+5.47%**（整体提升的 3.4 倍）；女性留存提升最高（约 +18pp）。
- **方法（被问「怎么做的」就答这个）**：
  - 构造 treat（6/1 有新增关注）/ control（同日有消费但未关注）两组；
  - 用 `statsmodels` OLS 跑 DID：`avg_duration ~ C(is_treat) + C(is_post) + C(is_treat):C(is_post)`，看**交互项系数是否显著**；
  - 分性别 / 年龄 / 城市级别做异质性分析。
- **最加分的点（诚实严谨，数据科学岗最爱）**：DID 验证后，关注对**时长提升不显著**（p 不显著）、对周日活天数提升也不显著——说明描述性对比看到的提升里混有自然增长。
  - **讲法**：「先讲描述性看有提升，再用 DID 交互项剥离混淆后我谨慎下结论——这正是数据科学该有的严谨。相关性≠因果，取数分析师常踩的坑就是把同期自然增长算成策略效果，我们用了 DID 验证真实增量。」
- **对接备战包**：原 Q1 因果题现在能甩这个真实案例，比中信框架实 10 倍。中信「因果归因」作业务背景，腾讯 DID 作方法证明。

## 弹药B｜QB大盘DAU六周下降拆解（指标异动归因经典框架）

- **钩子**：「核心指标掉了怎么分析？我用 QB 大盘 DAU 连续六周降 647 万的案例讲过完整框架。」
- **归因框架（被问「某指标下降怎么查」直接甩）**：
  1. 定义问题（6.15–7.26 线性下降，需拆业务原因、拿抓手）；
  2. 厘清事实（一年内三升三降，外生冲击=新发地疫情要完整看待，不能只怪策略）；
  3. 业务线拆解（大盘 / 资讯 / 文件 / 小说分别看降幅）；
  4. 量化归因（红点停投 ~200w、暑期文件下降 ~150w、push 消退 ~47w、用户活跃度流转 ~400w）；
  5. 建模定位关键因子（特征重要度）；
  6. 排除法（排除其他运营策略影响）；
  7. 给策略（可量化的 delta 预估 + 分群运营）。
- **数字（可甩）**：
  - 大盘 9057w→8410w（-647w，-7.7%）；小说降幅最深 -39.6%；
  - **特征重要度**：疫情前是高活用户的，留下来概率 63.1%；非高活用户仅 24%；首启主启比 <0.7 的高活用户 72.5% 流失。
- **策略落点**：桌面红点提频预计 +80w delta DAU；与 M15 合作做生命周期建模（成长期 / 衰退期分群拉动）。
- **价值**：这是面试官最高频的「指标异动归因」题的标准答案模板，展示结构化 + 量化 + 策略闭环。

## 弹药C｜QB用户分群模型（用户分群 / 生命周期建模方法论）

- **钩子**：「我做过分群模型，定位在千人一面和千人千面之间——既不像全局策略呆板，也不像个性化不可控，应用场景明确。」
- **方法**：K-means 聚类；特征 = 月活跃天数 + 主feeds 真实曝光次数 + 产品使用时长（选相关性偏弱但**业务含义充分、抓手明确**的）；抽样 94 万、分 64 组。
- **分群节点（可讲）**：节点1（月活5天 / 曝光5 / 30s）→ 节点2（15 / 10 / 120s）→ 节点3（25 / 30 / 300s），对应「逛 / 消费」梯度。
- **价值**：给「客群分层 / 用户生命周期建模」补一个工程案例，与中信分期客群三期分层（业务规则）互补——一个聚类方法、一个业务规则。

## 弹药D｜增长方法论（聊用户增长时的世界观弹药）

- 北极星指标按应用类型总结；**增长三板斧 = 红点 + push + 分享**（留存侧）；开源（拉新）+ 节流（留存）双轮。
- **Uplift Model（增益模型）**：阿里文娱智能营销增益模型——这是因果 ML 的工业实践，正好接「因果」话题（对谁发券有增量、对谁没增量）。
- 次留关键行为：信息流刷新 3 次以上留存显著增加 → 用交互设计引导关键行为（可讲「关键行为驱动留存」）。
- **价值**：聊「用户增长 / 留存」方向时有业界视野，不止自己那点事。

## 弹药E｜AB实验系统认知（工业背景，聊 peeking/CUPED 时撑得住）
