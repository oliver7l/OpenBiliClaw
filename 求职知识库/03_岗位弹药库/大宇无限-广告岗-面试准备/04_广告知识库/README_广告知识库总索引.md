## 高频考点 TOP（本知识库精华浓缩）

### 必背公式
- eCPM = bid × pCTR × pCVR × 1000
- oCPX 出价：bid = tCPA × pCTR × pCVR / (1+λ)
- LTV = p(付费) × E[金额]
- 贝叶斯平滑：pCTR = (点击 + α×先验CTR) / (曝光 + α)

### 必背框架
- 收入 = 请求量 × 填充率 × eCPM（下跌排查拆式）
- 漏斗：ADX询价→参竞→赢单→曝光→点击→到达→转化
- 指标体系四层：收入/效率/体验/健康
- OPPO 三步法：趋势 + 公式拆解 + 维度下钻

### 必背话术
- 为什么转数据分析：决定业务上限的不是模型，是问题定义/指标拆解/策略评估（主动选择，不是能力问题）
- 银行vs广告异同：方法论同构（人群分层→出价→转化→归因），广告多了竞价/计费/校准层
- 跳槽多：主线一直"数据+策略"，每一段都有完整产出，不是容易"待不住"的人
- 组织架构调整：不说"受影响"，说"方向变了"
