# 广告核心概念与机制（RTB / 竞价 / oCPX 全套）

> 来源：程序化广告学习笔记（436页PPT）+ 计算广告第3版
> 用途：广告算法面试"核心概念"题，可直接背诵。按最高频考点组织。

---

## 一、RTB（实时竞价）是什么

**一句话：** 每次用户曝光机会出现时，广告系统在约 100ms 内完成一次"拍卖"：多个广告主（通过 DSP）实时出价，价高者（按 eCPM）获得这次展示机会。

- 与传统广告"包段/排期"（固定价格，不管谁看到）不同，RTB 按每次曝光单独定价、单独竞价
- 能把流量卖给"最想要它的人"，提升媒体收入和广告主 ROI

**参与角色（必背）：**
| 角色 | 全称 | 干什么 |
|---|---|---|
| 广告主/代理商 | Advertiser/Agency | 出钱买量，设预算和目标（CPA/ROI） |
| DSP | Demand-Side Platform | 代表广告主参与竞价：人群定向、估价、出价、预算控制 |
| AdX | Ad Exchange | 广告交易所：撮合买卖双方，组织竞价 |
| SSP | Supply-Side Platform | 代表媒体管理流量：接多家AdX/DSP、设底价、优化填充和收益 |
| 媒体 | Publisher | 提供广告位（app、网站、应用商店等） |
| DMP/CDP | Data Platform | 提供用户画像、标签、设备数据，支持定向和估价 |
| TD | Trading Desk | 代理商/广告主操作台，通过API调用多家DSP统一管理投放 |

## 二、一次 RTB 请求的完整流程（100ms 内，必背）

1. 用户打开 app/页面
2. 媒体/SSP 产生一次广告请求（携带：广告位信息、设备ID、用户ID、上下文）
3. AdX 向各 DSP 发送 Bid Request（广播）
4. DSP 内部处理（通常 <50ms）：
   - 定向过滤（人群、地域、频次、预算是否还有）
   - 取用户特征/画像
   - 模型预估 pCTR / pCVR
   - 计算出价 bid（结合目标CPA、预算pacing、ROI约束）
   - 返回 bid + 创意
   - **超时严格 100ms，超时没返回直接判弃权**
5. AdX 排序：按 **eCPM = bid × pCTR（×pCVR）** 排序，执行竞价机制（一价/二价）
6. 胜出者下发创意 → 展示 → 点击/转化 → 计费、归因、回流数据

**关键点：** 整个过程是 per-impression 的实时决策，对延迟、特征实时性、模型推理效率要求极高（可挂钩端云协同、模型压缩经验）。

## 三、竞价机制：一价 vs 二价（必背）

### 1. 二价（Second Price / VCG / GSP）
- 最高价者赢，但支付第二高价（或第二高价+0.01）
- **重要性质：真实出价是占优策略（Vickrey定理）**——你出多少只影响"赢不赢"，不影响"付多少"，最优就是按真实价值 v 出价
- 多坑位场景用 GSP（广义二价）：第 k 名支付第 k+1 名的价格

### 2. 一价（First Price）
- 赢家按自己的出价支付
- 真实出价不再最优：出太高会"赢者诅咒"，于是出现 **bid shading（出价压价）**：根据对"竞得价分布"的估计，把出价压到"赢的概率×盈余"最优的点
- 近年行业（尤其 header bidding 后）普遍转向一价，所以 shading 是 DSP 的标配能力

### 3. 面试常问
- **Q：二价下最优出价是什么？** → 按真实价值 v 出价（truthful bidding）
- **Q：一价下怎么出？** → 建模赢率曲线 w(b)，最大化期望盈余 E[(v-b)·w(b)]，或用历史竞得价分布做 shading
- **Q：第一价 vs 第二价对平台收入影响？** → 一价收入更稳但需 shading 博弈；二价有 bid shading 导致平台收入下降（Google AdX 2019 改一价）

## 四、Header Bidding（扩展，加分）

- Header Bidding 是 RTB 的一种实现方式：在媒体页面 Head 中嵌入 JS 代码，同时向多个 ADX/DSP **并发**发起竞价
- 与传统"瀑布流（Waterfall）"对比：瀑布流是**顺序请求**（先问高价再问低价）；Header Bidding 是**并发请求**
- 好处：并发让所有 DSP 有公平竞争机会，媒体收入更高（通常提升 10-30%）
- 常见实现：Prebid.js

## 五、oCPX（智能出价）全套——最高频考点

### 1. 什么是 oCPX
- 广告主给**目标转化成本**（tCPA 或 ROAS），平台**自动出价**
- 本质：媒体侧替广告主做"自动出价（auto-bidding）"，数学和 DSP 出价完全一样

### 2. 核心公式（必背）
```
bid = tCPA × pCTR × pCVR / (1+λ)
```
- **tCPA**：广告主愿意为一个转化付的钱（"一个激活值20块"）
- **pCTR**：曝光→点击概率
- **pCVR**：点击→转化概率
- **pCTR×pCVR**：这次曝光最终带来转化的概率（把"转化"稀疏事件折算到每次曝光上）
- **tCPA×pCTR×pCVR**：这次曝光的**期望价值**（出价理论上限）
- **1/(1+λ)**：成本控制折扣系数，λ越大出价越保守

### 3. 为什么 ÷(1+λ)？（公式的精髓）
- **λ 是约束优化里的拉格朗日乘子**，代表"预算/成本约束的紧张程度"
- 优化目标：在"实际成本 ≤ tCPA"和"预算 B 花完"的约束下，最大化总转化
- 求解后，最优出价 = 期望价值 ÷ (1+λ)
- **λ 的直觉（节流阀）**：
  - λ=0：约束不紧（钱花不出去）→ 按全价值出价，放量
  - λ变大：约束变紧（成本超标/预算快花完）→ 所有出价等比压低，只赢便宜且优质的流量
  - λ很大：严重超标 → 出价趋近 0，几乎不参竞
- **为什么是"除"（等比缩放）而不是"减"？** 因为等比缩放**不改变流量优劣排序**（所有曝光的出价乘同一系数，系统仍优先买高价值流量），只是整体买得更少/更便宜，压成本不牺牲流量质量

### 4. λ 怎么调？（在线反馈）
- λ 不是拍脑袋的，按 campaign **实时（分钟级）用 PID 反馈调节**：
  - 实际 CPA > tCPA → 调大 λ → 出价降 → 成本回落
  - 实际 CPA < tCPA 且预算花不出去 → 调小 λ → 出价升 → 放量
- **整个 oCPX 是闭环**：预估 → 出价 → 竞得 → 成本回流 → 调 λ → 再出价

### 5. 面试口述版（30秒背下来）
> "这个公式本质是'按价值出价、按约束控制'。tCPA×pCTR×pCVR 是这次曝光的期望价值：pCTR×pCVR 是曝光到转化的概率，乘上广告主愿意为一个转化付的 tCPA，就是这次曝光值多少钱，也就是出价的理论上限。除以 (1+λ) 是成本控制：λ 是预算和成本约束的拉格朗日乘子，线上用实际成本和目标的偏差做 PID 反馈调节——成本超标就调大 λ 压出价，放量不足就调小 λ。所以这个公式把'价值预估'和'成本控制'统一在一个表达式里。这也解释了为什么 pCTR/pCVR 必须校准：出价直接乘预估值，预估偏高就会高价买低质流量，成本直接失控。"

### 6. oCPC / oCPM 区别（连环追问）
- **oCPC**（优化点击成本）：按点击计费，点击出价 = tCPA×pCVR/(1+λ)，排序时再乘 pCTR。百度 oCPC 分两阶段：第一阶段普通 CPC 出价积累 30+ 转化；第二阶段模型训练好自动调价
- **oCPM**（优化千次展示成本）：按曝光计费，直接 bid = tCPA×pCTR×pCVR/(1+λ)

### 7. pCVR 高估会怎样？（追问）
- bid 偏高 → 高价赢下低转化流量 → 成本超标；λ 会被迫调大压制，但**治本要靠校准**

## 六、RTB vs oCPX（面试高频，区分维度）

**二者不属于同一维度概念，不能直接比谁更先进。**

- **RTB**：是一套**流量交易/拍卖机制**。每次曝光发生时，多个外部 DSP 收到询价，DSP 在外部自己完成全部人群判断、eCPM 预估、出价，返回给 ADX 拍卖。核心：**需求方（DSP）自己做 CTR/CVR 预估**
- **oCPX**：是一套**智能出价优化策略**，跑在媒体/平台内部竞价体系里。广告主只填转化目标成本，**供给方（媒体平台）替广告主做 CTR/CVR 预估**，自动算 eCPM 参与内部竞价，计费和优化目标解耦

**面试可这样讲：** "oCPX 可以理解为平台内置了一个 DSP：它做 pCTR/pCVR 预估、出价、pacing 和成本控制，只不过竞价发生在平台内部排序（eCPM 排序）里。"

## 七、广告归因（Attribution）

常见模型：
- 最后点击归因（Last Click）：最常用，忽略前期渠道贡献
- 首次点击归因（First Click）：强调拉新渠道
- 线性归因：所有接触点均分
- 时间衰减归因：越靠近转化的接触点权重越高
- **数据驱动归因（Shapley Value）**：基于博弈论，算每个渠道边际贡献（加分项，和特征重要度同一套逻辑）

---

## 八、广告定向（Targeting）

- 上下文定向（Contextual）：按页面内容匹配
- 用户画像定向（Demographic）：年龄/性别/地域
- 行为定向（Behavioral）：浏览/搜索/购买历史
- 重定向（Retargeting）：对访问过广告主网站的用户再投放
- 相似人群扩展（Look-alike）：以种子用户扩展相似人群
- 自动定向（Auto Targeting）：算法自动学最优定向组合

---

## 九、程序化广告谱系（补全概念）

- **PDB（Programmatic Direct Buy）**：程序化直接购买，提前锁定优质流量，不走公开竞价（RTB是公开竞价，PDB是保量优先）
- **RTB vs PDB 核心区别**：RTB 每次曝光公开竞价、价高者得；PDB 是媒体与广告主事先约定价格/量，可退量
