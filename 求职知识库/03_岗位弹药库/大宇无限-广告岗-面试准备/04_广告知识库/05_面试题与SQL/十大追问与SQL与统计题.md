## 一、10 个面试级追问（广告岗检验题，每题都要能答）

1. **RTB 一次竞价的完整流程是什么？从用户打开页面到看到广告，经过哪些角色？** → 见《RTB与竞价与oCPX机制》第二节
2. **RTB 和 PDB 的核心区别？各自适合什么场景？** → RTB 公开竞价每次曝光实时出价；PDB 程序化直接购买提前锁定优质流量、保量可退量。RTB 适合长尾/弹性预算，PDB 适合品牌保量
3. **为什么 RTB 用第二价格拍卖而不是第一价格？** → 二价真实出价占优，出价成本低、博弈少；一价需 bid shading（见机制文档）
4. **DSP 出价时除了预估还要考虑什么？（至少3个）** → 预算剩余（pacing）、频次控制、广告主 ROI/成本约束、竞价环境（市价波动）、冷启动探索
5. **Pacing 是什么？为什么需要？pacing 系数怎么算？** → 预算随时间均匀花，避免早花完/晚花不完；pacing 系数 = 预算消耗节奏控制，常用剩余预算/剩余时间 结合 市价预测
6. **OCPX 的出价公式是什么？和 CPC 出价有什么区别？** → 见机制文档第五节
7. **填充率下降可能有哪些原因？（至少3个）** → 见《指标体系与AB实验与收入归因》漏斗表：参竞减少、出价/底价不匹配、定向收紧、人群包过期、创意审核不过
8. **Header Bidding 和传统瀑布流的区别？各自优劣？** → 并发 vs 顺序；并发公平收入高，瀑布流实现简单但低效
9. **重定向为什么转化率高？对延迟反馈有什么影响？** → 重定向用户已知晓品牌/访问过，意向强转化高；对延迟反馈：重定向会"回收"延迟转化的功劳，影响归因公平
10. **你在 OPPO 做的"分发排序"和广告的"eCPM 竞价排序"有什么异同？（面试串联题）** → 异：分发排序是平台内部对自有内容排序，无竞价、无计费；广告 eCPM 排序有出价、有预算、有竞价博弈。同：都是"把有限流量分给预估价值最高的对象"，排序依据都是预估价值（分发=ARPU/LTV，广告=eCPM=bid×pCTR×pCVR），都要校准预估

## 二、DSP 出价策略详解（题3 展开）

> "分两种情况：
> 没有预算约束时，DSP 精准估算每次展示的 eCPM，按 eCPM 出价即可。因为 ADX 用 GSP 二价计费，按真实价值出价是最优策略，有利润空间。
> 有预算约束时，这才是实际工作中的常态，策略完全不同。核心洞察是：广告市场价在一天内波动非常剧烈——凌晨可能只要 20 元 CPM，晚高峰可能要 80 元。如果不管什么时候都按 eCPM 出价，预算会在低价时段就花完，高价时段买不到，整体性价比很低。
> 所以正确的做法是：预测 eCPM 和市场价两条随时间变化的曲线，把预算集中分配到 eCPM/市价比值最大的流量上。简单说就是专挑'价值高但便宜'的流量买，同样预算能买到更多有效展示。
> 实践中时间维度最关键，其他维度（性别、地域等）影响相对小。"

## 三、SQL 速刷题单（广告/数据方向高频）

### 题1：7日留存率（LEFT JOIN）
```sql
-- 假设有活跃表：user_id, active_date
-- 求新用户第1天和第7天的留存
SELECT a.date AS 注册日,
       COUNT(DISTINCT a.user_id) AS 新增用户,
       COUNT(DISTINCT b.user_id) AS 第7天活跃
FROM 用户表 a
LEFT JOIN 活跃表 b
  ON a.user_id = b.user_id
 AND b.active_date = DATE_ADD(a.date, INTERVAL 6 DAY)
WHERE a.date BETWEEN '2026-01-01' AND '2026-01-24'
GROUP BY a.date;
```

### 题2：分组 Top N（ROW_NUMBER）
```sql
-- 每个广告主支出最高的3个计划
SELECT ad_id, plan_id, cost, rn
FROM (
  SELECT ad_id, plan_id, cost,
         ROW_NUMBER() OVER (PARTITION BY ad_id ORDER BY cost DESC) AS rn
  FROM 投放表
) t
WHERE rn <= 3;
```

### 题3：连续7天活跃（gap-and-island）
```sql
SELECT user_id
FROM (
  SELECT user_id, active_date,
         DATE_SUB(active_date, INTERVAL ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY active_date) DAY) AS grp
  FROM 活跃表
) t
GROUP BY user_id, grp
HAVING COUNT(*) >= 7;
```

### 题4：广告点击转化漏斗
```sql
SELECT date,
       SUM(impression) AS 曝光,
       SUM(click) AS 点击,
       SUM(conversion) AS 转化,
       ROUND(SUM(click)/SUM(impression), 4) AS ctr,
       ROUND(SUM(conversion)/SUM(click), 4) AS cvr
FROM 广告日报
WHERE date >= '2026-09-01'
GROUP BY date;
```

## 四、统计题速刷

### 1. 怎么判断 A/B 实验显著？
- 看 p 值（<0.05）和置信区间（不跨 0）
- 提前用功效分析定样本量，跑完再看，避免 peeking
- 同时看护栏指标

### 2. 最小样本量怎么估算？
- 四要素：基线转化率、MDE（最小可检测效应）、α=0.05、1-β=0.8
- 公式思路：n ≈ (z_α/2 + z_β)² × 2p(1-p) / δ²
- 效应越小、基线方差越大，需要样本越多

### 3. 辛普森悖论？
- 分组看都是 A 好，合并后 B 好——因分组权重不同
- 处理：分层看 + 看结构变化
- 广告案例：每行业 CTR 都提升，合并后下降，因流量往低 CTR 行业倾斜

### 4. p 值 vs 置信区间？
- p 值：在原假设下看到当前结果（或更极端）的概率，p<0.05 拒绝原假设
- 置信区间：参数真实值的区间估计，包含效应大小信息，比 p 值信息量更大

### 5. 数据泄露/穿越怎么防？
- 时间切分（训练集时间早于测试集）
- 不用未来信息做特征（如当天标签预测当天行为）
- 特征工程排除标签泄漏源（如用转化率做特征时要滞后）

## 五、归因与增量（加分题）

### 增量归因 vs 末次归因
- 末次点击归因：把转化功劳全给最后一次点击渠道，简单但低估了前期贡献，高估了渠道"边际"价值
- 增量归因（增量实验/Shapley）：算每个渠道的边际贡献。可用：地理实验、同期对照组、因果推断（PSM/DID/断点）
- 面试话术："归因最大的坑是'看起来有效不等于有增量'。比如重定向转化率高，但它只是把本来就会来的用户提前回收了。要看增量，得和'不投放这些用户'的对照比，这才是数据驱动归因。"
