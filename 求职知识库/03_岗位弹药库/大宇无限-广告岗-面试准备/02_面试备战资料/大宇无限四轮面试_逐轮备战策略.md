# 大宇无限 · 四轮面试 逐轮备战策略

> 生成：2026-09-04（HR面已完成，确认四轮流程）
> 流程：**广告负责人面 → 广告专业技术面 → 整体技术负责人面 → CEO面**
> 核心观点：**同一份弹药，四轮讲法完全不同**。负责人看业务、专业面看公式、技术负责人看架构、CEO看人和动机。本文档教你每轮怎么调"讲法"。
> 素材复用：预测题库（`03_速成包/`）+ 项目话术（`02_面试备战资料/`）+ 广告知识库（`04_广告知识库/`）+ 主打项目弹药（`02_方向知识库/推荐系统/09_微视账号推荐与看点图集项目弹药.md`）

## 〇、四轮总览（先看全局）

| 轮次 | 面试官 | 在筛什么 | 你的主武器 | 失败原因TOP1 |
|---|---|---|---|---|
| **1 广告负责人面** | 广告业务线负责人 | 懂不懂广告生意、项目真不真、能不能共事 | 业务结果 + 项目故事 | 只讲技术不讲业务价值 |
| **2 广告专业技术面** | 资深算法/技术专家 | 技术深度、公式级理解、手撕能力 | OPPO项目细节 + 八股 + 手撕 | 只会背概念，答不到落地细节 |
| **3 整体技术负责人面** | 技术总监/CTO | 技术视野、架构、工程、影响力 | 系统架构 + 微视全链路 + 技术判断 | 只讲单点不讲系统 |
| **4 CEO面** | CEO/创始人 | 人靠不靠谱、动机、稳定性、格局 | 动机叙事 + 文化契合 + 薪资 | 急于谈钱 / 态度不确定 |

**节奏预判**：第1-2轮可能连排（当天/隔天），第3轮隔几天，第4轮终面。每轮之间主动向HR确认下一轮面试官背景，定向准备。

## 一、第 1 轮 · 广告负责人面（业务视角）

### 这一轮在筛什么
广告负责人最关心：**你能不能直接上手帮我把广告业务做好**。他不逐条考公式，而是：
1. 你懂不懂"广告是一门生意"（流量→变现→ROAS闭环）
2. 你的项目是不是真做过、结果是不是真的
3. 你能不能和他（以及产品/运营）协作

### 怎么讲项目（调"业务"挡位）
- **OPPO 项目**：重点讲"为什么做、做了什么选择、业务结果"——多位置校准为了 ARPU+1.04%（收入），oCPX 为了广告主 ROAS+8%（商业化），冷启动为了新广告曝光+30%（供给丰富度）。**每件事都要落到钱/供给/效率上。**
- **微视账号推荐**：重点讲"推人场景如何带动关注→消费→留存"，日均关注量级、关注页 pCTR +10.59%（体现系统能力）。
- **中信客群**：13项策略、余额抢夺3.8亿/月——展示"策略从0到1落地、对业务指标负责"的能力（负责人很吃这套）。

### 高频题 + 应对
| 问题 | 应对要点 |
|---|---|
| 介绍下你做过的广告项目 | 讲 OPPO 八阶段（预估→校准→oCPX→冷启动→端云→多模态），每段带业务数字，别停在概念 |
| 你怎么理解大宇/Bridge Mile 的商业模式 | 自有流量（Lark Player/SnapTube）→ 广告平台 → 全球变现；eCPM 能闭环验证、再营销全球第五；**把"你的经验如何搬过来"讲清楚** |
| 出海广告和国内有什么不同 | 多语言/多地区/多文化/弱网/支付差异；我在百度做过国际化应用商店、OPPO做过全球商店，有直接经验 |
| 你怎么和产品/运营配合 | 用"问题→数据→方案→上线→复盘"的闭环讲协作；举一个真实跨团队案例（如冷启动扶持和运营的配合） |
| 你最大的优势是什么 | "10年'分发+变现'全链路 + 做过生意指标（ARPU/ROAS/成本）" |

### 反问（负责人轮适合问业务）
- "Bridge Mile 现在变现主力是哪块？主要靠哪些国家/市场？"
- "这个岗位进来，前3个月最想解决哪个问题？"

## 二、第 2 轮 · 广告专业技术面（公式视角）

### 这一轮在筛什么
**技术深度**。面试官会顺着你简历逐点往下钻，直到你答不上或答到真实边界。重点验证：八股不背、公式能推、代码能写、项目有真实细节。

### 怎么讲项目（调"技术"挡位）
- **OPPO oCPX 公式级**：`bid = tCPA × pCTR × pCVR / (1+λ)`；λ 用 PID 每30分钟调；`÷(1+λ)` 等比缩放不改变流量排序只整体压缩；10% 探索池；贝叶斯平滑做先验；渐进退出。
- **多位置校准**：成因（位置注意力/竞争环境差异）→ 做法（分位置 PCOC 比值校准/保序回归）→ 结果（30%→20%）。
- **腾讯 ESMM/MMoE**：ESMM 解决样本选择偏差+稀疏（曝光空间 pCTCVR=pCTR×pCVR，共享embedding）；MMoE 解决任务冲突（专家+门控软共享）。**广告里 CTR/CVR 样本空间不同是 ESMM 典型场景。**
- **手撕**：预估 SQL（双11留存、漏斗）、统计（t检验/A-B）、算法题（LeetCode 318 已复盘）。

### 高频八股清单（答案都在题库，直接背）
oCPX 公式与λ / RTB一价二价 / 冷启动三层 / 延迟转化两阶段 / 对比学习正样本构造 / 端云架构 / ESMM-MMoE 本质 / LTV / 多模态融合（CNN+BERT+Cross-Attention）/ DSSM 双塔召回 / 图Embedding(P/Q参数)

### 加分动作
- 主动讲"你踩过的坑"（如冷启动样本不足别过早下结论）——证明真做过
- 把微视账号推荐的"转粉能力建模、已关注过滤、作者退场机制"等工程细节抛出来——证明不是背的

## 三、第 3 轮 · 整体技术负责人面（架构视角）

### 这一轮在筛什么
技术总监看**系统的广度 + 你的技术判断力**：你能否站在架构层想问题、能否独立带方向、是否有技术影响力。不纠结单点公式，考"你怎么把一个系统搭起来并持续演进"。

### 怎么讲项目（调"架构"挡位）
- **微视账号推荐全链路**（推荐主心骨，本轮最值钱）：四路召回（作者追打/用户兴趣/热门/爱互动）→ 过滤（已关注/退场）→ 混排 → 特征体系；召回策略命名规范、配置化、中台评审。**讲"系统如何分层、如何扩展、如何服务多个场景"。**
- **看点图集多目标**：ESMM→MMoE→多目标下沉召回→无量3.0全量（BG第一个），讲"多目标如何在精排/召回/平台三层演进"。
- **OPPO 端云协同**：云训练/端推理/端云联合，讲"成本与实时性的架构权衡"。

### 技术判断力题（本轮特色）
- "如果让你从0搭一个广告系统，怎么设计？"→ 分层讲：数据（事件/特征）→ 模型（CTR/CVR/LTV）→ 出价（oCPX）→ 竞价（RTB）→ 冷启动 → 实验评估闭环
- "LLM 对广告/推荐的影响？"→ 两个层面：内容理解/特征抽取的上游 + 生成式交互重构（用 `10_技术前沿弹药`）
- "怎么评估一个新模型该不该上线？"→ 离线指标+AB+业务指标三层，讲置信度、长周期指标
- "你带过团队/做过技术影响力吗？"→ 开源组件（Recommendation_System 被腾讯网/全民K歌借鉴）、PCG代码委员会Python分会、5篇KM沉淀、品类训练pipeline

### 反问（技术负责人轮适合问架构/方向）
- "广告平台当前的模型/工程架构是自研还是 SaaS？后续技术路线怎么走？"
- "团队在 CTR/CVR 之外，下一个重点投入方向是什么？"

## 四、第 4 轮 · CEO面（人与动机）

### 这一轮在筛什么
CEO 看**人**，不考技术。三件事：① 这个人靠不靠谱、稳不稳定；② 他为什么来、会不会待住；③ 薪资能不能定下来、气场合不合。**CEO 面是"加分轮"，过了前面三轮，这轮别自己掉链子。**

### 核心话术（复用 HR 面话术，但升级到"格局"）
| 问题 | 应对 |
|---|---|
| 为什么从银行/为什么要走 | "能力补齐了回主线"（别贬低银行）；强调广告商业化是"分发+变现"主线的回归 |
| 跳槽多，能待住吗 | 主线一致 + 每段有产出 + "这次奔着长期来，广告是我想深耕的方向" |
| 为什么是我们 | 研究过：自有流量闭环变现 + 出海新兴市场 + 再营销全球第五；"我要的不是再跳一次，是把广告这件事做深" |
| 你3-5年规划 | "在广告变现方向做深做扎实，跟公司一起把 Bridge Mile 的变现效率做到行业头部" |
| 你期望薪资 | 区间中上（48-52K），强调更看重平台和做出成绩，package 合适可谈（别把价谈死） |

### CEO 轮加分动作
- 聊格局：出海广告是"中国互联网能力输出"，你懂海外市场（百度/OPPO 国际化经验）
- 聊稳定性：明确表达"这次要长期" + 到岗时间（在职交接1个月，可协调压缩）
- 气场：从容、不卑不亢、不急于求成；CEO 喜欢你"目标清晰、情绪稳定"

### CEO 轮别踩
- 别一上来谈钱 / 别谈太死
- 别表现出"手里很多 offer 在选"
- 别吐槽前公司
- 别显得犹豫（"再考虑考虑"）——CEO 面要的是确定感

## 五、面试全程排期建议

1. **向 HR 确认**：四轮大致时间间隔、每轮面试官角色与方向（第1轮负责人背景、第3轮技术总监背景），定向准备。
2. **每轮前一天**：`python3 _系统_知识库引擎/scripts/kb.py 速记 大宇` 出速记卡 + 读本轮的"挡位"要点。
3. **每轮结束当晚**：更新 `_系统_知识库引擎/数据/04_面试日志.csv` + 岗位目录复盘，把被问的新题补进题库。
4. **同一个项目，每轮换个挡位讲**：1业务→2公式→3架构→4动机。

## 六、一句话总结每轮

- **第1轮**：别讲公式，讲"我做的每件事都变成了钱/供给/效率"
- **第2轮**：别只背概念，公式能推、坑能讲、代码能写
- **第3轮**：别讲单点，讲"系统怎么分层、怎么演进、我怎么影响团队"
- **第4轮**：别谈细节，谈"人靠谱、动机纯、奔着长期来、薪资能定"
