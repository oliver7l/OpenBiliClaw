### 2.2 离线预测模拟 — xgb_predict_add_playcnt（加入视频播放量特征）

**文件清单**：compare.ipynb、model_new/xgb_feamap、xgb、query_result/（12个xlsx）

**讲了什么**
在基线XGB模型基础上，新增视频播放量（play_cnt）特征的迭代版本。
- **play_cnt特征工程**：从搜索结果layout_content中解析，fontType='E'的行包含"xx万播放"/"xx亿播放"文本，正则提取并换算为整数（万×10000，亿×100000000）。仅对group_mask 2008（视频）和1033（小视频）有效。
- **模型对比**：旧模型（ml_value）vs 新模型（ml_value_new，含play_cnt），对比同一query下各结果的排名变化。
- **视频品类加权策略实验**：
  - `final_score_by_formula` = ml_value × 0.5 + clk_rate × 0.5（基础融合分）
  - `merge_video_score`：视频组内取最高分，统一赋给组内所有视频（视频组内去重/提权）
  - `mul_1_5`：对视频/小视频的融合分×1.5（品类加权提权）
  - 对比四种策略下的排名：基础排名、merge后排名、新模型merge后排名、新模型×1.5后排名
- **示例结果**（query=周杰伦/易烊千玺等）：视频内容在×1.5策略下排名从第6-10名提升到第2-3名。

**与今日头条面试相关性**：高。视频播放量是内容侧核心信号，品类加权是推荐/搜索混排的常见策略。这个迭代体现了"发现信号→特征工程→AB策略→排名验证"的完整数据科学闭环。

**价值评级**：高

**可提炼的面试点**：
- 从非结构化UI字段（layout_content）中挖掘新特征的工程能力
- 视频品类加权策略的设计与离线排名验证
- 模型迭代的A/B对比方法论（旧模型vs新模型在同一query上的排名变化）

### 2.6 compare/compare.ipynb — 实体映射与实体加权重排序

**讲了什么**
搜索结果重排序实验，以query="优图"为例。
- **数据解析**：从搜索API返回的item_groups中解析各品类（视频、小视频、看点）的result_items，提取final_score、neo_score（实体分）等字段。
- **实体加权公式**：`neo_score_ratio = neo_score / 5 * 0.5 + 1`，对有实体匹配的结果，用该ratio乘以原始分数进行提权。neo_score/5归一化到[0,1]，×0.5+1映射到[1, 1.5]区间。
- **重排序**：按加权后分数重新排名，对比原始排名与实体加权后排名的变化。
- 这是搜索混排中**实体理解（Entity Understanding）**的直接应用——识别query中的实体，对匹配实体的内容提权。

**与今日头条面试相关性**：高。实体映射是搜索/推荐的核心技术，今日头条的内容侧（话题聚类、热点挖掘）大量依赖实体识别。实体加权重排序是可直接落地的策略。

**价值评级**：高

**可提炼的面试点**：
- 实体识别→实体匹配→实体加权重排序的完整链路
- 加权公式的设计思路（归一化→映射到提权区间→避免过度提权）
- 实体理解在搜索混排中的价值

### 3.2 v2/ — 深度学习CTR模型

**文件清单**：01_data_process_for_tensorflow.ipynb、01_data_process.ipynb、02_tensorflow_train.ipynb、02_keras_train.ipynb

**讲了什么**

**02_keras_train.ipynb — Wide&Deep风格CTR模型**：
- **数据规模**：训练集1,428,398样本，测试集204,754样本。
- **特征**：
  - 4个类别embedding：city（vocab 351, embed 100）、entity（vocab 67, embed 20）、gender（vocab 5, embed 2）、province（vocab 32, embed 10）
  - 4个wide数值特征（直接拼接）
- **模型结构**：
  - Embedding层 → Flatten → Concatenate(132维) → BatchNormalization → Dense(30, relu, L2正则0.01)
  - 与wide特征Concatenate(34维) → Dense(1, sigmoid)

**讲了什么**

**时效性分析报告.pdf（核心产出）**：
- **背景/现象**：看点热词搜索结果中存在几天前的旧文章，预期热词搜索应返回新发布文章。
- **分析思路**：获取文章doc_age（now - publish_time）+ 用户点击率，分析不同doc_age区间的CTR。
- **数据**：20180801，看点搜索热词来源综合tab。
- **结论**：
  1. CTR最高的是**12-24小时**doc_age区间（发布半天到一天的文章）。原因：特征每3小时更新一次，模型需要时间积累曝光反馈才能生效，生效周期可能是12-24小时。
  2. CTR最低的是**48小时后**的文章。
  3. 热词搜索场景下，**6小时内**文章CTR较高（用户期望新文章）。
  4. **6-12小时**CTR相对较低（热词热度褪去，新文章曝光反馈尚未充分积累）。
- 附doc_age分箱CTR折线图。

**main.ipynb — 分析代码**：
- cid_doc_age_data.txt：2,984,377个唯一内容ID，每个cid对应nowtm（文档年龄，秒）。
- cid_clk_data.txt：每个cid的曝光/点击数据。
- 合并doc_age与clk_ratio，按doc_age分箱：0-3h、3-6h、6-12h、12-24h、24-48h、48h+。
- 绘制各箱CTR折线图。

### 2.8 08 幻灯片集（2份pptx：召回模型.pptx、图集1拖N技术优化进展）

#### （1）召回模型.pptx
- **讲了什么**：系统性对比4种召回算法的原理和实验效果。
- **MF（矩阵分解）召回**：对user-item评分矩阵分解得到user向量和item向量，用户向量=历史点击item向量的加权组合。对比Item协同召回：CTR高4%左右，曝光量约为协同的90%。
- **YouTube深度召回**：用户点击ID序列+用户画像（性别/年龄/分类）→MLP→用户向量，Faiss向量索引TopK召回。对比Item协同：CTR高4%左右，曝光量约为协同的60%。
- **GloVe召回**：将用户行为序列视为"语料"，item视为"词"，通过共现矩阵拟合学习item向量。对比Item协同：CTR高5%左右，曝光量约为协同的45%。
- **CDAE（协同去噪自编码器）召回**：输入用户浏览历史（加噪）→隐层→输出浏览序列复现。改进方案：用户向量用历史浏览文章的tag生成（tag lookup table学习获得），文章用word2vec向量代替，在线计算用户向量和word2vec内积取TopK。对比离线召回和协同召回：CTR高8%以上，曝光量约为SCFR的30%。
- **现有召回方法优缺点总结**：基于内容的召回（时新但内容集中）vs基于协同的召回（泛化好但只能召回训练集内出现过的文章）。

**与今日头条面试相关性**：极高。召回算法的系统性对比是推荐系统面试的高频考点，4种算法各有trade-off（CTR vs 曝光量），展示了候选人对召回层的深度理解和实验验证能力。

**价值评级**：极高

**可提炼的面试点**：

## 一、2020年06月-图神经网络

**文件清单（6份PDF，SMP图神经网络在线研讨会2020报告课件）：**
1. 宋国杰（北大）— Network Representation Learning（57页）
2. 沈华伟（中科院计算所）— Graph Convolutional Neural Networks（50页）
3. 唐杰（清华）— 图神经网络及认知推理（97页）
4. 石川（北邮）— Heterogeneous Graph Neural Network and its Applications in E-commerce
5. 福利：刘知远团队《Introduction to Graph Neural Networks》书籍PDF
6. 智源周刊和智源AI技术社群（推广页，文本量极少）

**讲了什么：**
- **01 宋国杰**：网络表示学习（NE）全景。从传统降维（PCA/SVD/MDS/LLE/ISOMAP）→ Word2vec系（DeepWalk/LINE/PTE/node2vec）→ 矩阵分解统一框架（NetMF，WSDM'18最受引论文）→ 大规模加速（NetSMF/ProNE，单线程10分钟处理YouTube约1M节点，1亿节点29小时）→ 北大自研工作（SepNE可分离式嵌入、GraphLSP局部结构模式、DANE域自适应、GCN-LASE链属性、Tag2Gauss）。NE与GNN的关系：NE是浅层无监督编码器，GNN是深层聚合编码器。
- **02 沈华伟**：图卷积神经网络（GCN）技术纵深。谱方法路线：Spectral Graph CNN（Bruna'14，需特征分解O(n²)）→ ChebyNet（Chebyshev多项式近似，参数从n降到K，计算O(E)）→ GCN（Kipf'17，ChebyNet一阶简化，低通滤波器视角解释为何GCN比ChebyNet效果好）。空间方法路线：PATCHY-SAN（Niepert'16）→ GraphSAGE（Hamilton'17，采样+聚合，归纳式）→ GAT（Veličković'18，注意力加权）→ MoNet（混合模型统一框架）。中科院自研：GWNN（图小波神经网络，ICLR'19，用小波基替代Fourier基，稀疏+局部化+低计算量）、GraphHeat（热核GCN，IJCAI'19，e^(-sL)低通滤波，三个基准数据集SOTA）。图池化：DiffPool（粗化）/Self-Attention Pooling（节点选择）。核心洞察：GCN可视为WL同构测试的软版本。
- **03 唐杰**：从感知到认知的GNN。NE演进（DeepWalk→LINE→node2vec→NetMF统一→ProNE）→ GNN时代（GCN/GraphSAGE/GAT/FastGCN）→ 认知推理（CogQA，ACL'19，HotpotQA排行榜连续近3个月第一）。CogQA核心：双系统理论（System 1 BERT做隐式知识扩展+实体抽取，System 2 GNN做显式推理决策），迭代构建认知图谱，可解释推理路径。挑战：GNN过平滑/过拟合/非鲁棒；GNN与预训练（BERT/对比学习）结合。
- **04 石川**：异构图神经网络（HGNN）及电商应用。异构图（多种节点/边类型）的挑战：元路径、语义融合。模型：HAN（层次注意力：节点级+语义级）、HGT（异构图Transformer）、GTN（图Transformer网络）。电商场景应用：阿里的用户-商品-商家-品牌异构图，推荐/搜索/广告。
- **05 书籍**：刘知远《Introduction to Graph Neural Networks》，GNN入门教材。

### 6.1 M7-henrys汇报V1.2（QQ看点推荐研发中心季度汇报）

**低活用户优化（用户侧核心命题）：**
- 低活用户分层定义：
  - 低活1：tagNum≤500 且 7日内无点击 → **用户量占比32.7%，请求量占比10.1%**
  - 低活2：tagNum≤200 且 7日内无点击 → **用户量占比23.6%，请求量占比7.1%**
- 问题诊断：低活用户与活跃用户共用同一个模型，但重要特征（短期行为、短期画像、周画像月画像）缺失；人口属性召回偏泛化，推荐结果兴趣区分度小；中高活推荐体验明显好于低活，将低活用户当成中高活用户推荐是核心问题。

**新用户视频体验优化：**
- 视频纯新用户画像：**73%为19~40岁人群**
- 问题诊断：
  - 相关性不足：**88%用户有图文点击，但视频推荐不够精准**
  - 时新性不足：视频时新内容占比较低（用户持续点击巴萨时新图文，但视频推荐出陈旧内容）
  - 探索不足：非主流人群分发被主流人群带偏；游戏类目过度曝光，底部类目点击率较高但欠曝光
  - 渗透不足：**日报场景视频渗透率约40%，而约30%视频纯新用户来自日报**
- 优化方案：新增兴趣探索（基于人群/兴趣探索优质账号和内容）；排序模型优化（人群特征+外部画像+样本选取）；日报视频体验优化（提升曝光比例+优化排序）

**画像中台与召回算法：**
- 跨业务流水训练实验：w2v、dssm输出top100召回候选 → **曝光占比<1%，CTR<5%**（效果不佳）
- Peterrec工程化：在Tesla平台基于TensorFlow训练，输出top100召回候选 → **离线指标 Top5Recall@100 = 0.42**
- 视频渗透率当前约**60%**

**主流图文视频推荐优化：**
- 现状：主流图文视频为点击+时长双目标
- 问题：图文互动订阅行为稀疏，需平衡三个目标；图文互动订阅有样本选择偏差；视频下翻率低
