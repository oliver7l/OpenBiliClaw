## 💣 弹药1 · 留存因果分析（关注 → 留存/时长）★最对口头条

### 完整话术（主干）
> "我在腾讯看点做了一个**关注行为的因果分析**。背景是内容产品都在抢用户时长，我们发现'关注了账号'的用户留存明显更高，但这可能是**反向因果**——本来就活跃的人更容易去关注。所以我把它当正式的因果问题来分析：**关注账号到底对留存和时长有没有真实提升？**"

### 方法细节（被追问再展开）
- **数据三张表**：`t_dwa_kd_fans_focus_di_day`（粉丝关注关系增量表）+ `fcc_share_user_behavior_d`（日活用户行为聚合表）+ `fcc_share_user_profile_acc_d`（用户画像表）
- **设计**：选取 **6/1 当天新增关注关系的用户**，对比他们**关注前一周（5/25-5/31）vs 关注后一周（6/1-6/7）**的指标变化——**每个用户跟自己比**，消除个体差异
- **数据清洗**：剔除"王者荣耀、穿越火线、NBA中国"等**导流官方账号**——这些账号的粉丝是被运营动作带进来的，不是自然行为，混入会高估关注效果
- **分维度下钻**：性别 / 年龄 / 城市级别，看效果是否稳健、是否有分层规律

### 关键数字（背熟）
| 维度 | 指标 | 提升 |
|---|---|---|
| 整体 | 周活跃天数 | **+21.2%** |
| 整体 | 日均时长 | +1.6% |
| 整体 | 未来六天留存比例 | **+9.4 个百分点** |
| 性别 | 男性日均时长 | +2.2%（最显著） |
| 性别 | 女性留存 | +18pp（最高） |
| 年龄 | 50岁以上活跃天数 | +26.45%（最显著） |
| 年龄 | 31-40岁留存 | +13pp |
| 城市 | 一线城市日均时长 | +5.47%（整体 3.4 倍） |
| 城市 | 一线/新一线留存 | +10pp |

### 结论 → 业务含义
**关注是留存的关键抓手** → 排序/召回里加大"关注后消费"的建模权重；内容侧主动引导用户关注优质账号。

### 追问应对
- **"为什么用前后对比，不做随机实验？"** → 关注行为没法随机分配，属于观察性研究；用同一用户前后对比控制个体差异；为避免时间趋势混杂，再用分维度看稳健性。
- **"怎么证明不是时间趋势在起作用？"** → 取了历史正常周做参照、分维度一致，且关注这个动作是即时事件，效果好且集中在前一周窗口。
- **"SQL 怎么写的？"** → 三张表 join：关注增量表取当日新增（oper_type=1、剔除官方号）→ 关联行为表取前后两周指标 → 关联画像表做维度分组；`avg(关注后) vs avg(关注前)` 对比。

## 💣 弹药2 · DAU 持续下降排查（Case 题直接套）★字节必考

### 完整话术（主干）
> "我拆解过**大盘 DAU 连续六周线性下降**的问题（6.15-7.26 六个自然周，9057w → 8410w，降幅 647w / 7.7%）。我的方法分五步：**定义问题 → 厘清事实 → 建模找关键变量 → 逐项归因量化 → 竞品对照 + 行动**。"

### 五步法细节
**① 定义问题/核对口径**：先确认 647w 降幅是真实的——排除口径调整、数据 bug，明确时间窗口。
**② 厘清事实/看历史**：近一年 DAU 经历三升三降，当前处下降段；叠加外部事件（北京新发地二次疫情）——**疫情拉动的增量用户在退潮**（与一次疫情对称，但流失更严重）。
**③ 建模找关键变量（特征重要度）**：
- 疫情前**非高活**用户：76% 流失（连续7天未回）；**低活**用户 92.9% 流失
- 疫情前**高活**用户：仅 36.9% 流失
- 高活但**首启主启比例<0.7**（没建立"主启心智"）的用户：72.5% 流失
- **核心洞察：高活跃 + 主启心智 才能留人；中低活/沉默用户被疫情唤起后没承接住 = 这轮下跌主力**
**④ 逐项归因并量化（每项折算成 DAU 降幅）**：
| 原因 | 折算降幅 | 口径 |
|---|---|---|
| 桌面红点停投（7月起只投新/沉默/低活） | ≈ **200w** | 结合红点 AB 实验比例折算 |
| 暑期主动文件活跃下降（文件tab+高级功能降幅超大盘） | ≈ **150w** | 主动文件用户降幅比例折算 |
| push 热点消退 | ≈ **47w** | push 启 UV 降幅 × 0.3 |
| 高活→高活比例降、中活转低活/沉默升 | ≈ **400w** | 用户分层流转（与前三点有重叠） |
| 已知 CTR 下降 | 传导中 | 推荐侧排查中 |
**⑤ 竞品对照 + 行动**：腾讯新闻同期**同趋势** → 部分是行业/大盘因素；行动按优先级：M1 红点承接优化后提频（预计 +80w delta）→ M2 小说专项、0 业务渗透的 1400w 用户转化、外部调起 1200w 用户转主启。

### 追问应对
- **"归因数字怎么算出来的？"** → 红点用 AB 实验的比例折算；文件用主动文件用户降幅比例折算；push 用启 UV 降幅 × 0.3 经验系数。每个都标注口径，不混算。
- **"400w 和前几项重叠怎么办？"** → 说明这是两种切分视角（原因拆解 vs 用户分层拆解），我明确标注了重叠，避免重复求和，结论以"可解释比例"呈现。
- **"让你重做会怎么优化？"** → 先做"用户×周"面板的**新增/流失分解**（新用户减少 vs 老用户流失各占多少），再把策略事件当成准自然实验验证，最后做反事实估计。

## 💣 弹药3 · DID 因果量化（互动 → 时长/留存）★方法论杀手锏

### 完整话术（主干）
> "另一个有代表性的是**互动行为对时长/留存的因果量化**。难点是 **selection bias**：有互动的人本来就更活跃，直接对比'有/无互动'会高估。所以我用了 **DID（双重差分）准实验**。"

### 方法细节（被追问再展开）
- **treatment 定义**：以某天（6/15）是否发生互动行为分组——treatment 组 = 当天有点赞（或评论/分享），对照组 = 当天没有；另有频次维度（行为从 1 次 → 2 次）
- **观察窗口**：6/15 前一周 vs 后一周，每天的人均时长和次留率
- **回归方程**：`Y = β0 + β1·is_treatment + β2·is_post + β3·(is_treatment × is_post) + ε`
  → **DID 效果 = 交互项系数 β3**，看它是否显著
- **关键前提**：**平行趋势假定**——用图示法检验 treatment 发生前两组走势是否平行
- **为什么 DID 有效**：双重差分同时消掉"不随时间变的组间差异"（β1）和"不随组别变的时间趋势"（β2），剩下的交互项才是净效果

### 关键结论（背熟）
| 行为 | 对时长 | 对次日留存 |
|---|---|---|
| 有点赞 | **显著 +3.2 分钟** | 不显著 |
| 有评论 | **显著 +3.4 分钟** | 不显著 |
| 有分享 | 不显著 | 不显著 |
| 频次 1→2（点赞/评论/分享） | 不显著 | 不显著 |

### 业务含义
- 互动（尤其点赞/评论）确实提**时长**，但**不改次日留存** → 互动是"即时参与感"，不是"留存钩子"
- **频次没有边际增益** → 资源应放在**引导用户做出第一个互动**，而不是激励重复互动
- 分享不显著 → 分享更受内容/关系链驱动，不适合当通用干预目标

### 追问应对
- **"为什么不用随机实验？"** → 互动行为不能强制随机分配，只能观察；DID 通过"时间×组别"双重差分消除组间固定差异和时间趋势。
- **"平行趋势怎么检验？"** → 画 treatment 前两组时序图看是否平行，或用事件研究法（event study）看 treatment 前各期交互项系数是否≈0。
- **"还知道哪些因果方法？"** → RCT 金标准；观察数据：PSM、DID、断点回归、工具变量；归因：Shapley/数据驱动归因。

## 💣 弹药4 · 留存拐点 / Aha moment（关注数=14）★加分项

### 完整话术（主干）
> "我们还做过**留存 Aha moment 研究**：到底关注多少账号，用户就'留下来'了？"

### 方法细节
- 取 **4.1-4.30 的新用户**，追踪他们**达到关注数 14 后**的第 7/15/30 天留存
- 剔除噪音（异常用户），消除数据干扰
- 关注数与长留存相关性：**横向**看相关性高、时间越长关联越大；**纵向**看不是简单正相关

### 关键发现（背熟）
1. **关注到第 14 个账号是质变点**：关注数到达 14 时留存率最高
2. **超过 14 反而转负**：关注数与留存呈负相关 → 初步归因：**关注的账号整体质量不高**
3. **节奏比速度重要**：用户在第 **9-14 天**达成 14 个关注，长期留存表现最好；更快达成反而不如慢慢达成

### 业务含义
- 推荐要**控制"关注"的节奏和质量**——催关注不如让用户慢慢积累优质关注
- 关注数超 14 后质量下降 → 需要**账号质量分 / 生态治理**（正好接微视五维打分 + 达人扶持）

### 追问应对
- **"为什么是 14，不是别的数？"** → 这是从数据里看出的留存最高点（拐点），不是预设；用 7/15/30 天多个窗口验证一致性。
- **"超过 14 为什么转负？"** → 初步归因是关注账号整体质量不高，说明要建账号质量体系做把关——顺势讲微视的五维打分、关注率 +5.3%。
- **"这个发现怎么落地？"** → 推荐里对"关注数"做引导目标控制，优质账号优先露出，避免用户关注一堆低质账号；把"关注后消费"作为长期价值 label 进排序。
