### 2.1 离线预测模拟 — kandian_xgb_predict（基线版本）

**文件清单**：compare.ipynb、model_online/xgboost_feature_map.txt、xgboost_model1.txt、xgboost_model2.txt、query_result/（11个xlsx：query_春晚.xlsx等）

**讲了什么**
腾讯QQ看点搜索的XGBoost CTR预估离线模拟全流程。
- **数据来源**：从搜索CGI返回结果中解析dbg_msg（含MLFeatures/ml_value/clk_rate），提取每条结果的完整特征。
- **特征体系**（xgboost_feature_map.txt，14,182,434维稀疏特征）：
  - 用户侧：city_index（城市，250+维）、province_index（省份，30+维）、gender_index（性别）、age_index（年龄）、game_index（游戏偏好）、entity_clk_num（实体点击数）、entity features
  - 内容侧：ct_doc_score（文档质量分）、ct_ext_score（扩展分）、ct_doc_age（文档年龄/时效性）、ct_timeliness（时效性标签）、video_play_time（视频播放时长）、video_type（视频类型）、点赞/评论/图片数/视频数
  - 匹配侧：match_type（匹配类型，NONE等）、entity（实体ID）、query_category（query分类）
  - 统计侧：exp_pv（曝光PV）、total_exp_pv（总曝光）、ctr（点击率）、avg_ctr（平均CTR 0.072）
- **模型**：XGBoost二分类，libsvm格式，加载在线模型文件做离线预测。样本行："26x14182434 matrix with 351 entries"（26条结果，14M特征空间，平均每条351个非零特征）。
- **预测分数**：示例query预测score=0.035。
- **query_result xlsx**：每个query一个文件，包含result_id、ml_value（在线模型分）、clk_rate（点击率）、group_mask（品类：2008=视频、1033=小视频）、group_name、各重排策略下的排名。

**与今日头条面试相关性**：高。这是完整的搜索CTR预估工程，特征体系覆盖用户/内容/匹配/统计四维，与今日头条内容侧（供需/热点）和平台侧（推荐分发效率）直接对应。14M稀疏特征的XGB工程能力是数据科学工程师的硬实力。

**价值评级**：高

### 2.2 离线预测模拟 — xgb_predict_add_playcnt（加入视频播放量特征）

**文件清单**：compare.ipynb、model_new/xgb_feamap、xgb、query_result/（12个xlsx）

**讲了什么**
在基线XGB模型基础上，新增视频播放量（play_cnt）特征的迭代版本。
- **play_cnt特征工程**：从搜索结果layout_content中解析，fontType='E'的行包含"xx万播放"/"xx亿播放"文本，正则提取并换算为整数（万×10000，亿×100000000）。仅对group_mask 2008（视频）和1033（小视频）有效。
- **模型对比**：旧模型（ml_value）vs 新模型（ml_value_new，含play_cnt），对比同一query下各结果的排名变化。
- **视频品类加权策略实验**：
  - `final_score_by_formula` = ml_value × 0.5 + clk_rate × 0.5（基础融合分）
  - `merge_video_score`：视频组内取最高分，统一赋给组内所有视频（视频组内去重/提权）
  - `mul_1_5`：对视频/小视频的融合分×1.5（品类加权提权）
  - 对比四种策略下的排名：基础排名、merge后排名、新模型merge后排名、新模型×1.5后排名
- **示例结果**（query=周杰伦/易烊千玺等）：视频内容在×1.5策略下排名从第6-10名提升到第2-3名。

**与今日头条面试相关性**：高。视频播放量是内容侧核心信号，品类加权是推荐/搜索混排的常见策略。这个迭代体现了"发现信号→特征工程→AB策略→排名验证"的完整数据科学闭环。

**价值评级**：高

**可提炼的面试点**：
- 从非结构化UI字段（layout_content）中挖掘新特征的工程能力
- 视频品类加权策略的设计与离线排名验证
- 模型迭代的A/B对比方法论（旧模型vs新模型在同一query上的排名变化）

### 2.6 compare/compare.ipynb — 实体映射与实体加权重排序

**讲了什么**
搜索结果重排序实验，以query="优图"为例。
- **数据解析**：从搜索API返回的item_groups中解析各品类（视频、小视频、看点）的result_items，提取final_score、neo_score（实体分）等字段。
- **实体加权公式**：`neo_score_ratio = neo_score / 5 * 0.5 + 1`，对有实体匹配的结果，用该ratio乘以原始分数进行提权。neo_score/5归一化到[0,1]，×0.5+1映射到[1, 1.5]区间。
- **重排序**：按加权后分数重新排名，对比原始排名与实体加权后排名的变化。
- 这是搜索混排中**实体理解（Entity Understanding）**的直接应用——识别query中的实体，对匹配实体的内容提权。

**与今日头条面试相关性**：高。实体映射是搜索/推荐的核心技术，今日头条的内容侧（话题聚类、热点挖掘）大量依赖实体识别。实体加权重排序是可直接落地的策略。

**价值评级**：高

**可提炼的面试点**：
- 实体识别→实体匹配→实体加权重排序的完整链路
- 加权公式的设计思路（归一化→映射到提权区间→避免过度提权）
- 实体理解在搜索混排中的价值

  - 4个wide数值特征（直接拼接）
- **模型结构**：
  - Embedding层 → Flatten → Concatenate(132维) → BatchNormalization → Dense(30, relu, L2正则0.01)
  - 与wide特征Concatenate(34维) → Dense(1, sigmoid)
  - 总参数41,323
- **训练**：binary_crossentropy，Adam(lr=0.1)，batch_size=512，3 epochs。
- **结果**：Epoch 1 — loss 0.4396, acc 0.9716, val_loss 0.2720, val_acc 0.9797。Epoch 2被手动中断（KeyboardInterrupt）。
- 自定义AUC metric（my_auc，基于PTA/PFA的TF实现）。
- 回调：TensorBoard、ModelCheckpoint（save_best_only）、ReduceLROnPlateau。

**02_tensorflow_train.ipynb**：TensorFlow原生API版本的训练脚本，与Keras版本对应。

**01_data_process_for_tensorflow.ipynb**：为深度学习模型准备特征文件，将每个特征单独保存为npy/txt（fea_nn/目录下train_fea_city_index等），label单独保存。

**与今日头条面试相关性**：高。Wide&Deep是推荐/搜索CTR预估的经典架构，候选人从XGB到Wide&Deep的模型演进体现了技术深度。142万样本的深度学习训练是真实工程经验。

### 4.1 04_kd_timeliness.zip — 看点搜索时效性分析

**文件清单**：main.ipynb、时效性分析报告.pdf、cid_clk_data.txt（88MB，曝光点击数据）、cid_doc_age_data.txt（458MB，内容年龄数据）

**讲了什么**

**时效性分析报告.pdf（核心产出）**：
- **背景/现象**：看点热词搜索结果中存在几天前的旧文章，预期热词搜索应返回新发布文章。
- **分析思路**：获取文章doc_age（now - publish_time）+ 用户点击率，分析不同doc_age区间的CTR。
- **数据**：20180801，看点搜索热词来源综合tab。
- **结论**：
  1. CTR最高的是**12-24小时**doc_age区间（发布半天到一天的文章）。原因：特征每3小时更新一次，模型需要时间积累曝光反馈才能生效，生效周期可能是12-24小时。
  2. CTR最低的是**48小时后**的文章。
  3. 热词搜索场景下，**6小时内**文章CTR较高（用户期望新文章）。
  4. **6-12小时**CTR相对较低（热词热度褪去，新文章曝光反馈尚未充分积累）。
- 附doc_age分箱CTR折线图。

**main.ipynb — 分析代码**：
- cid_doc_age_data.txt：2,984,377个唯一内容ID，每个cid对应nowtm（文档年龄，秒）。
- cid_clk_data.txt：每个cid的曝光/点击数据。
- 合并doc_age与clk_ratio，按doc_age分箱：0-3h、3-6h、6-12h、12-24h、24-48h、48h+。
- 绘制各箱CTR折线图。

**与今日头条面试相关性**：极高。时效性分析是内容侧热点挖掘的核心命题，直接对应今日头条"内容侧（供需/热点挖掘）"维度。报告的分析框架（现象→思路→数据→结论→归因）是数据科学工程师的标准工作范式。"模型生效周期12-24小时"的归因体现了对推荐系统机制的深度理解。

**价值评级**：高

**可提炼的面试点**：
- 内容时效性与CTR关系的完整分析（298万内容ID，6个时间分箱）
- "模型生效周期"概念：特征更新频率（3h）→ 曝光反馈积累 → 模型生效（12-24h），这是对推荐系统冷启动/时效性的深刻洞察
- 热词场景下时效性偏好的差异化（6h内高CTR vs 6-12h低谷）
- 从badcase（热词搜索出现旧文章）到数据分析到结论的完整闭环
