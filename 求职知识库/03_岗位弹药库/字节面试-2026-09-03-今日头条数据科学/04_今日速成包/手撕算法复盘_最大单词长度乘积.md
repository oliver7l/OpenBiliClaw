# 手撕算法复盘：最大单词长度乘积（LeetCode 318）

> 来源：2026-09-03 字节今日头条数据科学一面手撕
> 类型：位掩码（bitmask）+ 哈希去重优化
> 难度：中等偏上，字节高频

---

## 一、题目复述

给定一个字符串数组 `words`，返回两个单词长度的乘积的最大值，要求**这两个单词不含有共同字母**。如果不存在这样的两个单词，返回 0。

### 示例
```
输入：["abcw","baz","foo","bar","xtfn","abcdef"]
输出：16  解释：words[0]="abcw" × words[4]="xtfn"，无公共字母，4×4=16

输入：["a","ab","abc","d","cd","bcd","abcd"]
输出：4   解释："ab"(2) × "cd"(2)=4，无公共字母

输入：["a","aa","aaa"]
输出：0   解释：都含字母 'a'，不存在合法配对
```

---

## 二、核心考点（面试官到底考什么）

1. **位掩码表示字母集合**：26 个字母 → 用 int 的 26 个 bit 编码，`mask = 1 << (c-'a')`
2. **无公共字符判断 O(1)**：`mask1 & mask2 == 0` ⟺ 两词无交集
3. **同掩码只保留最长单词**：哈希去重优化，这是能否通过大数据的关键
4. **复杂度分析 + 边界处理**

> 本质：把"字母集合比较"从 O(26) 降到 O(1) 位运算，再用"同集合留最长"剪枝。

---

## 三、解法演进（从暴力到最优）

### 解法1：暴力 + 集合比较（必挂，仅作对照）
- 每个单词转 `set`，两两检查 `set 交集是否为空`
- 复杂度 `O(n² × L)`，n 最大 1000、L 最大 1000 → **10⁹ 直接超时**

### 解法2：位掩码 + 两两比较
- 先把每个单词编码成 26 位掩码，两两判断 `mask[i] & mask[j] == 0`
- 复杂度 `O(n² + n×L)`，位运算常数极小，能过
- **仍可优化**：相同掩码的词会重复计算

### 解法3（最优）：位掩码 + 同掩码留最长
- 用字典 `{mask: max_len}`：**相同字母集合的多个词，只保留最长的那个**
- 理由：两个词无公共字母时，乘积只取决于"各自长度"；相同 mask 的词长度更短者，与任何兼容词相乘都 ≤ 最长者的乘积，**不可能成为最优解，直接丢弃**
- 只对去重后的 mask 两两配对，复杂度 `O(m² + n×L)`，m ≤ n（m 为不同掩码数，实测通常远小于 n）

## 四、标准代码（Python）

```python
from collections import defaultdict

def maxProduct(words):
    # 1. 编码 + 同掩码去重（留最长）
    mask_len = {}  # mask -> 该字母集合下的最长长度
    for w in words:
        mask = 0
        for c in w:
            mask |= 1 << (ord(c) - ord('a'))
        mask_len[mask] = max(mask_len.get(mask, 0), len(w))

    # 2. 两两配对（不同掩码才可能无公共字母）
    masks = list(mask_len.keys())
    ans = 0
    for i in range(len(masks)):
        for j in range(i + 1, len(masks)):
            if masks[i] & masks[j] == 0:   # 无公共字母
                ans = max(ans, mask_len[masks[i]] * mask_len[masks[j]])
    return ans
```

### 手写精简版（面试直接写这版）
```python
def maxProduct(words):
    d = {}
    for w in words:
        m = 0
        for c in w:
            m |= 1 << (ord(c) - 97)
        d[m] = max(d.get(m, 0), len(w))
    res = 0
    ms = list(d)
    for i in range(len(ms)):
        for j in range(i+1, len(ms)):
            if not ms[i] & ms[j]:
                res = max(res, d[ms[i]] * d[ms[j]])
    return res
```

### 复杂度
| 方案 | 时间复杂度 | 空间 | 评价 |
|---|---|---|---|
| 暴力 set | O(n²·L) | O(26n) | 大数据超时 ❌ |
| 位掩码两两 | O(n² + n·L) | O(n) | 能过 ✅ |
| 位掩码+去重 | O(m² + n·L)，m≤n | O(m) | 最优 ✅ |

## 五、面试高频追问 + 标准话术

### Q1：为什么用位掩码而不是 set？
**话术**：字母只有 26 个，可以映射到 int 的 26 个 bit。两个词"是否含共同字母"就变成两个整数做一次 `&` 位运算，从 O(26) 的集合比较降为 O(1) 常数时间。n 到 1000 时，用 set 是 10⁹ 量级必超时，位掩码降到 10⁶ 量级，差三个数量级。

### Q2：为什么相同掩码只保留最长？
**话术**：mask 相同的词，字母集合完全一样，它们对"外部任何一个词"的兼容性完全相同（要么都无公共字母，要么都有）。而最终目标是最大化长度乘积，所以同一集合里更短的词，和任意兼容词相乘的结果一定 ≤ 最长者，**永远不会成为最优解**，可以直接丢弃。这步把配对规模从 n² 压到 m²，m 通常远小于 n。

### Q3：边界情况怎么处理？
- 空数组 / 单元素 → 返回 0（无合法配对）
- 所有词都含公共字母 → 返回 0
- 单词可能重复 → 去重逻辑天然兼容（长度取 max）

### Q4：还能不能更快？（进阶加分）
- 若要求极致，可先按长度降序排序，一旦 `当前长度² ≤ ans` 即可剪枝提前退出
- 但面试 O(m²) 已是最优可接受答案，排序剪枝作为加分项提一句即可，不要喧宾夺主

## 六、易错点自检

- [ ] 编码时 `1 << (ord(c)-ord('a'))` 是**或运算累加**，不是加
- [ ] 判断无公共字符用 `mask[i] & mask[j] == 0`，括号写清楚避免优先级歧义
- [ ] 别忘了**同掩码去重留最长**（不写这步大数据会超时，也是面试官最想看到的优化点）
- [ ] 两两配对从 `i+1` 开始，避免重复计算和自配对
- [ ] 答案初值 0，无配对返回 0
