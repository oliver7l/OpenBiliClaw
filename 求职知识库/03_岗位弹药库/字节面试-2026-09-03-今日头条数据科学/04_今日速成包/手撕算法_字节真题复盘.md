# 手撕算法·字节真题复盘：最大单词长度乘积（LeetCode 318）

> 来源：2026-09-03 字节·今日头条数据科学 面试代码题
> 整理时间：2026-09-04
> 一句话：一个字符串数组，返回两个无公共字符单词的长度乘积最大值；无则返回 0。
> 考点：**位掩码 bitmask + 贪心去重**，字节高频位运算技巧题

---

## 一、题目（先确认理解）

输入 `words = ["abcw","baz","foo","bar","xtfn","abcdef"]`
输出 `16`（"abcw"(4) × "xtfn"(4) = 16，"abcw" 与 "xtfn" 无公共字符）

**边界**：
- 不存在任何一对无公共字符 → 返回 0
- 单词可重复、可含任意小写字母（LeetCode 限定 a-z；若含大写需扩展）
- 单个单词长度最长 1000，数组最长 1000

---

## 二、解法一：暴力 + 字符集合判交（先给这个，再优化）

```python
def maxProduct(words):
    n = len(words)
    ans = 0
    for i in range(n):
        for j in range(i+1, n):
            if not (set(words[i]) & set(words[j])):
                ans = max(ans, len(words[i]) * len(words[j]))
    return ans
```

- 复杂度：O(n² × L)，L 为单词平均长度
- 最坏 n=1000、L=1000 → 10⁹ 量级，**超时**
- 面试价值：体现"先有可行解"，但要立刻说出优化点

---

## 三、解法二：位掩码 bitmask（最优解，面试必背）

### 核心思想

每个单词用**一个 26 位整数**表示它包含哪些字母：

- `a → bit0`，`b → bit1`，… `z → bit25`
- 单词含某字母，就把对应位置 1：`mask |= 1 << (ord(c) - ord('a'))`
- 例：`"abc" → 0b111`（bit0/1/2 = 1）

**两个单词无公共字符 ⟺ `mask[i] & mask[j] == 0`**

把"字符集合判交"从 O(L) 降到 **O(1)**，这是本题的核心优化。

### 关键优化：相同掩码只保留最长单词（贪心去重）

不同单词可能有相同字符集合（如 `"abc"` 和 `"cab"`、`"bac"`），它们的 mask 一样。
- 对**相同 mask**，能产生最大乘积的一定是**最长的那条**（换成更长的替代，和其他任何单词组合结果都不差）
- 所以用字典 `mask -> 该 mask 下的最大长度`，直接剔除短单词

### 完整代码（Python，可直接背诵）

```python
def maxProduct(words):
    # 1) 建掩码：相同字符集合只保留最长长度
    best = {}
    for w in words:
        m = 0
        for c in w:
            m |= 1 << (ord(c) - ord('a'))
        best[m] = max(best.get(m, 0), len(w))   # 同掩码取最长

    # 2) 两两配对，无公共字符则更新答案
    ans = 0
    items = list(best.items())                  # [(mask, max_len), ...]
    for i in range(len(items)):
        m1, l1 = items[i]
        for j in range(i + 1, len(items)):
            m2, l2 = items[j]
            if m1 & m2 == 0:
                ans = max(ans, l1 * l2)
    return ans
```

### 复杂度

- 建掩码：O(n × L)
- 两两检查：O(m²)，m ≤ n 为去重后的不同掩码数
- 总：**O(n·L + m²)**，最坏 n=1000 → 10⁶ 量级，轻松通过

## 四、面试复盘要点（字节风格追问应对）

### Q1：为什么用位掩码而不是 set 判交？
> 判交从 O(L)（遍历字符/集合求交集）降到 O(1)（一次位与运算）。
> 字母表固定 26 位，一个 int（32 位）正好装下，无额外空间；
> 集合判交每次要哈希碰撞/遍历，n² 组合下累计是大头。

### Q2：相同掩码合并是否影响答案正确性？
> 不影响。掩码相同 = 字符集合相同，任意两个单词之间的"无公共字符"关系只由掩码决定、与具体单词无关；
> 对于同一掩码，用最长单词替换短单词去和其他掩码配对，乘积只增不减，所以贪心去重安全。

### Q3：复杂度？有没有更优空间？
> O(n·L + m²)。n=1000 时 m² ≤ 10⁶，已足够。
> 若想再快：按长度降序排序后，遇到 `l1*l2 <= ans` 直接剪枝跳过；
> 若字符集扩展到 Unicode/多语言，就不能用固定位掩码，改回集合/哈希。

### Q4：边界/坑有哪些？
1. 掩码更新必须用 `max`（同字符集多个单词，取最长）
2. 判"无公共字符"必须是 `& == 0`，写成 `!= 0` 就反了
3. 结果初始化为 0；不存在配对返回 0
4. 空串 mask=0，与任何单词都"无公共字符"——但长度 0 乘积恒 0，不影响答案（注意别因此歧义）

> "这题我用位掩码做。每个单词用一个 26 位整数编码它含哪些字母，这样判断两个单词有没有公共字符，就是一次位与运算是否为 0，把复杂度从 O(长度) 降到 O(1)。
> 先遍历所有单词建掩码，同时用一个字典做贪心去重：相同掩码只保留最长的那条，因为字符集一样、选更长的组合一定不差。
