## 一、岗位是什么（JD + 团队职责）

**职位描述（4 条）：**
1. 基于对用户、内容、作者和产品的理解与海量数据，参与多场景的**数据挖掘、策略设计、效果评估和策略改进**
2. **深度挖掘发现潜在收益空间大的业务机会/问题原因**，对业务痛点提出优化解决策略
3. 研究数据挖掘/统计领域前沿技术，挖掘**有增量价值的新认知、新策略**
4. 主动自驱发起并推动忠于**用户价值/产品体验**的数据挖掘项目或算法策略落地

**职位要求：**
- 数学/统计/数据挖掘/ML/计算机/经济学背景
- 逻辑思维 + 分析解决问题能力
- **精通 SQL**，熟练 R/Python，熟悉 Hadoop/Spark/Hive
- 两年以上数据挖掘经验，**有全局视角 + 推动拿到显著收益的业务策略挖掘经验者优先**

**团队职责（三大维度）：**
| 维度 | 核心工作 | 对应你的经验 |
|---|---|---|
| 用户侧 | 全生命周期建模、行为与**留存因果分析**、算法干预 → 提时长留存 | 中信留存/因果分析、腾讯关注→留存 |
| 内容侧 | 供需关系、**作者激励**、热点挖掘、话题聚类 | 微视达人扶持/五维打分、熊掌号评价 |
| 平台侧 | 超大规模推荐系统优化信息与**广告分发效率** → 扩大收入变现 | 百度 eCPM、OPPO ARPU、微视全链路 |

> 一句话定性：这个岗位不是纯广告算法岗，而是 **"数据分析 × 策略 × 算法落地"** 的数据科学岗，强调**用数据找机会、定策略、评估效果、拿到增量收益**。

## 二、上次面试（8/28）已覆盖的内容 — 从幻灯片记录看

上次备战 deck 共 90 页，覆盖以下模块（大概率已考核/已准备过）：
1. **手撕 SQL**（必考、LeetCode Medium-Hard）：窗口函数、连续登录 N 天、留存率、TopN、数据倾斜处理、间隔问题（lag/lead）
2. **账号推荐故事模板**：账号表征（内容 embedding 注意力加权 + 画像）、召回（CF + 二部图 embedding + 内容映射）、排序（P(关注)×P(关注后消费) 多目标）、生态（中尾部探索预算 + 质量分门槛 + 涨粉基尼监控）
3. **账号推荐 vs 内容推荐 Q&A**：本质区别、关注后消费 label 怎么定、防马太效应、新账号冷启
4. **业务 Case Study**：DAU/人均时长下降 5% 怎么排查、新作者激励策略怎么设计评估指标（拆解框架：内/外部因素、用户/内容/分发侧、短期/长期）
5. **用户"时间余额"争夺**：代理特征捕捉注意力外溢 + 钩子策略
6. **A/B 实验样本量计算**：基线指标、MDE、α、统计功效；用户渗透率/日活/周期
7. **LLM / Function Calling**（大模型方向）
8. **特征工程、建模/因果分析开发**：线索打分建模（稀疏特征/标签延迟/排序能力评估）、归因/PSM 匹配（渠道真实增量 ROI）

> 结论：SQL 手撕 + 业务 Case + 因果/AB 实验 是字节数据科学面试的核心盘，上次已系统准备过，本次重点应是**巩固 + 深化 + 换角度**。
