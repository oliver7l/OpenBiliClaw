## 0. 三十秒讲清这门生意（面试开场可以用）

> "游戏广告变现的本质是：**用免费玩家的注意力换广告收入，同时不能让他们跑掉**。所以这套系统有三个数：**每个用户每天能给多少广告（impressions/DAU）、每次展示值多少钱（eCPM）、以及这些广告对留存的伤害（uplift）**。我要做的算法工作，全在这三个数的乘积上。"

**收入恒等式（背下来）：**
```
收入 = DAU × (人均展示次数) × eCPM / 1000
       ↑            ↑                ↑
   留存/体验      频次控制         定价与预估
   （uplift）   （出广时机）    （pCTR×price、底价）
```
**这三个乘数正好对应 JD 里的三块要求**，你把这个框架先抛出来，后面的技术问题都会自动落到格子里。

## 1. 广告位类型与 eCPM 阶梯（必须先建立"价格感"）

**美国市场（Tier-1）2026 基准，量级记住排序即可：**

| 广告位 | 美国 eCPM | 人均每日展示次数 | 体验伤害 |
|---|---|---|---|
| **激励视频 Rewarded Video** | **$14–22** | 1–3 | 最低（用户主动，甚至提升留存） |
| **插屏 Interstitial** | **$9–14** | 3–6 | 中（打断节奏） |
| 开屏 App Open | $4–8 | 1–2 | 低（自然切换点） |
| 原生 Native | $3–5 | 2–5 | 低 |
| 中矩形 300×250 | $1.6–3 | 3–8 | 低 |
| 自适应横幅 Banner | $0.4–0.8 | **15–40** | 极低但单价极低 |

**三条铁律：**
1. **激励视频单价是横幅的 20-30 倍**，因为它自带用户主动选择（opt-in）——所以游戏行业最重要的问题永远是"**怎么让玩家愿意看**"，而不是"怎么多塞广告"。
2. **地理分层才是决定性因素**：巴西/印尼/印度的用户变现能力约为美国用户的 **5-20%**。所以全球发行的游戏必须做**分地区策略**（Block Blast 覆盖 200+ 国家，这条对它极其重要）。
3. **ATT 合规（iOS）**：没拿到授权，eCPM 会**直接掉 60-80%**——这是 iOS 广告最大的系统性风险，面试提到这个会显得你有真实业务感。

**休闲游戏（Hyper-casual）的 eCPM 比 Puzzle/Casual 低一档**（$11-16 vs $15-22），因为它的用户 LTV 低，广告主出价就低。Block Blast 属于 **Puzzle/休闲**，是 eCPM 中等偏上的品类。

## 2. 广告聚合（Mediation）与底价机制 —— 这是 JD 里"竞价广告底价设置"的语境

**一条广告从请求到展示的链路：**

```
游戏触发广告位 → SDK 向聚合平台请求 → 聚合平台向多个广告网络（AdMob/Unity/AppLovin...）询价
   → 出价最高且 ≥ 底价者赢得 → 加载创意 → 展示 → 计费（按 CPM/CPC 结算）
```

**两种卖流量的方式（面试高频）：**

| | 瀑布流 Waterfall | 头部竞价 In-App Bidding |
|---|---|---|
| 原理 | 按历史 eCPM 排序，**逐层串行**询价，每层设一个**底价 floor** | 所有网络**同时并发**出价，实时比价 |
| 优点 | 可控、能兜底、小网络也能吃量 | 无人工排序，**收入通常 +10-20%**，延迟低 |
| 缺点 | 排序靠猜、延迟高、**层数越多越容易掉填充** | 对网络质量依赖高 |
| 行业实践 | 8-15 层，**每层底价按历史 eCPM 的 -15~-25% 递减** | 与瀑布流混合使用（hybrid） |

**底价（floor price / reserve price）的核心矛盾——这就是要考你的地方：**

> **底价设高** → 单次展示更贵，但**填充率（fill rate）下降**，请求落空；
> **底价设低** → 填充率上去了，但 eCPM 被拉低。
> 目标函数不是 eCPM，也不是 fill rate，而是 **eCPM × fill rate = 实际千次请求收入（或 ARPDAU）**。

**算法化写法（你可以直接用这段回答"底价怎么定"）：**

1. **分段设底价**：按「广告位 × 国家/地区 × 时段 × 用户分层（新/老、是否付费）」分组，每组独立估一个最优底价——**这本质是一个多臂老虎机 / 在线学习问题**（探索 vs 利用：太低则浪费高价流量，太高则丢填充）。
2. **影子价格视角（和你熟的 pacing 是同一套数学）**：广告位库存是受限资源，底价就是库存的影子价格 **λ**。行业在预算节奏控制（pacing）里用的 **bid_eff = bid / (1 + λ)** 就是同一个思路——λ 由库存消耗进度反推，λ 越大越"惜售"。
3. **考虑长期效应**：底价拉高会让某些广告网络**放弃这个位置**（demand 流失），短期 eCPM 好看、长期填充率回不来——所以必须用**长期实验组**验证，而不是跑一周看数。

## 3. 出广时机与频次控制 —— 你的 uplift 直接落在这里

**"什么时候出广告"由三层决策构成：**

1. **频次上限（frequency cap）**：行业经验值——休闲游戏激励视频 **6-10 次/局或场，日上限 15-20**；插屏更保守。超过上限后用户反感陡增。
2. **时机选择**：**结算页、失败复活、翻倍奖励、登录奖励**是四大高转化位置；**禁忌**是"开局前强制广告"（直接毁掉首日留存）和"高操作强度时刻"（玩家正在心流里）。
3. **个体化判断（你最强的地方）**：不是所有用户都该看同样的广告——
   - 用 **uplift** 预测"给这个用户看这条广告，会不会让他明天不来了"
   - 四象限：**Persuadable**（看了会转化/留存影响不大，给）/ **Sure Thing**（本来就会留，可多给）/ **Lost Cause**（给不给都要走，可多给）/ **Do Not Disturb**（看了会流失，**宁可不出**）
   - 插屏和 banner 必须做 uplift；激励视频天然是 opt-in，主要优化"奖励额度是否值得"（行业经验：激励奖励的收益约等于付费玩家的 60-70% 时，既能留住免费用户又不破坏内购价值）

**可以直接说的观点：**
> "我觉得**频次控制不该是全局静态上限，而应该是 per-user 的 uplift 决策**——同一个第 6 次广告，对重度玩家是零伤害，对轻度玩家可能是流失的最后一根稻草。这件事用实验能验证：分群给不同频次上限，看 D7 和 ARPDAU 的联合变化。"

## 4. 指标字典（定义 + 基准值，被问到别卡壳）

| 指标 | 定义 | 健康基准 |
|---|---|---|
| **eCPM** | 每千次展示收入 = 收入/展示×1000 | 见第 1 节表 |
| **Fill Rate 填充率** | 有广告可返回的请求 / 总请求 | **≥95%**（低于 90% 说明底价过高或缺需求源） |
| **Show Rate 展示率** | 实际展示 / 填充到的广告 | 加载失败会拉低 |
| **Opt-in Rate（激励）** | 愿意看广告的用户 / 被提示的用户 | **40-70%**（<30% 要么位置错要么奖励太低） |
| **Completion Rate（激励）** | 看完整段视频 / 开始观看 | **≥90%**（<85% 查素材质量或频次） |
| **Impressions per DAU** | 人均日展示次数 | **2-6**（激励 1-3、横幅 15-40） |
| **ARPDAU** | 人均日收入 = 广告收入/DAU | 休闲 $0.03-0.16，Puzzle $0.07-0.16 |
| **LTV** | 用户全生命周期价值 = **ARPDAU × 平均生命周期天数** | 决定可承受 CPI 上限 |
| **CPI** | 单位获客成本 | Hyper-casual $0.4-1.2；Casual puzzle $1-2.5（美区） |
| **ROAS** | 回收/花费（D7/D30 为主看） | **广告变现型游戏看 D7 就能回本**（IAP 型要几个月） |
| **D1/D7/D30 留存** | 次日/7 日/30 日留存 | 行业中位 **23-28% / 4-8% / 1-3%**；Top25% **>32% / >10% / >4%**；**益智品类最好的那批：D1 32%、D7 12%、D28 4.5%** |

**一句能显得专业的补充**：Q4（黑五+圣诞）广告主预算暴涨，**eCPM 会季节性上浮 30-50%**，所以做预算/节奏类优化时必须做**季节性归因**，否则实验结论不可比。

## 5. 游戏广告 vs 内容/应用广告：差异在哪（必答）

| 维度 | 内容/电商推荐 | 游戏广告变现 |
|---|---|---|
| 目标 | 用户价值最大化（点击/时长/成交） | **平台收入 + 用户长期留存** 的平衡 |
| 谁是"用户" | 只有 C 端 | **双边**：玩家体验 + 广告主 ROI（广告主跑掉就没预算了） |
| 关键约束 | 相关性 | **不能打断心流**（游戏是主动沉浸场景，打断成本远高于信息流） |
| 数据特点 | 行为密集、样本多 | **单用户行为少、会话短（中位 4 分钟/次、日 3 次）**，时序信号强（关卡进度、连败/连胜） |
| 冷启动 | 靠内容特征 | 靠**受众/地区/设备**特征，且广告主新素材也需要扶持 |

**你能接的一句话**："我在 OPPO 做应用商店/游戏中心广告时，同时要照顾**广告主 ROAS** 和**用户体验**；游戏里这个矛盾更尖锐，因为一场游戏的沉浸被插屏打断，用户可能直接卸载——**所以游戏广告的护栏指标必须比信息流更严**。"

## 6. HungryStudio 自己的算法语境（面试官一定会聊到）

- **「Block 算法」**：近 **100 条嵌套子规则**实时运行，动态生成个性化关卡难度 → 这是**策略/决策类算法**（可以聊 bandit 做难度自适应：太难→流失，太易→无聊，本质也是探索-利用）
- **JD 里的"个性化出题"** 就是这个方向：给玩家出什么题（难度、类型）→ 与广告时机耦合（**难度曲线决定玩家在哪个点受挫 → 那个点就是激励视频的最佳位置**）→ 这句话说出来是**跨系统思考**的加分项
- **Block AI**：自研玩家行为模拟（深度网络），上线前高密度自动测试，**AI 操作与真人一致率 80%+、上线问题 -50%**
- **实验体系**：2025 年 **10000+ 次 A/B、300+ 并行、成功率 ~5%**；北极星 = **留存 + 时长**
- 他们 VP 公开承认的三个困惑（**主动引用 = 同频**）：①实验数量 vs 分析深度失衡 ②**新鲜感效应**难分辨、观察周期难定 ③核心算法的理解还需加深

**你接实验体系的话术：**
> "你们讲的'新鲜感效应'和观察周期问题，我在腾讯做多目标时踩过：新功能前 3 天的正向往往来自 novelty，我会用**长期实验组 + 分段衰减曲线**判断，同时用 **CUPED**（用实验前数据做协变量）压低方差，让结论更快可信；此外必看 **SRM 检验**——分流不均的时候，指标再好也不能信。"

## 7. 高频追问速答（8 条）

1. **"你怎么优化 eCPM？"** → 拆成三层：**预估准**（pCTR/pCVR 校准，我在 OPPO 把 CTR 偏差从 30%+ 压到 20% 以内、ARPU +1.04%）、**定价准**（底价/影子价格 λ）、**填充够**（多需求源 + 竞价，行业里 bidding 相比单一网络能多拿 15-25% 收入）。
2. **"pCTR 预估不准怎么查？"** → 按**位置/地区/新老用户**分桶看校准曲线（不是看 AUC），偏差集中在某桶就是特征缺失或分布漂移；必要时做分段校准。
3. **"多任务模型为什么能提升？"** → 任务相关性 + 样本空间共享（ESMM 解决 CV 空间缺失、MMoE 用 expert 路由缓解负迁移）；我在腾讯小说主 feeds 从 0 搭建 ESMM/MMoE，点击率 +15.3%、大盘时长 +0.32%。
4. **"广告多了收入高但体验差怎么办？"** → uplift + 护栏指标 + per-user 频控（见第 3 节）。
5. **"激励视频和插屏的算法差异？"** → 激励是**用户选择问题**（提示时机/奖励额度/opt-in 率），插屏是**时机与伤害问题**（uplift）。
6. **"冷启动怎么处理？"** → 新素材给扶持配额 + 快速回传 + 探索流量；我在 OPPO 做过冷启动扶持，**通过率 +15%、广告主 ROAS +8%、新广告曝光 +30%**（通过率 ≈ 你们的 Load Success Rate）。
7. **"全球多地区怎么做？"** → 分地区建模（Tier1/2/3 的 eCPM 差 5-20 倍）+ 分层预算 + 地区独立实验，避免用一个全局模型被高价值地区主导。
8. **"你了解大模型在游戏广告的应用吗？"** → 不要说训练，讲三个落地面：**创意生成/AI 素材**（他们自己投放素材就是 AI 生成趋势）、**内容理解与广告主匹配**、**生成式推荐的语义 ID（SID）方向**（我读过 OneRec/MiniOneRec 的公开工作：4 层效果归因里，NTP 只打平、**RL 奖励模型才是突破天花板的那一步**）。

## 9. 一句话备忘

**框架**（收入=DAU×频次×eCPM/1000）→ **三块技术**（预估校准 / 底价定价 / uplift 频控）→ **两个锚点**（留存+时长是北极星；护栏指标比收入优先）→ **一个同频点**（新鲜感效应与观察周期是他们公开的痛点，你正好有方法）。
