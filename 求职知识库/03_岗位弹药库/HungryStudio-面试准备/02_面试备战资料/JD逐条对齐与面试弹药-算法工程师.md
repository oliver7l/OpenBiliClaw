## 二、JD 逐条对齐

### 职责 1｜竞价广告底价设置 · 广告推荐 · 出广时机优化（平衡底价与加载成功率，提升 eCPM/ARPU/LSR/CTR）

**这是本岗位的绝对主战场，你有现成的两个 eCPM 数字：**

- **百度 MoboMarket 搜索 pCTR 预估（pCTR×price）→ 上线后 eCPM 提升 21%+**（A 级）
  → 讲法：做的是**预估 × 定价**的联合优化，不只是 CTR 模型本身——price 这一项就是"底价"的雏形
- **百度 Mobojoy 广告后台 pCVR 预估（XGBoost，pCVR×price）→ 小流量实验 eCPM +24%**（A 级）
  → 讲法：**同一套"预估×价格"框架迁移到 CVR 链路**，证明你不是只会调模型，而是理解收益公式
- **OPPO 多位置预估校准：CTR 预估偏差 30%+ → 20% 以内，ARPU +1.04%**（B 级）
  → 讲法：多个广告位共用一套预估值必然有位置偏差，做了**分位置校准**——这正是"多广告位负载均衡"的前置问题
- **OPPO 冷启动扶持：冷启动广告通过率 +15%、广告主 ROAS +8%、新广告平均曝光量 +30%**（B 级）
  → 讲法：通过率 ≈ **Load Success Rate**，是很直接的对应；核心矛盾是"新广告没数据→不该给量"与"不给量→永远没数据"，解法是扶持期配额 + 快速回传

**关于"底价 / 出广时机"这两个你**没做过**的子问题——用今天刚研究的行业做法讲思路（这是加分项，不是短板）：**

- **底价设置**：本质是**保留价（floor price）**优化，要在"要价高→填充率掉"和"要价低→eCPM 掉"之间找最优点。行业做法是按广告位/时段/流量质量分段设底价，并用在线实验持续探测；更进一步是把底价当作**影子价格 λ**，让出价被 λ 调节（bid_eff = bid/(1+λ)），λ 由"预算/库存消耗进度"反推——这时底价与 pacing 是同一套数学。
- **出广时机**：本质是**频次控制 + 时机选择**。SMOOTH 型预算节奏（均匀消耗）vs ASAP 型（越快越好）；用 PID/PI 控制器追踪理想消耗曲线 r(t)=G·t/T，误差反馈调速率；难点在**滞回/抖动**（λ 波动大 → 用迟滞或分段平滑把 λ 波动降下来）、**冷启动**（留 10% 流量做探针）。游戏场景还要叠一层"用户体验约束"——激励视频/插屏的时机必须看**负面体验**（退出率、次留），这就是 uplift 的用武之地。
- **一句话收尾**："底价和出广时机在我理解里是一件事的两面——都在做**收益与体验的受约束最优化**，我以前做的 eCPM 优化是收益侧，游戏场景多了体验侧的硬约束。"

### 职责 2｜插屏 / 激励 / banner 广告从请求到点击的全链路优化

- 你有的：OPPO 应用商店 & 游戏中心的广告算法（多位置预估校准、冷启动扶持、端云协同）——**多广告位场景**经验
- 你没有的（**要诚实说**）：激励视频（rewarded video）这个游戏行业主力广告位没做过
- **转译话术**："我在 OPPO 做的是应用商店/游戏中心的多广告位环境，位置差异导致的预估偏差和负载均衡我都处理过；激励视频我在产品侧很熟（作为用户和研究对象），业务上的差异是**它有天然的激励约束——用户看完必定有收益，所以完成率天然高，难点在频次与用户体验的边际**，这一层我需要在你们的实验体系里快速建立认知。"

### 职责 3｜深度学习：多任务学习、多模态、长序列建模、推理加速

- **多任务**：腾讯短内容浮层 **MMoE 多目标 → 互动 +35%、浮层时长 +6.8%、大盘时长 +0.42%**（A 级）；小说主 feeds **ESMM/MMoE 从 0 搭建 → 点击率 +15.3%、大盘时长 +0.32%**（A 级）→ 讲 **expert 路由 / 任务相关性带来的负迁移怎么处理 / 样本空间差异（ESMM 的 CV 空间）**
- **长序列**：图集推荐系统用 **DeepFM+Attention、DSSM、Transformer**（A 级，指标：点击率/时长/消费 PV 提升 20%+）→ 讲用户行为序列建模、DSSM 双塔召回与粗排的取舍
- **推理加速/成本**：OPPO **端云协同 → 云端负载成本 −25%**（B 级）→ 讲**成本视角**而非算子级优化（注意：别说"我做模型压缩/推理加速"，那是 C 级禁区，只讲负载与成本优化）
- ⚠️ **PyTorch 不用说"熟练"**（台账禁区），统一口径："主力 TensorFlow，PyTorch 上手过、能迁移"

### 职责 4｜研究方向：深度学习、**uplift 模型**、pCTR、大模型、模型压缩和推理加速

**JD 里明写 uplift——这在招聘 JD 里很罕见，你今天刚把它啃透，必须打出来：**

- ITE = P(Y|T=1) − P(Y|T=0)；四象限 **Persuadable / Sure Thing / Lost Cause / Do Not Disturb**
- 评估不用 AUC，用 **AUUC / Qini**；因果识别靠随机实验（CIA）+ 离线补 **PSM / IV**
- **中信客群策略建模：累计落地 13 项策略 + 客群分层模型 + DID/PSM 因果归因体系**（B 级）→ 这是你把因果用于**真实业务决策**的证据
- 落到游戏广告：**"哪种时机的插屏广告对体验伤害最小"就是标准的 uplift 问题**——不是预测"会不会点"，而是预测"出这条广告会不会让这个用户明天不来了"。Do Not Disturb 象限的用户，宁可不出广告
- 你在万联易达那场已经讲过一次四象限，这次要加**游戏语境**：激励视频天然是"Sure Thing"（用户主动选择），插屏/banner 才是需要 uplift 的地方

### 任职要求 5｜"极致追求 ABtest，看数闭环，迭代算法"

**这是这家公司的文化内核，不是套话**——Hungry Studio 2025 年跑了 **10,000+ 次 A/B 实验、常年 300+ 并行、平均成功率 ~5%**，自研 Block AI 机器人做上线前模拟（与真人操作一致率 80%+，上线问题 −50%）。

**接法（准备成一段 30 秒的"实验观"）：**
1. 实验设计：**SRM 检验先看分流是否均匀**，再看指标；方差缩减用 **CUPED**（用实验前数据做协变量）
2. **novelty effect**：新功能的初期正向可能来自新鲜感 → 用**长期实验组**或"分段衰减曲线"判断是否可持续（**这正是他们 VP 在专访里主动承认的困惑**，你答上来就是认知同频）
3. **多指标**：主指标 + 护栏指标（留存/时长是他们的北极星，广告收入不能以伤害留存为代价）
4. **看数闭环**：实验不是"跑完看结果"，是"上线 → 护栏监控 → 归因 → 迭代"的循环

### 任职要求 6｜有游戏场景经验优先

**你没有，正面承认 + 给迁移理由（不要装）：**
> "游戏我没有行业经验，但休闲游戏广告变现这个场景我研究过：它的特点是**高频轻决策、单用户 LTV 主要靠广告而非内购、留存和时长是北极星**。这跟我在应用商店/游戏中心做的事在收益结构上很像——都是**用广告收入换用户体验的平衡**，区别是游戏的体验伤害更即时（一局被插屏打断就会退出），容错更低。"

## 四、面试官可能会问的 8 个问题（含答法骨架）

1. **"你怎么理解游戏里的广告推荐和内容推荐的区别？"** → 内容推荐优化"用户想看的"，广告推荐优化"用户与广告主双赢"；游戏里还有第三层：**不能打断心流**（他们产品哲学是"混乱到秩序"的心流体验）。
2. **"底价设高设低你怎么决策？"** → 分段设底价 + 在线实验探测 → 提到影子价格 λ 与 pacing 同源。
3. **"广告出多了收入高但体验差，怎么办？"** → uplift + 护栏指标 + 频次上限，讲四象限。
4. **"你做过的最成功的实验是哪一个？"** → 用 A 级数字：小说主 feeds 从 0 搭建 ESMM/MMoE → 点击率 +15.3%、大盘时长 +0.32%（讲"从 0"的完整链路最有说服力）。
5. **"预估偏差怎么处理？"** → OPPO 多位置校准 30%+→20% 以内，讲分位置/分场景校准方法论。
6. **"多任务模型任务间负迁移怎么办？"** → MMoE expert 路由/门控、任务相关性、ESMM 的样本空间设计。
7. **"你了解哪些大模型在广告/推荐里的应用？"** → 不要吹训练，讲**LLM 做特征/内容理解/创意生成**，以及生成式推荐的方向（OneRec/MiniOneRec 的 SID 与语义 ID、NTP 与 RL 奖励模型）——你刚深读过，能讲出层次。
8. **"为什么来游戏行业？"** → 见第五节。
