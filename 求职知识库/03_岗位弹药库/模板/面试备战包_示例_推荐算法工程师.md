## 2. 定制项目话术

### 一句话定位
"在腾讯微视我负责'推人'推荐系统——给用户推荐**好友（一度/二度关系链）**和**达人（创作者）**，目标是提升关注率带动消费和留存，日均新增关注 190w+ 次。我做的是**召回-排序-重排全链路**，最核心、最经得起追问的是**基于图 Embedding 的召回体系**和**达人/好友混排策略**。"

### 主心骨讲述顺序
1. **召回（最值钱）**：多路召回，向量召回主力——Word2Vec i2i（32 维作者 Emb）+ DeepWalk + LINE + Node2Vec(P/Q 调偏置) + MetaPath2Vec(注入达人 side-info 缓冷启) + DSSM 双塔(规划)。
2. **重排混排**：分层 quota + Thompson Sampling 类目 E&E + `exp(-0.1×count)` 曝光降权 + 类目强间隔打散 + 好友/达人 swap。
3. **排序**：老用户 LR(正负 1:10, FTRL)；新用户规则 `0.7×共同好友+0.3×活跃`。
4. **指标/AB**：分场景分维度指标体系，真实收益可量化。

### 高频追问标准答
- **Q: 为什么不用纯 CF 而搞图 Emb？** → CF 只用到共同关注共现，稀疏达人训不好；图 Emb 把关注/互动/消费多种边建进图，随机游走上下文更丰富，MetaPath 还能注入内容 side-info 对长尾友好。线上验证：Graph Emb 全量后关注页 pCTR **+10.59%**、发现好友页 **+14.22%**。
- **Q: 向量召回怎么 serving？** → 离线训好 Emb 存向量索引，cos 相似度 ANN/TopN 召回；限制同二级类目内算 cos 提准降覆盖，按场景折中。
- **Q: Node2Vec 的 P/Q？** → P 小偏结构等价(同质)、Q 小偏同社区(同质内容)，按业务调。
- **Q: 重排怎么兼顾多样性与CTR？** → 类目 Thompson Sampling 增多样性防越推越窄 + 曝光降权沉老面孔 + 强间隔打散 + quota 控制好友/达人配比。

### 主动要抛的钩子
"我们当时还做了**多目标融合的自动调参**（网格搜 α/β/γ/δ + Flink 实时搜参），以及达人**五维打分体系**做分层扶持——切 45 级达人池后整体关注率 +5.3%。"（引导到多目标/生态建设，都是你能接住的）

## 3. 预测面试题 + 参考答案

### 3.1 技术深挖
**Q1：召回一般怎么做？i2i 和向量召回怎么选？**
- 标准答：召回目标是从百万级池子选千级候选，常用多路（倒排/标签、向量、热度兜底）。i2i 适合有共现行为的 item；向量召回（图 Emb/双塔）能泛化到长尾、跨模态。工业界多路并行后归并。
- 你的素材：微视 13 路并行（关系链+达人 Emb/CF/热度/人群/实时），图 Emb 为主力向量召回。
- 加分：Node2Vec P/Q、MetaPath 注入 side-info、DSSM 双塔 serving。

**Q2：Graph Embedding 你用过哪几种？区别？**
- 标准答：DeepWalk=随机游走+word2vec；LINE=显式一/二阶相似；Node2Vec=加 P/Q 偏置控制 DFS/BFS；MetaPath2Vec=异质图+元路径注入节点语义。
- 你的素材：微视从 Word2Vec→DeepWalk→LINE→Node2Vec→MetaPath2Vec 演进，长尾达人靠 side-info。
- 加分：`图embedding方法的总结.txt` 里有方法栈总括可复习。

**Q3：多目标排序怎么做？MMoE/ESMM 讲讲。**
- 标准答：MMoE 多门控混合专家，每任务独立 gate 解决任务冲突；ESMM 用 CTR×CVR 全空间建模解样本选择偏差。
- 你的素材：腾讯/OPPO 都用过 MMoE；多目标融合自动调参（网格搜权重 + 在线 Flink 搜参，目标覆盖 auc/时长/点击/点赞）。
- 加分：`多目标融合自动调参.txt` 有搜参范围与选择策略代码级细节。

**Q4：冷启动怎么处理？**
- 标准答：探索流量池 + 先验初始化 + UCB/Epsilon-Greedy + 渐进退出。
- 你的素材：微视 MetaPath 把达人 side-info 注入训练缓解向量冷启；OPPO 探索池+贝叶斯平滑。
- 加分：对比学习对齐多模态/行为表征做冷启（课程 part04/09）。

### 3.2 系统设计
**Q5：设计一个推荐系统的召回-排序-重排。**
- 要点：召回（多路 i2i/向量/热度）→ 粗排（轻量双塔压到百级）→ 精排（DeepFM/DIN/MMoE 多目标）→ 重排（MMR/打散/quota/业务规则）。
- 你的素材：直接讲微视真实架构（13 路召回 → LR/规则排序 → Thompson Sampling+降权+打散+swap），比空讲框架有说服力。

### 3.3 场景 / 数据分析
**Q6：CTR 涨了但关注率没涨，怎么分析？**
- 思路：拆 `关注率 = f(曝光,CTR,关注转化,内容匹配)`；可能高 CTR 低关注意愿的达人不该排前；引入关注转化预估或 LTV 导向重排。
- 你的素材：微视用"关注倾向"动态 quota + 曝光降权，正是为纠偏。

**Q7：AB 实验怎么看显著性？跑多久？**
- 标准答：样本量公式 `(Zα/2+Zβ)²(σ₁²+σ₂²)/δ²`；至少 1 个完整周期(7天)覆盖周末；警惕新奇效应。
- 你的素材：微视指标分场景分维度、固化 recommend_id，多策略分批分桶归因。

### 3.4 行为面 / 反问
**Q8：最有挑战的事？**
- 答法：微视 Graph Emb 上线——要平衡准确率与覆盖率（限同二级类目提准降覆盖），且长尾达人训练不充分，靠 MetaPath 注 side-info 解决，最终关注页 pCTR +10.59%。
