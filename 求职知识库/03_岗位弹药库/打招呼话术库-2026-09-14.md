# 打招呼话术库 · 2026-09-14

> 用途：Boss 直聘（及其他平台）与 HR/猎头的开场话术
> **铁律：全部文案只使用 `简历库/00_事实源/童力-事实台账.md` 里的真实数字，一个虚构表述都不许出现。**

---

## 0. 先说结论：问题出在哪

| 现状 | 问题 |
|---|---|
| 当前招呼语：「个人觉得我和贵公司这一岗位很匹配，可以聊聊么？」 | **零信息量**。HR 一天收几十条同样的客套话，无法判断你是谁、做过什么、多资深 |
| PC 端 65 条内置模板 | 全是大白话（"你好""方便聊聊吗"），**没有一条能写进候选人的真实战绩** |
| 自定义文案 | **PC 端没有入口，只能在 Boss APP 里设置** |

**核心逻辑**：招呼语是你唯一一次「不花钱就能让对方 3 秒决定要不要点开你简历」的机会。
10 年经验是你的最大武器——**但当前文案里一个字都没提到**。必须把「年限 + 一段最相关的硬数字」塞进去。

## 1. ⭐ 推荐方案：APP 自定义版（三个方向，选一条设为招呼语）

> 长度控制在 100–120 字：HR 多在手机上扫读，超过 3 行就会被折叠。

### A. 通用版（推荐岗 / 搜索岗 / 不确定方向时用这条）

```
您好，我是童力，10 年搜索推荐算法（腾讯 QQ 看点推荐、百度 Feed 与国际搜索）。
在腾讯负责图集推荐，点击率、时长等核心指标提升 20%+；小说主 feed 点击率 +15.3%；
搜索混排由点击率预估升级为 LTR 方案。看到这个岗位很对口，方便聊聊吗？简历随时可发。
```

**打法**：一句话交代「10 年 + 大厂」，紧跟三个可验证的硬数字，最后给一个轻量行动（方便聊聊）。
**注意**：不要写「贵司这个岗位」以外的具体岗位名——**招呼语是全局生效、不能按岗位定制的**。

### B. 广告 / 商业化岗版

```
您好，我是童力，10 年搜广推算法，近两年在 OPPO 应用商店负责广告算法。
主导多位置 CTR 预估校准，偏差从 30%+ 收敛到 20% 以内，ARPU +1.04%；
冷启扶持让新广告平均曝光 +30%、广告主 ROAS +8%。看到贵司岗位与我的经历很匹配，
方便聊聊吗？简历随时可发。
```

### C. 增长 / 策略 / 因果建模岗版（投滴滴这类岗位时最该用）

```
您好，我是童力，10 年搜广推 + 策略建模。在中信信用卡负责客群分层建模与因果归因
（DID/PSM），累计落地 13 项策略；此前在 OPPO 做广告出价与预算优化，ARPU +1.04%。
看到这个岗位偏因果推断与策略建模，正是我近两年的主线，方便聊聊吗？
```

> ⚠️ 招呼语全局生效，**只能三选一**。若你近期主攻方向变了（如从推荐转向增长/因果），再来找我换一版。
> 建议：现阶段用 **A 通用版**，覆盖面最广。

## 2. PC 端立刻能做的（不用打开 APP）

PC 端只能从 65 条内置模板里挑，**没有一条能写硬实力**，但至少可以从「纯客套」升级为「自信 + 明确诉求」：

| 推荐度 | 模板原文 | 理由 |
|---|---|---|
| ★★★ | 您好，我很有信心胜任这个职位，希望和您深入沟通 | 自信、不卑微，比当前那条更主动 |
| ★★☆ | 刚刚看了您发布的这个职位，我挺感兴趣的，希望您可以看看我的简历[愉快] | 明确引导 HR 看简历（你的简历才是武器） |
| ★☆☆ | 您好，我很有信心胜任这个职位，希望和您深入沟通 | — |

**操作路径**（只读说明，需要我代点也可以）：`zhipin.com/web/geek/notify-set` → 「设置打招呼语」tab → 点一下模板即生效（**没有保存按钮，点一下就已经改掉了**）。

### 2.5 ⭐ 按岗位定制招呼语：已打通（自动化）

Boss 产品层面招呼语是**账号级全局一条**（APP 也只能设一条），没有「按岗位绑定」功能。但可以用自动化实现等效的「按岗位定制」：

**流程**：投 A 岗前 → 把招呼语 set 成 A 岗定制文案 → 点「立即沟通」→ 投 B 岗前再换成 B 岗文案。

**工具**：`boss-zhipin-jobs/scripts/boss_greeting.py`
- `python3 boss_greeting.py set "文案"` —— 写入自定义招呼语（≤100 字，接口校验 max:100）
- `python3 boss_greeting.py get` —— 读当前生效招呼语
- `python3 boss_greeting.py get-tpl` —— 列出 90 条内置模板 id（备用回退）
- `python3 boss_greeting.py set-tpl 116` —— 切回某条模板

**技术要点**（实测 2026-09-14）：接口 `POST /wapi/zpchat/greeting/custom/saveV2`，body `templateId=&customType=2&content=<文案>`；缺 `zp_token`(=cookie `bst`) / `token`(=window._PAGE.token 首段) / `traceId` / `X-Requested-With` 任何一个头 → `code 121 请求不合法`。写入后立即全局生效，UI 设置页会同步显示。

**定制文案模板**（写岗位定制版时套用，≤100 字，严格遵守第 7 节纪律）：

> 您好，我是童力，10年搜广推算法（西交硕士，腾讯看点推荐/百度Feed与国际搜索）。看到贵司【岗位方向】的机会很对口，我的【相关经历一句话】或可直接复用，方便聊聊吗？

- 【岗位方向】按岗位填：如「国际出行补贴算法」「出海搜索」「信息流推荐」
- 【相关经历一句话】从第 3 节台账战绩句里挑最对口的一条，不新造数字
- 内置模板支持 `${position}` 占位符（发送时自动替换为对方职位名）；**自定义文案是否支持该占位符未实测**，定制版直接写死岗位方向即可（反正每次投递前都会重新 set）

## 3. ⭐⭐ 最关键的一步：沟通建立后的第一条跟进

**现实是**：招呼语发出去后，**大部分 HR 不会回复**——因为招呼语是群发模板，没有区分度。
所以真正决定成败的是**你主动补发的第一条消息**（这条 PC 端就能发，可以自定义）。

### 跟进模板（把「__」处替换成与该岗位最相关的一条战绩）

```
您好，补充一下我的背景，方便您判断匹配度：

10 年搜索推荐广告算法：腾讯 QQ 看点（推荐）→ 百度 Feed / 国际搜索 → OPPO 应用商店
（广告算法）→ 中信信用卡（客群建模与因果归因）。

与这个岗位最相关的是：__
```

**「__」按岗位选填（全部有出处，任选一条，不要堆砌）**：

| 岗位方向 | 填这句 |
|---|---|
| 推荐 / 信息流 | 在腾讯负责图集推荐系统，点击率、时长、消费 PV 等核心指标提升 20%+ |
| 推荐 / 多目标 | 短内容浮层用 MMoE 做多目标，互动 +35%、大盘时长 +0.42%；小说主 feed 点击率 +15.3% |
| 搜索 | 百度 MoboMarket 搜索 CTR 预估（pCTR×price），上线后 eCPM 提升 21%+ |
| 搜索 / 相关性 | 腾讯搜索混排由点击率预估改进为 LTR 方案，解决时效性与权威性 badcase |
| 广告 / 商业化 | OPPO 多位置 CTR 预估校准，偏差从 30%+ 收敛到 20% 以内，ARPU +1.04% |
| 广告 / 冷启与生态 | OPPO 冷启扶持：新广告通过率 +15%、广告主 ROAS +8%、新广告平均曝光 +30% |
| 增长 / 因果 / 策略 | 中信客群分层模型与 DID/PSM 因果归因体系，累计落地 13 项策略 |
| 效率 / 成本 | OPPO 端云协同策略，云端负载成本 −25% |

结尾一句（按需）：
```
附件简历一并发您，若方便想约个时间简单沟通，谢谢。
```

## 5. 找前同事内推的请求话术（转化率远高于海投）

```
XX 好，好久没联系，打扰一下。我最近在看机会，看到 XX 公司的「XX 岗」（链接），
和我这几年做的搜推/广告算法挺对口的。方便的话帮我内推一下？简历我发你，
另外需要我补充什么信息（比如内推系统要填的字段）你随时说，麻烦你了。
```

**要点**：附链接 + 一句为什么对口 + 主动提出「配合补齐内推系统字段」（降低对方操作成本）。
优先盘：**腾讯 / 百度 / OPPO 前同事**，尤其**阿里妈妈**与 **SHEIN**——这两家内推与直投的进面率差距明显。

## 7. 写招呼语的 5 条纪律（避免又写出污染）

1. **只写台账里的数字**——「SCI 2 篇 / 日活 1.2 亿 / CTR +12% / 强化学习优化混排 / 带 3 人小组」一律不得出现。
2. **一个数字胜过三个形容词**：写「核心指标 +20%」，不写「能力突出、经验丰富」。
3. **不写"贵公司是行业翘楚"这类空话**，HR 比你更清楚自家公司。
4. ~~别在招呼语里写具体岗位名（它是全局模板，会串岗）~~ → **已按岗位定制化**（2.5 节）：每次投递前 set 对应岗位方向的定制文案，写岗位名反而是加分项；只有手动 forget 换文案时才需要注意串岗问题。
5. **不卑不亢**：不说「希望得到垂青」，说「想和您聊聊匹配度」。

## 8. 四个强推岗位的定制招呼语（2026-09-14 定稿，待用户确认后随投随换）

> 每条 ≤100 字、已过 C 级禁用词扫描（SCI/1.2亿/CTR+12%/DIN/强化学习/带人 均零命中），战绩句全部出自第 3 节台账。

### 8.1 滴滴 · 国际出行智能司机补贴算法 Leader（北京，55-80K·15薪）94字
> 您好，我是童力，10年搜广推策略算法（西交硕士，百度国际化搜索/中信信用卡）。做过客群分层与DID/PSM因果归因体系，累计落地13项策略，与贵司补贴ROI/因果建模方向对口，方便聊聊吗？

- 打法：JD 核心是因果推断/弹性建模/补贴 ROI 归因 → 只打中信因果牌 + 百度国际化（多国市场）牌；**不提**运筹优化和 RL（JD 有但不是硬门槛，别主动引）。

### 8.2 传音控股 · 算法工程师/专家（深圳，50-80K·15薪）84字
> 您好，我是童力，10年搜广推算法（西交硕士，百度国际搜索/OPPO广告/中信因果归因）。熟悉多国市场出海场景与营销效果归因闭环，与贵司搜广推与营销方向对口，方便聊聊吗？

- 打法：JD 主打出海多国多市场 + 搜广推 + 营销转化 → 百度国际化（出海同源）+ OPPO 广告生态 + 因果归因三线并打。

### 8.3 客路 Klook · 高级搜索算法工程师（深圳，40-70K·14薪）87字
> 您好，我是童力，10年搜索推荐算法（西交硕士，百度应用商店搜索/腾讯搜索混排）。做过搜索CTR预估与相关性排序，上线eCPM+21%，与贵司搜索召回排序方向对口，方便聊聊吗？

- 打法：JD 要搜索召回/排序 + CTR/CVR → 用百度搜索 CTR 预估（eCPM+21%，pCTR×price 出自台账）+ 腾讯搜索混排 LTR；**不提** DSSM/Graph Embedding（简历里没有的别送上门）。

### 8.4 某大型知名互联网公司 · 推荐算法专家（北京，55-85K·16薪）90字
> 您好，我是童力，10年推荐算法（西交硕士，腾讯QQ看点推荐/百度Feed）。多目标MMoE互动+35%、小说feed点击率+15.3%，召回排序重排全链路，与岗位对口，方便聊聊吗？

- 打法：标准推荐全链路 → 图集/MMoE/小说 feed 三条硬数字；**面试注意**：JD 提 Go 和 DIN，Go 没写过别硬说、DIN 没做过不要认（能力红线）。
