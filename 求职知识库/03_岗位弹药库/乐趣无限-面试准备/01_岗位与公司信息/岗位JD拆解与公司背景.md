## 二、JD逐句拆解（面试官想听什么）

### 【岗位职责】

**1. 负责公司海外直播场景推荐系统优化，结合业务需求完成数据分析、优化设计、算法落地、效果跟进、持续优化，提升用户体验和业务指标**

- 关键词拆解：
  - **海外直播场景** → 这是乐趣无限的核心业务（4Fun 语音直播/短视频/社交，印度/中东/东南亚市场）
  - **推荐系统优化** → 不是从0搭建，是已有系统持续优化，要体现"增量思维"
  - **数据分析 → 优化设计 → 算法落地 → 效果跟进 → 持续优化** → 完整闭环，对应你的项目STAR闭环
  - **提升用户体验和业务指标** → 要同时讲体验和指标，不能只追指标

- 面试应对：准备一个"完整闭环"项目（痛点→方案→落地→效果→迭代），最好带"海外/多语言/冷启动"元素

**2. 独立负责公司产品推荐业务的持续迭代**

- 关键词：**独立负责** → 强调你能独当一面、owner意识
- 面试应对：讲清楚你在项目中的独立贡献，不只说"参与了"

### 【任职要求】

**1. 统招本科及以上，1年+推荐算法经验（考虑优秀26届毕业生）**

- 你10年经验完全溢出，注意**别显得 overqualified 有架子**，要体现"我经验丰富但愿意做事"

**2. 精通推荐系统架构（自研或熟练使用业内框架），掌握召回、粗排、精排、重排、曝光去重、流量调控相关算法**

- **召回/粗排/精排/重排** → 你的全链路弹药（见02_面试备战资料）
- **曝光去重** → 重点准备！推荐系统防重复推荐（历史曝光过滤、相似内容去重）
- **流量调控** → 保量机制、流量分配、冷启动扶持（你的弹药里有保量一期/二期）

**3. 精通深度召回和精排算法原理，具备建模、调优、服务部署经验**

- **深度召回** → DSSM双塔、TDM、图Embedding、行为Embedding（你的02_召回弹药）
- **精排** → 多目标（DEN/MMoE/ESMM）、特征体系、位置校准（你的03_排序弹药）
- **服务部署** → 模型上线、Serving、pipeline（你的01_系统架构弹药）

**4. 精通深度学习框架：Tensorflow、Pytorch、Easy-Rec**

- TF/Pytorch 你都有经验（腾讯用TF，OPPO用Pytorch/TF）
- **Easy-Rec** → 阿里开源的推荐算法库，需要提前了解！面试前查一下它的定位（基于TensorFlow的推荐系统工具，支持DSSM/MMoE/ESMM等常见模型，多目标、召回排序全链路）
- 面试话术：如果被问到，说"我在腾讯/OPPO主要用TF和Pytorch自研链路，Easy-Rec有了解，它是阿里开源的推荐工具库，模块化封装了召回排序和多目标模型，逻辑和我们自研的类似，可以快速上手"

**5. 熟悉机器学习算法基础，理解原理并应用于实际业务，具有数据分析和实验思维**

- 强调：原理理解 + 业务应用 + AB实验思维（你的统计/AB弹药）
- 面试应对：准备AB实验题（样本量/显著性/SRM/辛普森悖论）

**6. 熟悉Java、Python、G...（截图截断，推测是Go）**

- 你Python精通，Java/Go可提"能写能读"

## 五、与「算法专家」岗（搜索推荐算法）区分

乐趣无限同时招两个算法岗：
1. **推荐算法工程师**（本次投递，直播/社交推荐）→ 重推荐全链路
2. **算法专家**（搜索推荐，图文feed流+搜索个性化）→ 重多模态理解（ResNet/Bert/Seq2Seq）、搜索

面试前确认自己投的是推荐算法工程师岗（从你发的截图看是推荐算法工程师，25-45K）。若被问"为什么投推荐不投搜索"：推荐是我的主战场（10年），搜索相关技术（query处理、多模态）我有基础但更想深耕推荐链路。
