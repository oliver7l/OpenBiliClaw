# 拼多多 · 二面预测题库（基于一面情报推演）

> 依据：2026-09-11 一面信息——团队约 20 人（精排价值建模含 LTV 3-4 人 / **重排生成 4-5 人** / 全链路排查 2-3 人 / 新场景发券 3-5 人）；面试官自报"负责精排价值（含 LTV）、重排生成、全链路"；一面已问发券场景题 + Coding 数正方形 + 实验管理。
> 用法：按优先级准备——A 组（重排生成）> B 组（精排价值/LTV）> C 组（发券追问）> D/E/F 组。

## 一句话核心

**二面大概率围绕"重排生成 + 精排价值（LTV）"两个团队主力方向深挖**——一面只聊了你熟悉的架构，没碰团队自己在做的生成式重排和购买链路建模；这两块恰好是你的 Gap，也是最可能翻车的地方。

## A 组：重排 / 重排生成（最高概率，团队 4-5 人主力 + 你的 Gap）

### A1. 精排和重排的本质区别？为什么精排打分不能直接排？
**答**：精排是**单点预估**（逐 item 打分，只保证单个 item 的预估准），重排是**列表级优化**——item 间有交互（同质扎堆、配额、广告位），列表收益 ≠ 单点收益之和。精排打分高的放一起可能全是同类目，反而伤整体。重排要处理：多样性、去重、商家/类目配额、价格带分布、广告插入、探索流量。

### A2. 生成式重排（你们在做的"重排生成"）是什么？和传统重排的区别？⭐⭐⭐
**答**：传统重排（MMR/DPP/ListNet）是"打分-约束"范式——先打分再做多样性/规则调整。**生成式重排**把列表生成当成**序列生成任务**：用自回归方式逐个生成 item 序列（类似 NLG），模型直接以整个列表为输出目标优化，能天然建模 item 间依赖和全局收益。
- 业界参照：生成式推荐（Climber/HSTU/GR 语义 ID）、列表生成模型（ListGPT 思路）
- 优势：端到端学列表级目标，比手写规则/DPP 更灵活
- **难点（面试官一面提过）**：① 线上耗时——自回归逐个生成，序列长则延迟高，需高效解码（缓存/并行/蒸馏/两阶段）；② 样本不丰富——训练样本是打散后的结果，分布偏"好样本"，存在选择偏差
- 加分：坦诚"这块我没直接做过，但精排打分和列表约束我熟，从打分-约束到序列生成的转变我理解，落地我会先从两阶段（规则重排保底 + 生成式模型小流量）开始"

### A3. 重排样本不丰富（训练数据都是打散后的好结果），怎么训？⭐⭐
**答**：三个手段：① 曝光日志含正负样本，别只用点击/转化后的；② 样本权重/重要性采样校正打散带来的偏差（曝光偏差）；③ 用强化学习框架（离线策略评估，如 off-policy correction / CQL）学"打散策略下也能泛化的列表价值函数"。
**加分**：把 IPS/DR 去偏思路迁移过来——这和曝光偏差是同一类问题。

### A4. 线上重排的耗时约束怎么处理？⭐⭐
**答**：分层降耗——① 大部分流量用规则/轻量重排（打散、配额、去重，毫秒级）；② 小部分高价值流量上生成式/模型重排；③ 模型蒸馏 + 特征/中间结果缓存；④ 自回归生成用 beam/贪心截断 + 提前终止。核心是"算力花在刀刃上"——头部流量全量算，长尾用便宜方案。

### A5. 电商重排有哪些业务硬约束？
**答**：商家配额（别一家占满）、类目/价格带分布（别整屏一个价位）、库存履约、广告位固定插入、频控/去重、新品扶持。重排本质是在这些约束下的**约束优化**。

### A6. 广告和自然流量怎么混排？
**答**：广告位固定比例 + 按 eCPM 竞价；自然位和广告位统一打分但广告加约束（密度动态调：用户负反馈多就降广告）。**你的 OPPO 强项，主动抛**。

## B 组：精排价值 / 多目标 / LTV（团队 3-4 人方向）

### B1. 多目标（CTR/CVR/GMV/LTV）权重怎么定？目标冲突怎么办？⭐⭐
**答**：加权融分（pCTR^a×pCVR^b×price^c）→ 多任务模型（MMoE/PLE 分开学）→ 约束优化（GMV 最大化约束 CTR 不降）。权重调法：分层/分场景看（高客单 vs 低客单），业务护栏指标防目标崩坏。
**加分**：OPPO 把 LTV 接入排序就是短期点击 vs 长期价值的多目标平衡——**直接锚定**。

### B2. 购买决策链路建模（浏览→加购→下单）怎么做？⭐⭐
**答**：漏斗多阶段目标——曝光→点击→加购→下单，用链式建模（ESMM 思想扩展：pOrder = pClick × pCart|Click × pOrder|Cart），多阶段共享底层 + 各阶段头。样本按漏斗层级构造，用曝光空间训练避免选择偏差。
**加分**：ESMM 是链式建模的底子，你做过，讲"从 CTR/CVR 两段扩展到三段漏斗"。

### B3. LTV 怎么进排序？和短期指标怎么权衡？⭐⭐
**答**：LTV 是长期价值（复购+生命周期），短期指标（点击/转化）直接可优化。方案：① 分层（新客看 LTV、老客看短期转化+复购倾向）；② 多目标里给 LTV 独立塔，用长窗口样本；③ 约束优化——保短期 GMV 的同时抬长期 LTV。
**加分**：OPPO 的 LTV 接入排序经验（短期点击 vs 长期价值的平衡）。

### B4. 款估计/商品价值估计是什么？可能怎么考？
**答**：拼多多"款"≈商品价值/货款——估计商品的生命周期价值或当前款的价值，用于排序和流量分配。思路和 LTV 类似：商品维度长期价值模型（价格带、销量趋势、复购属性），和用户维度兴趣结合进排序。

## C 组：发券 / 增量建模（一面场景题追问）

### C1. 发券的增量怎么严格验证？（uplift 细节）
**答**：发券/不发券对照（同用户随机分桶）→ uplift 建模（T-learner/DR-learner）预估增量转化 → 只给高增量用户发（省钱提效）。**中信的因果/PSM 经验可讲**。

### C2. 券把 CTR 搞虚高了怎么办？（模型被扭曲）
**答**：发券样本进模型但要让模型学到"发券后的真实 CVR"，或把券特征（有无券/券额）显式建模，预估时分开预测"有券/无券"两套概率，用增量排序。

### C3. 券对长期价值（复购/价格体系）的影响？
**答**：后验看复购率、客单价、比价行为；防止"薅羊毛"用户（只领券不回购）；价格体系保护（券后价不低于底线价，防击穿定价）。

## D 组：项目深挖（拼多多爱刨，准备好 3 数字+1 故障）

- **D1 OPPO 多位置预估**：怎么消位置偏差？→ PAL（训练加位置特征预测时去掉）/ 多位置预估；线上全量计算量暴涨 → 位置合并（12/345）+ 头部流量全量 + 整体 eCPM beam search。**数字：偏差 30%→20%、ARPU+1.04%、云端成本-25%**
- **D2 腾讯 ESMM**：SSB 怎么解？→ pCVR=pCTCVR/pCTR 链式、曝光空间训练。**数字：点击+24.14%、人均时长+24.28%**
- **D3 冷启动**：新商品 → 类目/价格先验 + 探索流量池 + 贝叶斯平滑渐进退出
- **D4 故障故事**：OPPO 校准偏差排查（最稳妥的 1 个故障案例）

## E 组：全链路 / 系统

- **E1 搜索排序规划**：一面面试官提到"搜索不把销量最高直接排最前，按约束做排序规划"——准备：搜索排序 = 相关性 + 业务目标（销量/转化/供给），用约束排序（多目标 + 配额 + 时效）而不是纯销量

## G 组：搜广推全局（交叉技术面专属，⭐⭐⭐）

> 一面是直系 leader 看业务匹配；交叉面换人看**技术底线 + 全局视角**——问题不再局限推荐，而是搜/广/推整套体系。下面 8 题按优先级排。

### G1. 搜索排序 vs 推荐排序的本质区别？搜索排序怎么设计？⭐⭐⭐
**答**：推荐是"无明确意图，推用户可能喜欢的"；搜索是"有明确 Query，命中意图优先"。区别：
- 搜索**相关性是第一约束**（Query-文档匹配），推荐是兴趣匹配
- 搜索用户目的性强、转化率天然更高，排序要"相关性 × 业务目标"（销量/转化/供给）
- 搜索排序链路：Query 理解（分词/改写/意图）→ 召回（BM25+向量）→ 精排（相关性+CTR/CVR 多目标）→ 约束重排（销量/时效/配额——**不是销量最高就排最前**）
**加分**：一面面试官亲口提"搜索不把销量最高直接排前面，按约束做排序规划"——主动引这句话。

### G2. 广告和自然流量混排怎么设计？⭐（你强项，主动抛）
**答**：分三层：① 广告位配额（固定比例如 1/5 或按密度动态调）；② 统一打分 + 广告加约束（eCPM 竞价，自然位用业务分，广告位用 eCPM×质量分）；③ 混排后校验（广告对自然流量的挤出效应、用户负反馈监控）。**直接讲 OPPO oCPX 全链路 + 广告密度动态调**。

### G3. 电商全链路系统设计：从用户进来到看到列表，讲完整架构 ⭐⭐⭐
**答**：五层漏斗——
1. 数据层：行为日志→样本 pipeline→特征平台（实时特征 + 离线特征一致性）
2. 召回：多路（行为 I2I/向量双塔/类目热门/新品），通道配额 + 去重，百万→千
3. 粗排：轻量模型（双塔/浅 DNN）千→百
4. 精排：多目标深度模型（CTR/CVR/GMV/LTV），百→几十
5. 重排：列表级（多样性/配额/价格带/广告位/库存）+ 探索流量
**加分**：每层讲"算力-精度"权衡（粗排为什么存在、头部流量全量算），落延迟预算。

### G4. 冷启动在搜广推三场景分别怎么做？⭐
**答**：推荐（新品）→ 类目/价格先验 + 探索池；搜索（新 Query/新文档）→ 语义向量 + 文本匹配兜底；广告（新广告）→ 预估偏差大，贝叶斯平滑 + 冷启动出价保护。**OPPO 冷启动机制 + 万声 3%→40% 案例可引**。

### G5. 多场景（主站/买菜/不同端）统一模型还是独立模型？⭐⭐
**答**：统一 + 分场景适配——共享底层（用户/物品表征、共性特征）+ 场景塔/场景 gate（MMoE 变体、场景 embedding），数据多的场景为主、数据少的迁移。理由：独立模型重复建设 + 冷场景没数据；完全统一则场景差异（流量/目标）被抹平。**你腾讯多品类统一模型的经验直接对口**。

### G6. 大模型对搜广推的影响？你会怎么用？⭐⭐
**答**：三层面：① 特征层：LLM/多模态表征（文本/图像 embedding 进模型，缓解冷启动）；② 排序层：生成式推荐（Climber/HSTU）重构召回/排序；③ 交互层：对话式推荐（自然语言表达意图）。落地限制：延迟/成本，先离线生成表征 + 小流量。
**加分**：一面聊过大模型对信息流产品的冲击（你提过护城河判断）——延续这个话题展示思考深度。

### G7. 样本/特征工程：训练和线上不一致怎么排查？⭐
**答**：特征穿越（用了未来信息）、特征延迟（实时特征没到）、样本分布漂移。排查：特征一致性校验（训练/线上快照对比）、延迟监控、样本回放（用线上实时日志重训对比指标）。

### G8. AB 实验体系：多实验同时跑怎么保证可信？⭐
**答**：分层正交（Layered/重叠实验）、流量分层互不干扰、实验组间正交校验；关注网络效应/SUTVA；护栏指标（防实验 A 伤了留存换 B 的收益）。**一面聊过"拼多多流量充足、分层实验"——延续**。
