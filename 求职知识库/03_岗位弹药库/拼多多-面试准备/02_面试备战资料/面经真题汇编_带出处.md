## 2. 笔试真题（机考，4 题制）

### 2.1 2026-08-23 机考 `[S10]`
1. 展廊灯带后缀点亮 —— 贪心
2. 护栏补强 —— 贪心 + 二分
3. 驿站补给最短耗时 —— Dijkstra
4. 和差方程最少标定 —— 并查集

### 2.2 2025-09-14 秋招笔试（改编版）`[S9]`
1. 密码学家的挑战 —— 字符串拼接规律（奇偶位置提取）
2. 项目经理的难题 —— 带截止日期的调度优化（贪心 + 最大堆）
3. 魔法师的能量平衡 —— 子段和 = 长度 → 前缀和 + 哈希（key = S[i] − i）
4. 考试策略大师 —— 贪心 + 数论（最小公倍数 / 净贡献位置）

### 2.3 2024-08-25 笔试 `[S9]`
1. 删边产生最大联通分量 —— 边权排序贪心
2. 奇偶相加 —— 贪心（最先变奇数的优先）
3. 从右往左交换模拟 —— 模拟 + 前缀记录
4. 首尾字符能否相接 + 最大 01 区间 —— 模拟

### 2.4 实习笔试 `[S9]`
- T1 字符串解码模拟（`11a88b2c` → 11 个 a、88 个 b、2 个 c）
- T2 数 1 的个数（两两配对贪心）
- T3 三元组满意度 + 成本最小（二维/三维 DP，可滚动数组优化）
- T4 求 n 个数的中位数与平均数（**双堆** O(n log n)，树状数组暴力会 TLE）

### 2.5 多模态岗附加笔试 `[S1]`
1. 推箱子模拟（给定箱子/人位置 + 操作序列，判断能否推到目标）
2. 区间 [L,R] 内所有为 3 的倍数的子串
3. 向右看人数（单调栈；楼主只过 60%，边界没处理好）
4. 字符串替换最小字典序（题面极长）

**规律**：拼多多笔试 4 题、难度中上，**高频考点 = 贪心（几乎每场都有）+ 模拟 + 前缀和/哈希 + 图论（Dijkstra/并查集）**。反而是 DP 出现得少但一出现就偏难（T3 那种多维 DP）。

## 3. 八股真题（按方向归类）

### 3.1 推荐 / 搜广推基础 `[S4]`
- 去偏：位置偏差（**PAL**）、曝光偏差（**IPS**）、流行度偏差（**因果 embedding**）—— 三者来源与解法差异
- Wide&Deep / DeepFM / DCN / DIN 各自解决什么问题
- 双塔召回的优缺点；**为什么 serving 阶段不放交叉特征**
- 负采样 + in-batch negative + **logQ correction**
- **AUC vs GAUC**，为什么推荐场景看 GAUC

### 3.2 因果推断 / uplift / 多目标 `[S4 二面]`
- 智能补贴为什么用 **uplift 而不是 CTR**
- 只有观察数据怎么办（PSM / DR-learner）
- **T-learner / S-learner / X-learner / DR-learner** 的区别
- ESMM 如何解决 CVR 的样本选择偏差（SSB）
- **MMoE vs PLE**，什么时候发生 negative transfer
- **Pacing 算法**（PID / 线性规划）预算平滑

### 3.3 大模型 `[S2 一面/二面、S6 二面]`
- **RLHF / RLAIF / DPO** 原理与优劣对比；电商客服/导购场景适合哪种对齐
- SFT 的核心流程、训练目标、数据集构建原则；**过拟合 / 知识遗忘**怎么解决
- 训练日志与指标监控、**如何判断收敛**、训练崩溃如何快速定位
- 大模型**幻觉**成因；电商商品信息生成场景的缓解方案
- Transformer 架构、Encoder/Decoder 差异、自注意力计算过程
- **self-attention 为什么除以 √d**；时间复杂度是多少；有哪些降复杂度方案
- 主流大模型（GPT / Qwen / DeepSeek）架构差异；**Decoder-only 的优势**
- 分布式训练：数据并行 / 张量并行 / 流水线并行原理与适用场景
- **Megatron-LM 如何实现 Tensor Parallel**；**ZeRO 三个阶段**分别解决什么
- 只有 **8 张 A100 怎么训 30B 模型**
- **FlashAttention 为什么更快**；**LoRA 为什么能减参**、rank r 的影响
- 梯度消失 / 梯度爆炸的成因与解法；ReLU vs GLU 区别；显存优化方案
- 长上下文（Long Context）主流方案；电商长文本场景怎么优化

### 3.4 CV / 多模态 `[S1]`
- backbone 设计有什么讲究；**为什么 RepVGG 不适合做量化**、如何改进
- 目标检测发展史（传统 → YOLO/RCNN → anchor-free/based → DETR → CLIP 后的改进）
- **CLIP 原理与缺点**；CLIP 一次训练的 batch（图文配对）应该越大还是越小（从方差/区分度分析）
- **MoCo 原理**；MoCo 如何增大 batch（记录 encoded code book、滑动平均更新）
- 标签分配有哪些工作；DETR 怎么做；**二分图匹配（Sinkhorn 原理）**；NMS-free 还有哪些策略
- 优化器：**高斯牛顿 vs LM** 的区别；LM 可以从哪些视角看；SGD/Adam 与 momentum 原理
- 为什么深度学习不容易陷入局部最小
- 多模态训练中**图文不匹配、模态信息失衡**怎么解决

### 3.5 风控 / 数据分析 `[S5]`
- MySQL 主键与索引怎么设、为什么、底层数据结构
- XGBoost；怎么缓解过拟合；**KS / AUC**
- 特征有效性判断（**IV / PSI**）
- A/B test：DAG 图；**分层抽样为什么能减小方差（数学原理）**
- **DML 原理**：ATE 估计量怎么才算 **Neyman 正交**，背后的直觉
- 牛顿法 / 拟牛顿法；XGBoost 用哪种优化（二阶泰勒展开，本质牛顿法）

### 3.6 传统 ML / 框架 `[S12、S11]`
- **手推 LR**：从 logit 定义推到损失函数再到梯度
- **L1 正则化损失函数如何求解**
- **LSTM 公式**
- LR / 随机森林 / XGBoost 的区别与细节
- `tensor.detach()` 与 `tensor.item()` 的区别与使用场景
- 自监督 / 半监督 / 无监督 / 自回归之间有关系吗
