## 一、岗位职责（4 条）

1. **负责电商推荐场景排序、CTR/CVR 模型、重排等算法模型优化**
   - 核心：推荐排序模型 + CTR/CVR 预估 + 重排（rerank）
2. **负责提升推荐场景的各项业务指标，包括 GMV、广告收入等**
   - 核心：业务指标导向（GMV 转化、广告变现），不是纯技术指标
3. **挖掘和分析用户行为数据，进行用户长短期兴趣建模，以及潜在兴趣预测，提升推荐的精准性**
   - 核心：用户行为挖掘、长短期兴趣（long/short-term interest）、潜在兴趣（exploration）
4. **结合电商的业务特性，进行模型和算法创新，打造业界领先的推荐算法和系统**
   - 核心：电商场景特性（价格/促销/库存/履约）、算法创新

## 二、任职要求（4 条 + 2 加分项）

### 必须
1. 计算机或软件工程相关专业，有机器学习和模式识别相关经验
2. **在推荐、搜索、广告等大规模分发系统中有三年以上项目经验**
3. 熟悉 Linux，熟练使用 Java/C++/Python 任一，有 TF/Hadoop/Spark 等大数据和机器学习平台经验
4. 较好的数理基础和逻辑思维，热爱算法，主动性和沟通协作能力

### 加分
1. 有个性化推荐、广告、信息检索、NLP、机器学习等相关领域研究或项目实践
2. 在 KDD/NeurIPS/WWW/SIGIR/WSDM/ICML/IJCAI/AAAI/RecSys 发过论文，或有数据挖掘/ML 竞赛经历

## 三、核心考点提取（面试大概率被问）

| 考点类别 | 具体方向 |
|---|---|
| **推荐排序模型** | LR/GBDT/DNN/Wide&Deep/DeepFM/DIN/DIEN/DCN、特征工程、稀疏特征、embedding |
| **CTR/CVR 预估** | 样本选择偏差（SSB）、延迟反馈（delayed feedback）、CVR 建模（ESMM/ESM2）、多任务 |
| **重排（Rerank）** | 列表级排序、多样性、MMR、DPP、业务约束（价格/库存/促销）、生成式重排 |
| **用户兴趣建模** | 长短期兴趣分离、序列建模（Transformer/GRU）、兴趣提取（DIN attention）、潜在兴趣探索（exploration vs exploitation） |
| **电商业务指标** | GMV、CTR、CVR、客单价、复购、广告收入（eCPM/ROAS）、多目标权衡 |
| **多目标优化** | 多任务学习（MMoE/PLE/ESMM）、多目标融合（加权/Pareto）、业务约束下的优化 |
| **大数据工程** | Spark/Hadoop 离线训练、TF 在线推理、特征平台、样本 pipeline |
| **算法手撕** | 推荐相关算法推导、排序/哈希、动态规划、SQL（用户行为分析） |
| **场景理解** | 电商推荐 vs 广告/内容推荐的差异、价格敏感性、促销周期、库存履约约束 |

### 核心 Gap 与应对
1. **电商推荐场景经验**：最大 gap。应对 = 用"广告 CTR/CVR + 腾讯推荐"的方法论迁移到电商，讲清电商推荐的特殊性（价格敏感、促销周期、库存履约、GMV 多目标），展示快速学习能力。
2. **重排（rerank）**：需补基础概念和工业实践。
3. **Java/C++ 熟练度**：如实说明，强调 Python+Spark/TF 工程能力，表达学习意愿。
