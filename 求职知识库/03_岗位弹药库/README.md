## 新建岗位流程（标准动作）

当用户投递新岗位时：
1. 新建目录：`{公司}-{岗位}-面试准备/`
2. 归档 JD 截图/公司介绍到 `01_岗位与公司信息/`
3. 产出《公司背景与JD拆解》《面试攻略》到 `02_面试备战资料/`
4. 产出《预测题库》《速记卡》到 `03_速成包/`
5. 涉及方向的新知识，沉淀到 `02_方向知识库/` 对应方向

---

## 岗位 → 方向 → 原始库 联动

面试某岗位卡壳时，按此下钻：
- 岗位题库 → `03_岗位弹药库/该岗位`
- 方法论 → `02_方向知识库/对应方向`
- 原始细节 → `01_原始资料库/解码文本/` 或 `01_原始资料库/工作资料_腾讯/`
