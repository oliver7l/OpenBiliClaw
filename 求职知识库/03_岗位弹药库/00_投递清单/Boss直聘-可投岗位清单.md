## 🔧 技术备注（可复现）

### 数据通道
- 搜索页：`https://www.zhipin.com/web/geek/jobs?query=<关键词>&city=<城市码>`
- 接口：`GET /wapi/zpgeek/search/joblist.json?scene=1&query=<词>&city=<码>&page=<页>&pageSize=30`
  - 在已登录页面内 `fetch(url, {credentials:'include'})` 调用即可
  - **返回的 `salaryDesc` 是明文**（如 `"50-80K"`），字段还有 `brandName`、`jobExperience`、`jobDegree`、`skills`、`welfareList`、`brandScaleName`、`encryptJobId` 等
- 城市码：深圳 `101280600`、北京 `101010100`、上海 `101020100`、广州 `101280100`
- 详情页：`https://www.zhipin.com/job_detail/<encryptJobId>.html`

### 薪资字体反爬（已破解）
搜索页 DOM 里薪资用自定义字体 `kanzhun-mix` 渲染，文本是 **Unicode 私有区码位**，
例如 `\ue036\ue031-\ue039\ue031K` 实际是 `50-80K`。

映射规律（用同批岗位的 API 明文交叉验证，6/6 命中）：

```
数字 = 码位 - 0xE031
'0'=U+E031  '1'=U+E032  '2'=U+E033  '3'=U+E034  '4'=U+E035
'5'=U+E036  '6'=U+E037  '7'=U+E038  '8'=U+E039  '9'=U+E03A
```

### 风控要点（重要，下次别再踩）
- **接口请求间隔必须 ≥ 5 秒**。本次 0.5 秒/次，第 2 个请求就触发 `code=36`（账户异常行为）
