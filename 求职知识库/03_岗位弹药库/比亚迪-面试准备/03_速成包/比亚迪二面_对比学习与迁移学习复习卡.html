先立一个总纲（开口就能用）：自监督是"没有人工标注时怎么造监督信号"的范式，对比学习是自监督的一条路线（另一条是生成式：BERT mask / MAE / GPT 自回归）；迁移学习是目的（把 A 的知识用到 B），预训练+微调是实现它的手段，而对比学习常常就是那个"预训练目标"。这几层关系讲清楚了，后面所有模型名都是位置问题。

一、对比学习四大家族（CV 起源，讲清楚"防坍塌"这条主线）

模型核心机制靠什么防止表征坍塌（collapse=所有输入映射到同一点）工程要点
SimCLR
2020		 同一图做两种增强成正样本对，batch 内其余 N-1 个当负样本，InfoNCE 拉近正、推远负 靠负样本——负样本提供"排斥力"，没有就塌 需要大 batch（4096）才够负样本；非线性投影头 g(·) 很关键；强数据增强是效果上限
MoCo
v1/v2/v3		 动量编码器（EMA 更新）维护一个负样本队列（字典），把负样本数量与 batch size 解耦 靠负样本（队列里的一致性更好，因为 key encoder 更新慢） 小 batch 也能跑；动量系数 0.999；队列越长越好；v3 换成 ViT + 不再需要队列（batch 够大时）
BYOL
无需负样本		 online / target 双网络 + 一个额外 predictor 头；target 由 EMA 更新，target 分支 stop-gradient 不靠负样本：靠"非对称结构 + 预测头 + stop-grad"。去掉 predictor 立刻坍塌——这是最经典的追问点 对 batch size 不敏感；证明"负样本不是必须的"
SimSiam
极简		 连动量编码器都不要：两支共享权重 + predictor + stop-gradient 靠 stop-gradient 本身（本质是交替优化，类似 EM/k-means） 把 BYOL 的"经验技巧"提炼成原理：坍塌不是被负样本或动量挡住的，是被 stop-grad 挡住的
SwAV 不两两比，而是聚类对比：对两个 view 的聚类分配做 swap 预测（Sinkhorn） 靠聚类约束（原型分布均匀性） 需要 online 聚类，适合超大类别
Barlow Twins
/ VICReg		 不做对比，做去相关：让两 view 特征的互相关矩阵趋近单位阵（VICReg 再加方差约束） 靠特征维度去冗余而非负样本或 predictor 对 batch 较小也稳；VICReg 三件套：invariance + variance + covariance
一句话总结（背这句）："对比学习的主线其实是怎么防坍塌——最早靠负样本（SimCLR/MoCo），后来发现非对称结构加 stop-gradient 也能挡住（BYOL/SimSiam），再后来干脆用去相关的冗余消除（Barlow Twins/VICReg）。"

关键细节（算法背景面试官最爱抠的 4 个点）

1. InfoNCE 损失与温度系数 τ

  • 形式：L = -log[ exp(sim(z_i,z_j)/τ) / Σ_k exp(sim(z_i,z_k)/τ) ]，本质是一个 (K+1) 分类
  • τ 太小（<0.05）：过度聚焦 hard negative，梯度集中到少数样本，训练不稳、易过拟合噪声
  • τ 太大（>0.5）：分布趋平，对所有负样本一视同仁，学不到细粒度结构
  • 实践值：CV 常 0.07~0.2；推荐里因 item 长尾、相似度分布不同，需要调
  • 温度是"难度旋钮"：难任务/大数据集偏小，简单任务偏大

2. 负样本：数量、质量、假阴性

  • 数量：in-batch negatives 依赖 batch size（SimCLR），MoCo 用队列解耦
  • 质量：hard negative（相似但不相同）信息量最大，但太hard会破坏语义
  • 假阴性 false negative：语义相同的样本被当负样本推开 → 损害表征。解法：用监督信号找语义正样本（DuoRec）、按相似度截断、或加 debias 权重
  • 推荐场景特有：曝光未点击当负样本，但"没点"可能是没看见（position bias），要加权或去偏

3. 数据增强决定上限

  • 对比学习学到的是"对哪些变换不变"，增强定义了不变性，也就定义了表征里保留/丢弃什么
  • CV：裁剪、颜色抖动、高斯模糊——裁剪是关键（带来视角不变性）
  • 推荐里不能照抄：序列裁剪/重排可能改变语义（购物序列顺序有意义），要按业务设计
  • 常见序列增强：crop（截取子序列）/ mask（随机遮蔽）/ reorder（局部打乱）/ substitute（相似 item 替换）

4. 怎么评价学得好不好

  • 不看 loss，看下游迁移：linear evaluation（冻住编码器只训线性层）或 fine-tune
  • 表征质量的两个直觉指标：alignment（正样本对齐）+ uniformity（特征在超球面上均匀分布）
  • 工业落地真正看的还是线上 AB：我们 OPPO 看的就是中长尾用户 ARPU +2.3% 和冷启动曝光

模型做法解决什么与你的关系

多模态对比
你的加分项		 图标 CNN + 标题描述 BERT + Cross-Attention 融合，把多模态内容与用户行为序列对齐到同一语义空间 新应用冷启动：没有行为也能靠内容特征匹配用户 OPPO 项目，中长尾 ARPU +2.3%、新应用冷启动曝光提升
你的讲法（OPPO 项目，40 秒）："基于 SSL4Rec 的思路设计了三类对比辅助任务：一是 user-user 场景粒度对比，用 batch 内负样本，让同场景下行为相似的用户表征更近；二是正负反馈对比，用曝光未点击做负样本，学清用户不感兴趣的东西；三是深浅行为对比，把只有浅层点击的当负样本，让表征能区分'随手点'和'真要下载'。同时用 CNN+BERT+Cross-Attention 把图标和文本对齐到行为序列表征的同一空间，这样新应用没行为也能冷启动。最终中长尾用户 ARPU +2.3%。"
追问"为什么中长尾提升明显"："因为中长尾用户行为稀疏，监督信号不足，自监督信号正好补上；头部用户本身行为够多，边际收益小。"
诚实点（算法背景面试官会欣赏）：三类任务各自的增量贡献当时没做完整消融，无法判断哪类最有效、是否存在任务间负迁移——被追问时主动说这点，比硬编强。补一句改进：现在会做消融 + 用动态权重/梯度归一化缓解多任务梯度冲突。

类别搬的是什么代表方法典型场景
① 基于实例搬样本（对源域样本加权/重要性采样）TrAdaBoost、样本权重重估源域和目标域特征空间相同、分布不同

③ 基于参数/模型搬权重（预训练 → 微调）full fine-tune / freeze backbone / LoRA / Adapter / Prefix-Tuning / P-Tuning v2 / BitFit大模型时代主流；预训练表征迁移
④ 基于关系/知识搬结构或软标签知识图谱迁移、知识蒸馏（Teacher→Student soft label）跨域相似度、模型压缩与部署（你端云协同就是这类思路）

参数高效微调（PEFT）几个名字必须分清（LLM 方向必考）

方法改哪里特点
LoRA在 W 旁挂低秩分解 ΔW = B·A（r 通常 8~64），只训 A/B，推理可合并回原权重参数量 <1%，无额外推理延迟（可 merge），多任务可插拔不同 adapter；秩 r 太小表达不足、太大接近全量微调
Adapter在 Transformer 层间插入小模块（降维-升维瓶颈）有额外推理延迟（串行），但模块化清晰
Prefix / P-Tuning v2在输入/每层 KV 前加可学习 soft prompt不改模型权重，但占用上下文长度，长序列有代价
BitFit只训 bias 项极简基线，小数据场景常出奇地好

四、推荐里的迁移 / 跨域（你是 MiNet 这条线）

模型做什么关键机制
MiNet
你的简历		 跨域/多端兴趣迁移：源域（辅助行为，其他端/其他场景）帮助目标域（当前场景）预测 两级注意力：item-level attention（源域 item 与目标 item 的相关性筛选）+ interest-level attention（不同兴趣子空间加权融合），再加 兴趣对齐 loss

UPRec用户级预训练：用用户画像做自监督预训练，再迁到具体推荐任务把"用户属性预测"当预训练任务，缓解行为稀疏
DDTCDR双向跨域迁移：两个域互为源和目标，交替更新解决单方向的域漂移；工程上要防负迁移
MiNet 讲法："多端统一推荐的痛点是用户在每个端的行为都稀疏，但合起来是有信号的。MiNet 的做法是把其他端的行为当源域，用两级注意力迁到目标端：item 级注意力先筛掉跟当前候选无关的历史 item，兴趣级注意力再对不同兴趣子空间加权融合，最后把源域和目标域表征拼起来预测。这里最关键的是要判断域之间相不相关——无关域硬迁会负迁移，所以实践中会先算域相似度、或用门控限制源域贡献。"

五、被追问的高频问题（提前备好）

对比学习

  • 为什么 SimCLR 要投影头、推理时又丢掉？→ 投影头丢掉的是对增强不变但对下游无用的信息
  • BYOL 没有负样本为什么不坍塌？→ predictor + target 的 stop-gradient（去掉 predictor 就塌，这是论文结论）
  • 温度系数怎么调？→ 见上；太小不稳、太平无效
  • 假阴性怎么办？→ 语义正样本（DuoRec）、加权、去偏
  • 推荐里的增强和 CV 有什么不同？→ 序列有顺序语义，不能随便重排

迁移学习

  • 什么时候会负迁移？→ 源域与目标域相关性低、或源域噪声大；先做域相似度评估
  • 灾难性遗忘怎么解？→ 冻底层 + 小学习率 + 模型补丁（PeterRec）+ 回放/正则（EWC/L2-SP）
  • LoRA 的秩怎么选？→ 任务复杂度越高 r 越大，常 8/16/32 起调；数据少用小 r 防过拟合
  • 预训练-微调 vs 领域对抗（DANN）怎么选？→ 目标域有标签用微调；无标签才需要无监督域适配
  • 迁移学习和多任务学习区别？→ 多任务是同时学多个任务、共享即迁移；迁移是先后把 A 的知识给 B
