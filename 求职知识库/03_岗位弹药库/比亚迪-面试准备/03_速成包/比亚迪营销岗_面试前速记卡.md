## 2. 主打项目：中信余额抢夺（STAR 压缩版）
- **背景**：存量用户盘活授信额度，抢回他行分期需求
- **洞察**：人行征信识别他行信贷 587 万 / 他行分期 1142 万，锁定"近一年未分期+他行有行为"高意向客群
- **策略**：定价对标 / 节点营销 / 大额适配 / 渠道投放，累计 13 项，3.8 亿/月
- **归因**：能分流用"策略客群 vs 对照客群"算增量；不能严格 AB 用前后对比+趋势剔除，保守估计 → 定价对标累计抢 5.7 亿
- **难点**：定价过财务、额度过风险 → 量化收益+风险可控+分阶段试点
- **关联车企**："分期客群≈购车潜客，策略≈营销权益，渠道漏斗≈线索归因，方法论完全同构"

## 4. 高频追问速答
| 问 | 答 |
|---|---|
| 3.8亿/月怎么算的？ | 各策略上线后次月分期规模加总按策略拆分，能分流用对照客群算增量，不能严格AB用前后对比+趋势剔除并说明保守估计 |
| 为什么不用纯A/B？ | 金融部分策略涉及全量客群不能随机分流，用PSM对照+前后对比+趋势剔除做准实验；低频转化样本要够、窗口长 |
| 懂汽车行业吗？ | 承认业务细节在学，营销方法论通用；提腾势案例潜客邀约3%→80%、试驾率+21.9% |
| 长链路归因怎么做？ | 统一ID→分阶段漏斗(曝光→线索→试驾→购车)→增量归因→长期窗口评估 |
| 时序预测做过吗？ | 中信目标测算(趋势外推+策略增量) + OPPO指标监控(趋势预测+异常告警)；趋势分解+GBDT/LSTM+不确定性 |
| 怎么向业务解释？ | 先讲结论再讲依据最后讲怎么做；不说AUC 0.72说"能找出70%高意向客户"；一张图代替一段话 |
| 期望薪资？ | 40-50K 区间（10年+主导千万级项目），看职级体系，package合适可谈 |
