## 一、大模型在营销场景的应用全景（5 大方向）

### 1. 客户洞察与线索评分
- 用 LLM 理解非结构化数据：客户咨询记录、销售跟进笔记、社交媒体言论、客服对话
- 输出：潜客意向评分、需求标签、购买阶段识别、异议类型分类
- 比亚迪对应：线索评级模型已自研替代外部供应商，下一步可以用 LLM 做"语义级线索理解"——不只是看留资字段，而是理解客户在咨询/试驾/进店时说的话背后的真实意向

### 2. 内容生产与个性化触达
- AIGC 生成营销文案、短视频脚本、直播话术、邮件/短信内容
- 基于客户画像做千人千面的内容生成（不同车型、不同购车阶段、不同关注点）
- 案例：明源云启明大模型（行业首个营销大模型）覆盖内容生产、客户洞察、线索转化、销售辅助、客户运营全链路

### 3. 销售辅助与 Agent 自动化
- 销售 Agent：自动研究客户背景、生成跟进话术、安排会议、处理异议、更新 CRM
- 案例：LangChain GTM Agent 把潜在客户到合格商机转化率提升 250%，pipeline 增长 3 倍，节省 1320 小时
- 案例：腾讯 WorkBuddy 销售线索 Agent：新线索入库 AI 定制开场白、自动划分优先级、自主完成 2-3 轮跟进、邀约 demo、自动归档 CRM
- 案例：Salesforce Agentforce SDR Agent 24/7 与潜客互动

### 4. 智能客服与导购
- AI 导购/客服处理咨询、推荐产品、处理售后
- 案例：柒牌 AI 导购双十一贡献小程序商城超 70% GMV；特步 AI 店小蜜转人工率降 55%、询单转化率升 46%
- 比亚迪对应：官网/APP 智能客服、经销商销售助手、试驾邀约自动化

### 5. 营销效果归因与决策辅助
- 用 LLM 做营销活动复盘的自然语言分析、归因报告生成、预算分配建议
- 结合因果推断（PSM/DID）做增量效果评估，LLM 负责把复杂分析结果翻译成业务能懂的语言

## 二、Agent 在营销/销售场景的落地架构

### 典型架构（4 层）

```
用户交互层 → 智能体编排层 → 工具/能力层 → 数据层
```

1. **用户交互层**：企微/微信/APP/官网/电话，多渠道接入
2. **智能体编排层**：
   - 意图识别（LLM 理解客户想干什么）
   - 任务规划（拆解为多步动作）
   - 工具调用（查 CRM、查车型库存、发优惠券、预约试驾）
   - 记忆管理（客户历史对话、偏好、购车阶段）
3. **工具/能力层**：
   - RAG 检索（车型知识库、政策、竞品对比）
   - 业务系统 API（CRM、DMS、营销平台）
   - 计算能力（线索评分、价格计算、金融方案）
4. **数据层**：客户画像、行为日志、交易数据、知识库

### 关键技术点
- **RAG（检索增强生成）**：把企业私域文档（车型参数、政策、销售话术）导入向量库，LLM 回答时先检索再生成，解决幻觉问题
- **Function Calling / Tool Use**：LLM 不只是聊天，能调用业务系统执行动作（查库存、预约、发券）
- **记忆机制**：短期记忆（当前对话）+ 长期记忆（客户画像、历史偏好），用向量数据库存储
- **人工兜底**：高价值客户/复杂异议转人工，Agent 处理标准化场景

### 比亚迪的落地方向
- 销售场景语义理解（面试官提到的）：用 LLM 理解客户在咨询/试驾时的语言，识别真实需求和异议，辅助销售应对
- 线索跟进 Agent：新线索自动分级、自动发跟进消息、邀约试驾、归档 CRM
- 经销商销售助手：实时给销售提供话术建议、竞品对比、金融方案计算

## 三、大模型 + 推荐/广告系统的结合（你的核心优势）

这是你区别于纯营销背景候选人的关键——你有推荐系统和广告算法的工业经验，能讲大模型怎么和传统推荐链路结合。

### 1. LLM 用于召回阶段
- 语义召回：用 LLM 生成用户兴趣的语义向量，和商品/内容的语义向量做相似度召回
- 跨域召回：LLM 的跨域理解能力，实现不同品类之间的召回
- 冷启动召回：利用 LLM 的知识迁移能力，为新商品/新用户提供召回
- 案例：阿里 RecGPT，LLM 用于召回阶段，CTR/IPV 等核心指标提升超 5%

### 2. LLM 用于特征工程
- LLM 生成的 Embedding 作为强语义特征输入精排模型
- 案例：SAIL-Embedding，召回用向量召回、排序用强语义特征、冷启动用语义理解
- 案例：PRECTR-V2，用 LLM-Distilled Encoder 优化，人均订单 +1.39%，GMV +3.18%

### 3. 生成式推荐（从判别式到生成式）
- 传统推荐：判别式匹配（给用户和物品打分，选最高分）
- 生成式推荐：直接生成用户可能感兴趣的物品/内容，用 Prompt 控制多目标
- 案例：头条信息流生成式推荐，用户留存率提升 2.1 个百分点
- 案例：腾讯 OnePiece，微信视频号+腾讯广告的用户体验与商业变现统一

### 4. 大模型用于广告出价与创意
- 用 LLM 理解广告主需求，自动生成出价策略和创意文案
- 生成式广告：AI 生成广告素材、落地页、定向人群包

### 你的切入点（怎么讲）
> "我在腾讯做推荐系统时，核心是 DSSM 双塔召回 + MMoE 多目标排序。现在大模型对推荐系统的改造，我理解主要在三个层面：一是召回阶段用语义向量替代传统协同过滤，解决冷启动和跨域问题；二是排序阶段把 LLM Embedding 作为强语义特征，提升模型对内容的理解；三是从判别式走向生成式，用 Prompt 控制多目标。我自己也做过 LLM+推荐的预研，用用户行为日志做 appid 预训练，搭过 DS-Chat 训练环境。如果比亚迪要做大模型+营销推荐，我可以从这三个层面切入。"

## 四、结合比亚迪业务的具体落地方向

### 方向 1：语义级线索评级（当前已做线索评级，下一步升级）
- 现状：线索评级模型自研替代外部供应商，应该是基于结构化字段（留资信息、渠道、行为）
- 升级：用 LLM 理解非结构化数据（客户咨询文本、销售跟进笔记、客服对话），提取意向信号、异议类型、购车阶段，和结构化特征融合，提升线索评级准确率
- 你的优势：有 CTR/CVR 预估经验，知道怎么把多模态特征融合进排序模型

### 方向 2：销售场景语义理解（面试官明确提到）
- 场景：销售和客户沟通时（电话/微信/进店），AI 实时理解客户需求，给销售提供话术建议、竞品对比、金融方案
- 技术：ASR（语音转文字）+ LLM 语义理解 + RAG（车型/政策知识库）+ Function Calling（查库存/算价格）
- 难点：实时性要求高、领域术语多、需要本地化部署（比亚迪禁用 Claude，用本地化 Code）

### 方向 3：线索跟进 Agent
- 新线索入库 → AI 自动分级 → 高意向自动邀约试驾 → 中意向自动发资料/跟进 → 低意向培育 → 全程自动归档 CRM
- 你的优势：有用户分层和因果推断经验，知道怎么识别高意向客群、怎么评估策略增量

### 方向 4：大模型微调（销售场景）
- 用比亚迪的销售对话数据、车型知识库、客户咨询记录，微调领域大模型
- 技术：SFT（监督微调）+ RLHF/DPO + RAG 增强
- 难点：数据隐私（比亚迪要求严格，本地化部署）、领域数据质量、评估体系

## 六、可能被追问的问题及回答

### Q1：大模型在推荐系统里会不会完全替代传统模型？
> "不会，至少短期内不会。传统推荐模型（双塔、DeepFM、MMoE）在大规模实时推理上有成本和延迟优势，大模型更适合做语义理解和特征增强。比较合理的架构是'传统模型为主干 + LLM 语义特征增强 + 生成式探索长尾'，两者互补。阿里 RecGPT 和腾讯 OnePiece 都是这个思路。"

### Q2：Agent 在营销场景落地最大的难点是什么？
> "我觉得三个：一是幻觉问题，Agent 给客户的信息必须准确，所以 RAG 和人工兜底很重要；二是数据隐私，车企的客户数据敏感，需要本地化部署，比亚迪禁用 Claude 用本地化 Code 就是这个考虑；三是效果评估，Agent 的动作是多步的，怎么归因每一步的贡献、怎么做 A/B，需要结合因果推断。这三点我都有经验——RAG 我了解，本地化部署在银行做过，因果归因是我中信项目的核心。"

### Q3：怎么评估一个营销 Agent 的效果？
> "分三层：一是任务完成率（有没有成功邀约试驾、有没有正确回答客户问题）；二是业务指标（线索转化率、试驾率、购车率）；三是效率指标（销售节省的时间、响应速度）。关键是用因果推断做增量评估——Agent 带来的转化是'抢来的'还是'本来就会来的'，需要对照实验或 PSM/DID。这正是我在中信做的事。"

### Q4：大模型微调怎么做？需要什么数据？
> "销售场景的微调，数据来源主要是：历史销售对话（电话录音转文字、微信聊天记录）、客户咨询记录、车型知识库、销售话术手册。流程是：先做 SFT（监督微调），用高质量的销售对话对教模型怎么回答；再用 RAG 增强，让模型能检索最新的车型和政策；最后用 DPO/RLHF 优化回答风格。评估用业务指标（转化率、客户满意度）而不是纯 perplexity。"

### Q5：你怎么看比亚迪禁用 Claude、用本地化 Code？
> "这很合理，车企的客户数据和销售数据高度敏感，本地化部署是必须的。技术上，本地化部署需要考虑模型大小（用 7B/13B 而不是更大的模型）、推理优化（量化、蒸馏）、和业务系统的集成。我在银行做过类似的事——金融数据也不能出域，策略要过风控审批，方法论是相通的。"
