## 一、最重要的结论（先看这条）

**智联招聘对你这个方向的价值很低——不是你不够好，是供给结构问题。**

| | 深圳 | 北京 |
|---|---|---|
| 抓取量 | 186 | 136 |
| 薪资上限 ≥30K 且方向词命中的 | 48 | 46 |
| **其中真正对口（推荐/广告/数据科学/风控建模）** | **≈2（含你已在流程的比亚迪）** | **≈7** |

**深圳的坑**：智联深圳站挂出来的"算法岗" 90% 是**硬件/制造/自动驾驶/机器人**方向——大族数控、大族激光、欣旺达、顺丰无人机、文远知行、拓邦具身智能、亚特电器、海目星激光……要求的是 SLAM / 运动控制 / 电机控制 / 路径规划 / CUDA，**和你的履历零交集**。深圳的互联网推荐/广告岗基本不挂智联（都在 Boss / 内推 / 官网）。

**结论：深圳找推荐/广告岗，智联基本可以放弃；北京还能捞出几个能看的。**

**为什么是第一**：JD 里那四个方向词——**多目标优化（腾讯 MMoE/ESMM）、序列建模（Transformer 序列）、多场景建模、生成式推荐（刚做完的 OneRec/MiniOneRec 专题）**——几乎是照着你的弹药库写的；"推荐/搜索/广告任一领域"的宽松口径把百度广告 + 腾讯推荐 + OPPO 冷启动全算进去了。

**必须提前想好的两个缺口**：
1. **框架与编码**：JD 明写 "熟悉 TensorFlow/PyTorch 等分布式训练框架"、"优秀的编码能力、扎实的数据结构"——**红线区，不能吹**。说法："训练框架我主要在用 X，工程实现以 Java/Scala + 平台化为主"，把话题拉回建模与业务闭环。
2. **旅游业务无经验**：反向包装——旅游是**低频高决策、强时效、多目标（搜索-列表-详情-下单）**场景，和百度程序化广告转化链路、腾讯信息流多目标本质同一套问题，比高频场景更考验建模。
