## 二、必讲项目 Top 4（带数字口径，数字以事实台账为准）

1. **中信银行营销因果归因（DID/PSM）** ← 头牌，直接对应"银行营销优先"+"价值量化"
   - 讲清：营销活动的真实增量怎么算（相关性≠因果）、双差分/倾向得分匹配设计、如何排除混杂
   - 落点："AI 转型价值量化"本质就是这套准实验方法，我做过完整的
2. **中信风控/反欺诈建模（异常检测象限）**
   - uplift 四象限：可说服/必然响应/必然不响应/适得其反——"适得其反"=误杀好用户
   - 落点：异常检测不是孤立模型，要挂到决策收益上
3. **百度广告 pCTR×price（预测+出价联动，eCPM +21%）**
   - 讲清：小模型如何直接绑定业务收入、A/B 如何设计、线上效果如何归因
   - 落点：给他们听"模型→指标→钱"的完整链路
4. **OPPO 冷启动+校准（+15%、ARPU +1.04%）**
   - 讲清：无数据场景的建模思路、概率校准对决策阈值的意义
   - 落点：甲方新场景冷启动是这个岗位每天要面对的事

## 三、他们可能考的题（按能力分级预判）

**数据分析 4 级（重点考）**：
- 给你一个客户业务场景（如"银行信用卡激活率低"），你怎么做诊断？→ 答题框架：业务链路拆解→漏斗定位→假设树→数据验证→策略分层
- 怎么设计一套指标体系？→ 北极星指标+过程指标+护栏指标；口径唯一性；基线先行
- "AI 转型的 ROI 怎么算？"→ 价值基线（对照期/对照组）→ 增量归因（A/B 或 DID/PSM）→ 成本侧（人力替代+效率）→ 护栏（质量不降级）

**ML 小模型 3 级**：
- 样本不平衡怎么办（银行场景必考）→ 重采样/代价敏感/阈值校准/评估用 PR-AUC 不看 accuracy
- 模型上线后怎么监控 → PSI 稳定性、漂移告警、校准曲线、衰减预警
- 小模型 vs 大模型怎么选 → 场景问题：可解释性/延迟/成本约束下，逻辑回归+分箱在银行风控仍是主力；LLM 用于非结构化数据处理而非决策主链路

**综合咨询 3 级**：
- "客户不认可你的分析结论怎么办" → 先对齐目标口径→给选项而非单答案→用小实验降低决策成本
- 结构化表达：结论先行（金字塔），每层 ≤3 点

**HR 面**：
- 为什么看这个岗（10年经验 vs 3-5年要求）→ 口径："我想把因果建模和业务诊断这套能力用到更贴近经营决策的场景，贵司的数智化咨询正好是方法论的落地场。" 不说"降级将就"
- 期望薪资 → 不先报数："更看重方向匹配，薪资希望在了解职责全貌后结合贵司带宽再谈。"
