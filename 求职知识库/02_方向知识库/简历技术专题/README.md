## 使用方式

1. **被深挖某方向** → 进对应专题 README，先看「一句话定位 + 实战弹药」，再钻「八股 QA」。
2. **要数字口径** → 各专题注明出处，冲突的标记 ⚠️ 待统一（目前已知：多位置校准 50%+→20% vs 30%→20%）。
3. **新增素材** → 放进专题目录，并在该专题「资料索引」登记一行。

*对应简历条目：见 `01_原始资料库/06_简历/`，口径需与简历档案一致。*
