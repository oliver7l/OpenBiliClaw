# 专题 · 对比学习（Contrastive Learning）

> 最后更新：2026-09-09
> 简历落点：OPPO 应用商店/游戏中心推荐主架构上挂的**自监督对比辅助任务**（基于 SSL4Rec 多粒度框架）。
> 主线话术：**标签稀疏 → 用自监督把少量行为和群体相似性利用起来，让模型在标签不够时也认识用户；表征准了分发就准，收益集中在中长尾用户。**

---

## 一、一句话定位（开场）

> "对比学习解决的是'信号稀疏'。推荐里最能代表用户的是行为标签，但中长尾用户行为少、标签稀疏，单一监督信号学不准。我用法自监督的对比学习：让'相似的用户/行为'在 embedding 空间靠近、'不相似的'远离，不依赖密集标签也能学到有区分度的用户表征——表征准了，分发就准，变现自然涨。"

### 最硬数字
- **中长尾用户 ARPU +2.3%**，头部基本持平
- 因果链完整可解释：对比学习补稀疏 → 中长尾 embedding 更有区分度 → 相关性↑ → 点击/下载/付费↑ → ARPU↑

---

## 二、核心原理（讲透"三重构造"）

对比学习引入推荐的三个研究点，**难度依次增大**：

```
Data Augmentation（数据增强）
   ↓ 怎样造"同一样本"的不同视角
Sampling Strategy（采样策略）
   ↓ 正负样本对怎么选、难负例怎么控制
Loss Function（损失函数）
   ↓ 用什么对比损失把距离拉开
```

### 2.1 三条主流融合方式
| 方式 | 含义 | 是否常用 |
|---|---|---|
| **Joint Learning (JL)** | 对比任务作为辅助 loss 与主任务联合训练 | ✅ 最常用 |
| **Pre-training + Fine-tuning (PF)** | 先用对比自监督预训练表征，再下游微调 | 次之 |
| **Integrated Learning (IL)** | 深度整合进模型结构 | 少见 |

> 你简历用的是 **Joint Learning**：`Loss = Loss_main + α × Loss_contrastive`，serving 只出 embedding、不增线上开销。

### 2.2 数据增强的坑（被问"为什么不用图增强"）
- 方法繁多、需人工多次尝试、可能破坏原数据内部关联、需要先验知识。
- 例：序列推荐对长度2的节点做 Mask 可能和原序列完全无关；协同过滤二部图 edge dropout 可能把图变成两个分离子图。
- → 所以更稳的是**输入扰动**（借鉴 GAN 加噪声）：同一物品输入模型自带扰动，得到不同 embedding 做对比。DuoRec、GNN 每层加噪声都属此类。

## 三、实战弹药：OPPO 三个对比辅助任务（核心，按粒度展开）

> 框架：SSL4Rec 多粒度自监督训练框架，三个辅助任务的**粒度从粗到细**。

### 任务1 · user-user 场景粒度对比（学"相似用户"）
- 同一场景下（同一推荐位/时间窗）行为相似的**用户**互为增强。
- 正样本对：行为模式相近的用户；负样本对：不相似的用户。
- 目标：学用户在特定场景下的**群体表征**——稀疏用户借"相似活跃用户的群体表征"把自己拉正。

### 任务2 · 正负反馈对比（学"喜欢 vs 假喜欢"）
- 正样本：用户点击/下载的 item；负样本：曝光未点击的。
- 目标：拉大"真喜欢"和"假喜欢"，纯化兴趣信号。

### 任务3 · 深浅行为对比（点击 vs 下载 vs 激活）
- 浅层（点击）vs 深层（下载/激活）；正样本对=有深层行为的用户-物品对，负样本对=只有浅层或无行为。
- 目标：从"顺手点一下"里抽出**真实深层意图**。

### 讲法（一段背熟的完整话术）
> "对比学习我是在 OPPO 推荐主架构上挂自监督辅助任务：user-user 场景粒度让相似用户 embedding 靠近，正负反馈对比把'真喜欢'和'假喜欢'拉开，再加一个热门 item 去偏任务。联合训练 `Loss = Loss_main + α·Loss_contrastive`，serving 只出 embedding、不增开销，负样本用 batch 内 + 难负例控成本。它解决的是标签稀疏——中长尾用户行为少，但能借相似活跃用户的群体表征把自己拉正，所以提升集中在中长尾，ARPU +2.3%，头部基本持平。"

## 四、八股 QA（被追问）

**Q1：对比学习和协同过滤（emb、user2vec）有啥区别？**
A：协同过滤是离散的、基于统计的共现计数；对比学习是**端到端学连续表征**，能融更多特征（场景、序列、图像），且和主模型**联合优化**，直接服务排序目标。

**Q2：为什么提升集中在中长尾而不是头部？**
A：头部用户行为多、监督信号本就够，边际收益小；对比学习的价值在"自监督补稀疏"，所以主要惠及行为少的中长尾。可用分活跃度桶实验对齐：头部桶持平、中长尾桶 +2.3%，因果链对得上。

**Q3：为什么不直接加更多监督/特征？**
A：稀疏的本质是**行为本身就少**，不是特征不够；对比学习把"谁和谁像"这个自监督信号榨出来，是信息增量的另一来源，且能与其他特征融合。

**Q4：负样本怎么选？（成本/质量）**
A：batch 内负采样控成本 + 难负例（hard negative）提升判别力；避免全局全量负采样（开销大）。

**Q5：多任务/大模型 和 对比学习 什么关系？**
A：都补"信号不够"。对比学习补**标签稀疏**（自监督表征），大模型补**内容理解与冷启动**（对未见过的新 item 也能理解），前者在本场景是更轻、更稳的注入方式。
