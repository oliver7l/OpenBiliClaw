## 二、微视·账号推荐 —— 面试主心骨（已深挖，真实数字）

**一句话定位**："在腾讯微视负责'推人'推荐系统——给用户推荐好友（一度/二度关系链）和达人（创作者），提升关注率带动消费与留存。日均新增关注 190w+ 次。我做的是召回-排序-重排全链路，最体现算法深度的是**基于图 Embedding 的召回体系**和**达人/好友混排策略**。"

### 2.1 召回层（最值钱，务必讲透）

**好友召回（关系链）**
- 一度好友：合并 QQ 好友 / 微信好友 / 红包关系 / 通讯录关系 → `pid, friendspid(type)`。
- 二度好友：离线计算（二度关系如何算、阈值设置待补）。
- 实时一二度：接口返回 `[用户id, 好友list]`，逻辑同离线。

**达人召回（13 路并行，线上生效清单）** — 来源：`达人召回梳理.txt` / `好友达人梳理（总）.txt`

**图 Embedding 实验（真实 AB，来源 `各种emb实验.txt` / `图embedding方法的总结.txt`）**
- 方法栈：Word2Vec i2i → DeepWalk → LINE（一/二阶）→ Node2Vec（P/Q 偏置）→ MetaPath2Vec（注入达人 side-info 缓解长尾冷启）→ DSSM 双塔（规划）。
- Graph Emb 一期（20% 流量，4 天稳定）：**发现好友页 pCTR +14.22%、uctr +1.94%；关注页 pCTR +10.59%、uctr +2.21%；消息页 pCTR +5.17%**。
- w2v 替换实验（4.2）：发现好友页 pCTR +7.06%（相对 graph emb 略优，说明向量方法选型有 trade-off）。
- 热门达人池切 45 级达人池：**整体关注率 +5.3%（6 天稳定）**。

### 2.2 排序层（来源 `排序模型梳理.txt`）
- **老用户好友 LR 排序**：样本=过去 7 天，正样本(关注/查看主页) vs 负样本(曝光未点击)，**正负比 1:10**；特征=用户画像/统计/关注关系链 + 达人画像/统计 + 交叉（共同好友、是否微信/QQ 好友、关注链亲密交叉）；FTRL 训练（SparseLRWithFTRL）。
- **新用户好友规则排序**：`score = 0.7×共同好友 + 0.3×活跃`。
- **达人规则排序**：读共享内存达人得分降序。
- 模型深度分析系统（腾讯期）：单 slot / Shapley / 梯度三种特征重要度分析 → 面试亮点。

### 2.3 重排 / 混排层（来源 `好友达人梳理（总）.txt`）
1. **分层 quota 混排**：`layer_policy=1:13010@…;2:13804@…;3:14998@…`，按用户关注倾向动态配比（如倾向 0.6 → 先 6 达人后 4 好友）。
2. **类目 E&E**：**Thompson Sampling** 按品类维度采样，最多 16 类目进后续，增多样性防越推越窄。
3. **曝光降权**：`score = score × exp(-0.1 × count)`，老面孔高频无互动即下沉。
4. **类目强间隔打散**：同品类间隔≥1；相同类目 ret_num<10 最多 1 次、>10 最多 2 次。
5. **swap**：好友中有视频的 3 个前置。
6. **Pre-filter**：屏蔽/黑名单/机器人名单。

### 2.4 指标体系（来源 `好友推荐指标建设.txt`）
- 推人卡片：曝光卡片数、点击关注数/率、点击头像数/率、X 按钮（负反馈）、人均关注、全局关注转化率、次日留存/关注页次留。
- 分场景（关注页/消息页/发现好友页/个人主页，流量从大到小）、分维度（好友/达人、曝光/点击/头像/X）。
- 数据落 `recommend_id`（固化建议）、tdw 表口径清晰 → 体现实验严谨度。
