# 产品化项目弹药库

> 从原始材料深挖、按产品化方式提炼的面试项目卡片集合。每张卡片10段结构，可直接用于面试讲述。
> 生成时间：2026-09-04
> 数字来源：所有量化结果均来自 `01_原始资料库/` 原始材料，标注具体出处；无出处的明确标注"材料中未记录"。

## 卡片结构（统一10段）

1. **产品定位**（一句话）
2. **背景与业务问题**
3. **目标与核心指标**
4. **方案设计**（技术栈/模型/表，含ASCII架构图）
5. **技术实现要点**
6. **亮点与难点**
7. **量化结果**（真实数字+来源文件）
8. **复盘与局限**
9. **可迁移点**
10. **面试话术**（150-250字，STAR，第一人称，可直接背诵）

## 使用方式

- **自我介绍选项目**：从14张卡片中选2-3个最匹配岗位的作为主打项目
- **被追问细节**：每张卡片的"技术实现要点"和"亮点与难点"段可直接展开
- **数字背诵**：所有数字已同步到 `_系统_知识库引擎/数据/03_真实数字表.csv`（共60个）
- **项目速查**：`_系统_知识库引擎/数据/02_项目表.csv`（共24个项目，含可讲要点）
