# 微视个人主页与场景化推人

## 产品定位（一句话）
围绕"个人主页关注转化优化"和"零关注用户场景化推人"两大方向，从漏斗分析到策略落地，提升微视关注渗透率和社交关系链冷启动效率。

## 背景与业务问题
- **个人主页侧**：近一半的关注行为发生在个人主页，个人页关注转化率3.6%，其中61%的用户来自推荐页跳转（来源：关注价值分析.txt）。个人主页是关注转化的核心场景，但关注按钮的设计、推荐内容的相关性、页面信息的完整性都有优化空间。
- **零关注用户侧**：微视DAU中73%为零关注，登录用户中40%（约630万）为零关注，其中300万已授权关系链（来源：关注价值分析.txt）。零关注用户是关注增长的最大潜力人群，但推荐页对零关注用户的推人策略缺乏针对性，"一刀切"的推荐导致关注转化率仅0.8%。
- **兴趣召回侧**：零关注用户缺乏关注行为信号，传统的协同过滤召回效果差，需要基于用户的一级/二级兴趣标签做内容和达人召回，解决冷启动问题。

## 目标与核心指标
- **个人主页优化目标**：提升个人主页关注转化率（从3.6%起步）、提升个人页到关注的漏斗效率。
- **场景化推人目标**：提升零关注用户的关注转化率、降低零关注用户占比、提升人均关注次数。
- **兴趣召回目标**：提升零关注/新用户的召回覆盖率和相关性，提升关注转化率。
- **核心指标**：
  - 个人主页关注转化率、个人页UV→关注转化率
  - 零关注用户占比、零关注用户日均关注次数
  - 推荐页推人pCTR/uCTR、关注转化率
  - 兴趣召回覆盖率、召回多样性

## 方案设计（含技术栈/模型/表，可用ASCII图）

### 一、个人主页优化梳理

#### 漏斗分析
```
推荐页曝光 → 点击头像/昵称 → 进入个人主页 → 浏览内容 → 点击关注按钮 → 关注成功
     │              │                │              │            │
  3000万/天      61%来自推荐页    关注转化率3.6%   内容相关性   按钮设计/位置
```

#### 优化方向（来源：个人主页优化梳理.md）
1. **关注按钮优化**：
   - 按钮位置：从页面底部移到更显眼的位置（如头像旁、内容区顶部）
   - 按钮状态：已关注/未关注/回关三种状态的视觉差异化
   - 按钮文案：从"关注"到"关注TA"+社交证明（如"X位好友已关注"）
2. **个人主页内容推荐优化**：
   - 精选内容置顶：将高互动、高质量的作品置顶展示
   - 内容分类Tab：按视频/图文/合集分类，方便用户浏览
   - 相关达人推荐：在个人页底部推荐"相似达人"，延伸浏览路径
3. **个人主页信息完整性**：
   - 作者简介、认证信息、权威等级标签的展示
   - 粉丝数、关注数、作品数等社交证明信息
   - 共同好友数展示（"你有X位共同好友"）
4. **关注后反馈优化**：
   - 关注成功后的即时反馈（动画/提示）
   - 关注后推荐更多相似达人
   - 关注流的内容消费引导

### 二、零关注用户场景化推人

#### 用户分层与场景定义（来源：推荐页-零关注用户场景化推人.txt）
```
零关注用户
  ├── 新用户（注册≤7天）
  │     ├── 已授权关系链 → 好友优先推荐
  │     └── 未授权关系链 → 兴趣达人推荐
  ├── 老用户零关注（注册>7天）
  │     ├── 有消费行为 → 基于消费兴趣推达人
  │     ├── 无消费行为 → 热门达人+兴趣探索
  └── 回流零关注用户 → 兴趣重建+好友推荐
```

#### 场景化推人策略
1. **新用户+已授权关系链**：
   - 优先推荐微信/QQ好友（一度好友），其次二度好友
   - 展示"X位好友已在微视"的社交证明
   - 一键关注多个好友的批量操作
2. **新用户+未授权关系链**：
   - 基于注册时选择的兴趣标签，推荐对应领域的头部达人
   - 兴趣选择页的多标签选择，覆盖一级兴趣和二级兴趣
   - 热门达人兜底，保证召回覆盖率
3. **老用户零关注+有消费行为**：
   - 基于用户消费历史（观看/点赞/评论的视频品类），推荐对应领域的达人
   - 一二级兴趣召回：一级兴趣（如"游戏"）粗召回，二级兴趣（如"王者荣耀"）精召回
   - 消费过的视频的作者优先推荐（"你看过TA的视频"）
4. **老用户零关注+无消费行为**：
   - 热门达人+平台推荐，配合兴趣探索引导
   - 低门槛关注引导（如"关注3个达人，发现更多精彩内容"）

### 三、一二级兴趣召回

#### 兴趣标签体系（来源：一二级兴趣召回.txt）
```
一级兴趣（粗粒度，~20类）
  ├── 游戏 → 二级：王者荣耀/和平精英/原神/...
  ├── 美食 → 二级：家常菜/烘焙/探店/...
  ├── 音乐 → 二级：流行/摇滚/古风/...
  ├── 舞蹈 → 二级：街舞/国风/韩舞/...
  └── ...
```

#### 召回策略
1. **用户兴趣画像构建**：
   - 基于用户消费历史（观看/点赞/评论/分享），统计各一级/二级兴趣的消费占比
   - 时间衰减加权：近期消费权重更高
   - 兴趣覆盖度：用户消费过的兴趣类别数量
2. **达人兴趣标签匹配**：
   - 达人基于发文内容（视频标题/标签/品类）标注一级/二级兴趣标签
   - 达人多兴趣标签：一个达人可对应多个二级兴趣
   - 达人兴趣专注度：发文在某一兴趣的占比
3. **召回逻辑**：
   - 一级兴趣召回：用户Top-N一级兴趣 → 对应领域的头部达人（粗召回，保证覆盖率）
   - 二级兴趣召回：用户Top-M二级兴趣 → 对应领域的精准达人（精召回，保证相关性）
   - 兴趣扩展召回：基于兴趣相似度，推荐相邻兴趣的达人（探索性）
4. **冷启动适配**：
   - 零关注/新用户缺乏消费行为时，基于注册时选择的兴趣标签做召回
   - 无任何兴趣信号时，热门达人兜底
   - 兴趣标签的实时更新：用户消费行为实时反馈到兴趣画像

## 技术实现要点
1. **个人主页漏斗分析**：基于用户行为日志（推荐页曝光→点击头像→进入个人页→浏览→点击关注→关注成功），构建完整的关注转化漏斗，定位各环节的流失点。
2. **零关注用户实时识别**：基于用户关注数实时特征（共享内存/Redis），在推荐请求时实时判断用户是否为零关注，路由到对应的场景化推人策略。
3. **用户兴趣画像实时更新**：用户消费行为实时上报，流式计算更新用户的一级/二级兴趣画像，保证兴趣召回的时效性。
4. **达人兴趣标签体系建设**：基于达人发文内容的NLP分类（标题/标签/描述），构建达人的一级/二级兴趣标签，定期更新。
5. **多策略混排框架**：不同场景化策略（好友推荐/兴趣召回/热门兜底）的召回结果统一进入混排层，按场景权重和用户特征动态调整各策略的曝光比例。
6. **A/B实验框架**：个人主页优化和场景化推人策略均通过A/B实验验证效果，零关注用户单独分流，避免与全量用户实验互相干扰。

## 亮点与难点
- **亮点1：从漏斗分析到策略落地的完整优化闭环**。个人主页优化不是拍脑袋改按钮，而是先做完整的漏斗分析（推荐页→个人页→关注），定位流失环节，再针对性设计优化策略，最后通过A/B实验验证。
- **亮点2：零关注用户的精细化场景分层**。不是简单地给零关注用户推更多人，而是按新老用户、是否授权关系链、是否有消费行为等维度精细分层，每层匹配差异化的推人策略，体现了"千人千面"的推荐思维。
- **亮点3：一二级兴趣召回的分层设计**。一级兴趣粗召回保证覆盖率，二级兴趣精召回保证相关性，兴趣扩展召回保证探索性，三层召回配合解决零关注用户的冷启动问题。
- **亮点4：社交证明的巧妙运用**。在个人主页和推人场景中，"X位好友已关注""你有X位共同好友"等社交证明信息，利用了微视独有的关系链资产，提升关注转化率。
- **难点1：零关注用户的信号稀疏性**。零关注用户缺乏关注行为信号，消费行为也可能有限，兴趣画像的准确性难以保证，需要多源信号融合（注册兴趣、消费历史、设备/地域等）。
- **难点2：个人主页优化的变量控制**。个人主页涉及按钮设计、内容推荐、信息展示等多个变量，A/B实验中需要精细控制变量，避免多个优化同时上线导致无法归因。
- **难点3：场景化策略的效果平衡**。不同场景化策略（好友/兴趣/热门）的效果差异大，混排权重需要动态调整，避免某一策略过度曝光导致用户疲劳。
- **难点4：兴趣标签体系的维护**。达人发文内容变化快，兴趣标签需要定期更新；一级/二级兴趣的分类体系也需要随内容生态演进而调整，维护成本较高。

## 复盘与局限
- **复盘**：个人主页优化和零关注用户场景化推人是微视关注生态建设的两大核心抓手。个人主页作为关注转化的核心场景（近一半关注发生在此、转化率3.6%），通过漏斗分析定位优化点，从按钮设计、内容推荐、信息展示、关注反馈四个维度系统优化。零关注用户作为最大潜力人群（73% DAU），通过精细化场景分层（新老用户×是否授权关系链×是否有消费行为），匹配差异化的推人策略，配合一二级兴趣召回解决冷启动问题。这两个方向共同构成了"降低零关注占比→提升关注渗透率→提升留存"的完整增长链路。
- **局限1：A/B实验效果未记录**。个人主页优化、场景化推人、一二级兴趣召回三个方向的材料中均未记录具体的A/B实验效果数字，无法量化各策略的提升幅度，这是项目记录的重要缺口。
- **局限2：个人主页优化策略未全量记录**。个人主页优化梳理文档中列出了优化方向，但未记录哪些策略最终上线、哪些被否决，以及各策略的优先级排序。
- **局限3：兴趣召回的标签覆盖度未知**。一二级兴趣召回的效果高度依赖达人兴趣标签的覆盖度和准确性，材料中未记录标签覆盖率、准确率等基础数据。
- **局限4：零关注用户的长期追踪缺失**。场景化推人策略对零关注用户的长期影响（如7天/30天后的关注数、留存、消费时长）未在材料中记录，无法判断策略的长期价值。
- **局限5：与因果推断项目的联动不足**。关注到留存因果推断项目已经证明了关注对留存的正向效应（PSM +22~33%），但个人主页和场景化推人项目未明确引用这一结论来论证项目价值，项目间的联动可以更紧密。

## 可迁移点
1. **个人主页漏斗优化方法论**：从"曝光→进入主页→浏览→关注"的完整漏斗分析，到按钮/内容/信息/反馈四维优化，可迁移到任何有个人主页/店铺页/详情页的产品（电商、社区、短视频、直播）。
2. **零关注/新用户场景化推人框架**：按用户生命周期（新/老/回流）×关系链状态（已/未授权）×行为丰富度（有/无消费）的三维分层，匹配差异化推荐策略，可迁移到任何需要用户冷启动的内容/社交产品。
3. **一二级兴趣召回的分层设计**：一级粗召回保覆盖、二级精召回保相关、兴趣扩展保探索的三层召回架构，可迁移到任何内容/商品/广告推荐的冷启动场景。
4. **社交证明在关注转化中的应用**："X位好友已关注""共同好友数"等社交证明信息的设计，可迁移到任何有社交关系链的产品的关注/加好友/订阅场景。
5. **多策略混排+动态权重框架**：不同召回策略（好友/兴趣/热门）的统一混排和动态权重调整，适用于任何多路召回的推荐系统。
