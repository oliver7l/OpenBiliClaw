# 微视关注到留存因果推断

## 产品定位（一句话）
用因果推断方法严谨论证"关注行为是否真正提升用户留存与时长"，从描述性相关（9.4pp）到DID不显著再到PSM+22~33%，为关注生态建设提供决策依据。

## 背景与业务问题
- 微视团队希望提升关注渗透率，但需要回答一个根本问题：**关注行为到底能不能提升用户留存和时长？** 如果关注只是"活跃用户的副产品"而非留存的原因，那么大力推关注就是浪费资源。
- 描述性统计显示：当天有关注行为的用户次留比无关注用户高9.4pp，但这存在严重的**自选择偏差**——本身更活跃的用户更可能关注，也更可能留存，相关不等于因果。
- 业务方需要一个严谨的因果论证来决定是否投入资源建设关注生态，以及关注的"质变阈值"在哪里。

## 目标与核心指标
- **核心目标**：估计关注行为对用户留存（次日/7日/14日/30日）、消费时长、活跃天数的**因果效应（ATE/ATT）**。
- **关键指标**：
  - 描述性差异：有关注vs无关注用户的留存差（9.4pp）
  - DID估计：双重差分法下的因果效应
  - PSM估计：倾向得分匹配后的平均处理效应（+22~33%）
  - 关注质变阈值：关注数达到多少时留存出现质变（14个）
  - 关注节奏：多久达到14个关注效果最佳（第9-14天）

## 方案设计（含技术栈/模型/表，可用ASCII图）

### 三层因果论证框架
```
描述性分析 → 准实验DID → 观测数据PSM
   (相关)      (自然实验)    (匹配因果)
     │            │              │
  9.4pp差异    不显著        +22~33%显著
     │            │              │
  自选择偏差   样本量不足    控制可观测混淆
```

### 第一层：描述性分析
- 直接对比当天有关注行为 vs 无关注行为用户的留存/时长。
- 结果：次留差9.4pp，但存在自选择偏差。
- 新用户细分：登录态新用户当天关注2个用户次留58%，对比关注1个的用户次留+9pp（日均1.5万用户）（来源：关注价值分析.txt）。
- 老用户细分：老用户有关注行为次留76%，无关注64%（来源：关注价值分析.txt）。

### 第二层：DID（双重差分法）
- 利用"关注行为发生的时间点"作为自然实验，对比关注用户在关注前后的留存变化，与未关注用户的同期变化做差。
- 结果：DID估计不显著。原因分析：
  1. 关注行为本身是用户主动选择，处理组和对照组在关注前就存在系统性差异（趋势不平行）。
  2. 关注行为的"处理效应"可能需要时间累积，短期DID窗口难以捕捉。
  3. 样本量和关注事件的稀疏性导致统计功效不足。

### 第三层：PSM（倾向得分匹配）
- **方法**：用Logistic回归估计每个用户的"关注倾向得分"（基于关注前的用户特征：活跃度、消费时长、兴趣画像、注册时长等），然后为每个关注用户匹配1个或多个倾向得分相近的未关注用户，在匹配后的样本上估计关注对留存的因果效应。
- **匹配变量**：关注前的消费VV、点赞/评论/分享行为、注册天数、兴趣标签覆盖度、设备/地域等可观测混淆变量。
- **结果**：PSM匹配后，关注行为对留存的因果效应为**+22%~+33%**（相对提升），统计显著。
- **结论**：关注行为确实能提升留存，但描述性的9.4pp严重低估了真实效应（因为活跃用户更可能关注，拉低了边际效应），PSM控制混淆后真实效应更大。

### 关注质变阈值分析
- **数据集构建**：4月1日-30日的新用户，追踪达到关注数14后的7天、15天、30天留存（来源：关注数与长留存的关联.txt）。
- **发现1**：关注数与长留存的相关性较高，且时间越长关联性越大。
- **发现2**：关注数与留存率不是简单正相关——**关注数到达14时留存率最高**，之后呈现负相关（初步归因于关注账号整体质量不高）。
- **发现3**：用户在**第9到第14天**这个区间达到关注数14，后期留存表现最好；相对于更早完成14个关注，慢慢达成的效果更好。

## 技术实现要点
1. **PSM倾向得分模型**：Logistic回归，特征为关注前的用户行为和画像特征；匹配方法采用1:1最近邻匹配（带卡钳），匹配后检验标准化均值差异（SMD<0.1）确认平衡性。
2. **DID平行趋势检验**：在关注事件前的多个时间窗口检验处理组和对照组的留存趋势是否平行，不平行则DID结果不可靠。
3. **长留存追踪数据集**：以新用户队列为基础，按"达到关注数14的时间点"对齐，追踪后续7/15/30天留存，控制注册时间的混杂。
4. **多维度异质性分析**：按新用户/老用户、登录态/未登录态、关注数量分层、关注节奏分层，估计不同子群的因果效应差异。
5. **敏感性分析**：改变匹配比例（1:1 vs 1:k）、改变匹配窗口、加入不同的混淆变量，检验PSM估计的稳健性。

## 亮点与难点
- **亮点1：三层递进的因果论证**。从描述性相关→DID准实验→PSM观测因果，方法层层递进，既展示了对因果推断方法论的深度理解，又给出了业务可执行的结论。
- **亮点2："描述性低估真实效应"的反直觉发现**。通常描述性差异会高估因果效应（因为活跃用户更可能关注），但本项目发现PSM后效应更大（22~33% vs 9.4pp），原因是关注行为的边际效应在控制活跃度后更显著——这需要对数据有深入理解才能解释。
- **亮点3：关注质变阈值和节奏的发现**。不仅回答了"关注有没有用"，还回答了"关注多少有用"和"多久关注完有用"——14个是质变阈值，第9-14天慢慢达成效果最好，直接指导了后续关注引导策略的设计。
- **难点1：自选择偏差的处理**。关注行为是用户主动选择，处理组和对照组在关注前就存在系统性差异，DID的平行趋势假设难以满足，需要PSM来控制可观测混淆。
- **难点2：未观测混淆的局限**。PSM只能控制可观测变量，对于"用户对微视的内在兴趣"等未观测变量无法控制，因果效应的估计仍有局限，需要在结论中诚实说明。
- **难点3：关注行为的稀疏性**。日均关注行为用户量有限（新用户日均1.5万），DID的统计功效不足，需要PSM在更大样本上估计。

## 复盘与局限
- **复盘**：这个项目的核心价值在于用严谨的因果方法回答了业务最根本的问题——"关注值不值得做"。三层递进的论证框架（描述性→DID→PSM）既展示了方法论深度，又给出了明确的业务结论：关注确实能提升留存（PSM +22~33%），且存在14个的质变阈值和第9-14天的最佳节奏。这些结论直接支撑了后续"零关注用户场景化推人""个人主页优化""关注流消费提升"等一系列项目的立项和资源投入。
- **局限1：未观测混淆**。PSM只能控制可观测变量，对于用户内在兴趣、社交动机等未观测因素无法控制，因果效应的估计可能仍有偏差。更严谨的方法需要工具变量（IV）或随机实验（A/B Test），但关注行为难以随机化。
- **局限2：DID不显著的解释**。DID不显著可能是因为平行趋势假设不满足，也可能是因为样本量不足或效应延迟，需要更细致的异质性分析才能确定原因。
- **局限3：关注数>14后的负相关**。初步归因于关注账号质量不高，但未做进一步验证（如控制关注账号质量后的留存变化），需要后续项目跟进。
- **局限4：因果效应的长期追踪**。PSM估计的是中短期留存效应（7/14/30天），关注对3个月以上长期留存和LTV的影响未在材料中记录。

## 可迁移点
1. **"描述性→准实验→观测因果"三层论证框架**：适用于任何需要论证"某行为/功能是否真正提升业务指标"的场景，如电商加购对复购的影响、内容收藏对长期活跃的影响、会员开通对LTV的影响等。
2. **PSM在用户行为因果分析中的应用**：当随机实验不可行时，PSM是控制可观测混淆、估计因果效应的实用方法，匹配变量选择和平衡性检验是关键。
3. **"质变阈值+最佳节奏"的用户成长分析**：不仅关注"有没有用"，还关注"多少有用""多久有用"，这种分析框架可迁移到任何用户成长/激活场景（如电商首单金额阈值、内容平台阅读时长阈值）。
4. **因果思维驱动业务决策**：用因果推断而非描述性统计来指导资源投入决策，避免"把相关当因果"导致的资源错配，这是数据科学家的核心价值。
