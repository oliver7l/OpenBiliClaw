# 腾讯_微视账号推荐系统1.0

## 产品定位（一句话）
面向微视/QQ看点用户的"关注建联"推荐系统，在消息页、关注页、个人主页、发现好友页等多场景推荐值得关注的好友与达人，通过提升关注率带动用户后续消费和留存，是社交线"用户建联—关注分发—端内外互动"大思路的基础第一环。

## 背景与业务问题
- QQ看点UGC化后，作者生态起来，但用户"关注更多优质账号"的需求没有被系统化满足，关注复购和转粉效率低。
- 微视端内推人场景分散（推荐页、推人卡片、个人主页关注icon、关注列表），各场景逻辑不统一，缺乏统一的召回—排序—重排架构。
- 好友关系链（QQ+微信）和达人内容生态是两类完全不同的推荐对象，需要混排但又要兼顾亲密度和兴趣匹配。
- 新用户画像不稳定，老用户关注行为丰富，需要差异化策略。

## 目标与核心指标
- **北极星指标**：日均关注次数（推人卡片贡献62万/天，整体日均190万次，节假日峰值230万次）
- **过程指标**：
  - 人均关注数（3月10个 → 6月12个）
  - 关注中位数（0 → 1个），关注三分位数（3 → 6个）
  - 各场景pctr/uctr（曝光点击率/用户点击率）
  - 转粉率、关注后7日留存

## 方案设计
整体架构：**多路召回 → 过滤 → 排序（达人LR/好友LR/新用户规则）→ 重排（升降权+多样性打散+混排）→ 多场景下发**

```
用户请求（消息页/关注页/个人主页/发现好友页）
  │
  ├─ 好友召回（一度/二度/实时）
  │    ├─ 一度好友：QQ+微信+红包+通讯录关系链merge，max150，30天活跃
  │    ├─ 二度好友：好友的好友，max100，30天活跃，周级更新
  │    └─ 实时一二度好友：新用户实时计算
  │
  ├─ 达人召回（显式7路 + 隐式6路）
  │    ├─ 显式：画像热门达人 / UGC45级作者 / LBS同城 /
  │    │        推荐页行为感兴趣达人 / 热门兜底 / 好友关注达人 / 外部画像
  │    └─ 隐式：w2v达人i2i / DeepWalk / LINE / Node2Vec /
  │             MetaPath2Vec（规划中）/ DSSM双塔（规划中）
  │
  ├─ 过滤：已关注去重 / 黑名单 / 隐私开关 / 作品数限制 / 跨刷去重
  │
  ├─ 排序
  │    ├─ 达人LR模型（训练AUC 0.81，测试AUC 0.80，正负比1:5）
  │    ├─ 好友LR模型（过去7天数据，正负比1:10）
  │    └─ 新用户规则：score = 0.7×共同好友得分 + 0.3×活跃得分
  │
  ├─ 重排
  │    ├─ 升降权：45级UGC提权 / 单向关注提权 / 曝光降权(score×exp(-0.1×count))
  │    ├─ E&E：Thompson Sampling按类目采样，最多16个类目
  │    ├─ 多样性：达人按一/二级品类强间隔打散，好友不打散
  │    └─ 混排：根据用户关注倾向个性化决定达人/好友比例（如6:4）
  │
  └─ 多场景下发（每条8-20个账号）
```

**达人基础池定义**：反作弊后粉丝数>1000的用户 + 45级P/UGC作者 + 运营提供的优质账号。

## 技术实现要点

### 召回层
- **好友关系链离线计算**：一度好友天级更新，二度好友周级更新（计算资源限制），最终出库到BDB存储，线上调用BDB召回。数据格式包含好友类型、共同好友数、亲密度、是否互关、共同关注好友数等9个字段。
- **达人CF召回**：基于用户共同关注达人计算两两达人相似度，公式 `score=log(用户关注数)/(log(达人A粉丝数)×log(达人B粉丝数))`，同一级类目×20、同二级类目×50、同9/10级优先级×25，groupbykey累加后归一化，召回topN相似达人。
- **Embedding召回**：用用户7天内正向行为（赞转评/完播）的达人序列（长度5-5000），Word2vec训练32维达人emb，相同一级类目下算cos距离取top10相似达人，线上用用户最近关注10个达人触发，共召回100个。
- **Graph Embedding系列**：依次实验了DeepWalk（随机游走+w2v）、LINE（一阶/二阶相似性）、Node2Vec（P/Q参数控制DFS/BFS游走），均已全量上线。

### 排序层
- **达人LR特征**：用户侧（年龄、性别、Top3长时画像兴趣、关注数、分群）；达人侧（等级、性别、总发文数、总粉丝数、发文倾向Top1类目及发文数、近90天进推荐池视频数、近30/7天粉丝增长）；交叉特征（用户画像×达人类目、性别×达人类目、性别×达人性别、年龄×达人类目、分群×粉丝数）。
- **好友LR特征**：用户/好友侧（性别、年龄、地区、学历、一级兴趣、粉丝/关注/评论/点赞/分享数、已关注各类型好友数）；交叉特征（共同好友数、好友关系类型、是否微信/QQ好友、item与user已关注的人是微信/QQ好友的数量）。
- **模型部署**：离线训练→特征分桶→模型权重上传共享内存→在线预测；后续接入算法中台，升级为多目标DNN模型，部署到taf服务。

### 重排层
- **分层quota控制**：`layer_policy=1:13010@13008@...;2:13804@...;3:14998@...`，按优先级分层，quota比例0.5:0.3:0.2。
- **达人类目限制**：ret_num<10时相同类目最多出现1次，ret_num>10时最多2次。
- **曝光降权**：Redis记录用户-Item曝光次数，`score = score × exp(-0.1 × count)`。

## 亮点与难点
- **从0到1搭建统一账号推荐架构**：覆盖好友+达人两大异质对象，4个端内场景+手Q场景，统一召回ID体系（13001-14998）和配置化脚本管理。
- **Graph Embedding从实验到全量的完整闭环**：依次验证w2v→DeepWalk→LINE→Node2Vec，发现好友页pctr最高提升14.22%，关注页pctr提升10.59%，逐步全量。
- **转粉能力建模**：从每小时900万行关注流水（20.4万账号量级）中挖掘follow_level（转粉率换算的能力等级），作为高转粉账号挖掘信号，解决账号数据稀疏问题（20万账号仅4k能关联分类）。
- **新老用户差异化**：老用户用LR模型排序，新用户用规则打分（共同好友+活跃度），解决新用户画像稀疏问题。
- **混排策略设计**：达人/好友个性化比例 + 品类多样性打散 + E&E探索，兼顾匹配精度和生态多样性。

- 达人LR模型训练AUC 0.81，测试AUC 0.80（来源：同上）
- 关注流水每小时900万行，账号量级20.4万（来源：05_UGC推荐/UGC推荐-账号推荐.md）
- Graph Embedding实验：发现好友页pctr相对提升14.22%（20%流量4天数据），关注页pctr提升10.59%（来源：工作资料_腾讯/2020年09月-内部资料/微视账号推荐/各种embedding实验.md）
- 切换45级达人池实验：整体关注率提升5.3%（来源：工作资料_腾讯/2020年09月-内部资料/微视账号推荐/好友达人梳理（总）.md）

## 复盘与局限
- **排序模型较基础**：一期以LR为主，多目标DNN接入中台尚在进行中，对关注后质量（如关注后是否持续消费）建模不足。
- **二度好友计算资源受限**：只能周级更新，实时性差；且按共同好友数截断可能丢失长尾关系。
- **冷启动达人覆盖不足**：低粉丝、少VV的达人训练数据偏少，MetaPath2Vec引入sideinfo的方案停留在实现中，未全量。
- **场景间策略复用不够**：端内和手Q虽然召回源配置相同，但排序和重排逻辑存在差异，统一中台化是后续方向。
- **LBS召回停留在规划中**：同城作者推荐未落地。

## 可迁移点
- **社交+内容双轨推荐架构**：好友关系链召回与内容兴趣召回的融合方法，可迁移到任何有社交关系的内容平台（如社区、音乐、阅读）。
- **Graph Embedding在账号/作者推荐中的落地经验**：w2v→DeepWalk→LINE→Node2Vec的演进路径和实验方法论，可迁移到关注推荐、好友推荐、商品推荐等i2i场景。
- **多场景统一推荐框架**：召回ID体系、配置化脚本、分层quota混排的设计，可迁移到多入口推荐系统建设。
- **新老用户差异化策略**：新用户规则+老用户模型的渐进式方案，可迁移到用户冷启动场景。

## 面试话术（一段可直接背诵，150-250字）
我在腾讯微视负责从0到1搭建账号推荐系统，目标是帮用户在内容消费之外建立关注关系，提升留存。这个系统要同时处理好友和达人两类完全不同的对象，覆盖消息页、关注页、个人主页、发现好友页四个场景。我设计了多路召回架构：好友侧用QQ+微信关系链做一度二度召回，达人侧做了显式7路加隐式6路召回，隐式里我依次实验了w2v、DeepWalk、LINE到Node2Vec的Graph Embedding方案，发现好友页点击率提升14%后全量。排序层达人用LR模型（AUC 0.81），好友用单独LR，新用户用共同好友加活跃度的规则打分。重排做了曝光降权、品类多样性打散和达人好友个性化混排。系统上线后推人卡片每天贡献62万次关注，整体日均关注190万次，人均关注数从10个涨到12个。
