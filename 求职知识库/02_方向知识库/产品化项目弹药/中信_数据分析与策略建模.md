# 中信数据分析与策略建模

## 产品定位（一句话）
在中信银行信用卡中心，作为策略建模负责信用卡分期客群策略建模，搭建客群分层模型与因果归因体系，应用机器学习模型驱动精准营销，累计落地13项策略，抢夺分期规模3.8亿/月。

## 背景与业务问题
- 信用卡分期业务是中信银行信用卡中心的核心收入来源之一，需要从他行抢夺余额，提升分期规模和收入。
- 全量客户数千万，不同客群对定价/额度的敏感度差异大，"一刀切"的营销策略效率低，需要精准分层和差异化策略。
- 他行信贷/分期客户是余额抢夺的核心目标，但如何从数千万客户中精准识别有他行信贷/分期行为的客户，是关键技术挑战。
- 六大营销渠道（外呼、动卡、短信、企微、公众号、APP）的触达→响应→转化分析口径不统一，渠道效能评估和优化缺乏数据基础。
- 竞品借贷（他行消费贷/经营贷）对信用卡分期业务形成替代，需要前置预测客户的他行借贷概率和本金，提前干预。

## 目标与核心指标
- **核心目标**：提升分期规模（余额抢夺3.8亿/月）、提升营销办理率、降低营销成本、提升客户生命周期价值。
- **客群分层目标**：精准识别分期目标客群（3819万）、余额抢夺客群（1944万）、竞品借贷客群（678万）。
- **人行征信识别目标**：基于人行征信数据识别他行信贷客户（587万）和他行分期客户（1142万）。
- **定价对标目标**：定价对标规模5.7亿。
- **策略落地目标**：累计落地13项策略。
- **竞品借贷预测目标**：30天他行借贷概率与本金预测，办理率提升约10%。
- **渠道统一目标**：六大渠道触达→响应→转化分析口径统一。

## 方案设计（含技术栈/模型/表，可用ASCII图）

### 整体策略建模框架
```
客户数据(人行征信+行内交易+行为) → 客群分层模型 → 差异化策略 → 多渠道触达 → 效果归因 → 策略迭代
                                      │
                    ┌─────────────────┼─────────────────┐
                    ▼                 ▼                 ▼
              分期目标客群       余额抢夺客群       竞品借贷客群
               (3819万)          (1944万)           (678万)
                    │                 │                 │
               定价/额度策略      余额抢夺话术      前置预测+干预
              (类出价与机制)     (对标他行利率)    (树模型预测)
```

### 一、客群分层建模

#### 数据基础
- **人行征信数据**：客户在他行的信贷余额、分期余额、信用卡使用率、查询记录等
- **行内交易数据**：信用卡消费、还款、分期历史、额度使用率
- **客户行为数据**：APP登录、营销响应、渠道偏好
- **人口属性**：年龄、性别、地域、职业、收入

#### 分层维度
1. **按分期潜力分层**：
   - 分期目标客群（3819万）：基于消费行为、额度使用率、历史分期记录预测分期潜力
   - 高潜力/中潜力/低潜力三级分层
2. **按余额抢夺潜力分层**：
   - 余额抢夺客群（1944万）：基于人行征信的他行信贷/分期余额，识别可抢夺的余额规模
   - 按他行余额规模分层（高余额/中余额/低余额）
3. **按竞品借贷风险分层**：
   - 竞品借贷客群（678万）：基于人行征信的他行消费贷/经营贷记录，识别已被竞品分流的客户
   - 高风险/中风险/低风险三级分层

#### 建模方法
- **树模型（XGBoost/LightGBM）**：预测客户的分期概率、余额抢夺潜力、竞品借贷风险
- **特征工程**：人行征信特征（他行信贷余额、分期余额、查询次数、信用卡使用率）、行内交易特征（消费金额、消费频次、还款行为、额度使用率）、行为特征（APP活跃度、营销响应率）
- **模型评估**：AUC、KS、Lift曲线、客群分层稳定性（PSI）

### 二、人行征信识别他行信贷/分期目标客群

#### 识别逻辑
- **他行信贷客户（587万）**：
  - 基于人行征信报告中的"其他贷款"栏目，识别客户在他行的消费贷、经营贷、车贷等信贷余额
  - 筛选有他行信贷余额且余额>阈值的客户
  - 按信贷余额规模、剩余期限、利率水平分层
- **他行分期客户（1142万）**：
  - 基于人行征信报告中的"信用卡"栏目，识别客户在他行信用卡的分期余额
  - 筛选有他行信用卡分期余额的客户
  - 按分期余额规模、分期期数、手续费率分层

#### 应用场景
- 余额抢夺：针对他行信贷/分期客户，提供更优的分期利率/额度，抢夺余额
- 定价对标：基于他行利率水平，设计有竞争力的分期定价（对标规模5.7亿）
- 精准营销：针对不同他行余额规模的客户，匹配差异化的营销策略和话术

### 三、定价/额度策略（类出价与机制策略）

#### 定价策略
- **基于客户分层的差异化定价**：
  - 高价值客户（高分期潜力+高余额抢夺潜力）：提供最优利率，提升转化率
  - 中价值客户：标准利率
  - 低价值客户：较高利率，控制风险
- **对标他行利率的动态定价**：
  - 基于人行征信的他行利率水平，设计有竞争力的定价
  - 定价对标规模5.7亿
- **类出价机制**：
  - 将营销资源（利率优惠、额度提升、权益）类比为广告中的"出价"
  - 不同客群的"出价"不同，高潜力客群出价更高（更优惠的利率/更高的额度）
  - 类似广告中的oCPX出价，目标是最大化分期规模（类比广告中的转化）

#### 额度策略
- **基于风险和潜力的额度调整**：
  - 高分期潜力+低风险客户：提升分期额度，刺激分期消费
  - 高风险客户：降低额度，控制坏账
- **临时额度策略**：
  - 针对特定营销活动，为目标客群提供临时额度提升
  - 临时额度的有效期、金额基于客户分层动态调整

### 四、竞品借贷前置预测模型

#### 模型设计
- **目标**：预测客户未来30天在他行借贷的概率和借贷本金
- **模型**：树模型（XGBoost/LightGBM）
- **标签**：
  - 分类标签：客户未来30天是否在他行有新增借贷（基于人行征信查询记录和信贷余额变化）
  - 回归标签：客户未来30天他行新增借贷的本金金额
- **特征**：
  - 人行征信特征：他行信贷余额、查询次数、信用卡使用率、近期征信变化
  - 行内特征：信用卡消费、还款、额度使用率、近期行为变化
  - 宏观特征：利率环境、季节因素
- **动态调优**：
  - 模型定期重训练（月级/周级），适应客户行为变化
  - 结合营销反馈动态调整预测阈值和干预策略

#### 干预策略
- 对高概率他行借贷客户，提前营销：提供更优的分期利率/额度，将客户的借贷需求留在行内
- 对高本金预测客户，配置专属客户经理跟进，提供定制化方案
- 效果：办理率提升约10%（来源：品牌版简历）

### 五、六大渠道统一分析口径

#### 渠道列表
外呼、动卡（动卡空间APP）、短信、企微（企业微信）、公众号、APP

#### 统一口径
- **触达**：各渠道的实际触达人数/次数（去重逻辑统一）
- **响应**：客户对营销的响应行为（点击链接、回复短信、接听电话、打开APP等）
- **转化**：客户完成分期办理（申请→审批→放款）
- **漏斗**：触达→响应→申请→审批→放款的完整转化漏斗
- **渠道效能**：各渠道的触达率、响应率、转化率、单客成本、ROI

#### 应用
- 识别可营销未触达客户：有分期潜力但未被任何渠道触达的客户
- 渠道组合优化：基于各渠道效能，优化渠道组合和名单投放
- 归因分析：多渠道触达的归因（首次触达/末次触达/线性归因）

### 六、因果归因体系
- **策略效果评估**：用PSM（倾向得分匹配）/DID（双重差分）评估每项策略的因果效应，避免描述性统计的自选择偏差
- **增量贡献分析**：计算每项策略的增量分期规模和增量收入
- **策略迭代**：基于因果归因结果，优化策略参数和客群选择

## 技术实现要点
1. **人行征信数据的特征工程**：人行征信报告包含丰富的他行信贷信息，需要从结构化和非结构化字段中提取特征（他行信贷余额、分期余额、查询次数、信用卡使用率、近期变化趋势等），这是客群分层和余额抢夺的核心数据基础。
2. **树模型在金融场景的应用**：XGBoost/LightGBM在金融风控和营销场景中广泛应用，特征重要性分析可解释性强，适合需要业务解释的金融场景。
3. **类出价机制的策略设计**：将广告中的oCPX出价思路迁移到金融营销，不同客群配置不同的"出价"（利率优惠/额度提升/权益），目标是最大化分期规模，这是跨领域方法论迁移的亮点。
4. **多渠道统一口径的工程实现**：六大渠道的数据来源、格式、去重逻辑各不相同，需要构建统一的数据仓库和分析口径，是数据工程的重点。
5. **因果归因在策略评估中的应用**：用PSM/DID评估策略效果，避免"营销了高潜力客户所以效果好"的自选择偏差，是数据驱动决策的核心能力。
6. **动态调优机制**：竞品借贷预测模型和定价策略需要定期重训练和动态调整，适应客户行为和市场环境的变化。

## 亮点与难点
- **亮点1：13项策略落地的规模化成果**。累计落地13项策略，余额抢夺3.8亿/月，这是从数据到策略到落地的完整闭环，不是纸上谈兵。
- **亮点2：人行征信数据的深度挖掘**。基于人行征信识别他行信贷587万、他行分期1142万客户，这是其他银行难以复制的数据优势，也是余额抢夺的核心武器。
- **亮点3：类出价与机制策略的跨领域迁移**。将广告中的oCPX出价思路迁移到金融营销，不同客群配置不同的"出价"（利率/额度/权益），这是从广告算法到金融策略的能力迁移，在面试中极具辨识度。
- **亮点4：竞品借贷前置预测的前瞻性**。不是等客户被竞品抢走后再挽回，而是前置预测30天他行借贷概率和本金，提前干预，办理率提升10%，体现了前瞻性思维。
- **亮点5：六大渠道统一口径的数据工程能力**。外呼/动卡/短信/企微/公众号/APP六大渠道的统一分析口径，是数据驱动营销的基础工程，体现了数据工程和业务理解的结合。
- **亮点6：因果归因体系的严谨性**。用PSM/DID评估策略效果，避免自选择偏差，体现了数据科学家的严谨性和对因果推断的掌握。
- **难点1：人行征信数据的合规使用**。人行征信数据涉及客户隐私，使用需要严格遵守合规要求，数据获取和使用流程复杂，需要与合规部门紧密协作。
- **难点2：金融场景的可解释性要求**：金融监管要求模型和策略有可解释性，树模型虽然比深度学习可解释，但仍需要特征重要性分析和业务规则结合，不能纯黑盒。
- **难点3：多渠道归因的复杂性**。客户可能被多个渠道触达，转化归因复杂（首次触达/末次触达/线性归因/数据驱动归因），需要构建合理的归因模型。
- **难点4：策略效果的延迟性**。金融营销的效果（分期办理、余额抢夺）可能有延迟，客户从看到营销到办理分期可能需要数天甚至数周，效果评估需要考虑延迟。
- **难点5：客群分层的稳定性**。客户的行为和征信状态会变化，客群分层需要定期更新，分层稳定性（PSI）监控是关键，避免分层漂移导致策略失效。

## 复盘与局限
- **复盘**：中信时期是我从算法工程师向数据/策略分析师转型的关键阶段，将广告算法中的"预估—出价—归因"方法论迁移到金融营销场景，取得了规模化的业务成果。13项策略落地、余额抢夺3.8亿/月，验证了数据驱动策略的商业价值。人行征信数据的深度挖掘（他行信贷587万、他行分期1142万）是核心数据优势，类出价与机制策略是跨领域方法论迁移的亮点，竞品借贷前置预测体现了前瞻性思维，六大渠道统一口径是数据工程的基础能力，因果归因体系保证了策略评估的严谨性。这些能力共同构成了"数据→洞察→策略→落地→归因→迭代"的完整数据科学闭环。
- **局限1：各策略的单独增量贡献未明细记录**。13项策略的总成果（3.8亿/月）有记录，但每项策略单独的增量贡献、ROI、成本未明细记录，无法判断哪项策略效果最好。
- **局限2：模型的离线指标未记录**。客群分层模型和竞品借贷预测模型的AUC、KS、Lift等离线指标未记录，无法评估模型的技术质量。
- **局限3：风险指标的平衡未体现**。分期规模提升的同时，坏账率、逾期率等风险指标的变化未记录，金融业务需要在规模和风险之间取得平衡。
- **局限4：因果归因的具体方法未详细记录**。提到了因果归因体系，但具体用PSM还是DID、匹配变量选择、效应估计值等细节未记录。
- **局限5：多渠道归因的方法未明确**。六大渠道的转化归因方法（首次/末次/线性/数据驱动）未明确记录，渠道效能评估可能存在归因偏差。
- **局限6：客户LTV的长期影响未记录**。策略对客户生命周期价值（LTV）的长期影响未记录，短期分期规模提升可能以长期客户流失为代价。

## 可迁移点
1. **"预估—出价—归因"方法论的跨领域迁移**：将广告算法中的CTR/CVR预估→oCPX出价→效果归因方法论，迁移到金融营销中的客群分层→差异化定价/额度→因果归因，这是算法能力跨领域迁移的典范。
2. **人行征信数据的特征工程方法**：从人行征信报告中提取他行信贷余额、分期余额、查询记录等特征，用于客群分层和风险预测，可迁移到任何需要征信数据的金融场景。
3. **类出价与机制策略设计**：将营销资源（利率/额度/权益）类比为广告出价，不同客群配置不同出价，目标最大化转化，这一思路可迁移到任何需要差异化资源分配的营销场景（电商、教育、医疗等）。
4. **前置预测+提前干预的策略思路**：不是等问题发生后再应对，而是前置预测风险/机会，提前干预，这一思路可迁移到客户流失预警、欺诈检测、库存预测等任何前瞻性决策场景。
5. **多渠道统一分析口径的数据工程方法**：六大渠道的统一触达→响应→转化口径，可迁移到任何多渠道营销的企业（电商、零售、教育等）。
6. **因果归因在策略评估中的应用**：用PSM/DID评估策略效果，避免自选择偏差，这一方法可迁移到任何需要评估策略/功能/活动效果的场景。
7. **客群分层+差异化策略的框架**：按业务目标（分期潜力/余额抢夺/竞品风险）多维度客群分层，每层匹配差异化策略，这一框架可迁移到任何用户异质性强的行业。
