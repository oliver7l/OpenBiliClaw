# 百度广告CTR/CVR预估

## 产品定位（一句话）
在百度国际化应用商店MoboMarket，从协同过滤推荐起步，演进到GBDT CTR预估和XGBoost CVR预估，按pCTR×price/pCVR×price排序实现商业化收益优化，是"预估—排序—收入"广告链路的完整实践。

## 背景与业务问题
- 百度国际化应用商店MoboMarket是百度海外移动分发的核心产品，分发直接挂钩下载与商业化收入，需要在"分发效率"和"商业化收益"之间取得平衡。
- 初期应用详情页推荐采用协同过滤，推荐相关性有限，且未与商业化收益挂钩。
- 搜索结果页的排序缺乏点击率预估，按规则排序导致广告位收入未最大化。
- 广告后台需要更精准的转化预估（CVR）来优化广告排序和收益，但缺乏用户画像基础数据。
- 熊掌号/百家号的内容质量评估缺乏量化体系，需要构建搜索指数和资源方评分模型。

## 目标与核心指标
- **CTR预估目标**：提升搜索结果页/广告位的点击率预估准确率，按pCTR×price排序最大化eCPM。
- **CVR预估目标**：提升广告转化（下载/安装）预估准确率，按pCVR×price排序进一步提升eCPM。
- **用户画像目标**：基于安装APP列表构建性别/年龄预测模型，丰富用户画像基础数据。
- **内容评价目标**：构建熊掌号搜索指数和百家号资源方评分模型，量化内容质量。
- **核心指标**：
  - eCPM提升（CTR模型+21%，CVR模型+24%）
  - pCTR/pCVR预估准确率（AUC/LogLoss）
  - 用户画像覆盖率和准确率
  - 内容评分模型的鲁棒性

## 方案设计（含技术栈/模型/表，可用ASCII图）

### 整体商业化链路
```
用户搜索/浏览 → 候选集召回 → CTR/CVR预估 → 出价排序(pCTR×price) → 曝光 → 点击 → 转化
                    │                │                                      │
              协同过滤/规则      GBDT/XGBoost                          收入(eCPM)
```

### 一、应用详情页推荐（协同过滤）
- **方法**：基于用户行为日志（下载/浏览/搜索历史）的Item-based协同过滤。
- **用户画像构建**：安装APP列表、搜索历史、点击偏好。
- **推荐位置**：应用详情页"相关推荐"模块。
- **局限**：未与商业化收益挂钩，推荐相关性有限，为后续CTR预估提供基础。

### 二、搜索CTR预估（GBDT）
- **模型**：GBDT（Gradient Boosting Decision Tree），训练CTR预估模型。
- **排序公式**：`score = pCTR × price`（广告竞价机制的雏形，按预估点击率×出价排序）。
- **核心优化点**（来源：简历各版本）：
  1. **样本构建策略优化**：
     - 正样本：用户点击的广告/应用
     - 负样本：曝光未点击
     - 样本时间窗口：过去N天数据
     - 去重/去噪：过滤异常点击（爬虫/作弊）
  2. **样本不平衡处理**：
     - 正负样本比例调整（欠采样/过采样）
     - 类别权重调整
  3. **历史特征平滑**：
     - 广告/应用的历史CTR特征存在稀疏性（新广告无历史数据）
     - 贝叶斯平滑：`平滑CTR = (点击数 + α) / (曝光数 + α + β)`
     - 时间衰减：近期数据权重更高
  4. **特征选择**：
     - GBDT特征重要性分析，筛选高贡献特征
     - 去除冗余/低贡献特征，降低过拟合
  5. **用户特征引入**：
     - 用户画像特征（性别/年龄/地域/兴趣）
     - 用户历史行为特征（搜索词、点击偏好、安装列表）
     - 用户-广告交叉特征
- **效果**：eCPM提升21%+（来源：简历各版本）。

### 三、广告后台用户画像与CVR预估（XGBoost）
- **用户画像构建**：
  - 基于用户安装APP列表构建性别/年龄预测模型
  - 方法：分类模型（性别二分类、年龄多分类）
  - 特征：已安装APP的类别向量（One-hot/Embedding）
  - 价值：丰富用户画像基础数据，可直接迁移到广告定向场景
- **CVR预估模型**：
  - 模型：XGBoost
  - 排序公式：`score = pCVR × price`（从CTR预估到CVR预估的自然演进）
  - 转化定义：用户点击广告后完成下载/安装
  - 特征：用户画像特征、广告特征、上下文特征、用户-广告交叉特征
- **效果**：小流量实验验证eCPM提升24%（来源：简历各版本）。

### 四、熊掌号搜索指数 & 百家号资源方模型
- **内容评价体系**（与产品运营共建）：
  - 优质度：内容质量评分（原创性、专业性、丰富度）
  - 领域集中度：作者发文在某一领域的专注度
  - 原创度：内容原创比例
- **搜索指数特征库**：
  - 内容特征：标题质量、正文长度、关键词覆盖、多媒体丰富度
  - 作者特征：发文频率、粉丝数、互动率、历史质量分
  - 交互特征：点击率、停留时长、分享/评论/点赞
- **评分模型**：
  - 多模型融合（GBDT + LR + 规则）提升鲁棒性
  - 特征重要性分析指导特征迭代
- **内部查询系统**：开发内部查询工具，方便非研发人员（产品/运营）查询和使用搜索指数。

## 技术实现要点
1. **GBDT CTR模型的工程化**：GBDT模型训练（XGBoost/LightGBM），特征工程（离散特征One-hot、连续特征分桶、交叉特征），模型上线（离线训练→模型导出→线上打分服务）。
2. **pCTR×price排序机制**：这是广告竞价的核心机制——按预估点击率×出价排序，最大化eCPM（每千次展示收入）。这一机制从搜索CTR预估延伸到CVR预估，是"预估—排序—收入"链路的核心。
3. **历史特征贝叶斯平滑**：新广告/新应用缺乏历史数据，直接用原始CTR会有极大偏差，贝叶斯平滑通过先验分布收缩估计，是广告系统中的经典技巧。
4. **样本不平衡处理**：广告点击是稀疏事件（CTR通常1-5%），正负样本极度不平衡，需要通过欠采样/过采样/类别权重调整来保证模型训练效果。
5. **基于安装列表的用户画像**：用用户已安装APP的类别向量预测性别/年龄，是冷启动用户画像的经典方法——APP安装列表蕴含了丰富的用户兴趣和人口属性信息。
6. **多模型融合提升鲁棒性**：在熊掌号评分模型中，GBDT+LR+规则的多模型融合，比单一模型更鲁棒，能应对内容质量评估中的主观性和噪声。

## 亮点与难点
- **亮点1：从推荐到CTR到CVR的完整商业化链路**。从协同过滤推荐→GBDT CTR预估（eCPM+21%）→XGBoost CVR预估（eCPM+24%），完整经历了"分发→变现"的技术演进，每一步都有明确的业务收益。
- **亮点2：pCTR×price排序机制的深度理解**。这是广告竞价的核心机制，在百度时期就已经掌握并实践，为后续OPPO的oCPX智能出价打下了坚实基础。
- **亮点3：系统优化而非单点调参**。CTR模型的优化不是简单调参，而是从样本构建、样本不平衡、历史特征平滑、特征选择、用户特征引入五个维度系统优化，体现了对广告算法的全面理解。
- **亮点4：用户画像的冷启动方案**。基于安装APP列表预测性别/年龄，是在缺乏用户注册信息时的经典冷启动方案，这个能力可直接迁移到广告定向场景。
- **亮点5：跨领域能力复用**。熊掌号内容评价体系的特征工程和模型优化思路，可直接复用到广告质量分评估场景，体现了技术能力的可迁移性。
- **难点1：国际化场景的数据稀疏性**。MoboMarket面向海外用户，用户行为数据相对国内更稀疏，样本量和特征覆盖率都有限，模型训练更具挑战。
- **难点2：CTR/CVR预估的延迟反馈问题**。用户从点击到转化（下载/安装）存在时间差，CVR模型的正样本标签有延迟，需要处理延迟反馈带来的预估偏差。
- **难点3：新广告冷启动**。新广告无历史CTR数据，贝叶斯平滑只能部分缓解，需要探索性流量分配来快速积累数据。
- **难点4：内容质量评估的主观性**。熊掌号/百家号的内容质量评估涉及主观判断，标签噪声大，需要多模型融合和人工审核来保证质量。

## 复盘与局限
- **复盘**：百度时期是我广告算法生涯的起点，从协同过滤推荐到GBDT CTR预估再到XGBoost CVR预估，完整经历了"分发→变现"的技术演进。CTR模型的eCPM+21%和CVR模型的eCPM+24%，验证了"预估—排序—收入"链路的商业价值。更重要的是，在这个过程中我系统掌握了广告算法的核心技术：样本构建、特征工程、模型训练、pCTR×price排序机制、贝叶斯平滑、样本不平衡处理等，这些基础能力为后续OPPO的oCPX智能出价、端云协同、对比学习等更复杂的广告项目打下了坚实基础。熊掌号内容评价体系的工作，则让我积累了与产品运营共建指标体系、开发内部工具的跨团队协作经验。
- **局限1：材料中缺乏技术细节**。百度时期的项目主要来自简历描述，缺乏工作资料和实验记录的支撑，很多技术细节（如具体特征列表、模型参数、实验配置）无法还原。
- **局限2：eCPM提升的实验细节缺失**。eCPM+21%和+24%是简历中的权威数字，但实验的流量比例、观察周期、统计显著性等细节未记录。
- **局限3：CVR模型的延迟反馈处理未记录**。广告转化存在延迟反馈问题，材料中未记录CVR模型如何处理延迟标签，这是广告CVR预估的核心难点之一。
- **局限4：国际化场景的特殊性未充分体现**。MoboMarket面向海外用户，数据稀疏性、用户行为差异、合规要求等国际化场景的特殊性在材料中未充分体现。
- **局限5：熊掌号项目的量化结果缺失**。熊掌号搜索指数和百家号资源方模型的效果（如内容质量提升、搜索体验改善）未在材料中记录量化数字。

## 可迁移点
1. **"预估—排序—收入"广告链路的核心方法论**：pCTR×price排序机制是所有广告系统的核心，从搜索广告到信息流广告到应用商店广告，这一方法论通用。
2. **CTR模型系统优化的五个维度**：样本构建、样本不平衡、历史特征平滑、特征选择、用户特征引入，这五个维度是任何CTR/CVR模型优化的标准检查清单。
3. **贝叶斯平滑在稀疏特征中的应用**：新广告/新内容的历史特征平滑是广告/推荐系统中的通用技巧，可迁移到任何有冷启动问题的场景。
4. **基于行为列表的用户画像冷启动**：基于安装APP列表/浏览历史/购买记录预测用户人口属性，是用户画像冷启动的经典方法，可迁移到电商、内容、广告等任何需要用户画像的场景。
5. **多模型融合提升鲁棒性**：GBDT+LR+规则的多模型融合，在内容质量评估、广告质量分、风控评分等需要高鲁棒性的场景中通用。
6. **与产品运营共建指标体系的方法论**：从业务目标出发，拆解为可量化的评价维度（优质度/领域集中度/原创度），构建特征库和评分模型，开发内部工具降低使用门槛，这一方法论可迁移到任何需要跨团队协作的指标体系建设项目。
