# 大模型推荐 · 落地能力与案例

> 本目录承载大模型推荐专题的**六大落地能力分述**与**真实案例数字**，用于面试"具体能带来什么"时的实例支撑。完整方法论见 [`01_方法体系/00_总论`](../01_方法体系/00_总论_LLMforRecommendation.md)。

---

## 六大落地能力一览（面试挑 2-3 个讲透）

| 能力 | 一句话 | 关键数字/代表 |
|---|---|---|
| **① 跨语言语义对齐** | 多语搜索词与应用描述映射到同一空间 | Coupang CSRM-LLM：缺陷率 **-45.8%**、会话购买率 **+0.866%** |
| **② 新兴市场冷启动** | LLM 生成伪行为/软标签，自蒸馏检索模型 | 面向东南亚多语稀缺场景 |
| **③ 文化偏好理解** | 世界知识编码为推荐信号 | "斋月印尼用户祈祷/慈善应用激增" |
| **④ 冷启动应用推荐** | 新应用上架首日即合理推荐 | LLM-InS（WSDM 2024）伪交互数据，优于所有传统 |
| **⑤ 游戏体验个性化匹配** | 评论语义+视觉风格+跨游戏关联推理 | 盛大 Tokyo **MeepleLM**（MDA 三层 + 五类玩家画像） |
| **⑥ 游戏冷启动与长尾分发** | 独立游戏也能被精准分发 | 避开头部大作垄断 |

---

## 能力边界（先讲清擅长/不擅长，显专业）

- ✅ 擅长：语义理解、跨语言对齐、内容理解、知识推理、数据生成
- ❌ 不擅长：实时排序（P99 需 <50ms，LLM 秒级）、隐式协同过滤信号建模

> 结论话术："大模型是内容理解引擎，协同过滤交给传统模型，各干各擅长的。"

---

## 方法体系的四条主流路线（快速回看）

1. 特征增强（工业最成熟，核心价值冷启动）
2. 端到端生成式推荐（OneRec **+1.6%** 观看时长 / Meta HSTU / Google PLUM / 网易 Ciimber）
3. 对话式推荐（用户直接对话表达需求）
4. 用户仿真（Meta RecoWorld：LLM 虚拟用户训练推荐策略）

另见两条业界技术路线：fine-tune LLM（TALLRec）+ Generative Retrieval（semanticID）。
