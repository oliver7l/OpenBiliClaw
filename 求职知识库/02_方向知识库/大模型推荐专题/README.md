## 一句话主线（先背这个）

> "大模型在推荐系统中是**上游内容理解引擎**，不是在线排序器。用它擅长的事（语义/跨语言/内容/知识推理/数据生成）做离线特征生成和冷启动内容理解，产物注入传统轻量级排序模型，兼顾质量与速度；端到端生成式推荐（OneRec/HSTU）是前沿方向但工程成熟度仍在爬坡。"
