## 一句话定位
腾讯看点搜索调研工具规划

## 核心内容摘要
该文档详细描述了在线 debug、Label 平台、Query 抽取平台等调研工具的设计与功能，用于支持产品和研发团队进行效果评估及问题分析。

## 关键方法 · 模型 · 指标
- 在线 debug：抓取 query 对应的环境静态页面，对比不同环境的效果。
- Label 平台：提供任务提交、全量 query 抓取结果展示、前 N DIFF 链接等功能。
- Query 抽取平台：支持普通随机 Q、时效性随机 Q 和突发 Q 的抽取。
- ABtest、intervaling 实验、LB 测试等 A/B 测试方法。

## 与推荐/广告/数据科学面试的关联
- 在线 debug 和 Label 平台可用于评估推荐系统和广告系统的性能，分析用户行为。
- Query 抽取平台可以用于优化搜索算法和提高广告相关性。
- ABtest、intervaling 实验等 A/B 测试方法适用于验证推荐策略的有效性。
