# D2Q端到端语义检索召回

## 一句话定位
腾讯微视/QQ看点的D2Q端到端语义检索召回方案。

## 核心内容摘要
该项目旨在提升资讯文章底部query推荐的相关性和时效性，通过DSSM模型架构（如Bi-LSTM RNN）进行文本表示，并基于线上点曝数据训练模型。目标是每日线上点击相对提升10%。

## 关键方法 · 模型 · 指标
- 文本表示：Word->word2vec词表、Title/Sentence->tf-idf生成词权、Doc Paragraph->LDA主题表示。
- DSSM模型架构：Bi-LSTM RNN。
- 训练数据：线上query推荐的点曝数据。
- 模型训练与finetune：基于Query-Title进行finetune，随语料定期更新。
- 服务搭建：D2U端到端语义召回服务（similarity、Vectorization）。

## 与推荐/广告/数据科学面试的关联
- 推荐系统中的文本表示方法和模型架构。
- 端到端的服务设计与实现。
- 基于历史点击数据训练推荐模型的方法。
- 提升搜索推荐相关性的技术手段。

## 关键术语
- D2Q：Doc to Query
- DSSM：Deep Structured Semantic Model
- Bi-LSTM RNN：双向长短时记忆网络
- tf-idf：词频-逆文档频率
- LDA主题表示：Latent Dirichlet Allocation 主题模型
