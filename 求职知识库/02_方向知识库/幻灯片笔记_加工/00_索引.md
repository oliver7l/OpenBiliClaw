## 三、常用命令

```bash
cd 求职知识库/_系统_知识库引擎/scripts

# 1) 处理（可断点续跑，已完成的自动跳过；指定 part 或全部）
python3 slides_pipeline.py part16
python3 slides_pipeline.py

# 2) 查看处理台账
python3 slides_pipeline.py --status

# 3) 重建全文索引 + 检索
python3 slides_index.py
python3 slides_index.py 查 对比学习

# 4) 登记三层产出与未处理项
python3 slides_ledger.py
```

数据库查询示例：

```bash
sqlite3 ../数据/幻灯片笔记.db "SELECT layer, topic, lines FROM processed_notes;"
sqlite3 ../数据/幻灯片笔记.db "SELECT item, reason FROM unprocessed WHERE status='待处理';"
```

## 五、已知待确认（重要）

1. **多位置校准偏差口径冲突**：幻灯片笔记原文写 **"50%+ → 20% 以内"**，简历/其他知识库写 **"30% → 20%"** —— 面试前必须统一成一个版本。
2. OCR 失真处已在加工层用「?」标注（如某生成式推荐项目名、MeepleLM 机构名），引用时需谨慎。
3. 加工层部分话术原为"回百度国际化"场景撰写，用于其他岗位时**必须改写**（比亚迪版已改写完成）。
