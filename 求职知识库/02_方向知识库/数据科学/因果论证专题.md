# 面试专题：怎么证明"确实是因果"（不是相关）

> 通用备战资产。凡 JD 含「因果分析 / 策略效果评估 / AB 实验 / 增量」，本题必被追问。
> 核心心法：**能随机一定随机；不能随机先验证识别假设；假设不成立就如实说不可靠，别给业务假数字。**

---

## 一、30 秒标准答（开场背这个）

> "证明因果我按优先级来：**第一，能随机就一定做 AB 随机实验**——随机化打断混淆，是黄金标准；**第二，不能随机**（用户自选择、政策类、客群层面干预）就用观测因果，按场景选 DID / PSM / 合成控制 / IV / RDD；**第三，观测因果的关键是识别假设**——DID 靠平行趋势、PSM 靠条件独立+共同支撑，必须先验证假设再谈结论；**第四，一定做稳健性检验**（安慰剂、事件研究、换对照组、换时间窗），结论才敢落地。
> 我在腾讯那个关注行为分析里就是这么做的：描述性看留存高 9.4pp，但用 DID 剥离后不显著——因为基线本身就不可比（活跃天数 4.57 / 3.35 / 2.54），我如实下了"因果增量不成立"的结论，没把选择偏差当效果。"

## 二、因果识别方法速查表（什么场景用什么）

| 方法 | 适用场景 | 核心假设 | 怎么验证假设 | 估计什么 |
|---|---|---|---|---|
| **AB 随机实验** | 能随机分流（策略/UI/算法/触达） | 随机化 → 处理独立于潜在结果 | SRM 检验（样本比例不匹配）、A/A 测试、预实验期 AA | ATE |
| **DID 双重差分** | 有明确干预时点 + 处理/对照两组 | **平行趋势** | 干预前多期趋势图；安慰剂检验（把干预时点人为提前）；事件研究法 | ATT |
| **PSM 倾向得分匹配** | 观测协变量多，想构造可比组 | **条件独立（可忽略性）** + 共同支撑 | 匹配后标准化偏差 <10%、共同支撑图；**只能解决观测混淆，未观测混淆无力** | ATT |
| **PSM + DID** ⭐ | 基线差异大时（最推荐） | 平行趋势 + 条件独立 | 先匹配出基线可比样本，再 DID，双保险 | ATT |
| **合成控制** | 单个处理单元（某城市/某地区政策） | 合成组能复刻处理组干预前路径 | 干预前拟合优度；安慰剂（换处理单元） | ATT |
| **IV 工具变量** | 有内生性 / 未观测混淆 | 相关性 + **排他性约束** | 弱工具检验（F 值）、过度识别检验 | LATE（compliers） |
| **RDD 断点回归** | 有连续变量 + 明确断点（分数/阈值/额度线） | 断点附近局部随机、无操纵 | McCrary 密度检验、协变量连续性 | LATE（断点附近） |
| **Uplift / ITE** | 不只问"平均有效"，问"对谁有效" | 需随机或条件独立 | Qini 曲线 / 增益分位数 | ITE（个体效应） |

## 三、你的弹药A案例：完整回答模板（被追问直接甩这套）

**背景**：腾讯QQ看点，分析"用户关注账号"行为是否真提升留存和时长。

**步骤化答法（5 步，能扛追问）**：

1. **先问能不能随机** → 不能。关注是用户自选择行为，不能随机强制用户去关注（强制也不合用户意愿）。所以只能走观测因果。

2. **构造处理/对照，跑 DID**
   - 处理组：6/1 有新增关注关系的用户（86.2 万）；对照组：同日有消费但未关注、以及从未关注过的用户。
   - 模型（statsmodels OLS）：`avg_duration ~ C(is_treat) + C(is_post) + C(is_treat):C(is_post)`，**看交互项系数是否显著**——交互项就是 DID 估计量，即剥离时间趋势后的政策净效应。

3. **验证识别假设（最关键，面试官就问这步）**
   - DID 成立靠**平行趋势**：如果没发生关注，两组用户的时长/留存变化轨迹应一致。
   - 我的验证：①把干预前窗口（5/25–5/31）两组的趋势画出来看是否平行；②做**安慰剂检验**——把干预时点人为提前，若交互项仍显著，说明是时间趋势本身而非关注在起作用；③更严谨做**事件研究法**，画干预前后各期 DID 系数，干预前的系数应在 0 附近且不显著。

4. **结论：不显著 → 我不下因果结论**
   - 描述性看：关注用户 6 天留存 93.9%，vs 整体 84.5%、vs 从未关注 75%，高出 9.4pp / 18.9pp，看着很美。
   - 但 DID 交互项不显著，所以这个"提升"很大程度是**选择偏差**：本来就更活跃、更愿意深度使用产品的用户才会去关注账号——**基线数据已经说明两组不可比**（干预前活跃天数 4.57 / 3.35 / 2.54，日均时长 3414s / 1198s / 676s）。
   - 所以我的结论是：**关注的因果增量不成立**（至少对时长/活跃天数），不能拿"关注用户留存高 9.4pp"去忽悠业务做关注引导。

5. **改进方案（展示你懂下一步）**
   - 做 **PSM + DID**：先用干预前的活跃天数、日均时长、消费次数等做倾向得分匹配，找出基线可比的用户对，再在匹配样本上跑 DID，这样平行趋势更可信。
   - 或换更干净的对照组：用"近期即将关注但尚未关注"的用户（not-yet-treated）做对照。
   - 若做异质分析：分人群看（一线城市 +5.47%、女性留存 +18pp）是否在某些子群显著，做成 **Uplift 视角**——对谁引导关注才有增量。

## 四、高频追问防御（每个都给口径）

**Q1：平行趋势怎么验证？**
→ 干预前多期趋势图（目视+回归）；安慰剂检验（提前干预时点，交互项应不显著）；事件研究法（干预前各期系数应在 0 附近）。三条一起上。

**Q2：你那个对照组构造合理吗？关注用户本来就活跃，这不就是选择偏差？**
→ 完全同意，这正是我做 DID 而不是直接比留存的原因。先承认基线不可比（4.57/3.35/2.54），再说明 DID 用前后差分消掉**不随时间变化的组间差异**，但**随时间变化的选择偏差消不掉**——所以结论是不显著，我不会硬说有效。更严谨就 PSM+DID。

**Q3：DID 不显著怎么解释？**
→ 三种可能：① 真实无因果增量（描述性虚高来自选择偏差）；② 平行趋势不成立（DID 估计有偏）；③ 统计功效不足（样本量/方差/指标噪声）。我这个 case 基线差异巨大，主要是 ①+②，所以结论要谨慎。

**Q4：为什么不做 AB？**
→ 关注是自选择行为，没法随机强制；业务上也不能强制用户关注。所以走观测因果。**但能随机的策略我一定做 AB**——比如红点提频、触达策略、推荐策略上线，都是随机分流，最干净。

**Q5：Uplift 和因果什么关系？**
→ Uplift 就是个体处理效应 ITE 的估计，本质是异质因果——不只问"平均有没有效"，而是"对谁有效"。阿里文娱用 Uplift 做智能营销，只对有增量的人发券，避免在"本来就会来"的人身上浪费预算。

**Q6：举个相关≠因果的例子？**
→ 冰淇淋销量与溺水人数正相关（共同原因=气温）；我的 case 里"关注用户留存更高"（共同原因=用户本身更活跃）。

**Q7：你中信的因果归因怎么做的？** `⟦确认实际方法后钉死⟧`
→ 能随机的策略（外呼/短信/企微触达、定价梯度）走 AB 随机分流看增量；客群层面、不能随机的干预（如额度/定价整体调整）走 DID/PSM 剥离混淆；**统一口径是增量，不是绝对量**——避免把同期自然增长算成策略效果。

## 五、各段经历怎么接因果话题（口径统一）

| 经历 | 因果口径 |
|---|---|
| **中信** | 策略能随机的做 AB（触达/外呼/短信随机分流）；定价/额度这类客群层面干预用 DID/PSM；目标=增量口径 |
| **腾讯QQ看点** | **弹药A**：关注行为 DID 不显著 → 敢说"无因果增量"；DAU 下降拆解（弹药B）用流转矩阵+建模定位关键因子，而非只看相关 |
| **OPPO / 微视** | 推荐/算法策略一律 AB 随机分流（微视关注页 +10.59%、发现好友页 +14.22% 都是随机实验结论），最干净的因果 |
| **百度** | eCPM +23% 为策略上线后的实验增量 |

**统一红线**：永远说"**增量**"，不说"上线后涨了 X%"——后者没有对照组，是最容易被判定为不严谨的表达。

## 六、一句加分收尾（自然带出来）

> "我做因果分析有个原则：**先问能不能随机，能随机绝不搞观测；不能随机就先验证识别假设，假设不成立就如实说结论不可靠，而不是给业务一个漂亮的假数字。** 因为策略一旦按假结论推广，损失是真金白银。"
