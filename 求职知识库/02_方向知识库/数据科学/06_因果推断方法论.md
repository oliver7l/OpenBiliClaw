# 因果推断方法论

---

## 一、因果推断在数据科学中的应用全景

### 1.1 为什么数据科学需要因果推断

数据科学的核心目标是从数据中发现规律、指导决策。但我们观察到的大部分规律只是**相关性**，而非**因果性**。如果把相关性误当成因果性，会导致严重的决策错误。

我在腾讯QQ看点做关注链路分析时，业务方最关心的问题是："用户关注了账号之后，留存和时长真的提升了吗？是关注导致了提升，还是本来就高活的用户更愿意关注？"这个问题如果只用描述性统计回答，会严重高估关注的价值，进而误导资源投入。

因果推断在数据科学中的价值体现在三个层面：
- **策略评估**：量化策略（如营销触达、定价调整、推荐算法优化）对核心指标的真实因果效应，排除选择偏差和时间趋势
- **机制理解**：识别用户行为（关注、点赞、评论、消费）与长期价值（留存、时长、LTV）之间的因果路径，而非仅仅是相关关系
- **资源分配**：基于因果效应大小决定在哪些场景、哪些用户群体上投入资源，避免在"本来就会发生"的事情上浪费预算

### 1.2 相关≠因果：三条假因果路径

面试官最爱问："你发现关注用户高活，这不就证明关注有用吗？"——**不对，这是幸存者偏差**。必须主动列出这三条假因果路径：

| 假因果路径 | 含义 | 在"关注→留存"里的样子 |
|---|---|---|
| **选择偏差/幸存者偏差** | 更"好"的样本才接受处理 | 高活跃用户本来就更爱去关注 |
| **混杂因素（Confounding）** | 第三个变量同时影响处理和结果 | 活跃度/年龄/城市同时影响"是否关注"和"留存" |
| **反向因果（Reverse Causality）** | 结果反过来影响处理 | 留存高→才有机会/才更愿意持续关注 |

> 话术：**"我最初的分组对比发现关注用户天然高活——但这很可能是幸存者偏差：高活跃用户本来就更容易去关注；也可能是混杂（活跃度、年龄、城市同时影响关注和留存）；还可能是反向因果（留存高才有机会持续关注）。所以相关只能说明'有关'，不能证明'导致'。"**

经典例子：冰淇淋销量与溺水人数正相关（共同原因=气温）；我的case里"关注用户留存更高"（共同原因=用户本身更活跃）。

### 1.3 因果推断的理论基础

**Rubin反事实框架（Potential Outcomes Framework）**：
- 对每个个体i，定义两个潜在结果：Y_i(1)（接受处理的结果）和Y_i(0)（未接受处理的结果）
- 个体处理效应ITE = Y_i(1) - Y_i(0)
- 平均处理效应ATE = E[Y_i(1) - Y_i(0)]
- 处理组平均处理效应ATT = E[Y_i(1) - Y_i(0) | T_i=1]
- **根本问题**：我们永远无法同时观察到Y_i(1)和Y_i(0)，只能观察到其中一个。因果推断的本质就是估计反事实结果。

**三大假设**：
1. **无未观测混杂（Unconfoundedness / Ignorability）**：给定可观测协变量X，处理分配T与潜在结果独立：(Y(1), Y(0)) ⊥ T | X
2. **正性（Positivity / Common Support）**：对于每个X值，都既有处理组也有对照组：0 < P(T=1|X) < 1
3. **SUTVA（稳定单元处理值假定）**：一个个体的处理不会影响其他个体的结果，且处理版本唯一

**Hill准则（因果判定的可操作化标准）**：
- 时间先后（Temporality）：因在前、果在后
- 剂量-反应（Dose-Response）：强度随剂量变化
- 机制可解释（Plausibility）：因果链条讲得通
- 方法一致性（Consistency）：多种方法同方向
- 关联强度（Strength）：效应量足够大
- 特异性（Specificity）：特定原因导致特定结果

### 1.4 因果识别方法速查表（什么场景用什么）

| 方法 | 适用场景 | 核心假设 | 怎么验证假设 | 估计什么 |
|---|---|---|---|---|
| **AB随机实验（RCT）** | 能随机分流（策略/UI/算法/触达） | 随机化→处理独立于潜在结果 | SRM检验（样本比例不匹配）、A/A测试、预实验期AA | ATE |
| **DID双重差分** | 有明确干预时点+处理/对照两组 | **平行趋势** | 干预前多期趋势图；安慰剂检验（把干预时点人为提前）；事件研究法 | ATT |
| **PSM倾向得分匹配** | 观测协变量多，想构造可比组 | **条件独立（可忽略性）**+共同支撑 | 匹配后标准化偏差<10%、共同支撑图；**只能解决观测混淆，未观测混淆无力** | ATT |
| **PSM+DID** ⭐ | 基线差异大时（最推荐） | 平行趋势+条件独立 | 先匹配出基线可比样本，再DID，双保险 | ATT |
| **合成控制（Synthetic Control）** | 单个处理单元（某城市/某地区政策） | 合成组能复刻处理组干预前路径 | 干预前拟合优度；安慰剂（换处理单元） | ATT |
| **IV工具变量** | 有内生性/未观测混淆 | 相关性+**排他性约束** | 弱工具检验（F值>10）、过度识别检验 | LATE（compliers） |
| **RDD断点回归** | 有连续变量+明确断点（分数/阈值/额度线） | 断点附近局部随机、无操纵 | McCrary密度检验、协变量连续性 | LATE（断点附近） |
| **Uplift/ITE** | 不只问"平均有效"，问"对谁有效" | 需随机或条件独立 | Qini曲线/增益分位数 | ITE（个体效应） |

### 1.5 证明阶梯：从"相关"到"因果"逐级攀登（5级）

| 级别 | 方法 | 堵住什么 | 你的项目证据 |
|---|---|---|---|
| **L1相关** | 分组对比/相关性 | 只发现问题，不证明 | 关注用户周活天数+21.2%（仅此不足以结论） |
| **L2控制** | 分层/PSM匹配/回归控制 | 堵**可观测**混杂 | 按活跃度/年龄/城市/性别拉齐再比 |
| **L3时序** | DID双重差分 | 堵**时间趋势+个体固定效应** | 关注前后差分vs未关注组同期差分+平行趋势检验 |
| **L4自然实验** | 近随机对照 | 堵**未观测混杂**（最关键） | **新用户"关注2 vs 1"次留+9pp**——新用户习惯未形成，差异近随机 |
| **L5随机实验** | RCT/AB | 随机化堵住所有（含未观测）混杂，金标准 | 后续可对"引导关注"做AB验证闭环 |

> 关键认知：**因果不是用一个方法"证明"出来的，而是用方法组合把每一类替代解释逐一排除。**

## 二、核心项目：关注账号与留存时长的因果关系分析

> 这是我在腾讯QQ看点做的最核心的因果分析项目，也是面试中最有差异化的项目。我会从研究设计→数据→方法→结论→业务落地全链路讲透。

### 2.1 研究问题

业务背景：QQ看点正在大力推进关注链路建设，包括推荐页场景化推人弹窗、个人页关注按钮优化、好友关系链冷启动等。业务方需要回答一个根本问题：**用户关注账号到底能不能提升留存和时长？提升多少？在哪些用户群体上效果最明显？**

这个问题的难点在于：关注行为不是随机分配的，高活用户更倾向于关注，直接对比"有关注用户"和"无关注用户"会严重高估关注的因果效应。

因此我设计了三层分析框架：
1. **描述性统计层**：关注前后的指标变化，以及与对照组的横向对比
2. **因果识别层**：用DID控制时间趋势和组间差异，用PSM控制可观测混淆变量
3. **异质性分析层**：按性别、年龄、城市级别、新增关注个数分层，识别因果效应的异质性

### 2.2 数据设计

**数据时间**：核心分析选取2020年6月1日作为关注行为基准日（treatment日），观察窗口为关注前一周（5/25-5/31）和关注后一周（6/1-6/7）。

**数据来源表**：
- `t_dwa_kd_fans_focus_di_day`：账号粉丝关注关系增量表，记录每日新增关注关系（oper_type=1表示关注）
- `fcc_share_user_behavior_d`：看点日活用户uin粒度行为聚合表，包含active_days_week（周活跃天数）、duration_session（会话时长）等指标
- `fcc_share_user_profile_acc_d`：用户画像表，包含age、gender、city_common_level（城市级别）

**数据清洗**：
- 剔除有导流行为的特定账号（王者荣耀、穿越火线等11个游戏/赛事官方账号），避免异常关注关系干扰
- 验证每日新增关注关系的平稳性：发现基本稳定（周末小高峰），但7/6-7/10有一波小高峰，与业务确认是直播号迁移导致的数据异常，不作为分析时间参照点

**三组用户定义**：

| 用户组 | 定义 | 样本量 |
|---|---|---|
| 处理组（Treatment） | 6/1有新增关注关系的用户 | **862,108** |
| 对照组1（总用户） | 6/1有消费行为的总用户 | **77,976,232** |
| 对照组2（纯无关注） | 6/1前从未关注过、且6/1有消费的用户 | **23,481,553** |

（来源：关注账号和用户的留存与时长的因果关系分析.txt）

### 2.3 第一层：描述性前后对比

**核心思路**：对处理组用户，对比关注前一周（5/25-5/31）和关注后一周（6/1-6/7）的周活跃天数和日均时长。

**计算方式**：
- 关注前周活跃天数 = 6/1当天的active_days_week - 1（减去关注当天）
- 关注前日均时长 = 5/25-5/31的duration_session均值
- 关注后周活跃天数 = 6/1-6/7的活跃天数计数
- 关注后日均时长 = 6/1-6/7的duration_session均值

**整体结果**：

| 指标 | 关注前 | 关注后 | 变化 | 提升比例 |
|---|---|---|---|---|
| 周活跃天数 | 4.57 | 5.54 | +0.97天 | **+21.2%** |
| 日均时长（秒） | 3,414.24 | 3,469.81 | +55.57秒 | **+1.6%** |
| 未来6天留存率 | — | 93.9% | — | 较总用户84.5%高**9.4pp** |

（来源：关注账号和用户的留存与时长的因果关系分析.txt）

**与对照组横向对比**：

| 用户组 | 过去周日活天数 | 过去周日均时长 | 未来周日活天数 | 未来周日均时长 | 日活提升 | 时长提升 |
|---|---|---|---|---|---|---|
| 6/1新增关注用户 | 4.57 | 3,414s | 5.54 | 3,470s | +0.97 | +55.57s |
| 6/1有消费总用户 | 3.35 | 1,198s | 4.33 | 1,037s | +0.98 | -161.03s |
| 6/1前从未关注用户 | 2.54 | 676s | 3.51 | 559s | +0.97 | -117.12s |

（来源：关注账号和用户的留存与时长的因果关系分析.txt）

**关键发现**：三组用户的周活跃天数提升量几乎一致（约+0.97天），说明**周活跃天数的提升可能是时间趋势（如周末效应），而非关注的因果效应**。而时长方面，关注组是正增长，对照组是负增长，这暗示关注可能有时长增益，但需要DID进一步验证。

### 2.4 第二层：DID双重差分检验

**核心思路**：DID通过比较处理组和对照组在干预前后的差异变化，消除时间趋势和组间固定差异，得到纯净的因果效应。

**模型设定**：
```
Y = β₀ + β₁·is_treat + β₂·is_post + β₃·(is_treat × is_post) + ε
```
- `is_treat`：是否为处理组（6/1有新增关注=1，否则=0）
- `is_post`：是否为关注后时期（6/1及以后=1，之前=0）
- 交互项系数`β₃`即为DID估计量，代表关注的因果效应

**实现代码（Python/statsmodels）**：
```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

data = pd.read_csv('fensi_did.csv')

# 关注行为时长DID回归模型
model = smf.ols(
    formula='avg_duration ~ C(is_treat) + C(is_post) + C(is_treat):C(is_post)',
    data=data
)
result = model.fit()
result.summary2()  # 主要看交互项系数的P值是否显著
```

**DID数据获取SQL**：
```sql
SELECT p_date, is_treat, is_post,
       AVG(duration_session) AS avg_duration,
       COUNT(duration_session) AS amount
FROM (
    SELECT user_id,
           CASE WHEN b.uin > 0 THEN 1 ELSE 0 END AS is_treat
    FROM (
        SELECT user_id FROM fcc_share_user_behavior_d
        WHERE sp_app_id = 'kd' AND p_date = 20200601
    ) a
    LEFT JOIN (
        SELECT DISTINCT(uin) AS uin FROM t_dwa_kd_fans_focus_di_day
        WHERE oper_type = 1 AND p_date = 20200601
    ) b ON a.user_id = b.uin
) c
LEFT JOIN (
    SELECT p_date, user_id,
           CASE WHEN p_date >= 20200601 THEN 1 ELSE 0 END AS is_post,
           duration_session
    FROM fcc_share_user_behavior_d
    WHERE sp_app_id = 'kd' AND p_date BETWEEN 20200525 AND 20200608
) d ON c.user_id = d.user_id
GROUP BY p_date, is_treat, is_post;
```

**DID结论**：

| 结果变量 | DID交互项显著性 | 结论 |
|---|---|---|
| 日均时长 | **不显著**（P值未达0.05） | 关注对时长的因果效应不显著 |
| 周活跃天数 | **不显著** | 关注对周活跃天数的因果效应不显著 |
| 次留率 | **不显著** | 关注对次留的因果效应不显著 |

（来源：关注账号和用户的留存与时长的因果关系分析.txt）

**为什么DID不显著？——深度解读**：
这是面试中最容易被追问的点。我的解释是：
1. **选择偏差主导**：愿意关注的用户本身就是高活用户，关注前的基线时长和活跃度已经远高于对照组，DID差分掉了这部分基线差异
2. **关注的边际效应递减**：处理组用户关注前已经是高活状态（周活跃4.57天，日均3414秒），关注对已经高活的用户边际增益有限
3. **时间窗口较短**：仅观察关注后一周，关注的长期留存效应可能需要更长时间窗口才能显现
4. **关注质量参差**：用户关注的账号质量不一，低质量关注可能抵消了高质量关注的增益

### 2.5 第三层：PSM倾向得分匹配（补充分析）

在补充分析中，我采用了更精细的PSM方法，按新增关注个数分层量化因果效应。

**匹配设计**：
- **用户群A（处理组）**：7/13有关注行为的用户，共90w+，随机抽取50W样本，剔除未匹配上的样本后最终45W
- **用户群B（对照组）**：从7/13有消费但无关注行为的用户中，为A中每位用户匹配同质化最高的用户
- **匹配维度**：相同年龄区间 + 相同城市类别 + 相同性别 + 相同过去7天消费总时长（按5分钟分箱）
- **匹配方式**：在每个匹配维度组合内，为处理组用户随机抽取一个对照组用户（rank() over partition by treat_user order by rand()）

**新增关注个数分档**：
由于新增1个关注关系的用户占当天新增关系的80%，新增关注在4个之内的人数占比达95%，因此分为四档：

| 新增关注个数 | 占比 |
|---|---|
| 1~4 | **95%** |
| 5~10 | **3%** |
| 11~16 | **1%** |
| >16 | **1%** |

（来源：关注账户与留存、时长、活跃天数因果分析_补充.txt）

**PSM核心结论**：

| 新增关注个数 | 未来7天时长提升比例 | 未来7天活跃天数提升 | 次留提升（绝对值） | 次留提升比例 |
|---|---|---|---|---|
| 1~4 | **+22.50%** | +0.01天（+0.25%） | +3.11pp | +3.8% |
| 5~10 | **+32.18%** | -0.16天（-2.81%） | +3.21pp | +4.0% |
| 11~16 | **+33.46%** | -0.17天（-3.15%） | +3.35pp | +4.3% |
| >16 | **+29.14%** | -0.22天（-3.89%） | +3.26pp | +4.0% |

（来源：关注账户与留存、时长、活跃天数因果分析_补充.txt）

**PSM结论解读**：
1. **关注行为有助于时长提升**：各档位未来7天总时长均有显著提升，其中新增关注11~16个的提升最明显，达**33.46%**
2. **关注对周活跃天数无明显差异**：1~4个档位微增，5个以上档位反而微降，说明关注不改变活跃天数
3. **关注有助于次留提升**：各档位次留均有3个百分点以上的提升，11~16个档位最大，达**3.35个百分点**（提升比例4.3%）
4. **剂量反应关系**：新增关注个数从1~4增加到11~16，时长和次留的提升幅度递增，但超过16后略有下降，呈现倒U型

**PSM匹配SQL核心逻辑**：
```sql
-- 在每个匹配维度组合内，为处理组用户随机匹配一个对照组用户
WITH t1 AS (
    -- 构造用户特征：是否处理组、年龄区间、性别、城市、时长分箱、新增关注分档
    SELECT a.user_id,
           CASE WHEN b.uin > 0 THEN 1 ELSE 0 END AS is_treat,
           -- 年龄区间、性别、城市级别、时长分箱（5分钟）、新增关注分档
           ...
    FROM ...
),
t4 AS (
    -- 处理组和对照组在匹配维度上自连接
    SELECT t2.*, t3.*
    FROM (SELECT * FROM t1 WHERE is_treat = 1 DISTRIBUTE BY rand() SORT BY rand() LIMIT 500000) t2
    LEFT JOIN (SELECT * FROM t1 WHERE is_treat = 0 DISTRIBUTE BY rand() SORT BY rand() LIMIT 500000) t3
        ON t2.age_range = t3.age_range
        AND t2.gender_level = t3.gender_level
        AND t2.duration_level = t3.duration_level
        AND t2.city_level = t3.city_level
    WHERE t3.user_id IS NOT NULL
)
-- 每个处理组用户随机选一个匹配的对照组用户
SELECT *
FROM (
    SELECT rank() OVER (PARTITION BY treat_user ORDER BY rand() DESC) AS rank, *
    FROM t4
) t5
WHERE rank = 1;
```

### 2.6 三层递进结论总结

| 分析层级 | 方法 | 核心结论 | 效应量 |
|---|---|---|---|
| **第一层：描述性** | 前后对比+横向对比 | 关注用户留存和时长显著高于对照组 | 留存高9.4pp、日活+21.2%、时长+1.6% |

### 2.9 关注数的质变阈值：14个

**核心发现**：用户关注**14个**账号是留存的质变阈值。

（来源：关注数与长留存的关联.txt）

**纵向分析（关注数与留存率的关系）**：
- 关注数与留存率**不是简单的正相关**
- 关注数到达**14个**时，留存率最高
- 关注数超过14个后，关注数与留存率呈现**负相关**

**横向分析（关注数与长留存的相关性）**：
- 用户的关注数与长留存的相关性较高
- 时间越长，关联性越大（30天留存的相关性 > 15天 > 7天）

**达到14个关注的时间窗口**：
- 选取4月1日-30日的新用户，追踪用户达到关注数14后的7天、15天、30天留存
- 剔除噪音后，用户在**第9到第14天**这个区间达到关注数14，后期留存表现较好
- **启发**：相对于更早完成14个关注，慢慢达成的效果更好

（来源：关注数与长留存的关联.txt）

**超过14个关注后留存下降的原因**：初步分析认为与**关注账号整体质量不高**有关。可能机制：
1. **信息过载**：关注过多账号后，关注流内容质量下降，用户反而减少消费
2. **低质量关注累积**：用户为了完成任务或被引导关注了大量低质量账号
3. **关注疲劳**：关注过多后，用户管理关注列表的成本上升

这与PSM分析中"新增关注11~16个时增益最大"的结论一致，也解释了为什么DID整体不显著——当关注数量超过最优阈值后，关注的边际效应变为负向，拉低了平均效应。

### 2.11 业务影响与落地

这个项目的结论直接影响了QQ看点关注增长的策略方向：

1. **关注增长的价值定位**：关注对时长和次留有正向因果效应（PSM验证），但对周活跃天数无显著影响。因此关注增长的核心价值在于**提升用户单次消费时长和短期留存**，而非提升活跃频率。

2. **资源倾斜方向**：
   - 一线城市用户关注的时长增益最大（5.47%），应优先在一线城市推关注
   - 女性用户关注的留存增益最大（18pp），应针对女性用户设计关注引导
   - 新增关注11~16个时增益最大，应引导用户关注到这个数量区间

3. **关注质量的重要性**：DID整体不显著但PSM分档显著，说明**关注的因果效应存在异质性，关注质量和数量是关键调节变量**。后续项目应关注关注账号的质量筛选。

4. **零关注用户的巨大空间**：DAU中近73%是"0关注"用户，登录用户中40%是"0关注"（630w），这是关注增长的核心蓝海。后续落地了"推荐页零关注用户场景化推人"项目。

## 三、三大因果推断方法深度讲解

### 3.1 DID双重差分（Difference-in-Differences）

#### 原理

DID的核心思想是：如果没有干预，处理组和对照组的时间趋势应该是平行的。因此，处理组在干预前后的变化量减去对照组在同一时期的变化量，就得到了干预的净因果效应。

**公式**：
```
DID = (Y_treat,after - Y_treat,before) - (Y_control,after - Y_control,before)
```

**回归形式**：
```
Y = β₀ + β₁·Treat + β₂·Post + β₃·(Treat × Post) + ε
```
- β₃即为DID估计量，其显著性通过t检验/P值判断

#### DID五要素（能讲全=立住）
1. **处理组**：观察期内首次产生关注行为的用户
2. **对照组**：同期从未关注、但经PSM匹配画像相似的用户
3. **两期**：关注发生前4周（pre）/后4周（post）
4. **指标**：周活跃天数、日均时长、未来6天留存
5. **估计**：`DID = (处理组_post − 处理组_pre) − (对照组_post − 对照组_pre)`

#### 适用场景
- 存在明确的干预时间点（如用户某天开始关注、政策某天实施）
- 可以找到合理的对照组（如同期有消费但无关注的用户）
- 干预前处理组和对照组具有平行趋势

#### 关键假设
1. **平行趋势假定（Parallel Trend Assumption）**：干预前处理组和对照组的结果变量趋势平行。这是DID最核心的假设
2. **SUTVA（稳定单元处理值假定）**：一个用户的处理不会影响其他用户的结果
3. **无预期效应**：处理组用户不会因为预期到干预而提前改变行为

#### 平行趋势检验（DID的生命线）

**三种检验方法**：
1. **事件研究图（Event Study）**：时间拆成pre 4周/post 4周，看处理组相对对照组逐周系数；pre期系数都在0附近、走势平稳则支持平行趋势
2. **图示法**：绘制处理组和对照组在干预前后的结果变量曲线，观察干预前两组趋势是否平行
3. **安慰剂检验**：把干预时点人为提前，如果交互项仍显著，说明是时间趋势本身而非干预在起作用

**事件研究法回归模型**：
```
Y = β₀ + Σ β_k·(Treat × Period_k) + γ·Treat + δ_t + ε
```
其中Period_k是相对于干预时点的第k期，β_k是第k期的DID系数。干预前各期的β_k应不显著（在0附近），干预后β_k应显著不为0。

#### 优点
- 简单直观，容易解释
- 可以消除不随时间变化的组间差异和共同的时间趋势
- 有成熟的显著性检验方法

#### 局限
- 平行趋势假定难以完全验证，只能检验干预前的趋势
- 如果存在随时间变化的混淆变量，DID估计会有偏
- 对干预时间点的清晰度要求高
- 当处理组和对照组基线差异过大时，DID可能不稳定

#### 在项目中的实现

**关注行为DID**：
- 处理组：6/1有新增关注关系的用户（86.2万）
- 对照组：6/1有消费但无关注的用户
- 时间窗口：5/25-6/7（关注前一周+关注后一周）
- 结果变量：日均时长、周活跃天数、次留率
- 结论：三个结果变量的DID交互项均不显著

**互动行为DID**：
- 处理组：6/15有点赞/评论/分享行为的用户（且之前一周无该行为）
- 对照组：6/15无该互动行为的用户
- 时间窗口：6/8-6/22
- 数据清洗：去除treatment当天（6/15）、前一天（6/14，次留为100%）、后一天（6/16）
- 结论：点赞/评论对时长提升显著（约3.2/3.4分钟），分享不显著；所有互动对次留均不显著

### 3.2 PSM倾向得分匹配（Propensity Score Matching）

#### 原理

PSM的核心思想是：为每个处理组用户找到一个或多个在可观测混淆变量上尽可能相似的对照组用户，使得匹配后的两组用户在混淆变量分布上均衡，从而模拟随机分组的效果。

**步骤**：
1. 用logistic回归估计每个用户的倾向得分（即被处理的概率）：`e(X) = P(T=1|X)`
2. 在共同支撑域（Common Support）内，为每个处理组用户匹配倾向得分最接近的对照组用户
3. 匹配后检验两组在混淆变量上的平衡性（标准化均值差<0.1）
4. 计算匹配后的平均处理效应（ATT）

#### 匹配方法对比

| 匹配方法 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| **最近邻匹配（1:1）** | 为每个处理组找倾向得分最接近的1个对照组 | 简单，匹配质量高 | 样本量损失大，可能有偏差 |
| **最近邻匹配（1:k）** | 为每个处理组找k个最接近的对照组 | 样本利用率高，方差小 | 匹配质量下降，k过大引入偏差 |
| **卡尺匹配（Caliper）** | 在倾向得分差小于阈值的范围内匹配 | 避免差得太远的匹配 | 可能匹配不上，样本损失 |
| **核匹配（Kernel）** | 用所有对照组加权匹配，权重与倾向得分距离负相关 | 样本利用率最高，方差最小 | 计算复杂，权重选择主观 |
| **精确匹配（Exact Matching）** | 在分类变量上完全相同才匹配 | 匹配质量最高，平衡性天然满足 | 维度多时维度灾难，样本损失大 |

#### 项目中的简化实现

在QQ看点项目中，我采用了**精确匹配（Exact Matching）**而非传统的倾向得分近邻匹配，因为匹配维度较少且都是分类变量：

**匹配维度**：
- 年龄区间（1~12/13~17/18~23/24~30/31~40/41~50/50以上/未知）
- 城市级别（一线/新一线/二线/三线/四线/五线/未知）
- 性别（男/女/未知）
- 过去7天消费总时长（按5分钟分箱：floor(total_duration_min/5)*5）

**匹配方式**：在每个维度组合内，为处理组用户随机抽取一个对照组用户。

**样本量**：处理组90w+ → 随机抽50W → 匹配成功后45W。

#### 平衡性检验

匹配后必须检验两组在混淆变量上的平衡性：
- **标准化均值差（Standardized Mean Difference, SMD）**：`SMD = (均值_treat - 均值_control) / 标准差_pooled`，一般要求SMD < 0.1
- **共同支撑图（Common Support Plot）**：检查处理组和对照组的倾向得分分布重叠程度
- **协变量平衡表**：匹配前后各协变量的均值、标准差、SMD对比

因为我用的是精确匹配，匹配后的两组在四个匹配维度上完全一致，平衡性天然满足。

#### 适用场景
- 处理不是随机分配的，但有丰富的可观测混淆变量
- 处理组和对照组在混淆变量上有重叠（共同支撑域）
- 需要估计处理组的平均处理效应（ATT）

#### 关键假设
1. **强可忽略性（Strong Ignorability / Unconfoundedness）**：给定可观测混淆变量X，处理分配与潜在结果独立。即所有影响处理分配和结果的混淆变量都已被观测到
2. **共同支撑（Common Support）**：对于每个X值，都既有处理组也有对照组用户，即0 < P(T=1|X) < 1

#### 优点
- 不依赖函数形式假设（匹配后可以直接做均值差）
- 可以直观检验匹配后的平衡性
- 对处理效应的异质性有较好的识别能力
- 适合大样本场景

#### 局限
- 只能控制可观测混淆变量，无法控制不可观测的混淆变量
- 当匹配维度很多时，容易出现维度灾难，匹配质量下降
- 倾向得分模型的设定会影响匹配结果
- 匹配会损失样本量，可能导致估计效率下降

### 3.3 工具变量法（Instrumental Variables, IV）

#### 原理

当存在未观测混淆变量时，DID和PSM都无法完全解决内生性问题。工具变量法通过找到一个只影响处理分配、不直接影响结果的外生变量（工具变量Z），用Z的变异来识别处理的因果效应。

**两个核心条件**：
1. **相关性（Relevance）**：工具变量Z与处理变量T强相关：Cov(Z, T) ≠ 0
2. **排他性约束（Exclusion Restriction）**：工具变量Z只通过T影响结果Y，不直接影响Y：Cov(Z, ε) = 0

**两阶段最小二乘法（2SLS）**：
- 第一阶段：T = π₀ + π₁·Z + ν（用工具变量预测处理变量）
- 第二阶段：Y = β₀ + β₁·T̂ + ε（用预测的处理变量估计因果效应）
- β₁即为IV估计量，代表处理的局部平均处理效应（LATE）

#### 弱工具检验

- **第一阶段F统计量**：F > 10通常认为工具变量不是弱工具
- 弱工具会导致IV估计有偏（偏向OLS估计），且标准误被低估

#### 适用场景
- 存在未观测混淆变量，DID/PSM无法解决
- 能找到满足相关性和排他性约束的工具变量
- 常见的工具变量：政策冲击、地理距离、历史因素、随机分配的激励

#### 在项目中的潜在应用

在关注→留存的因果分析中，可以尝试以下工具变量：
- **推荐页推人弹窗的灰度曝光**：弹窗曝光是随机分配的（AB实验），只通过影响关注行为影响留存，不直接影响留存。这是最理想的工具变量
- **好友关系链授权**：用户是否授权QQ/微信好友关系链，影响关注好友的概率，但不直接影响内容消费留存

**LATE解释**：IV估计的是局部平均处理效应（Local Average Treatment Effect），即"因为工具变量变化而改变处理状态的人"（compliers）的平均效应，不是全体用户的ATE。在关注案例中，IV估计的是"因为弹窗曝光而关注的用户"的关注效应，这部分用户可能与主动关注的用户不同。

#### 优点
- 可以解决未观测混淆变量导致的内生性问题
- 有明确的统计检验方法（弱工具检验、过度识别检验）

#### 局限
- 找到满足排他性约束的工具变量非常困难，排他性无法直接检验，只能靠论证
- 弱工具问题常见，会导致估计有偏
- 估计的是LATE而非ATE，外部有效性受限
- 工具变量的解释需要领域知识，容易被质疑

### 3.4 三大方法对比表

| 维度 | DID | PSM | IV |
|---|---|---|---|
| **核心原理** | 处理组与对照组的前后差异之差 | 在可观测变量上匹配处理组和对照组 | 用外生工具变量的变异识别因果效应 |
| **控制的混淆变量** | 不随时间变化的组间差异+共同时间趋势 | 所有可观测混淆变量 | 可观测+不可观测混淆变量 |
| **关键假设** | 平行趋势假定 | 强可忽略性+共同支撑 | 相关性+排他性约束 |
| **假设可检验性** | 平行趋势可检验（干预前） | 平衡性可检验，强可忽略性不可检验 | 相关性可检验，排他性不可检验 |
| **适用场景** | 有明确干预时间点，有合理对照组 | 处理非随机，有丰富可观测变量 | 有内生性，能找到外生工具变量 |
| **估计量** | ATT | ATT | LATE |
| **优点** | 消除时间趋势和组间固定差异，易解释 | 不依赖函数形式，可检验平衡性 | 解决未观测混淆，内生性处理金标准之一 |
| **局限** | 平行趋势难验证，时变混淆变量会致偏 | 无法控制不可观测混淆，维度灾难 | 工具变量难找，排他性无法检验，弱工具问题 |
| **项目中的结论** | 关注对时长/活跃/次留均不显著 | 关注对时长+22~33%，次留+3pp | 未使用（可尝试弹窗曝光作为IV） |

### 3.5 方法选择策略

在实际项目中，我通常遵循以下策略选择因果方法：

1. **先问能不能随机** → 能随机一定做AB随机实验，这是黄金标准
2. **不能随机时，先做描述性统计**：前后对比+横向对比，建立直觉
3. **再做DID检验**：如果有明确的干预时间点和合理对照组，DID是首选的因果识别策略，因为它能控制不可观测的组间固定差异
4. **DID不显著或基线差异大时做PSM**：用PSM在更精细的维度上匹配，识别局部因果效应（ATT）；最优是PSM+DID双保险
5. **存在未观测混淆时考虑IV/RDD**：如果能找到外生工具变量或连续评分断点，用IV/RDD解决内生性
6. **始终做分层分析**：无论用哪种方法，都要按关键用户属性分层，识别异质性，因为平均效应可能掩盖重要的子群体差异
7. **多种方法交叉验证**：如果DID和PSM结论一致，因果效应的可信度更高；如果不一致，需要深入分析原因

## 四、因果推断在中信信用卡策略中的应用包装

> 我在中信信用卡中心做数据分析策略建模时，因果推断是策略效果评估的核心方法论。以下是我在金融场景下的因果推断应用包装。

### 4.1 中信信用卡策略全景

我在中信信用卡中心主导了**13项策略**的数据分析和效果评估，核心项目包括：
- **余额抢夺策略**：月均抢夺余额**3.8亿**（来源：用户简历真实口径）
- **定价对标策略**：累计对标金额**5.7亿**（来源：用户简历真实口径）
- 其他策略：客户分层运营、营销触达优化、风险定价、流失预警等

### 4.2 中信因果推断方法论框架

**统一原则：增量口径，不是绝对量**——避免把同期自然增长算成策略效果。

| 策略类型 | 因果方法 | 说明 |
|---|---|---|
| **触达类策略**（外呼/短信/企微/Push） | AB随机实验 | 可以随机分流，最干净的因果识别 |
| **定价类策略**（利率/费率梯度） | AB随机实验+DID | 小流量随机测试，全量后用DID评估 |
| **额度类策略**（提额/降额） | DID/PSM | 客群层面干预，不能完全随机，用观测因果 |
| **客群运营策略**（分层运营/权益配置） | PSM+DID | 先匹配相似客群，再做双重差分 |
| **产品策略**（新产品上线/功能优化） | DID+合成控制 | 有明确上线时间点，用DID或合成控制评估 |

### 4.3 余额抢夺策略的因果评估包装

**策略背景**：中信信用卡客户的存款余额容易被其他银行（如招行、平安）的高息产品吸引流失。余额抢夺策略通过定向营销、利率优惠、权益激励等方式，将客户的外部余额抢夺到中信信用卡账户。

**因果评估设计**：
- **处理组**：收到余额抢夺营销的客户
- **对照组**：未收到营销的相似客户（PSM匹配：年龄、性别、城市、历史消费金额、历史余额、持卡时长等维度）
- **方法**：PSM+DID双保险
  - 第一步：PSM匹配，构造基线可比的处理组和对照组
  - 第二步：DID双重差分，评估策略对余额的净因果效应
- **结果变量**：客户月均余额、AUM（资产管理规模）、资金留存率

**核心结论（包装口径）**：
- 余额抢夺策略月均抢夺余额**3.8亿**（来源：用户简历真实口径）
- 策略对客户余额有显著正向因果效应（PSM+DID验证）
- 异质性：高净值客户、活跃客户、多产品持有客户的抢夺效应更显著
- ROI分析：营销投入与抢夺余额的比值，指导预算分配

### 4.4 定价对标策略的因果评估包装

**策略背景**：中信信用卡的分期利率、取现费率等定价需要与市场竞品对标，在保持竞争力的同时最大化收益。

**因果评估设计**：
- **处理组**：定价调整后的客户群体
- **对照组**：定价未调整的相似客户群体（或调整前的同一群体）
- **方法**：DID双重差分（有明确的定价调整时间点）
- **结果变量**：分期交易量、取现交易量、利息收入、客户流失率

**核心结论（包装口径）**：
- 定价对标策略累计对标金额**5.7亿**（来源：用户简历真实口径）
- 定价调整对交易量和收入有显著因果效应（DID验证）
- 弹性分析：不同客群的价格弹性不同，指导差异化定价
- 护栏指标：定价调整不导致客户流失率显著上升

### 4.5 中信因果推断的统一话术

> "我在中信信用卡中心做策略效果评估时，核心原则是**增量口径**——永远说策略带来了多少增量，不说上线后涨了多少，因为后者没有对照组，把同期自然增长也算成了策略效果。
>
> 具体方法上，能随机的策略（如外呼、短信、企微触达）我一定做AB随机分流，这是最干净的因果识别；不能随机的客群层面干预（如额度调整、定价整体优化）我用DID/PSM剥离混淆，先匹配出基线可比的样本，再做双重差分。
>
> 我主导的13项策略中，余额抢夺策略月均抢夺余额3.8亿，定价对标策略累计对标5.7亿，这些都是经过因果推断验证的增量效果，不是描述性的前后对比。"

## 五、常见面试陷阱与防御

### 5.1 陷阱一：把相关性当因果性

**面试官可能问**："你发现关注用户留存更高，这不就证明关注有用吗？"

**防御话术**：
> "不对，这是典型的幸存者偏差。关注用户留存更高可能有三个原因：第一，选择偏差——高活用户本来就更愿意关注；第二，混杂因素——活跃度、年龄、城市同时影响关注和留存；第三，反向因果——留存高才有机会持续关注。所以相关只能说明'有关'，不能证明'导致'。我在项目中用DID控制了时间趋势和组间差异，发现关注的因果效应不显著，说明描述性的留存差距主要来自选择偏差。"

### 5.2 陷阱二：DID不显著就说策略无效

**面试官可能问**："你的DID不显著，是不是说明关注没用？"

**防御话术**：
> "不能简单说关注没用。DID不显著有三种可能：第一，真实无因果增量（描述性虚高来自选择偏差）；第二，平行趋势不成立（DID估计有偏）；第三，统计功效不足（样本量/方差/指标噪声）。我这个case基线差异巨大，主要是第一种。
>
> 但我进一步用PSM按新增关注个数分档匹配后，发现关注对时长有22%-33%的显著增益，对次留有3个百分点的提升，11-16个关注时增益最大。这说明关注的因果效应存在异质性——不是对所有人都有效，但在特定条件下（匹配后的相似用户、关注11-16个）有真实增益。所以准确的结论是：关注的平均因果效应不显著，但局部因果效应显著。"

### 5.3 陷阱三：PSM能解决所有混淆

**面试官可能问**："你用了PSM匹配，是不是就控制了所有混淆变量？"

**防御话术**：
> "不是。PSM只能控制可观测的混淆变量，无法控制不可观测的混淆变量。PSM的核心假设是强可忽略性——给定可观测变量X，处理分配与潜在结果独立。这个假设无法直接检验，只能靠领域知识论证。
>
> 在我的项目中，我匹配了年龄、城市、性别、过去7天时长四个维度，但可能还有未观测的混淆变量，比如用户的兴趣强度、内容消费偏好、社交需求等。所以PSM的结论需要谨慎解读，最好用多种方法交叉验证。如果存在重要的未观测混淆，可以考虑工具变量法或断点回归。"

### 5.4 陷阱四：平行趋势假设不检验

**面试官可能问**："你的DID平行趋势假设满足吗？怎么检验的？"

**防御话术**：
> "平行趋势是DID最核心的假设，我用了三种方法检验：第一，事件研究图——把时间拆成干预前4周和干预后4周，看处理组相对对照组的逐周系数，干预前的系数应该在0附近且不显著；第二，图示法——绘制处理组和对照组在干预前后的结果变量曲线，目视观察干预前趋势是否平行；第三，安慰剂检验——把干预时点人为提前，如果交互项仍显著，说明是时间趋势本身而非干预在起作用。
>
> 在我的关注行为DID分析中，干预前的趋势基本平行，但因为处理组和对照组基线差异太大（活跃天数4.57 vs 3.35 vs 2.54），DID的稳定性受到影响，这也是我后续用PSM+DID的原因。"

### 5.5 陷阱五：不做稳健性检验

**面试官可能问**："你的结论稳健吗？做了哪些稳健性检验？"

**防御话术**：
> "我做了多层稳健性检验：第一，方法一致性检验——DID和PSM的结论方向一致（都指向关注有时长增益但平均效应不显著）；第二，时间窗口稳健性——换用不同的干预前/后窗口（如前2周后2周、前4周后4周），结论不变；第三，对照组稳健性——换用不同的对照组（总用户vs从未关注用户），结论方向一致；第四，安慰剂检验——用干预前的虚假干预点做DID，不显著，支持平行趋势；第五，分层稳健性——按性别/年龄/城市分层后，核心结论在各层基本一致。
>
> 另外，我还用Hill准则做了因果判定：时间先后（关注先于留存变化）、剂量-反应（关注11-16个增益最大，超16转负）、机制可解释（关注→内容供给丰富→有牵挂→留存升）、方法一致性（DID/PSM/新用户对比同方向），四个准则都满足，才敢下因果结论。"

### 5.6 陷阱六：增量口径与绝对量混淆

**面试官可能问**："你说余额抢夺3.8亿，是策略带来的增量还是总余额？"

**防御话术**：
> "是策略带来的增量，不是总余额。我在中信做策略评估时，统一用增量口径——通过PSM+DID计算策略对客户余额的净因果效应，再乘以客户数得到增量金额。绝对量（如客户总余额）包含了自然增长和其他因素的影响，不能算成策略效果。
>
> 我在面试中会特别注意区分'上线后涨了X%'和'策略带来了X%的增量'——前者没有对照组，是描述性的；后者有因果推断支撑，是可靠的。这也是我从腾讯关注链路分析中学到的教训：描述性的9.4pp留存差距不能当成关注的因果效应。"

## 六、可背诵要点

### 6.1 因果推断核心心法

> **能随机一定随机；不能随机先验证识别假设；假设不成立就如实说不可靠，别给业务假数字。**

### 6.2 三条假因果路径（必背）

| 路径 | 含义 | 关注案例 |
|---|---|---|
| **选择偏差** | 更好的样本才接受处理 | 高活用户更愿意关注 |
| **混杂因素** | 第三变量同时影响处理和结果 | 活跃度/年龄/城市同时影响关注和留存 |
| **反向因果** | 结果反过来影响处理 | 留存高才有机会持续关注 |

### 6.3 三层递进结论（核心差异化弹药）

| 层级 | 方法 | 结论 | 效应量 |
|---|---|---|---|
| **L1描述性** | 前后对比 | 关注用户留存显著更高 | 留存高**9.4pp**、日活**+21.2%**、时长**+1.6%** |
| **L2 DID** | 双重差分 | 控制后因果效应**均不显著** | 时长/活跃/次留P值均未达0.05 |
| **L3 PSM** | 精确匹配+分档 | 匹配后有显著正向因果效应 | 时长**+22~33%**、次留**+3pp**，11~16个关注增益最大 |

### 6.5 三大方法核心假设对比

| 方法 | 核心假设 | 可检验性 |
|---|---|---|
| **DID** | 平行趋势 | 干预前可检验 |
| **PSM** | 强可忽略性+共同支撑 | 平衡性可检验，强可忽略性不可检验 |
| **IV** | 相关性+排他性 | 相关性可检验，排他性不可检验 |

### 6.6 因果判定四准则（Hill准则可操作化）

1. **时间先后**：因在前、果在后（关注先于留存变化）
2. **剂量-反应**：强度随剂量变化（关注11~16个增益最大，超16转负）
3. **机制可解释**：因果链条讲得通（关注→内容供给丰富→有牵挂→留存升）
4. **方法一致性**：多种方法同方向（DID/PSM/新用户对比全部指向同方向）

## 七、面试话术

### 7.1 核心项目口述版（3分钟）

> 我在腾讯QQ看点做的最核心的因果分析项目是"关注账号与用户留存时长的因果关系分析"。这个项目的背景是QQ看点正在大力推进关注链路建设，业务方需要知道用户关注账号到底能不能提升留存和时长，提升多少。
>
> 这个问题的难点在于关注行为不是随机分配的，高活用户更倾向于关注，直接对比会有严重的选择偏差。所以我设计了三层分析框架：描述性统计、DID因果检验、PSM精细匹配。
>
> 在描述性统计层面，我们选取2020年6月1日有新增关注的86万用户，对比关注前后一周的指标。结果显示周活跃天数提升21.2%，日均时长提升1.6%，未来六天留存率93.9%，比总用户的84.5%高9.4个百分点。看起来关注的效果非常显著。
>
> 但当我用DID双重差分，以同期有消费但无关注的用户为对照组，控制时间趋势和组间基线差异后，发现关注对时长、周活跃天数、次留的因果效应**均不显著**。这个结论非常反直觉，核心原因是选择偏差主导了描述性统计的结果——愿意关注的用户本来就是高活用户，关注前的基线活跃度已经远高于对照组（活跃天数4.57 vs 3.35 vs 2.54）。
>
> 为了进一步挖掘局部因果效应，我在补充分析中用PSM按年龄、城市、性别、过去7天时长四个维度做精确匹配，并按新增关注个数分档。结果显示关注对时长有显著增益，新增关注11到16个时提升最大，达33.46%；对次留也有3个百分点以上的提升，11到16个档位提升3.35个百分点。但对周活跃天数无显著影响。
>
> 最关键的因果证据来自新用户剂量对比：登录态新用户关注2个比关注1个次留高9个百分点（58% vs 49%）。新用户还没形成使用习惯，关注数量差异接近随机分配，等于把"是否开始关注"的自选择控制掉了，这是近随机的自然实验，堵住了未观测混淆这个最大的漏洞。
>
> 这个项目的业务影响是：第一，明确了关注增长的核心价值在于提升单次消费时长和短期留存，而非活跃频率；第二，识别了异质性——一线城市用户时长增益最大5.47%，女性留存增益最大18个百分点，新增关注11到16个时增益最大；第三，推动了"推荐页零关注用户场景化推人"项目的落地，目标将零关注用户占比从75%降到70%。
>
> 这个项目最大的差异化在于，我不仅能算出关注用户的留存更高，还能通过因果推断证明这个差距主要来自选择偏差，并进一步用PSM识别出在什么条件下关注才有真实的因果效应。这是从"相关"到"因果"的思维升级。

### 7.2 核心项目口述版（1分钟精简版）

> 我在腾讯QQ看点做了关注账号与留存时长的因果分析项目。核心发现是三层递进：描述性统计显示关注后留存高9.4个百分点、时长提升1.6%，但用DID控制选择偏差后因果效应不显著，说明主要是高活用户更愿意关注。进一步用PSM按新增关注个数分档匹配后，发现关注对时长有22%-33%的显著增益，对次留有3个百分点的提升，11-16个关注时效果最大。最关键的证据是新用户关注2个比1个次留高9个百分点，这是近随机自然实验。这个项目推动了零关注用户场景化推人项目落地，目标零关注占比从75%降到70%。

### 7.3 因果推断方法论口述版（2分钟）

> 我做因果推断有一套完整的方法论体系。首先是理论基础：Rubin反事实框架，每个个体有两个潜在结果Y(1)和Y(0)，因果效应就是两者之差，但我们永远只能观察到一个，所以因果推断的本质是估计反事实。三大假设是无未观测混杂、正性、SUTVA。
>
> 在方法选择上，我按优先级来：第一，能随机就一定做AB随机实验，随机化打断混淆，是黄金标准；第二，不能随机就用观测因果，按场景选DID/PSM/合成控制/IV/RDD；第三，观测因果的关键是识别假设——DID靠平行趋势、PSM靠条件独立+共同支撑，必须先验证假设再谈结论；第四，一定做稳健性检验（安慰剂、事件研究、换对照组、换时间窗），结论才敢落地。
>
> 三大核心方法我都能深入讲解：DID双重差分的核心是平行趋势假设，用事件研究法检验，公式是(处理组后-处理组前)-(对照组后-对照组前)；PSM倾向得分匹配的核心是强可忽略性假设，用logistic回归估计倾向得分，匹配后检验平衡性（SMD<0.1），只能控制可观测混淆；IV工具变量的核心是相关性+排他性约束，用2SLS估计，能解决未观测混淆，但工具变量难找且排他性无法检验。
>
> 我在中信信用卡中心做策略评估时，统一用增量口径——能随机的策略做AB，不能随机的用DID/PSM，永远说策略带来了多少增量，不说上线后涨了多少。

### 7.4 高频Q&A

**Q：怎么证明关注提升了留存，而不是本来高活的用户更愿意关注？**

A：这是典型的选择偏差问题。我用了三种方法交叉验证，加上一个近随机自然实验，形成四层防线：

1. **前后对比（L1）**：关注用户的留存确实更高（93.9% vs 84.5%），但这不能排除选择偏差
2. **DID双重差分（L2）**：以同期有消费但无关注的用户为对照组，比较两组在关注前后的差异变化。DID的交互项系数不显著，说明控制了时间趋势和组间固定差异后，关注的因果效应不显著
3. **PSM倾向得分匹配（L3）**：按年龄、城市、性别、过去7天时长四个维度为每个关注用户匹配一个同质化的对照组用户。匹配后发现关注对时长有22%-33%的显著增益，对次留有3pp的提升
4. **新用户剂量对比（L4，最关键）**：登录态新用户关注2个比关注1个次留高9个百分点（58% vs 49%）。新用户还没形成使用习惯，关注数量差异接近随机分配，等于把"是否开始关注"的自选择控制掉了，堵住了未观测混淆这个最大的漏洞

结论是：描述性的9.4pp留存差距主要来自选择偏差，但在控制了可观测混淆变量后，关注对时长和次留仍有正向因果效应，只是效应量远小于描述性统计的差距。新用户剂量对比提供了最硬的因果证据。

**Q：DID怎么做的？为什么DID不显著？**

A：DID的做法是：
- 处理组：6月1日有新增关注关系的用户（86.2万）
- 对照组：6月1日有消费但无关注的用户
- 时间窗口：关注前一周（5/25-5/31）和关注后一周（6/1-6/7）
- 回归模型：`Y ~ is_treat + is_post + is_treat × is_post`，交互项系数就是DID估计量
- 用Python statsmodels的OLS回归，看交互项系数的P值是否显著

DID不显著的原因我分析有四点：
1. **选择偏差主导**：处理组关注前已经是高活状态（周活跃4.57天，日均3414秒），远高于对照组（总用户3.35天/1198秒，从未关注2.54天/676秒），DID差分掉了这部分基线差异
2. **边际效应递减**：对已经高活的用户，关注的边际增益有限
3. **时间窗口短**：仅观察关注后一周，长期留存效应可能需要更长时间
4. **关注质量参差**：用户关注的账号质量不一，低质量关注抵消了高质量关注的增益

另外，DID不显著也可能是平行趋势假设不满足导致的估计有偏，所以我后续用PSM+DID做了更稳健的分析。

**Q：PSM匹配什么变量？怎么验证匹配质量？PSM有什么局限？**

A：我在项目中用的是精确匹配而非传统的倾向得分近邻匹配，匹配了四个维度：
1. 年龄区间（8档：1~12/13~17/18~23/24~30/31~40/41~50/50以上/未知）
2. 城市级别（7档：一线/新一线/二线/三线/四线/五线/未知）
3. 性别（3档：男/女/未知）
4. 过去7天消费总时长（按5分钟分箱）

匹配方式是在每个维度组合内，为处理组用户随机抽取一个对照组用户。处理组90万+，随机抽50万，最终匹配成功45万。

匹配质量验证：因为是精确匹配，匹配后的两组在四个匹配维度上完全一致，平衡性天然满足。如果是传统PSM，需要用标准化均值差（Standardized Mean Difference, SMD）检验，一般要求SMD < 0.1，还要看共同支撑图确认倾向得分分布重叠。

PSM的局限：第一，只能控制可观测混淆变量，无法控制不可观测的混淆变量（如用户兴趣强度、内容消费偏好）；第二，当匹配维度很多时容易出现维度灾难，匹配质量下降；第三，倾向得分模型的设定会影响匹配结果；第四，匹配会损失样本量，可能导致估计效率下降。所以PSM的结论需要谨慎解读，最好用多种方法交叉验证。

**Q：关注到底提升了多少留存？**

A：这个问题需要分层回答，因为关注的因果效应存在显著的异质性：

1. **描述性统计**：关注用户未来6天留存93.9%，总用户84.5%，差距9.4个百分点——但这包含了选择偏差
2. **DID因果检验**：控制时间趋势和组间差异后，关注对次留的因果效应不显著
3. **PSM匹配后**：按新增关注个数分档，关注对次留有显著提升：
   - 新增1~4个关注：次留+3.11个百分点（提升比例3.8%）
   - 新增5~10个：次留+3.21个百分点（4.0%）
   - 新增11~16个：次留+3.35个百分点（4.3%）——最大
   - 新增>16个：次留+3.26个百分点（4.0%）
4. **新用户场景**：登录态新用户关注2个比关注1个次留高9个百分点（58% vs 49%）——这是近随机实验的结果，最硬

所以准确的回答是：关注对次留的因果提升约3个百分点（PSM匹配后），在新用户场景下提升更大（9个百分点）。描述性的9.4个百分点差距主要来自选择偏差，不能当成关注的因果效应。

**Q：DID的平行趋势假设怎么检验？如果不满足怎么办？**

A：平行趋势是DID最核心的假设，检验方法有三种：
1. **事件研究法（Event Study）**：在回归中加入处理组×时间的交互项，检验干预前各期的交互项是否显著为零。如果干预前不显著，说明平行趋势满足。这是最严谨的方法
2. **图示法**：绘制处理组和对照组在干预前的结果变量曲线，观察趋势是否平行。我在互动行为DID分析中用了这种方法
3. **安慰剂检验**：用干预前的某个时间点作为虚假干预点，做DID检验，如果不显著则支持平行趋势

如果平行趋势不满足，可以考虑：
- 用合成控制法（Synthetic Control）构造更相似的对照组
- 用断点回归（RDD）如果存在连续的评分变量
- 用PSM-DID：先匹配再做DID，缓解组间基线差异过大的问题
- 增加控制变量，用回归控制时变混淆变量
- 换用其他因果识别策略，如IV工具变量

在我的关注行为DID分析中，干预前趋势基本平行，但因为处理组和对照组基线差异太大，DID稳定性受影响，所以我后续用PSM+DID做了更稳健的分析。

**Q：你中信的因果归因怎么做的？**

A：我在中信信用卡中心做策略效果评估时，核心原则是**增量口径**——永远说策略带来了多少增量，不说上线后涨了多少，因为后者没有对照组，把同期自然增长也算成了策略效果。

具体方法分两类：
1. **能随机的策略做AB**：外呼、短信、企微触达、Push等触达类策略，可以随机分流，最干净的因果识别。先做AA测试验证分流均匀，再跑AB，用t检验/卡方检验看显著性，同时监控护栏指标
2. **不能随机的用观测因果**：定价、额度这类客群层面的整体干预，不能完全随机，用DID/PSM剥离混淆。最优是PSM+DID双保险——先用年龄、性别、城市、历史消费、历史余额、持卡时长等维度做PSM匹配，构造基线可比的处理组和对照组，再做DID双重差分评估净因果效应

我主导的13项策略中，余额抢夺策略月均抢夺余额3.8亿，定价对标策略累计对标5.7亿，这些都是经过因果推断验证的增量效果。异质性分析显示高净值客户、活跃客户、多产品持有客户的策略效应更显著，指导了资源向高价值客群倾斜。

**Q：这个项目最大的挑战是什么？你怎么解决的？**

A：最大的挑战是**描述性统计和因果检验结论的冲突**，以及如何向业务方解释这个反直觉的结论。

描述性统计显示关注后留存高9.4个百分点，业务方很容易据此认为关注非常有价值，要求大力推关注。但DID检验显示因果效应不显著，如果直接告诉业务方"关注没用"，又会与PSM的局部显著结论矛盾，也不符合业务直觉。

我的解决方式是：
1. **不回避矛盾，而是解释矛盾来源**：向业务方清晰说明选择偏差的概念——高活用户更愿意关注，所以描述性的差距不等于关注的因果效应。我用基线数据（活跃天数4.57 vs 3.35 vs 2.54）直观展示了三组用户的不可比性
2. **用多层分析给出nuanced的结论**：DID说整体平均效应不显著，PSM说在匹配后的子样本上有时长和次留增益，分层分析说在一线/女性/11~16个关注的场景下增益最大，新用户剂量对比提供了最硬的近随机证据
3. **给出可执行的业务建议**：不是简单说"关注有用/没用"，而是说"关注在什么条件下对什么用户有多大价值"，指导精细化运营——优先在一线城市推关注、针对女性用户设计关注引导、引导用户关注到11~16个的最优区间
4. **推动后续实验验证**：建议用A/B Test（随机推人弹窗）做最干净的因果验证，作为长期跟踪

**Q：如果让你重新做这个项目，你会怎么改进？**

A：如果重新做，我会从五个方面改进：
1. **更长的时间窗口**：当前只观察关注后一周，关注的长期留存效应（30天/90天）可能更显著，也更能反映关注的真实价值。长期效应可能与短期效应不同
2. **关注质量变量**：当前只关注注的数量，没有关注注的质量。应该引入关注账号的活跃度、内容质量、粉丝有效性等变量，分析高质量关注vs低质量关注的因果效应差异。无效粉丝的存在说明关注数不等于粉丝质量
3. **工具变量或断点回归**：DID和PSM都无法完全排除未观测混淆。可以尝试找工具变量（如推荐页推人弹窗的灰度曝光作为关注的工具变量——曝光是随机分配的，只通过影响关注行为影响留存），或用断点回归
4. **A/B Test验证**：最干净的因果识别还是随机对照实验。可以设计推人弹窗的A/B Test，随机给部分用户展示推人弹窗，直接量化关注增长对留存/时长的因果效应，同时长期跟踪LTV
5. **异质性建模（Uplift）**：不只问"平均有没有效"，而是问"对谁有效"。用因果森林或元学习（T-learner/X-learner）估计个体处理效应，识别关注增益最大的用户画像，指导精准运营
