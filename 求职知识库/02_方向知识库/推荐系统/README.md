## 推荐系统全链路地图

```
用户请求
   │
   ▼
┌─ 召回（Recall）─────────────────────────────────────┐
│  多路召回：DSSM双塔 / TDM树 / YouTube DNN / ICF     │
│  / 图Embedding / 行为Embedding / RL召回 / 兴趣召回  │
│  目标：从百万级item库召回~千级候选，毫秒级延迟       │
│  评估：Recall / Coverage / HitRate / 正逆率          │
└──────────────────────────────────────────────────────┘
   │ 候选集（~1000）
   ▼
┌─ 粗排（Pre-ranking）────────────────────────────────┐
│  DNN粗排 / 无监督融合粗排                             │
│  目标：特征精简、低延迟，从千级筛到百级               │
│  评估：与精排一致性 / AUC                             │
└──────────────────────────────────────────────────────┘
   │ 候选集（~100）
   ▼
┌─ 精排（Ranking）─────────────────────────────────────┐
│  多目标模型：DEN / Muti-gated DEN / MMoE             │
│  特征：用户画像 / 行为序列 / 物品特征 / 交叉特征      │
│  目标：pCTR / pDuration / pLike / pFollow 多目标预估 │
│  评估：AUC / GAUC / NDCG                              │
└──────────────────────────────────────────────────────┘
   │ 排序分数
   ▼
┌─ 重排（Re-ranking）──────────────────────────────────┐
│  DPP多样性 / 个性化重排 / 保量机制 / 运营锁定位       │
│  目标：列表级优化，平衡相关性/多样性/业务约束          │
│  评估：覆盖率 / 基尼系数 / 熵 / 保量达成率            │
└──────────────────────────────────────────────────────┘
   │
   ▼
展示 → 用户行为 → 数据回流 → 模型迭代（闭环）

横向支撑：
├─ 因果分析：DID / PSM / 分层，量化策略真实因果效应
├─ 指标体系：北极星→过程→漏斗三层，离线+在线双轨评估
└─ 实验系统：AB分流 / 显著性检验 / 护栏指标
```

## 核心项目与关键数字速查

### 1. 微视账号推荐体系（主战场）

| 项目 | 核心方法 | 关键数字 | 来源文档 |
|------|----------|----------|----------|
| 行为Embedding召回 | Word2vec Skip-gram，32维达人emb | 用户最近10关注达人→100相似达人；分层策略第2层30% quota | 好友达人梳理（总） |
| Graph Embedding实验 | DeepWalk随机游走+Word2vec | 发现好友页pCTR +11.19%（10%流量2天）；扩大后+2.58% | 各种emb实验 |
| DSSM双塔召回 | pair-wise margin loss + FAISS IVF+PQ | SIMNET百亿模型：100亿样本、500w词表、正逆率1.57→1.60 | 百亿量级SIMNET模型规划 |
| TopK RL集合召回 | REINFORCE + Off-Policy + TopK梯度修正 | 应用宝必备弹窗人均下载+20%；奖赏重定义（<=3个下载用户给最高奖赏） | 基于策略梯度的TopK集合召回 |
| 达人池切换 | 45级达人池分层 | 关注率+5.3% | 达人召回梳理 |

### 3. 因果分析（最核心差异化弹药）

| 分析 | 方法 | 核心结论 | 来源文档 |
|------|------|----------|----------|
| 关注→留存/时长 | 描述性统计 | 关注后日活+21.2%、时长+1.6%、留存比总用户高9.4pp | 关注账号和用户的留存与时长的因果关系分析 |
| 关注→留存/时长 | DID | **因果效应均不显著**（时长/活跃/次留P值未达0.05）——差距主要来自选择偏差 | 同上 |
| 关注→时长/次留 | PSM精确匹配 | 时长+22~33%、次留+3pp；11~16个关注增益最大（时长+33.46%、次留+3.35pp） | 关注账户与留存因果分析_补充 |
| 点赞/评论→时长 | DID | 点赞+3.2分钟、评论+3.4分钟（显著）；分享不显著；所有互动对次留不显著 | 点赞评论分享对时长留存增益 |
| 关注数阈值 | 纵向+横向分析 | **14个关注是留存质变阈值**，超过后负相关；第9-14天达到14个关注效果最好 | 关注数与长留存的关联 |
| 零关注用户规模 | 描述性统计 | DAU中73%零关注；登录用户40%零关注（630w）；推荐页关注转化率仅0.8% | 关注价值分析 |

### 4. 重排与保量

| 项目 | 方法 | 关键数字 | 来源文档 |
|------|------|----------|----------|
| DPP多样性重排 | 行列式点过程 + Cholesky增量更新 + sliding-window | 前两位固定+topN不打散；上线精选/个人页多模块 | DPP+多样性重排 |
| 保量一期 | PID控制（5分钟分片×24） | 误差=配置占比-实际占比；频道页卡六小图模块 | 保量机制一期 |
| 保量二期 | VV预估驱动全局扶持 + 全链路加权 | 缺量分级加权1.05~1.35；综艺播放用户+0.78%、VV+0.9% | 保量机制二期 |
