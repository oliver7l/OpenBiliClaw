# 新增岗位 · 标准流程（完整闭环）

> 目的：每来一个新岗位，都能按**统一闭环**产出标准备战包并登记入库，且每投一岗都留痕、可校准。
> 借鉴：ai-job-search（MadsLorentzen）的 `/setup→/rank→/apply→/interview→/outcome` 闭环 + 双 Agent 审查 + ATS 校验；second-brain 的概念关系登记。
> 前置：先有岗位信息（公司/岗位/JD/面试时间/简历版本）。

---

## 步骤 0 · 匹配评估（投递前，新增）

- 按 `规范/岗位匹配评估.md` 做**五维打分 + deal-breaker 检查**，产出匹配评估卡。
- 结论 = 投 / 谨慎投（列差距清单）/ 不投。
- 评估卡存 `03_岗位弹药库/<公司>-面试准备/01_岗位与公司信息/匹配评估卡.md`。
- **不投的岗位**：到此为止，仅登记在岗位表备注，不建三件套。

## 步骤 1 · 建目录

```
03_岗位弹药库/<公司>-面试准备/
├── 01_岗位与公司信息/     # JD截图、公司资料、JD拆解、匹配评估卡、简历版本
├── 02_面试备战资料/       # 面试攻略、项目话术、HR面话术、逐轮策略
├── 03_速成包/             # 预测题库、速记卡、问答集
└── 04_知识库(如有)/       # 该岗位专属知识库
```

## 步骤 2 · 产出三件套

| 文件 | 内容要点 |
|---|---|
| `01_岗位与公司信息/公司背景与JD拆解.md` | 公司/团队/JD逐条→你的弹药映射 |
| `02_面试备战资料/面试攻略.md` | 定位话术 + 三个必打点 + 自我介绍(30s/1min) + 逐轮策略(多轮面时) |
| `03_速成包/预测题库.md` | 高频题 + 答案（含手撕题） |

（模板参考：`03_岗位弹药库/模板/面试备战包_模板.md`；多轮面试拆逐轮策略参考：`大宇无限-广告岗-面试准备/02_面试备战资料/大宇无限四轮面试_逐轮备战策略.md`）

## 步骤 3 · 双 Agent 审查（新增）

- 三件套起草后，**换面试官视角独立审查一遍**：抓遗漏关键词 / 薄弱 framing / 泛泛表述 / 数字未查表。
- 修订后定稿，审查点一句话留痕。

## 步骤 4 · ATS 简历校验（新增，投递前）

- 按 `规范/录入规范.md` 第五节做简历文本层校验 + JD 关键词覆盖率；差距如实标注。
- 确认用哪个简历版本（登记岗位表"简历版本"列）。

## 步骤 5 · 登记系统层

- `数据/01_岗位表.csv` 加一行（公司/岗位/时间/状态/主打方向/备战目录/简历版本/备注含 deal-breaker）
- `数据/05_面试题索引.csv` 加行（指向新题库）
- 面试时间有变更 → 更新岗位表；总索引速查同步
- 新概念 → `数据/07_概念关系表.csv` 登记 + 同步知识地图
- 跑 `python3 scripts/doctor.py` 确认 PASS

## 步骤 6 · 面试前

```bash
python3 scripts/kb.py 速记 <公司>     # 一键生成速记卡
python3 scripts/kb.py 查 <关键词>      # 临时检索弹药
python3 scripts/doctor.py              # 系统健康检查（可选）
```

## 步骤 7 · 面试后（outcome + 校准，24h 内）

- `数据/04_面试日志.csv` 补一行（日期/公司/轮次/面试官角色/被问要点/复盘/复盘文档）
- 岗位目录 `03_上次面试记录/` 写复盘
- 被问的新题补进 `03_速成包/`，同步题库索引
- **校准回路（新增）**：
  1. 若被问倒/答得不好的点 → 进 `05_面试题索引.csv` + 补对应弹药文档；
  2. 若"匹配评估打了高分却没过初筛/面试" → 回看 `岗位匹配评估.md` 权重与打分是否失真，反向修正；
  3. 若连续多岗的某个差距反复出现 → 列入 `upskill` 学习清单（可补简历/提升）。
- 静默 >10 天无回音 → 依 `04_面试日志` 起草一次跟进（只起草，不代发）。
