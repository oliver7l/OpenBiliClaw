# 录入规范（素材怎么进知识库）

> 目的：任何新素材进来，都有固定的去处和登记动作，保证知识库可持续、可审计。
> 原则：**原文保留（可追溯） + 提炼入库（可复用） + 数字守门（可查证） + 关系登记（可织网）**。
> 借鉴：second-brain（zhiwehu）的"AI 自动分类 + Layer3 schema 概念关系"；ai-job-search 的"Drafter+Reviewer 双审查 + ATS 文本层校验"。

---

## 一、素材进哪一层（自动分类规则）

> 判断顺序：先问"这是谁生产的、谁要用"→ 原始素材进 01、可跨岗位的方法论进 02、按岗位用的备战物进 03、事实数据进系统层。

| 素材类型 | 去向 | 动作 |
|---|---|---|
| JD 截图 / 招聘链接 / 公司资料 | `03_岗位弹药库/<公司>-面试准备/01_岗位与公司信息/` | 存原件 + 登记岗位表 |
| 简历新版本 / 简历 PDF | `01_原始资料库/简历/` | 登记岗位表的"简历版本" |
| 工作文档 / 腾讯文档导出 | `01_原始资料库/腾讯文档资料/`（或对应子目录） | 更新腾讯文档资料 README |
| 方法论 / 技术调研（可跨岗位复用） | `02_方向知识库/<方向>/` | 提炼成 md + 更新方向 README |
| 面试被问的题 / 题库 | `03_岗位弹药库/<公司>/03_速成包/` 或 `05_面试题索引.csv` | 登记题库索引 |
| 面试过程 / 复盘 | `04_面试日志.csv` + 岗位目录"上次面试记录" | 24 小时内补录 |

**新增·概念关系登记**：每次提炼出新方法论/项目/关键技术点，顺手在 `数据/07_概念关系表.csv` 登记一行（概念/类型/关联概念/关系类型/关联数字/出处文档），并核对 `02_方向知识库/00_知识地图_概念关系网.md` 是否需同步。

---

## 二、数字守门（最高优先级）

1. 任何数字在进入回答/文档前，先查 `数据/03_真实数字表.csv`。
2. **只有**能从简历、工作文档、晋升材料等真实材料追溯的数字才可入库。
3. 查无来源的数字：**不入库、不用于面试回答**，标注"待补充"。
4. 豆包或 LLM 生成的数字（如 17.5 亿/13.2 亿类）**一律禁用**，不写入任何文档。

---

## 三、新增/更新数据表的动作清单

- **新增岗位** → `01_岗位表.csv` 加一行；按 `规范/新增岗位流程.md` 走完整闭环。
- **新增项目/数字** → `02_项目表.csv` / `03_真实数字表.csv` 加行，注明来源。
- **新增概念** → `07_概念关系表.csv` 加行 + 同步知识地图。
- **面试后** → `04_面试日志.csv` 补一行 + 岗位目录写复盘。
- **新题入库** → `05_面试题索引.csv` 加行，指向答案文档。
- **每次变更** → 同步更新 `00_总索引.md`（检索速查）。

## 四、双 Agent 审查（借鉴 ai-job-search Drafter+Reviewer）

**适用范围**：面试攻略 / 预测题库 / 项目话术 / 速记卡 等**要当面讲的交付物**。

1. **起草**：按素材产出第一版。
2. **独立审查**：换一个"面试官视角"重读——抓：遗漏的关键词、薄弱 framing、泛泛而谈的表述、数字是否查过表。
3. **修订**：按审查意见修订后才算定稿。
4. **留痕**：审查意见与修订点写进交付物"审查记录"小节（一句话即可）。

> 目的：单人一次过的内容往往带着"自说自话"，双视角能补上面试官会挑的刺。

---

## 五、ATS 简历校验（借鉴 ai-job-search ATS parseability check）

**适用范围**：每次投递简历前（新公司/新岗位）。

1. 简历 PDF 的**文本层**必须能被解析出：联系方式、阅读顺序、无乱码字形。
2. 对照 JD 关键词覆盖率打分：我真实支持的关键词补进简历；真实不支持的差距**如实标注**，绝不硬塞。
3. 校验动作记入该岗位 `01_岗位与公司信息/` 的简历版本备注。

---

## 六、命名与结构约定

- 顶层仅 4 项：`00_总索引.md`、`01_原始资料库`、`02_方向知识库`、`03_岗位弹药库`，加系统层 `_系统_知识库引擎`（下划线开头=非内容层）。
- 岗位目录统一结构：`01_岗位与公司信息 / 02_面试备战资料 / 03_速成包 / 04_知识库(如有)`。
- 方向知识库统一：每方向一个目录 + 数字编号 md（如 推荐系统/09_...md）+ 方向 README；根目录 `00_知识地图_概念关系网.md` 为 schema 层视图。
- 文件名用"自解释中文"，禁止用 agent id / 时间戳等无意义命名。
- 系统健康：每次重大变更后跑 `python3 scripts/doctor.py`，PASS 才算完成。
