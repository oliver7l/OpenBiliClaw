## 模型能力

OpenAI 这次发布的是一个系列： **Sol、Terra、Luna** 。Sol 是旗舰模型，Terra 是平衡性能和成本的中间档，Luna 是最快、最便宜的版本

![](https://picx.zhimg.com/v2-d67e4881b631c4dc3173c4818caa10c9_1440w.jpg)

从Artificial Analysis评测来看，GPT-5.6 Sol模型得分在59左右，排名第二，仅仅比Fable 5低了一分

![](https://pic3.zhimg.com/v2-0bc88970a4f3c8e57a1d65f60221f5b6_1440w.jpg)

但是在差距不明显的情况下，它的花费简直太有性价比了，价格比Fable 5便宜了一半以上。

![](https://pic4.zhimg.com/v2-9e95aef513f6cb426a1d1207590dfa31_1440w.jpg)

这是因为，Sam Altman 专门发推说了这件事，表示自己希望能降低 AI 的使用成本。确实在好用和性价比来看，用GPT-5.6感觉会更好

![](https://pic4.zhimg.com/v2-89876aeea92a5dc50274e303749dd925_1440w.jpg)

最值得关注的第一点，是 **Ultra 模式** 。OpenAI 明确说 GPT-5.6 引入了新的 max reasoning effort，让 Sol 能花更多时间深度推理；同时引入 ultra 模式，通过 **subagents** 超越单 Agent 能力，加速复杂任务。这个信号很关键：模型能力提升不再只是“参数更大、推理更强”，而是开始把多 Agent 编排内置进模型产品形态里。

从下面这张图可以看到，使用了ultra 模式下，gpt-5.6效果在TerminalBench 2.1榜单上达到了91.9%的效果（Terminal-Bench 2.1 测试需要规划、迭代和工具协调的命令行工作流。）超过了之前Claude模型引以为傲的Mythos 5模型。

![](https://pic3.zhimg.com/v2-90e9b2ed543992144e5ac49c1bcd5986_1440w.jpg)

**第二点优势在于，是它更像一个面向“长程任务”的工程模型。** OpenAI 强调 GPT-5.6 Sol 除了在TerminalBench 2.1评测上效果很强，在 GeneBench v1 上相较 GPT-5.5 更强且 token 更少，在网络安全长程任务上也明显推进。换句话说，这次更新的重点集中在 **代码、科研、安全、工具调用、长任务执行** 。

![](https://pica.zhimg.com/v2-2cb8c71930734b00fa44bdf436c1d458_1440w.jpg)

GPT-5.6 Sol（白色线）在所有输出长度下均保持最高得分，尤其在长文本生成时优势显著，30k tokens 时得分已超 30%，远超其他模型。

**第三点，是 OpenAI 的发布机制变了** 。这次 GPT-5.6 不是直接大规模上线，而是在美国政府要求下先做有限预览，参与方信息也与政府共享，OpenAI 同时表示这种政府访问流程不应成为长期默认机制。外媒也把这次发布解读为前沿模型进入“监管预发布审查”阶段。

**第四点，是安全栈明显加厚，尤其是网络安全和生物安全。** OpenAI 在 system card 里把 Sol、Terra、Luna 都视为网络安全和生物/化学风险上的 **High capability** ，但未达到最高的 Critical；

Sol 和 Terra 能发现漏洞和 exploit 组件，但在测试中还不能对 hardened targets 完成自主端到端攻击。同时它使用模型内拒答、实时 cyber/biology 分类器、生成中暂停审查、账号级信号、差异化访问等多层防护，并投入超过 70 万 A100 等效 GPU 小时做自动红队。

![](https://pic4.zhimg.com/v2-eb77723e6b906983a13fdc460db225d5_1440w.jpg)

当让，GPT-5.6还有其他的一些优点。它明显在Agent能力上有优化。GPT-5.6 可以通过 Programmatic Tool Calling，在内部编写轻量程序，对工具调用结果进行筛选、聚合和条件判断，而不是每调用一次工具，都把大量原始结果重新塞回上下文。

这会带来几个实际变化：

- 工具调用轮次更少；
- 中间结果占用的 Token 更少；
- 长任务不容易执行到一半偏离目标；
- 面对失败结果时，更容易调整方案继续尝试。

OpenAI 还加入了多 Agent 能力，可以让多个子 Agent 并行执行，再由主模型统一汇总。Ultra 模式默认使用四个 Agent 并行处理复杂任务。

## 官方展示的效果

GPT-5.6在工程设计上，确实有明显的提升。从官方发布的各种演示视频来看，让人眼前一亮。

比如在设计一个博物馆展示网页，属于 **国际一线艺术馆/设计展官网** 的典型风格，设计完成度很高，视觉冲击力很强。如果这是一个艺术展、博物馆或高端品牌官网首页，它已经达到了国际优秀案例的水准。

![](https://pica.zhimg.com/v2-8680b0cc2be72bf10b290382806b767c_1440w.gif)

这个室内设计的PPT，整体水平比较高，属于 **偏高端品牌展示、杂志风（Editorial Style）** 的设计，在企业汇报、品牌介绍、产品发布中都比较耐看。

![](https://pica.zhimg.com/v2-1c576b769a7f394621ec565ae483fbec_1440w.gif)

收集钟表小游戏。从这段约 5 秒的试玩视频来看，这个小游戏完成度比我预期要高，整体给人的第一印象不错。整个画面采用了：

- Low Poly 美术
- 暖色调秋景
- 中古钟表村庄
- 等距（Isometric）视角

很容易让人想到《纪念碑谷》《Townscaper》或者一些独立解谜游戏。这种风格很舒服，也比较容易建立自己的辨识度。

[https://www.zhihu.com/video/2058956703920661218](https://www.zhihu.com/video/2058956703920661218)

没有逐步指导，没有手把手教学。

仅仅烧掉了 3000 多万个 Token，总成本不过几百美元，就成功复刻出了一个 **Google Earth** 的克隆版。这就是现在 AI Coding 的能力边界。

[https://www.zhihu.com/video/2058956737588224068](https://www.zhihu.com/video/2058956737588224068)

这个帆船游戏的 **第一眼完成度很高** ，已经不像普通 AI Demo，更像一个可以继续扩展的独立游戏原型。

画面上，海面、天空、帆船和尾浪的整体风格比较统一，清爽、有辨识度；UI 信息也比较完整，包含速度、帆面角度、风向、目标距离和比赛进度，能让玩家快速理解当前状态。

[https://www.zhihu.com/video/2058956762833752359](https://www.zhihu.com/video/2058956762833752359)

不过也有一些问题也比较明显：核心操作主要还是调整方向和帆面，短时间内缺少明显的风险、对抗和策略变化，容易给人“很好看，但玩久了可能比较单调”的感觉。另外，尾浪和粒子效果略显夸张，UI 文字偏小，画面中央的目标提示也有些遮挡视线。

从统计的费用情况来看，GPT-5.6算是性价比很高的一个模型了，Sol的价格只有Fable 5的一半，但是智力水平差不多。 **Terra 永远约为 Sol 的一半，Luna 永远约为 Sol 的五分之一** 。因此，常规业务默认使用 Terra、批量任务使用 Luna、少量高难任务升级到 Sol，是最经济的组合。

## 写在最后

对了，这一次Chatgpt的更新，还新增了一个Sites 功能，简单的说就是

![](https://pic1.zhimg.com/v2-c9b6355c3c27e1467b19a9570989a0f2_1440w.jpg)

只需要在 Prompt 里说一句话，AI 就能直接生成并部署一个可访问的网站。

生成后的网页会自动上线，拥有独立链接，你可以一键分享给朋友、同事或团队成员，无需本地运行，也不用额外部署。对于普通用户来说，大大降低了创作和分享的门槛，让 AI 生成的内容真正实现“即做即分享”。

![](https://pic3.zhimg.com/v2-cf96f2fe152f93e566386240b3640af0_1440w.jpg)

GPT-5.6 给我最大的震撼，不是某一个评测超过了 Claude，也不是它生成了一个多么漂亮的网页，而是 AI 产品开发的门槛正在快速接近于零。

不过GPT-5.6 当然还不完美，还需要把价格降低一下，把性价比做高就更好了。

现在Claude Fable 5 会不会慌，我不知道。但可以确定的是，随着 GPT-5.6 正式入场，前沿模型之间的竞争，已经从单纯比较“谁更聪明”，进入了比较“谁能以更低的成本，真正完成更多工作”的新阶段。
