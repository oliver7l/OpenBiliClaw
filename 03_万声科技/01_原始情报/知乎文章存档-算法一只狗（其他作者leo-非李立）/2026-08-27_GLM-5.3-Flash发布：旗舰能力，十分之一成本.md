GLM-5.3-Flash发布：旗舰能力，十分之一成本

**智谱终于把开始把旗舰模型的能力，压进 Flash 级别的成本里。**

GLM-5.3-Flash 是 **320B-A18B MoE** ，也就是总参数 320B，但每个 Token 实际只激活约 18B。

官方明确说这是一个 **重新训练的 Base Model** ，架构和训练方案都重新围绕效率设计，引入了：

- Sparse Attention + Linear Attention 混合架构
- mHC（Manifold-Constrained Hyper-Connections）
- 30T Token 多模态预训练数据

核心目标就是： **用更少的推理计算量，尽量保住旗舰模型能力。** (

![](https://pic3.zhimg.com/v2-deddc0f5fcaab78eca5cb5e28edaf6a6_1440w.jpg)

这一点其实和最近 Qwen3.8-Flash-Next 的方向非常像：

下一轮模型竞争，可能已经不只是“谁参数更多”，而是谁能用更低的 Active Params 跑出旗舰能力。

![](https://pic2.zhimg.com/v2-97ef13c9b16c7434fc612e021d777f65_1440w.jpg)

## **新的性价比之王：GLM-5.3 大约 90% 的能力，十分之一左右成本**

Artificial Analysis 最新结果里，GLM-5.3-Flash模型得分是57分

![](https://pic4.zhimg.com/v2-544aab1b35b60230585f1a4fb6d57141_1440w.jpg)

也就是说，AA 这套评测下只掉 **3 分** ，任务成本却下降到大约 **十分之一** 。官方 API 当前价格是 输入、0.15/𝑀输入、 **0.50/M 输出.**

![](https://pic4.zhimg.com/v2-d477cd735ee881dd6f7938085449e5f5_1440w.jpg)

如果你是日常的一些任务，那么直接使用 **GLM-5.3-Flash** 版本，我觉得已经完全够用了。

尤其是日常 Coding、简单 Agent、信息整理、文档处理这些任务，本身就没有必要一直调用旗舰模型。GLM-5.3-Flash 最大的意义，就是把原本旗舰模型才能提供的能力，压到了一个可以长期、大量调用的价格区间。

真正复杂的长程 Agent、超大型 Repo 修改，或者对成功率特别敏感的任务，再切回 GLM-5.3。

所以未来模型的使用方式可能也会越来越像现在的推理分级：

**80% 的普通任务交给 Flash，剩下 20% 的高难任务再交给旗舰模型。**

从这个角度看，GLM-5.3-Flash 甚至可能比 GLM-5.3 本身更有实际使用价值。

## **Coding / Agent 能力非常激进**

官方公布的数据里面，几个数字挺有意思的

![](https://pic3.zhimg.com/v2-47fd1b694549a0be871ee989c126513e_1440w.jpg)

尤其 DeepSWE 从 **46.2 → 63.4** ，Agent 自动化从 **26.2 → 48.8** ，提升已经不是“小版本升级”了。

当然，这里面部分结果来自官方评测，Harness、Thinking Budget、Context Management 都会影响最终结果，要真实测试之后才会直到最好的效果

但至少可以确定，目前 **18B Active 的模型，Coding Agent 已经进入第一梯队。** 这个很恐怖。

## **另一个容易被忽视的变化：GLM 正式进入“原生多模态Agent”**

这是 GLM-5 系列第一个 **原生多模态模型** ，而不是额外挂一个视觉模型。

![](https://pic4.zhimg.com/v2-0d1f066c95bfd12ed6461f97ec7bc2e3_1440w.jpg)

除了文本，还可以处理图像等多模态输入，官方明显在往 Browser Use、Computer Use 这种方向推。

视觉 Benchmark 也不弱，例如：

- OfficeQA Pro：62.4
- Chartography：78.0
- MVBench：77.8
- MMVU：80.5

但视觉还不能说全面 SOTA，比如 BabyVision 53.4，仍明显低于 GPT-5.6 Terra 和 Gemini 3.7 Flash。

所以我更愿意把它理解为： **智谱不是在做一个“VLM”，而是在给 Coding Agent 补眼睛。**

官方给出的实例确实让人眼前一亮，比如帮你做一个酒店说明。

![](https://pic3.zhimg.com/v2-9e82adc2cbd3b8702d7c5b848a56c59c_1440w.jpg)

## 之前匿名模型Ox Alpha就是GLM-5.3-Flash

很早之前，我就通过模型的tokenizer判定，Ox模型其实就是GLM系列的。

![](https://pic2.zhimg.com/v2-79002f9c34547e563c097704687ab793_1440w.jpg)

有社区测试者拿 Ox Alpha 和 GLM-5.3 做 tokenizer fingerprint，测试英文、中文、代码、emoji 等多组字符串后，发现： **Ox Alpha 的 prompt token 数始终等于 GLM-5.3 + 75 tokens。**

这个恒定的 75，很像额外塞进去的一段隐藏 system prompt；更关键的是， **tokenizer 本身几乎完全一致** 。而同样测试 Kimi、Qwen、MiMo、MiniMax 时并不一致。

![](https://pica.zhimg.com/v2-6fcb61f58122fdbdcea48f68d6986722_1440w.jpg)

还有第二个证据甚至更有意思。给 Ox Alpha 传不合法的 reasoning_effort 时，它返回的错误行为和 GLM-5.3 极其接近：模型强制 Thinking，只接受：low / high / max

而公开观察到的 Ox Alpha API profile 也是： **1,048,576 context 131,072 max output reasoning 强制开启 low / high / max 默认 max temperature=1 top_p=0.95**

这一整套都和 GLM-5.3 高度重合。

## **我的判断**

我觉得最近模型行业正在出现一个很明显的变化。以前大家好像都在卷模型的参数，谁的更大，那就是谁家的更好。但是现在好像不太一样。

Qwen、DeepSeek、GLM 都开始卷另一件事： **怎么把旗舰模型的能力压缩到更少的 Active Params 和更低的 Token 成本里。**

像这一次的GLM-5.3-Flash模型就是一个这样子的例子。

**320B 总参数、18B 激活，AA 57 分，能力距离 GLM-5.3 的 60 分已经很近，但任务成本只剩大约十分之一。** (

如果这种趋势继续下去，未来真正的“模型斩杀线”可能会不断上移。

这才是 GLM-5.3-Flash 对 DeepSeek V4 Flash、Qwen3.8-Flash-Next，以及整个国产模型价格战最大的意义。
