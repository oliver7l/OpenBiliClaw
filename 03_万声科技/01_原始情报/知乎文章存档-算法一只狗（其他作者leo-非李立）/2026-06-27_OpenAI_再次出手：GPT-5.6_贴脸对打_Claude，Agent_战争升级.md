OpenAI 再次出手：GPT-5.6 贴脸对打 Claude，Agent 战争升级

从目前发布来看，GPT-5.6 还是 **有限预览** ，并不是所有 ChatGPT 用户都能用。OpenAI 这次发布的是一个系列： **Sol、Terra、Luna** 。Sol 是旗舰模型，Terra 是平衡性能和成本的中间档，Luna 是最快、最便宜的版本；预览阶段只面向少量可信合作伙伴和组织，通过 API 和 Codex 使用，ChatGPT 暂时不可用。

![](https://pic1.zhimg.com/v2-ce1a727f3fd6530ef4be8438bc8e991c_1440w.jpg)

最值得关注的第一点，是 **Ultra 模式** 。OpenAI 明确说 GPT-5.6 引入了新的 max reasoning effort，让 Sol 能花更多时间深度推理；同时引入 ultra 模式，通过 **subagents** 超越单 Agent 能力，加速复杂任务。这个信号很关键：模型能力提升不再只是“参数更大、推理更强”，而是开始把多 Agent 编排内置进模型产品形态里。

从下面这张图可以看到，使用了ultra 模式下，gpt-5.6效果在TerminalBench 2.1榜单上达到了91.9%的效果（Terminal-Bench 2.1 测试需要规划、迭代和工具协调的命令行工作流。）超过了之前Claude模型引以为傲的Mythos 5模型。

![](https://picx.zhimg.com/v2-190ac24555b39b0293535b92e4f67e3b_1440w.jpg)

**第二点优势在于，是它更像一个面向“长程任务”的工程模型。** OpenAI 强调 GPT-5.6 Sol 除了在TerminalBench 2.1评测上效果很强，在 GeneBench v1 上相较 GPT-5.5 更强且 token 更少，在网络安全长程任务上也明显推进。换句话说，这次更新的重点集中在 **代码、科研、安全、工具调用、长任务执行** 。

![](https://pica.zhimg.com/v2-94fa378d7d2ab7cfce0c6dcc577fbf08_1440w.jpg)

GPT-5.6 Sol（白色线）在所有输出长度下均保持最高得分，尤其在长文本生成时优势显著，30k tokens 时得分已超 30%，远超其他模型。

**第三点，是 OpenAI 的发布机制变了** 。这次 GPT-5.6 不是直接大规模上线，而是在美国政府要求下先做有限预览，参与方信息也与政府共享，OpenAI 同时表示这种政府访问流程不应成为长期默认机制。外媒也把这次发布解读为前沿模型进入“监管预发布审查”阶段。

**第四点，是安全栈明显加厚，尤其是网络安全和生物安全。** OpenAI 在 system card 里把 Sol、Terra、Luna 都视为网络安全和生物/化学风险上的 **High capability** ，但未达到最高的 Critical；

Sol 和 Terra 能发现漏洞和 exploit 组件，但在测试中还不能对 hardened targets 完成自主端到端攻击。同时它使用模型内拒答、实时 cyber/biology 分类器、生成中暂停审查、账号级信号、差异化访问等多层防护，并投入超过 70 万 A100 等效 GPU 小时做自动红队。

![](https://pica.zhimg.com/v2-9570043a06d5f4d3e5e2108776ab7c16_1440w.jpg)

价格上也很有意思： **Sol 是 $5/百万输入 token、$30/百万输出 token，和 GPT-5.5 的标价基本一致；Terra 是 $2.5/$15，Luna 是 $1/$6** 。这意味着 OpenAI 竟然很良心，并没有进行显著的涨价，同时GPT-5.6 还加入更可预测的 prompt caching，包括显式 cache breakpoints 和 30 分钟最短缓存生命周期。

![](https://pic4.zhimg.com/v2-f6dd69a40cd0d4b7fa0a4bbc2db0ad55_1440w.jpg)

从官方给出的价格来看，Sol 的 $35/百万入出，比 Claude Fable/Mythos 的 $60 便宜约 **42%** ，但比 Claude Opus 4.8 的 $30 还贵一点。

Terra 是 $17.5，Claude Sonnet 4.6 是 $18，几乎相差不大。而Luna 是 $7，Claude Haiku 4.5 是 $6，Luna 略贵一点，但如果能力明显强于 Haiku。

![](https://pic4.zhimg.com/v2-fd0b886ba31dd096e0be7a8744a43af7_1440w.jpg)

最后这里说一句，现阶段还是DS价格更加实惠呀。

![](https://pica.zhimg.com/v2-647720d2958e15821f92a0668629491e_1440w.jpg)

目前由于大众都不能使用 GPT-5.6 模型，所以对于它的实际效果，外界很难做出真正可靠的判断。现在能看到的，更多还是官方口径、少量合作伙伴反馈，以及 benchmark 上的数字表现。

但有一点是比较明确的：GPT-5.6 这次明显是贴着 A 家模型来打。每次 Anthropic 推出一款更强的大模型，OpenAI 很快就会拿出一个更强、更贵、更偏 Agent 的版本回应。这进一步说明，现在前沿大模型的竞争已经进入了一个非常卷的阶段：跑分要卷，榜单要卷，代码能力要卷，长上下文要卷，Agent 工程能力也要卷。
