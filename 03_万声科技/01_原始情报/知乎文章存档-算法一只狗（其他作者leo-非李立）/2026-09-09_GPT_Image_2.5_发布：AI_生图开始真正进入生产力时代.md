OpenAI 在 9 月 8 日正式发布 ChatGPT Images 2.5。相比 Images 2.0，官方重点其实就四个： **生成速度最高提升 50%、参考图人物/主体保持更好、局部编辑更精准、多轮编辑一致性明显增强** 。同时新增了 Sketch 草图输入、图片局部评论修改、Poster / Merch 等模板。

![](https://pic2.zhimg.com/v2-0f6cad3e8947a2851a6efa07eaad6dd7_1440w.jpg)

API 这次还拆成两个模型：

| 模型 | 定位 |
| --- | --- |
| GPT-Image-2.5 Flare | 快速版，适合日常生成、批量素材、UI 原型 |
| GPT-Image-2.5 Sunburst | 高质量版，重点强化复杂生成和精细编辑 |

OpenAI 把 Flare 定位成默认模型，官方称相比 GPT Image 2 **质量更高、延迟降低约 50%** ；Sunburst 则主要针对广告、产品图等需要连续精修的场景。

而且这次 Arena 成绩确实很猛。目前 Text-to-Image 榜上 **Sunburst 第一、Flare 第二、GPT Image 2 第三** ；单图编辑榜同样是这三个顺序。尤其编辑榜上 Sunburst 1520、Flare 1491、GPT Image 2 为 1461。

![](https://pica.zhimg.com/v2-2802d38063e6355c867d86e2eec0f8aa_1440w.jpg)

## 比较有意思的网友实测

## ① 有人已经直接把它用到了 UI 设计生产中

Reddit 的 r/codex 有一个很有价值的测试。一个做 **12ui** 项目的开发者长期测试各种图像模型，拿 GPT Image 2、2.5 Flare 和 Sunburst 跑了一批复杂 UI Prompt。

他的结论是：2.5 是第一个在他的所有 UI 测试中，真正全面超过 GPT Image 2 的模型。

而且他最后直接把 **Flare Medium 作为主要 UI 草稿生成模型上线了** 。Flare Medium 大概是最佳平衡点：生成明显更快，而且 UI 的间距、布局、参考图融合都更稳定。

![](https://pic2.zhimg.com/v2-cb15a372783f621f00c8266254e1c1e3_1440w.jpg)

如果后面 **GPT Image 2.5 能进一步和 Coding Agent、网页开发、游戏开发工具链打通** ，我觉得它直接成为 Agent 工作流里的一个视觉能力模块。

## ③ 草图直接直出

这是这次最值得先试的功能，因为它直接降低了生图的门槛： **你不再需要很会写 Prompt。**

在 ChatGPT 输入框里输入 **@Sketch** ，会弹出一个手绘面板。你只需要先把大致构图、人物位置和元素关系画出来，再补一句想要的风格和细节描述，模型就会把这张草图当作构图参考，直接生成完成度更高的成品图。

相比纯文字生图，它最大的价值是： **从“描述你想要什么”，变成“直接画给 AI 看”。**

![](https://pic4.zhimg.com/v2-2d8deeadca846adfdabde0ef19282bbd_1440w.jpg)

比如你还可以描述：一个树形的书架，真实地摆放着各种图书，宜家家居展示间效果。

![](https://pica.zhimg.com/v2-437992887b75d3e8ed06f15c76b2ab2c_1440w.jpg)

这个功能我觉得特别适合 **UI、海报、产品草图、室内设计、游戏场景** 这类对构图要求比较明确的场景。

对于普通用户来说门槛会低很多；对于设计师来说，它更像是把 **线框稿 / 草稿直接变成高保真效果图** 。

## 写在最后

以前最大的问题是不可控：改姿势可能把脸改了，换背景又把衣服改了，很难围绕同一个素材持续迭代。

现在参考图锁定、局部编辑、多轮一致性、Sketch 草图这些能力，本质上都在解决同一个问题：

**让 AI 从“会画图”，变成“会改图、会连续干活”。**

尤其是 Sketch，未来很多视觉任务可能直接变成：

**随手画草图 → AI 生成 → 圈选修改 → Coding Agent 实现。**

UI、游戏素材、产品图、广告图，都可能被压缩到一个对话窗口里完成。

所以我觉得， **GPT Image 2 解决的是“AI 能不能画得好”，GPT Image 2.5 开始解决的是“AI 能不能真正进入视觉生产流程”。**

这才是这次升级最值得关注的地方。
