模型架构上，它使用了 Kimi Delta Attention、Attention Residuals 和 Stable LatentMoE，官方称整体 Scaling 效率相比 K2 提升约2.5倍。

![](https://picx.zhimg.com/v2-663f83271ec873a8c585dbb6bd6fc06b_1440w.jpg)

左上角是 K3 的 MoE 模块。其中绿色是 **Shared Expert，共享专家** ；蓝色是 **Routed Expert，路由专家** 。每个 Token 进入模块后，会同时走两条路线：

- 共享专家始终参与计算，负责处理通用知识和基础能力；
- Router 根据当前 Token 的内容，从大量路由专家中选择少数几个参与计算。

路由专家的结果会先聚合，再经过归一化和线性变换，最后与共享专家的结果相加。这套设计解决了传统 MoE 的两个问题。

- 第一，纯路由专家容易出现负载不均衡。有些专家被频繁调用，有些专家长期闲置。加入共享专家后，通用能力不需要全部挤到少数热门专家里。
- 第二，超大规模 MoE 在训练时容易出现数值波动。图中路由专家聚合后增加了 Norm + Linear，可以理解为对专家输出重新校准，让2.8万亿参数规模下的训练更加稳定。

左下角是 **Kimi Delta Attention，简称 KDA** 。

传统 Transformer 的标准注意力，在序列变长后计算和显存开销会迅速增加。KDA 的目的，就是让模型能够以更低的成本处理超长上下文。

从图中可以看到，输入会被投影成多个分支：

- 部分分支经过 Linear + Conv，提取局部连续信息；
- 部分分支经过归一化，用于稳定查询和键的匹配；
- 多个门控分支通过 Sigmoid 控制信息的写入、保留和输出；
- KDA 计算完成后，再经过 Norm、门控相乘和线性投影。

这里的卷积主要负责捕捉邻近 Token 之间的局部模式，而 KDA 负责维持更长距离的信息状态。两者结合后，模型既能理解附近的词语关系，也能处理几十万甚至更长上下文中的远距离依赖。图中还有一条绕过 KDA 的支路，最终与归一化后的注意力结果相乘。这是一种门控机制，模型可以自行控制

而从右侧主干可以看到，K3 并没有完全抛弃传统注意力。一个大的网络结构中，主要采用：

- **3组 KDA + Stable LatentMoE**
- **1组 Gated MLA + Stable LatentMoE**

也就是大约采用“三次高效注意力，再插入一次高精度注意力”的混合方式。

总结起来就是，用 Stable LatentMoE 做大容量，用 KDA 做长上下文，用 Gated MLA保住精度，再用 Attention Residuals打通不同深度的信息流。

## 真实案例

网友Command Code设计了一个飞机大战的游戏，Kimi K3 对设计风格的把握非常准确，也清楚游戏中应该加入哪些内容。整体节奏和游玩体验都保持得很好。

相比之下，Fable 5 和 GPT-5.6 Sol 生成的游戏节奏都太快了。需要说明的是，视频并没有进行加速处理。综合排名：开发体验、功能与成本

→ **Kimi K3：9.5/10，成本 0.030 美元**

→ **Fable 5：7.5/10，成本 0.38 美元**

→ **GPT-5.6 Sol：7/10，成本 0.11 美元**

[https://www.zhihu.com/video/2061588037667140484](https://www.zhihu.com/video/2061588037667140484)

用 Kimi K3 做了一个受《纸片马力欧》启发的游戏，并使用 Grok Build 作为 Harness。

它能够调用 Agent Skills 和各种工具，自动生成 2D 和 3D 素材。其中，2D 素材使用了 Spriterrific，3D 素材则通过几何建模生成。

在游戏的过程中，当玩家角色走到树后面时，它竟然知道要自动把树冠顶部变成半透明。

除此之外，它还自行完成了“卡片翻转”动画。

## 写在最后

在网页生成、游戏开发、UI 设计和 Coding Agent 等场景中，K3 不仅能完成任务，还会主动补充交互、动画和设计细节。相比单纯“把代码写对”，它更像是在尝试“把产品做好”。

当然，K3 的推理成本和部署门槛依然不低，也未必能全面超过 GPT-5.6 Sol 和 Claude Fable 5。但至少在部分任务中，它已经不再是闭源模型的替代品，而是一个真正有竞争力、甚至更有创造力的选择。

2.8 万亿参数只是表面。K3 真正的大招，是让开源模型第一次有了顶级闭源模型的完成度，以及属于自己的审美和创造力。
