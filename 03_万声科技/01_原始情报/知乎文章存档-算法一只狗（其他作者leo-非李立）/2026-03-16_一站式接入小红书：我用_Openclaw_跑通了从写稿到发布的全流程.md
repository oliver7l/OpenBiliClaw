一站式接入小红书：我用 Openclaw 跑通了从写稿到发布的全流程

以前做小红书内容，最麻烦的其实不是“写一篇文章”，而是那一整套又碎又杂的流程。

你要先想选题，再定人设，再写文案，再找配图，最后还得自己打开平台一点点发布。

如果只是偶尔发一篇还好，但只要你想稳定更新，很快就会发现，真正消耗精力的并不是创作本身，而是这些重复、零散、机械的动作。

所以我最近一直在折腾一件事：能不能把“小红书内容生产”这件事，尽可能交给 Agent 一站式完成？

从选题、写作、配图，到最后自动打开页面完成发布，整条链路尽量打通。

这篇内容，就来分享一下我是怎么用 Openclaw 把这套流程真正跑起来的。

![](https://pic3.zhimg.com/v2-a6faf8ecfed772e410cd96bf7680e9e4_1440w.jpg)

## 设定你的小龙虾人设

我们可以直接编辑Openclaw的Agent文件，设定选题人设，具体的prompt可以参考这里： [https://docs.qq.com/aio/DZEJ6UHZNUGZEWmZz?p=qO3dEYGv0HTpd4ITCH9DF6](https://docs.qq.com/aio/DZEJ6UHZNUGZEWmZz?p=qO3dEYGv0HTpd4ITCH9DF6)

![](https://picx.zhimg.com/v2-1fcf654d96f784e99f2d308a2251b101_1440w.jpg)

测试一下它的选题效果：可以看到它能够搜索AI热点话题，然后根据这些人地话题，给出不同的评分，然后进行选择

![](https://pic3.zhimg.com/v2-5963fae56540350af7b08da3f6185f64_1440w.jpg)

然后再定义soul.md，它是用来定义性格，让你的Agent有一个人格灵魂：

![](https://pic1.zhimg.com/v2-658b9fcec7c061bed9336c46158b6f58_1440w.jpg)

最后测试一下它的写文章效果，比如我让写一篇这个话题的小红书推文：《个人AI化妆师，居然免费！》

![](https://picx.zhimg.com/v2-5a547dadc016991b384991519e766f71_1440w.jpg)

## skills安装

现在Openclaw有了初步的写文章能力，但是需要加上一些配图信息，我这里直接使用GPT的生图能力，它的一个官方skills：openai-image-gen

**图片生成skill安装** ： [https://clawhub.ai/steipete/openai-image-gen](https://clawhub.ai/steipete/openai-image-gen)

![](https://pica.zhimg.com/v2-5208cc9ff109894e434acdfe20a6885a_1440w.jpg)

然后直接让openclaw帮我安装一下：

![](https://pica.zhimg.com/v2-5aad61fc4a10245a75cd239f4630865c_1440w.jpg)

这个skill需要去到GPT申请一个API key，把这个API Key提供一下就可以了：API keys - OpenAI API

![](https://pic2.zhimg.com/v2-d6c95790785bde16efafe8e58bec17d1_1440w.jpg)

当然你也可以使用国内的一些生图skill，比如Qwen Image、即梦等等，也需要去到它的官网拿到api key才能进行生图。

![](https://picx.zhimg.com/v2-042dd8a107ef01bb1d6dcef8882c1b65_1440w.jpg)

最后测试一下它的生图效果，感觉还可以：

![](https://pica.zhimg.com/v2-3dd7b5ee25c0202ea08736d7171eb042_1440w.jpg)

**安装自动化发布小红书skills：**

帮我安装这个skill， [https://github.com/Xiangyu-CAS/xiaohongshu-ops-skill](https://github.com/Xiangyu-CAS/xiaohongshu-ops-skill)

安装这个skills之后，Openclaw会全程自动化的帮助你打开小红书页面，然后进行发布。需要注意的是，第一次使用的时候，需要扫码进行登录。

## 最后效果

最后就可以看到具体的效果了~

比如你可以只生成文字，让它进行自动发布

![](https://pic2.zhimg.com/v2-1af5ba19cfdb717d405d88cb612bbe97_1440w.jpg)

当然，也可以图文一起生成，一键式发布

![](https://pic1.zhimg.com/v2-70f3fd473cbe809471f02342287acf7a_1440w.jpg)

整体体验下来，我现在的感受很明确：

Openclaw 真正有意思的地方，不只是“能聊天”，而是它开始具备了把一整段工作流接起来的能力。

当你把人设、性格、写作能力、配图能力和发布能力都串到一起之后，它就不再只是一个会生成文案的工具，而更像一个能实际帮你干活的内容 Agent。

当然，这套流程现在还谈不上完美。比如不同 skill 的稳定性、API 成本、账号安全、平台风控、自动化操作的兼容性，这些都还需要边用边调。

但至少从结果上看，一套“选题—写稿—生图—发布”的闭环，已经是可以真正跑通的了。

如果你也想做自己的内容 Agent，或者想把小红书这类平台的发布流程尽量自动化，这套方案还是很值得亲自试一试的。

## 很多时候，效率提升不是来自某一个超级强的模型，而是来自你有没有把这些能力真正接成一条链。
