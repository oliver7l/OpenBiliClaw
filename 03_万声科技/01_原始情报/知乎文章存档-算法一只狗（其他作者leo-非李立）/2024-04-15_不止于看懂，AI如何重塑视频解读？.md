AI视频的生成，在另一方面也要求AI能够读懂视频中的内容，才能够有效地针对不同内容生成结果。因此，AI视频理解成为另一个至关重要的领域，如同一位聪明的大脑，解析着视觉世界的奥秘。

本文主要介绍两个比较重要的视频理解模型，分别为GPT4Video和MiniGPT4-Video。

## GPT4Video

第一个模型叫GPT4Video模型，是腾讯AI LAB基于大模型训练出来的，有两个主要优势： 1）它在视频理解和生成场景方面都展现出令人印象深刻的能力。例如，GPT4Video在视频问答任务上比Valley高出11.8%，在文本到视频生成任务上比NExt-GPT高出2.3%。  2）赋予LLM/MLLM视频生成能力，无需额外训练参数，可灵活对接多种模型进行视频生成。

### 技术细节

模型主要有三个不同的模块构成： - 视频编码阶段：视频编码模块使用冻结的ViT-L/14模型来捕捉原始视频特征 - 大模型LLM推理：GPT4Video的核心由一个冻结的LLaMA模型提供动力，并通过LoRA进行有效的微调。LLM使用自定义的以视频为中心和安全对齐的数据进行训练，使其能够理解视频并生成适当的视频提示 - 视频生成：LLM生成的提示随后被用作文本输入到模型Text-to-Video Model Gallery中，同时不需要微调就可直接生成。

![](https://pic4.zhimg.com/v2-4d55353065559ef56a35764533afaa43_1440w.jpg)

## MiniGPT4-Video模型

第二个模型则能够实现自己上手部署，免费白嫖。同时它在AI视频理解上达到了最新的效果。

### 本地部署

在github仓库上，minigpt4-video有详细的部署步骤：

> [https://github.com/Vision-CAIR/MiniGPT4-video](https://github.com/Vision-CAIR/MiniGPT4-video)

1. 克隆仓库代码

```text
git clone https://github.com/Vision-CAIR/MiniGPT4-video.git
cd MiniGPT4-video
```

1. 安装和激活环境

```text
conda env create -f environment.yml
```

1. 下载模型 |MiniGPT4-Video (Llama2 Chat 7B)|MiniGPT4-Video (Mistral 7B)| |-|-| |Download|Download| 

2. 运行代码 


```text
# Llama2
python minigpt4_video_demo.py --ckpt path_to_video_checkpoint --cfg-path test_configs/llama2_test_config.yaml
# Mistral
python minigpt4_video_demo.py --ckpt path_to_video_checkpoint --cfg-path test_configs/mistral_test_config.yaml
```

### 技术细节

**模型的一些方法总结：**

- MiniGPT4-Video建立在MiniGPT-v2的基础上，后者在将视觉特征翻译到LLM空间中表现出色，用于单一图像，并在各种图像-文本基准测试中取得了较好的结果。
- 该模型将每四个相邻的视觉令牌合并为一个令牌，以减少信息损失，并且还结合了字幕，从而提高了模型对视频内容的理解能力。

**训练方式：**

- 利用大规模图像-文本对预训练和视频-文本对预训练，这些都是用来使模型适应视频内容的。
- 该模型在预训练阶段使用了线性层将视觉特征映射到LLM的文本空间，使用了EVA-CLIP视觉编码器和LoRA技术进行细致调整。

**具体包含三个步骤进行训练：**

- **图文对齐的预训练：** 第一个步骤利用EVA-Clip模型进行预训练，让模型理解图片和其对应的描述
- **视频文本对齐的预训练** ：由于视频是多个图片帧拼接，那么可以构造成一帧一帧的图片加上文字输入到后续的模型层中。
- **视频问答的微调：** 利用一些高质量的问答数据集在大模型（LLM）上进行微调

![](https://pic1.zhimg.com/v2-32bf188c086c601835f3310ce0dafa34_1440w.jpg)

MiniGPT4-Video在多个视频基准测试中表现优异，包括MSVD、MSRVTT、TGIF和TVQA，在这些基准测试中取得了显著的性能提升。

![](https://pic2.zhimg.com/v2-7eed2fe8dd39117114e8bc451695aded_1440w.jpg)

总的来说，这个模型已经展示出能够初步捕捉视频内容的潜力，但是要想达到ChatGPT那种令人惊艳的水平，还需要跨越一段不小的距离。
