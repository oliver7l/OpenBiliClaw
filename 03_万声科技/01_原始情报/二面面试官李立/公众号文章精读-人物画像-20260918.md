## 二、他写了些什么（十年主题演化）

**2016 · 教科书式连载期（32 篇）**
强化学习九连更（MDP→Q-Learning→DQN→逆强化学习）是全年最大主线，用一个自创的"机器人找金币"案例从头讲到尾；穿插统计补课（EM、卡方、T 检验、MCMC）、游戏 AI 环境（两次换平台、进度难产）、Spark/Akka/Maven 系统工程。开号第一篇是评论 npm left-pad 事件。

**2017-2018 · 棋牌 AI 野心的两年（26 篇）**
三条线并行：① Akka 四部曲 + Spark 优化（本职大数据）；② 热情所系——判断"多人合作博弈（斗地主/桥牌）是 Libratus 搞不定的 totally different story"，立项开源项目 **RoomAI**（非完全信息博弈环境，支持德州/斗地主/桥牌/麻将），此后所有技术文（Python 深拷贝、私有制、候选采样）全部回扣这个项目；③ 广告推荐工程实战——用自家业务数据给热点泼冷水：《XGBoost+LR 就是加特征而已》《树模型的失落》《模型吞噬特征工程》。多 Agent 强化学习综述、DQN 棋牌实验也在这两年。

**2019-2021 · 团队主编与组织反思期（10 篇）**
发文骤降：2019 年密集 7 篇（一半是团队成员署名的教程，他成了"主编"）；2020 年 2 篇事故复盘（TF Serving 内存爆炸 n! key 事故、深度学习×大数据融合研判）；2021 年仅 1 篇——《5%的时间做算法，95%的时间做工程》，全文最核心的价值观表达：算法工程师是"娇贵的工种"，应该指挥三路支持团队、坚决不做工程活，并坦诚自己组织实验的失败转向。

**2026 · 复出评论员期（6 篇）**
转向 AI 行业祛魅与方法论：《对不起，OpenClaw 不是你的救赎》（AI 是专业者的放大器，普通人三重无力）、《AI 无法取代人类，但可能取代"你"》（创意/架构/实现三层框架）、《推荐系统从 0 到 1 到 10》（给跳槽中小厂的算法负责人的技术地图）、《闭源狂奔，开源 AI 音乐模型春季突围》（为东家立场找论据）、《大模型当道，小模型何用？》（小模型是"用能力妥协换业务闭环"）、《别怕，Claude Mythos 无法毁灭世界》（媒体/厂商/公众三方共谋的流量阳谋）。

## 三、他是个什么样的人

1. **反炒作是刻在骨子里的**。全网吹 Master 他先查证消息源；自媒体吹 AlphaGo Zero 通用智能他说"这是不对的"；XGBoost+LR 被神化他用自家数据打脸；2026 年复出第一件事就是给 OpenClaw 和 Claude Mythos 造神叙事泼冷水。对 Anthropic/OpenAI 一视同仁放进传播学显微镜，不站队不崇拜。
2. **不推导就不算懂的学院派**。从贝尔曼等式到 Hoeffding 不等式自己推一遍；讲 CNN 不堆术语，用一个"A 字母滑动匹配"的手工例子从第一性原理还原。但落到工程上又是极端务实派：空间换时间、源码读到底（CPython deepcopy、log4j）、敢自改 TF 源码重编译不等官方。
3. **冷幽默自嘲是他的人设招牌**。读者问"不看论文能掌握机器学习吗"，他全文回两个字："**没有**"。自称"数据民工""学霸中的学渣"，自评文章"国内最清楚之一（大牛们轻喷）"。
4. **罕见的坦诚**。为拖更公开道歉、自曝 RoomAI 代码缺陷、承认 DQN"并没有太强"、白纸黑字复盘自己组织变革的失败。面试官视角看：这人接受被证伪。
5. **文人气质的理工科**。爱用历史编年笔法（"人类公元 1997 年"）、古诗词（"滚滚长江东逝水"）、文学典故（达摩克里斯之剑、茨威格、弗兰肯斯坦母题）、毛式叙事（星星之火）混搭网络梗（+1s、"问就是"）。
6. **行动主义者**。"杠杆只对支点起效""红利属于在别人惊叹时已挽起袖子的人"——他自己就是蓝本：读博期间写连载、在职两年押注 RoomAI、三次迁徙（腾讯→荣耀→万声）。

## 四、他的偏好清单

**技术栈**：Python（主业+RoomAI）、Spark/Scala、Akka、TensorFlow→TF2、golang（推荐服务框架）、C++/Redis；2026 日常用 Claude Code、Cursor、Codex。
**方法论偏好**：数学推导 → 第一性原理还原 → 用自家业务数据做对照实验 → 空间换时间 → 最小闭环先行（"一切炫技的复杂模型都是阶段 1 的敌人""拿着阶段 100 的图纸盖阶段 1 的房子，这叫高射炮打蚊子"）。
**领域热情**：强化学习（尤其非完全信息博弈/多 Agent）是精神原点；广告推荐系统是饭碗；AI 音乐生成是现任阵地（判断"音乐生成门槛远低于 LLM，开源有四两拨千斤的机会"）；大模型时代立场 = 闭源天花板 + 小模型垂直微调做落地 + Agent 是杠杆。
**口味**：反鸡汤、反速成、反宏大叙事；喜欢 ROI 算计先行（连"要不要上推荐系统"都先算商业账，还写进文章——与其面试官身份互文）；信息来源横跨 arXiv/GitHub/QuestMobile/抖音，中文互联网一手案例敏感度极高。
**行文习惯**：早期 = 系列编号 + 生活场景开头 + 结尾预告下期 + 文末推 RoomAI；现在 = Part 编号 + 故事钩子开场 + 密集参考文献 + 金句收尾。不变的是：先给结论再给证据，最后一定落回建设性。
