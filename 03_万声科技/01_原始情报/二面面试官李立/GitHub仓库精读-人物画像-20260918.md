## 二、逐仓库精读

### 1. Reinforcement_Learning_Blog —— 教科书级的"从零手写"（2016-08）

**结构**：按公众号"强化学习系列之一~之八"逐篇建目录，每章一个独立可运行包（算法实现 + experiment 实验脚本 + tests 单元测试），外加 `FlappyBird/`（pygame 游戏脚手架）和 `MultiArmedBandits/`（多臂老虎机）。README 只有 3 行有效内容：指向 algorithmdog.com 的系列目录。代码即博客的"配套实验环境"。

**逐章读到的硬货**：

- **之一（MDP）**：9 宫格世界，`compute_random_pi_state_value()` 用 100 万次重复采样+增量平均算随机策略状态值，γ 每步衰减 0.5。蒙特卡洛估计讲得用的就是蒙特卡洛算——教学方法论自洽。
- **之二（策略迭代）**：policy_evaluate/policy_improve 经典结构，收敛阈值 1e-6。**亮点在测试**：`test_policy_iteration.py` 里写死了手推的正确值（v[1]=-1.0, v[2]=0.8, v[3]=1.0, v[4]=-0.8, v[5]=-1.0），断言到 1e-6。教学博客代码配手算值的单元测试，这在 2016 年的中文 RL 圈极其罕见。
- **之三/四（模型无关学习）**：MC、SARSA、Q-learning 三个算法全部手写，ε-greedy 完整实现；收敛度量不是拍脑袋——先跑出 `best_qfunc` 存文件，训练时逐迭代算与最优 Q 的平方误差画曲线。**实验脚本拆得极细**：`experiment_epsilon_greedy.py`、`experiment_learning_rate.py`、`experiment_variance.py`、`experiment_near_optimal.py`——每篇博客控制一个变量做对照实验，这是做研究的人的习惯，不是教程搬运工的习惯。
- **之五（价值函数逼近）**：线性 Q 函数 + 特征向量，θ 梯度更新，三算法同一框架重写，接口抽象出 `Policy.qfunc/update` 复用。
- **之六（策略梯度）**：`SoftmaxPolicy`（softmax 显式实现）与 `ValuePolicy`（线性 Q + ε-greedy）双策略类，特征-动作 one-hot 拼接向量。
- **之七（逆向强化学习）**：**整个库存档里最见功力的文件** `apprenticeship_learning.py`：从最优 ε-策略采 5000 条专家轨迹 → 学徒学习迭代：用 **pulp 解线性规划**猜奖励函数（θ ∈ [-1,1] 约束、max-margin 形式，教科书原版的 Abbeel-Ng 框架），再用猜出的奖励跑 Q 学习，20 轮迭代画"与专家策略差距"收敛曲线。注意 `maxent_learning.py` 只有 1 行 shebang——**MaxEnt IRL 的代码是空壳**，博客对应章节只讲了学徒法。
- **之八（OpenAI Gym）**：把同一套 SARSA/Q-learning 移植到 gym 接口（`env.reset()/step()`），展示接口迁移能力。
- **彩蛋——`secret/` 目录**：每章都有 `sys.path.append("./secret")`，环境实现（grid_mdp.py，奖励 +1/-1/-1 的三出口格子世界）**刻意对读者隐藏**，博客教算法、环境当习题——这是设计过的教学法，不是随手为之。
- **FlappyBird**： pygame 渲染层（小鸟/障碍/背景三张自备素材图），只搭了环境没接 agent——游戏 AI 实验的脚手架。

**代码风格**：Python 2 + numpy + matplotlib，全手写零框架；所有脚本 `random.seed(0)`；英文注释；命名规范统一。2016 年没有稳定 RL 库的年代，这就是"讲明白"的唯一方式，而他确实做到了。

### 2. Representation-based-Multilabel-Learning —— 博士研究本尊（2016-12）

**这份仓库证明了他的学术身份**：README 明确列出三个实现——WSABIE（Weston 2011）、LEML（Yu 2013）、**RMLS = "Li et al., Towards Label Imbalance in Multi-label Classification with Many Labels, arXiv:1604.01304 (2016)"——他自己的论文**。博士课题是"超大多标签分类中的标签不平衡"，公众号 2016 年写《PCA模型加先验》等统计文章的学术底座就在这里。

**工程含金量（2394 行）**：
- `latent_factor.py`（598 行）：`Model` 类是完整的多层网络——特征 → 若干隐层 → k 维隐因子 → 标签层；**Xavier 初始化**（`sqrt(6/(fan_in+fan_out))`）、tanh/linear/relu 激活可选、NLL/最小二乘损失可选、**AdaGrad** 自适应学习率（`learnrate.py`）、标签采样机制对抗不平衡（sampling_ratio）、多标签阈值选择（`threshold.py`）、外部内存接口（注释："we will implement as soon as possible"——未完成）。2016 年 PyTorch 还没发布，这是纯 numpy/scipy.sparse 手搓的深度模型。
- 实验基建完整得像个小实验室：svm-light/arff 双格式 IO、`sampler.py`、主动学习模块 `active.py`、`tool/` 里 imR（不平衡排序指标）计算器 + 交叉验证统计汇总，`tool/run_rep_cv.sh` 等 10 个 shell 脚本——WSABIE/LEML/RMLS/baseline 四方法 × 交叉验证全自动。
- 有 Logger 封装、模型 save/load 文本协议、predict 独立入口——是能给别人用的研究代码，不是跑一次就扔的脚本。

### 3. AkkaUsageLearner —— 在腾讯学 Spark 时的功课（2016-12 ~ 2017-06）

Scala 2.10 + JDK 1.7.0_79 + maven，四个子目录一一对应 Akka 博客四篇：快速入门（Teacher/Student Actor 收发消息）、测试（testkit 的 testProbe/testActorRef）、层次结构与容错（oneForOne/allForOne 监督策略，hierarchy1/hierarchy2 两个文件）、Future（同步机制）。README 明说动机："Spark 就用 Akka 实现内部通信"——**这是他在腾讯 IEG 做大数据/推荐时补分布式通信底层的学习笔记**（与 QCon 专访里"深度学习与大数据融合"的岗位线吻合）。

**冷幽默实锤藏在测试道具里**（TeacherActor.scala，2016-12-22 创建）：Actor 只会答三道题——
- "1+1等于多少？" → "1+1等于2"
- "历史上规模最大的众筹行动是什么？" → "历史上规模最大的众筹行动是 **+1s**"
- "腾讯第一网红是谁？" → "腾讯第一网红是**我去**"
- 兜底回复："这个问题，老师也得查查书"

+1s 和"我去"都是当年腾讯系内部梗，写进了示例代码。公众号文字里的冷幽默，在代码里原样存在。

### 4. RoomAI —— 他最认真的开源野心（2017-05 定稿）

**是什么**：非完全信息博弈 AI 的对标 OpenAI Gym 的工具包，`pip install roomai` 可装（有 setup.py），README 里示例玩家代码可直接运行，并公开征集贡献者（留 gmail 邮箱）+ 预告 Model Zoo。

**架构设计的水平**：核心抽象（`roomai/abstract/Abstract.py`）把 Info 拆成 public_state / person_state / private_state 三层，**private_state 永不进入任何 Info**，每个 Info 是状态 deepcopy——从类型系统层面杜绝了作弊可能。这个"信息隔离"设计正是非完全信息博弈平台的命门，他一开始就想清楚了。`compete()` 循环与两年后的 Gym API 同构。

**游戏覆盖**：Kuhn 扑克（150 行，规则/结算逐分支实现干净）、Five Card Stud（671 行）、德州扑克（715 行 + 牌型评估 197 行），**mahjong/MahjongUtil.py 只有 1 行——麻将计划了没做**；models/Model Zoo 的 README 只有 1 行标题——平台先行、模型阵营是空支票。与公众号 2017-18"棋牌 AI"叙事对照：他搭好了竞技场，但 AlphaHoldem 那级别的 bot 并未在 GitHub 出现。

**测试**：每游戏一个 test 文件（testKuhn/testTexas/testFiveCardStud），框架级工程纪律保持一致。

### 5. machine-learning-algorithms —— 教学散件 + 四年后的一次闪回（2016 → 2020）

- `EM/GMM/`：EM 算 GMM 从零实现，E 步/M 步拆开，画对数似然收敛曲线。细节见功底——`st_normal()` 手写了正态分布 CDF 的 **Zelen-Severo 多项式近似**（不调 scipy.stats 也能算概率），配可视化。
- `UnbalancedClassification/`：TV 频道广告检测数据集（TIMESNOW）预处理，按 5%/95% 概率切训练测试**人为制造类不平衡**——对应公众号不平衡分类文章的实验设计。
- 时间戳彩蛋：该仓最后一次活动是 **2020-12-09 合并了 balbirsingh08 的 PR**——内容停在 2016，但他四年后还在处理陌生人发来的 pull request，开源习惯一直在线。

## 三、代码里的李立：与公众号画像的互相印证与增量

公众号精读得到的画像（反炒作、第一性原理、冷幽默、坦诚、RL/博弈为精神原点、现阵地 AI 音乐），在代码里找到了七条硬证据级别的印证，外加三条公众号看不出来的增量：

**印证一：第一性原理 = 全部手写。** 五个仓库没有一处 import sklearn/torch/现成 RL 库。价值迭代、Q-learning、策略梯度、IRL 的 LP 对偶、EM、正态 CDF、多标签深度模型，全部从数学原式写起。这不是时代限制（2016 年末 PyTorch 已出、sklearn 一直都在），是**他只信自己推过的东西**。

**印证二：教学者人格。** 每个仓库都是公众号某系列的"实验台"；`secret/` 目录是留的习题；测试写着手推值；README 示例保证可运行；连 FlappyBird 的三张素材图都是自己画的。写作和写码在他的工作流里是同一件事的两半。

**印证三：冷幽默跨媒介稳定。** "+1s"、"我去"、"老师也得查查书"——公众号式冷笑话原封不动出现在 Scala 教学代码里。人设不是文章里演的。

**印证四：研究者的实验纪律。** 所有随机过程加 seed；对照实验一次只动一个超参；收敛度量对齐最优解而非"看起来变好"；交叉验证脚本化。公众号里那种"我用数据说话、拒绝讲故事"的文风，源头是这套习惯。

**印证五：坦诚/不装。** `maxent_learning.py` 空壳照样提交、Model Zoo README 只有一行标题、麻将只有 1 行、"external memory 尽快实现"挂了多年——他不做完不发、也不掩饰没做完的。与公众号"承认不知道"、"没有"式回答同一底色。

**印证六：时间线闭环。** 2016-08 RL 八讲博客+代码 → 2016-12 博士课题仓库 + Akka（腾讯在职证据）→ 2017-05 RoomAI → 2020 仍在维护。GitHub 内容与公众号叙事、履历（北大博士→腾讯 IEG）三方咬合，无一冲突。
