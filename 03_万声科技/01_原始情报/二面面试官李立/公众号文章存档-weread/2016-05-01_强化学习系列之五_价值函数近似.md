目前，我们已经介绍了一些强化学习的算法，但是我们无法在实际问题中运用这些算法。为什么呢？因为算法估算价值函数 
![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfnVEAGMFbsvD4yWdeTTmnvcxaEzyJ39Lg39RQgCwq9JyuZWMHVibXSsg/0?wx_fmt=png)
 或者 
![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfo9K5efG2z1q3dtpibFMMlX2Ce53NZa8ztDRCv0v7wmYBBxWdh9QIZIg/0?wx_fmt=png)
，保存这些价值函数意味着保存所有状态。而实际问题中，状态的数目非常巨大，遍历一遍的事情就别想了。比如，围棋的状态总数是
![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfRoaDQlxEHBoDyLicwRIZrHWoA1EbX59r5AZNo9NAJja7ArSyt8Jss4A/0?wx_fmt=png)
，听说比宇宙的总原子数还多，23333。解决这个问题的方法是抽特征。对于一个状态 s, 我们抽取一些特征 
![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfTUnZPJAsH2QnbTmlyF0SicqE35bP57vQOLibzETTickJe1icElJZ0PibkMQ/0?wx_fmt=png)
，将这些特征代替状态作为价值函数的输入，即 
![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfym2dU9r53wp3JpjEibNHZzKTicpGtlccXpxmgmcB24NGgrEia17ic9SWJw/0?wx_fmt=png)
 或者 
![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfg0B9NLGfQRDKrOTImGVP4DycYzShfum6tQiblBen2FcaiaBytM2lUgnw/0?wx_fmt=png)
。这种方法我们称之为价值函数近似。价值函数近似解决了海量状态之后，我们才能实用强化学习算法。

![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfyNeW6WuVWptSxe0Z7JbgL5A3ZoyPakyKiafYceaa9bP1ZUsQU9k7x1w/0?wx_fmt=png)

3. 做个实验

      我们用机器人找金币做个实验吧。实验中，我们用了两种特征。一种特征是强特征，也就是上述四个方向是否有墙特征。另一种特征是 id 特征，特征向量长度为状态个数，第 i 个状态的特征向量的第 i 位为 1，其他位置为 0。实验对比了三种算法: MC Control, SARSA 和 Q Learning。
![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfbq0zM7441mB2AP5lTnVL2icbAibCzMqY5opH6zLKyMUWwItIcja9iaQpg/0?wx_fmt=png)
贪婪策略的 
![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWf7tfOJu0ebjzZrRw7aTImYvyMzQggZJcw0NvydKI3fEQFtaDnIiaRR1Q/0?wx_fmt=png)
 设为 0.2， 学习率
![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfXAKHgPbypjwUFRawT2icDrsVV19hU33FFVuibTDNS7Pvurib8nSng4xCw/0?wx_fmt=png)
 设为 0.001。和上文一样，算法计算得到的状态(特征)-动作价值和最优策略的状态-动作价值之间的平方差，当做评价指标。实验的结果如下图所示。

![](http://mmbiz.qpic.cn/mmbiz/Q3H1TCddfvMpLnhUs0FkFRgcb7KbZAWfoPq841gHKwicIlcCJfmAKIBeokibDzevPDfiaojCylK327icTV56zlGpJw/0?wx_fmt=png)

      这个实验结果告诉我们的第一件事就是选好特征。墙特征比 id 特征差。状态2 和 4 都是南北方向有墙，墙特征是一样的，会造成混淆。id 特征就没有这个问题。表现在实验结果上，MC Control 和 SARSA 在墙特征上都不停震荡，同时三种算法在墙特征的表现都不如其在 id 特征上的表现。

      Q Learning 一如既往地表现出优越的效果。在墙特征上， Q Learning 不仅没有像 MC Control 和 SARSA 一样震荡，而且效果远远好于它们两者。在 id 特征上， Q Learning 完美拟合了最优策略的状态-动作价值。

4. 总结

      实际问题中，状态的数目非常多，因此基于状态-动作价值的强化学习算法不适用。为了解决这个问题，人们提出了价值函数近似的方法。价值函数近似用特征表示状态或者状态-动作，用参数向量计算价值。价值近似之后，我们才算能把强化学习算法应用在实际问题上。本文代码可以在 Github 上找到，欢迎有兴趣的同学帮我挑挑毛病。强化学习系列的下一篇文章将介绍基于梯度的强化学习。
