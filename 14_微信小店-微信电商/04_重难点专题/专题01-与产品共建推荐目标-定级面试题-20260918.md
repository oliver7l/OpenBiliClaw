# 专题 · 定级面试题：「你怎么跟产品定一个推荐目标」

> 考点来源：微信小店-高级推荐算法工程师（T10,T11）JD 职责③「与产品、工程、运营团队深度合作，理解业务发展，参与制定推荐策略的目标」（2026-09-18 深读，见 `01_原始情报/JD存档-…已投.md`）。
> 定级面试问这题，考的不是流程背诵，是三件事：**①业务目标→技术目标的翻译能力 ②有没有真实协作机制（不是口号）③冲突处理成熟度**。

## 一、这题在筛什么

| 你的回答形态 | 面试官读出的信号 |
|---|---|
| 「产品给目标，我来实现」 | 执行者思维 → T8 封顶 |
| 「目标是我定的，产品配合」 | 不懂协作 → 不适合大厂体系 |
| 「我们一起定，机制是…，冲突时…」 | 共建者思维 → T10 对口 |
| 能说清「目标为什么这么定、错了怎么发现」 | 有方法论 → 加分 |

## 二、答题主线（四步，每步都有真事可举）

### 第 1 步：先搞清楚业务要什么，再谈推荐要什么

开场定调：**「先问业务这季度的北极星是什么，推荐在其中的角色是承接还是创造增量」**。

- 电商（小店语境）：北极星通常是 GMV / 买单用户数，推荐的角色是把首页/频道/详情页的流量变成成交——那推荐目标就要对齐 **CTR × CVR × 客单价** 的漏斗，而不是单点 CTR。
- 内容（我的腾讯经历）：北极星是人均时长/留存，推荐对齐「人均 feed 消耗 + 消费深度」。

### 第 2 步：把业务指标翻译成推荐可动的代理指标，并验证代理有效性

这是算法岗的差异化价值所在：**不是拿到目标就拆，而是先验证「动这个代理指标，业务指标真的会跟着动」**。

- 做法：离线分析代理指标与北极星的相关性 / 分层看不同人群的转化链路；上线后用小流量实验验证增量，而不是假设成立。
- 举例（腾讯）：「互动」和「时长」天然互相抢量，不能拍脑袋都拉——我们离线先看了不同品类里互动用户后续留存的贡献，确认互动是留存的先行指标，才把互动放进目标集。

### 第 3 步：多目标权重的初值来自业务口径，不是网格搜索

**「融合权重的初值我用业务价值当量定，再用边际收益微调」**——这句是 T10 和 T8 的分水岭。

- 腾讯实例：多品类统一排序，MMoE 各目标互相抢量。与产品定的方案：**时长为北极星、互动为辅助目标**，融合权重初值按业务给的价值当量（一个互动 ≈ 多少秒时长的口径与运营对齐），线上再按各目标的边际收益动态调——短内容互动 +35%、浮层时长 +6.8%。
- OPPO 实例（电商同构）：变现混排 pCVR×price，price 口径（出价档位）就是和运营共建的客单价当量，eCPM +24%。
- 百度实例（最早）：内容优质度/领域集中度/原创度的**评价口径与产品运营共建**，指标不是算法单方面定的。

### 第 4 步：机制化——目标定完靠什么维持，不靠感情

- **对齐**：目标写进季度规划，产品/算法/运营三方对同一份口径文档（我在腾讯把模型分析工具沉淀成团队标准流程，就是让各方看同一套数）。
- **实验纪律**：判据预注册，先说清看什么指标、升多少算赢，再开实验——避免「出了结果再找有利指标」。
- **复盘**：月度联合复盘，目标达没达、偏差在哪，下一季调不调权重有数据依据。
- **冲突升级路径**：有分歧先跑小流量实验用数据裁决；数据说明不了的业务判断（比如生态/商家公平）升级到双方 leader 对齐——**先数据后上升，不私下较劲**。

## 三、电商语境的两个预埋回答（小店面试大概率追问）

**追问 A：「新商品没有行为数据，目标怎么定？」**
→ 冷启动期目标要给探索留预算：曝光保障 + 探索流量池的目标是「信息获取」（测出商品真实转化率），短期 CTR/GMV 会小亏，但这是投资不是浪费；用保护期 + 贝叶斯先验控制探索成本，探索期结束转正常竞争（我在 OPPO 的机制：新内容曝光 +30%、通过率 +15%，同时大盘不受损）。

**追问 B：「推荐目标和 GMV 冲突怎么办（比如推荐预估转化高但客单价低）？」**
→ 目标函数里写清楚：优化的是 GMV 贡献（pCVR×price 类）而非点击；如果短期 GMV 伤害长期复购/用户留存，就要把留存/复购放进目标集——这正是多目标建模要解决的业务问题，不是目标设置的失败。

## 四、收尾一句（体现阶段观，加分）

**「目标不是一次定死的——业务在拉新期、变现期、生态建设期，推荐目标的主次会变，所以目标制定是个季度迭代的机制，不是一次评审。」**

## 五、避坑清单

1. 别只谈技术指标（AUC/CTR）不谈业务换算——这题就是在筛「技术翻译」能力。
2. 别把「协作」说成态度（「我沟通很好」）——要讲机制：口径共建、判据预注册、冲突升级路径。
3. 别说「我们目标一致没有冲突」——不真实；说「有冲突，但我们有裁决机制」反而加分。
4. 数字只用真实口径：+35% / +6.8% / +24% / +15% / +30%，别现场编。
5. 提到「参与制定」要具体到「我贡献了什么」：比如「价值当量口径是我提的」「代理指标有效性验证是我做的」——JD 原文是「参与制定」，说清楚自己的那部分即可，不抢功也不缩水。
