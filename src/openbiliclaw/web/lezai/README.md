## 怎么来的

1. **两个来源**
   - 班级相册（QQ 群相册「中三班」，7853 张全库扫描）
   - 个人相册（夸克网盘「乐仔的照片」）
2. **先判"照片里有没有乐仔"** —— kNN 近邻模型（`lezai_model_v3.json` + 婴儿期辅助库 `lezai_aux_infant.json`），
   阈值 0.55（置信度见 `清单.csv` 的「乐仔置信」列）
3. **合并去重** —— 感知哈希比对，328 张两来源重复的同一张照片**只保留一份**（优先用个人相册的高清原件）
4. **分类**
   - 班级相册照片 → 幼儿园（带活动与月份标签）
   - 个人相册照片：与班级相册同图 / macOS 本地视觉模型判为教室场景 / 家长在园拍摄 → 幼儿园；其余 → 家庭生活
   - 场景不确定的 10 张 → 待确认

## 已知边界

- 幼儿园/家庭的分界主要依据**班级相册**（权威），个人相册里的在园照片是补充，可能有个别遗漏；
  想更全可以把 `03_待确认/` 过一眼，或把漏掉的照片从原目录挪进 `01_幼儿园/家长拍摄·<年份>/`。
- 幼儿园照片来自班级相册（微信压缩件，约 250KB/张）；若个人相册有同一张的高清原件，库里用的是高清版。
- 家庭生活的日期优先取 EXIF，缺失时取文件名时间戳；两者都没有的归入「未知年份」。
