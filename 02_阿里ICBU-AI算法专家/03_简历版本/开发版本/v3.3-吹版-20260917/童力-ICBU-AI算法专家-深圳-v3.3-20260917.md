### AI+Sales：大模型销售线索挖掘与智能工作流　中信银行信用卡中心　2023.10 – 至今

面向客服与电销团队，把销售流程里原本用不上的非结构化文本，变成一条**可执行、可回收、可迭代**的 AI 工作流。我负责其中从数据处理、大模型能力到策略落地的完整链路：

- **① LLM 抽取层（工作流入口）**：对坐席通话录音转写、人行征信报告、他行信贷与查询记录等文本，用大模型统一抽取为需求标签与强度特征，替代此前的关键词 / 规则匹配——口语化表述、跨格式表格、非标准字段都能被识别。先做文本而不是先做画像，是因为**对话与报告里的语义信息量高于结构化画像**（业界公开研究亦显示，销售对话前 90–120 秒的语义比客户人口统计特征更能预测转化）。
- **② 线索评分与触达名单（信号 → 可执行）**：基于需求特征构建线索评分与客群分层，落地到汽车分期等重点产品的触达名单，**月均产出线索 20 万条、线索承接率 35%**（承接率是回收指标而非产出指标，我用它衡量名单质量而不是名单数量）。
- **③ 智能工作流与口径统一**：统一外呼、动卡、短信、企微、公众号、APP 六大渠道的"触达 → 响应 → 转化"口径并构建全链路转化漏斗，把名单从"发出去"变成"能回收、能迭代"，驱动渠道组合与投放节奏持续优化。
- **④ RAG 知识库与数据问答 Agent**：负责行内智能问答（知识库检索增强）试点的检索链路设计——文档切分与元数据标注、"关键词 + 向量"混合召回、重排与引用溯源，使回复可回溯到原文条款；并把"查口径 → 取数 → 出名单"的常用动作封装为大模型可调用的工具集，由模型按目标编排执行，动作用只读白名单与人工确认双重约束。
- **⑤ 增量验证（让 AI 建议可被业绩验收）**：在**没有随机分流**的真实业务里，用 DID / PSM 与 uplift 评估策略对转化与业绩的真实影响，**累计落地 13 项策略**——专门解决"模型测试好用、一线不用"的断层。

### 端到端 LLM 系统：RAG 检索 + Agent 编排　个人项目 · 独立设计开发（Python）　2026.06 – 至今

工作之外独立开发并长期维护，完整走了一遍「检索 → 评估 → 排序 → 生成 → 反馈回流」的工程闭环，也是我理解 AI 产品该怎么落地的试验田：

- **RAG 检索链**：多源采集（B 站 / YouTube / 知乎 / 小红书 / 播客）后做统一解析与切分，用"关键词 + 语义向量"混合召回并做查询改写以缩小语义鸿沟，再以重排与整组去重控制结果多样性。
- **把大模型放在门控位、不放在终排位**：让大模型批量判断候选"能否进入结果池"，真正的排序交给可解释的多路融合分，并用真实停留时长在线校准门槛——避免把大模型打分的偏好直接放大成大盘结果。
- **智能 Agent 的边界与降级**：Agent 只负责排序编排与文案生成，工具调用限定在白名单内；探索阶段用使大盘波动可控的采样策略，批量生成时以内容绑定防错位、整组去重、限流降级保证稳定。
- **效果与性能**：换一批延迟由 2.6s 优化到 0.6s（embedding 并发预热、语义缓存命中、批量写库优化）。

- **新供给冷启动机制**：设计"保护期 + 专属探索流量池 + 贝叶斯平滑初始化"的冷启动扶持机制，冷启动广告**通过率 +15%**、新广告**平均曝光量 +30%**——与新商家 / 新商品拿不到曝光是同一类问题。
