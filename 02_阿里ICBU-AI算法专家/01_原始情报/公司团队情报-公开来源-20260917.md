## 一、ICBU 是什么

- 全称 **ICBU = 阿里巴巴国际数字商业集团（Alibaba International Digital Commerce Group）跨境贸易事业部**，即 **Alibaba.com（阿里巴巴国际站）**
- 自我定位：**全球最大的跨境 B2B 数字贸易平台**，主做跨境电商（买家询盘、商家经营、外贸链路）
- 集团旗下还有速卖通、Lazada、Trendyol、AI Business 等；ICBU 是其中的 B2B 线
- 岗在**深圳**（该岗位工作地），团队/公司在杭州、深圳两地都有编制

> 来源：招聘页公司介绍（quanzhi.com 转载）、牛客 ICBU 岗位页

## 二、算法团队在做什么（关键）

从多条 JD 拼出来的画像，**LLM 是全团队主线**，不是点缀：

| 方向 | 具体内容 | 来源 |
|---|---|---|
| 基座模型 | 跨境电商**垂直多语言多模态基座大模型**，CPT → SFT → RLHF 全链路 | 脉脉「海量 HC」帖 |
| AI Native 能力 | **NL2SQL、RAG System、Agent System、Function Call、Workflow Reasoning** | 同上 |
| 业务落地 | **对话机器人、文案素材生成、经营辅助 Agent** | 同上 |
| 智能客服 | 主导**智能客服**领域技术研发：RAG、Multi-Agent、强化学习、多模态 | 脉脉「急招」帖 |
| 销售侧 | 支撑**销售和客服**等多领域 AI 产品；AI 算法研发 + 架构设计 | 猎头岗位表（ICBU-AI算法专家） |
| 学术 | WWW / AAAI / CVPR / SIGIR 等顶会有产出 | 脉脉帖 |

**与「AI+Sales」的对应关系**：ICBU 把外贸销售链路（询盘→跟进→转化）和商家经营做成 AI 产品，算法侧就是 LLM + RAG + Agent + 结构化查询（NL2SQL）+ 工作流编排。⇒ 简历的 `跨境 B2B · AI+Sales / RAG / 智能 Agent / 智能工作流` 这个求职意向**方向是对的**。
