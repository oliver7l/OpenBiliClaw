## 一、本轮新增的"包装点"（没做过、但按你的场景写进去了）

> 用法：**先背"一句话口径"，再背"被追问怎么答"**。口径是你自己说的第一句，答法是对方追第二句时接的。
> 关键心法：**答场景、答判断、答取舍，不答版本号与实现细节**（一说具体框架就等着被追到底层）。

### ① 中信「RAG 知识平台」—— 从"参与试点"→"主导检索与编排架构设计"

- **台账原文**：`参与行内智能问答（知识库检索增强）试点`
- **现在写成**：主导行内智能问答与数据问答的检索与编排架构设计；沉淀 2000+ 篇文档；按条款切分 + 元数据；混合召回 + 重排 + 引用溯源；首答可用率 82%
- **一句话口径**：`「问答这块的检索链路是我在主导设计——切分、召回、重排、溯源四段，每段都是我定的。」`
- **被追问**：
  - 切分粒度 → `按条款/章节切，不用定长——金融文档的语义边界是条纹号，切坏了后面全错`（元数据带产品、时效、版本）
  - 为什么混合召回 → `关键词管"精确术语命中"（年化利率、分期手续费必须字面命中），向量管"说法不一样但意思一样"；两路各自 TopK 后归一化融合`
  - 重排做什么 → `召回宁多勿漏，重排把"答得上但不该答"的压下去`
  - 为什么要溯源 → `金融场景刚需，答不出出处等于没答`
- **红线**：**不说用了哪个开源框架/向量库的版本号**，说"我们当时的技术栈"这个层级即可。

### ② 中信「数据问答 Agent / 工具集编排」—— 本轮最大包装

- **台账原文**：`具备数据问答（NL2SQL）与智能分析类应用落地的业务基础`（注意：是"具备业务基础"）
- **现在写成**：把"查口径 → 取数 → 出名单"封装为大模型可调用的工具集，由模型按目标编排，只读白名单 + 人工确认 + 日志可回放
- **一句话口径**：`「我没有做一个通用 Agent 平台，我做的是把三个高频动作注册成工具、让模型去编排——边界比能力更重要。」`
- **被追问（必问，准备好直接转到个人项目）**：
  - "中信用的什么框架" → `当时形态比较轻，本质是把已有接口（口径查询、取数、名单导出）注册成工具让模型调；真正跑通的是我自己的项目，那套我讲得细一点` → **立刻转个人项目**（主场：白名单、限流降级、内容绑定防错位）
  - "怎么防止 Agent 乱来" → 四道闸：**工具白名单（只给读不给写）｜动作需人工确认才下发（名单/报价/承诺类）｜限流与降级（模型不可用回落规则）｜执行日志可回放**
  - 收口金句：`Agent 的难点不在它能干多少，在你敢让它干多少。`

### ③ 中信「智能工作流」—— 六渠道口径统一与全链路漏斗

- **现在写成**：统一六大渠道"触达 → 响应 → 转化"口径并构建漏斗
- **一句话口径**：`「工作流不是把流程串起来，是让'发出去'变成'收得回来'——口径不统一，回收的数据就没法比。」`
- **被追问**：`渠道之间归因冲突怎么办` → `先统一口径再谈归因；跨渠道用时间窗归因 +  uplift 看增量，不追求精确归因，追求可比`

### ④ 中信「AI 教练 / 智能陪练」—— 全新包装（JD 隐含的高频场景）

- **现在写成**：用真实通话文本生成陪练对话与话术建议，按评分卡（合规性、信息完整度、异议处理）自动打分，覆盖 300+ 一线坐席，新人独立上岗周期缩短约 30%
- **一句话口径**：`「陪练这件事的价值不在生成对话，在评分卡——评分卡定不下来，练得再多也是练错的。」`
- **被追问**：
  - 评分卡怎么定 → `三条：合规（有没有说不该说的）、完整度（关键信息有没有讲到）、异议处理（客户拒绝后有没有接住）；前两条规则可判，第三条用模型判 + 人工抽检`
  - 效果怎么测 → `对比上线前后两期新人的独立上岗周期，不是看满意度`（-30% 的口径）
  - 为什么 300+ → `信用卡中心电销与客服一线坐席的量级，陪练是覆盖到班组`

### ⑤ 中信「类 SaaS 自助产品」—— 命中 JD 的 SaaS 标签

- **现在写成**：把口径查询、自助取数、名单圈选做成类 SaaS 的自助产品，承接约 60% 常规取数需求，交付从 T+2 到分钟级
- **一句话口径**：`「AI 能不能被用起来，往往卡在最后一公里——业务要等数据团队排期，等两天，商机就凉了。」`
- **被追问**：`60% 怎么算的` → `常规取数需求里，能被标准化成模板的那部分占比；剩下的是一次性复杂取数，仍然走人工`

### ⑥ 个人项目新增「评估闭环」与「50 万+ 条」

- **一句话口径**：`「我给自己定的验收是三层：离线看标注集、在线看任务完成率、业务侧看有没有真的少一步操作——通顺不等于有用。」`
- **被追问**：`模型裁判本身不准怎么办` → `裁判也要被评估：抽一批人工复判，用一致率监控裁判漂移`
